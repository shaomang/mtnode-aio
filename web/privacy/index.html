MTNode 隐私政策

本页面说明 MTNode AI 编排器（下称「本应用」）及其配套在线服务在你的电脑上、以及在网络传输中会处理哪些信息、为什么处理、保留多久、以及如何删除。全文只用日常语言，不含法律黑话；每一条「收集 / 不收集 / 传输 / 保留」的表述都以本项目的源码与服务器实测记录为依据。

生效日期：2026-09-04 政策版本 v1.0 无遥测 · 无埋点 · 无广告 API Key 只存本机 MIT 开源

1. 适用范围与生效日期

本政策适用于：① 本应用的 Windows 桌面端（下载页提供的 NSIS 安装包，以及 Microsoft Store 的 MSIX 版本）；② 由本项目运营的配套在线服务 mt-agent.com，包括应用内自动更新、应用插件目录、扩展目录（插件 / 技能 / MCP）、创意工坊（模板与技能分享）、讨论区、桌宠与本地后端的安装包下发；③ 本隐私政策页面本身。

本政策不适用于：你在「设置 · 服务商」里自行配置并自行计费付费的第三方 AI 服务商 API、你自行添加的 MCP 服务器、以及安装本地后端时下载依赖与模型所来自的第三方站点（PyPI 镜像、ModelScope、Hugging Face 及其镜像、npm registry、GitHub、阿里云 OSS 等）。这些对象各自的隐私条款由它们自己发布和约束，请一并阅读。

本政策自 2026-09-04 起生效。继续版本更新后继续使用本应用，即表示你接受当时生效的最新版本；重大变更会在下方第 14 节登记。

2. 一句话结论

结论

本应用不需要注册账号就能使用（账号只在「创意工坊」上传/点赞和「讨论区」发话题/回复时才需要，属于可选项）；应用内不内置遥测、埋点、广告 SDK 或第三方统计脚本；你的画布、素材、配置与 API Key 全部留在本机；只有在你自己点击「运行」的时候，提示词与输入内容才会发往你自己配置的模型服务商。

同时有三点必须如实说明，它们与「不收集」并不矛盾，但确实涉及你的数据或本机权限：

  • 运行节点、发起对话、检查更新、浏览商店与安装后端，都会向对应服务器发出网络请求；mt-agent.com 的 Web 服务会记录访问日志（含 IP 与 User-Agent）。
  • mt-agent.com 当前仅提供 HTTP（80 端口）访问，未启用 HTTPS。对第三方服务商的访问是否加密，由你配置的地址决定（内置的 DeepSeek 官方端点默认为 https://api.deepseek.com）。
  • Agent 网关按授权可以在本机读写文件、执行命令（第 8 节）。这是应用的核心功能，不是信息收集，但它会让被读到的文件内容进入你选择的模型服务商的请求里。

3. 我们处理哪些数据：留在本机的部分

本应用的所有用户数据都写在 Electron 的用户数据目录下，默认是 %APPDATA%\pipeline-console\（应用数据在其下的 pipeline-console\ 子目录）。你可以在「设置」里改「配置数据目录」，此时只有指针文件 data-root.json 留在原处。这些数据不会被自动上传到任何服务器。

内容是什么 / 在哪里
工作流与素材画布 JSON（save/<id>.json：节点提示词、输入文本、参数、@引用）与拖入图片的原文件副本（assets/<工作流id>/）。
快照与回收站定时快照 save-backups/（每 5 分钟一次、仅在源文件变化时复制，每条工作流保留最近 72 份，约 6 小时）；删除画布时整体搬入 trash/。
配置与 API Keyconfig.json 保存服务商列表、API Key（明文存在本机文件里）、创意工坊登录令牌、在线源列表、语言与主题等；每次改动服务商配置前会先写一份历史副本到 config-backups/（最近 30 份）。API Key 只保存在这台电脑上，仅随请求发往你为它配置的那家服务商，绝不上传到 mt-agent.com。
事实库数据库超级节点的记录（SQLite + FTS5），来自你在画布建表与录入的事实条目及其引用的本机文件路径。
Agent 会话与回滚dsh-home/sessions/（对话正文与工具调用结果的 JSONL）、dsh-home/rollback/（Agent 改写文件前的原内容副本）、dsh-home/attachments/（带图会话的图像附件）。其中可能包含 Agent 读到的本机文件内容片段。
引擎设置dsh-home/settings.yaml：服务商路由名、baseURL、思考档、权限预设等；密钥只写环境变量名（如 MTNODE_KEY_1），运行时经进程环境变量注入，不写密钥值。
匿名标识文件dsh-home/.anonymous-user-id：首次模型请求前由本机生成的随机 UUID v4（一行裸值）。它不含姓名、邮箱或任何硬件信息，不由服务器下发，本项目也无法用它关联到自然人。唯一用途见第 4 节。
插件与缓存已安装的应用插件及其自存数据 app-plugins/；讨论区话题与图片缓存 forum/；创意工坊预览图与模板包缓存 store-cache/。
日志error.log、logs/error.log（4MB 滚动）、dsh.log；详见第 9 节。
运行环境自带存储Electron / Chromium 自行维护的 Cache、Local Storage、IndexedDB、Preferences 等渲染缓存与网络状态文件，位于同一数据根目录。
本地后端与模型Music3 / H3 / TTS / llama / Remotion 等后端的模型权重与 Python/Node 依赖，落在数据目录下的同名子目录以及你选择的安装目录。这些文件不含你的用户数据。

以下信息我们不采集：不申请摄像头、麦克风、屏幕与地理位置权限；不读取网卡 MAC、主机名、硬件序列号、Windows 账户名或 MachineGuid 等设备标识；不加载任何第三方 CDN、字体或统计脚本；不内置遥测与埋点上报（框架自带的 OTLP 遥测组件在安装包内已被摘除且未挂载）。

4. 我们处理哪些数据：发往 AI 服务商 API 的部分

运行文本 / 图像 / 智能节点或发起助手对话时，本应用会把该次请求所需的内容发送给你在「设置 · 服务商」里自行配置、自行向服务商计费付费的接口地址（内置默认为 https://api.deepseek.com）。请求一律由主进程或网关子进程发出，界面页面本身无法直连外网。发送内容包含：

  • 你写的提示词与系统 / 人设提示；被 @引用进这次请求的节点正文；用户上传并被引用进节点的图像内容。
  • Agent 会话中，被授权读取的本机文件内容与命令输出，会作为工具结果回流进下一轮模型请求。
  • 请求头 User-Agent: deepseek-harness/<版本>：框架强制发送的应用归因标识，不含个人信息。
  • 走 DeepSeek 官方路由时另附 HTTP 头 x-deepseek-harness-user-id（即本机生成的随机匿名 UUID，见第 3 节），有会话时另发 x-deepseek-harness-session-id。两者只出现在请求头里，不写进请求正文，模型不可见。
  • 联网搜索的查询词：搜索提供方固定为 DeepSeek 官方，只认你自己的 DeepSeek Key。
  • 你自行添加的 MCP 服务器：stdio 型为本机进程；remote 型会按你填写的任意 URL 连接，工具调用的入参出参会发往该地址。

换句话说：内容流向哪家服务商、按什么条款处理，完全由你在设置里配置什么地址、用什么 Key 决定。我们不提供中转，也不替你保存这些请求的副本（第 3 节的本机会话记录除外）。

5. 访问 mt-agent.com 的用途与数据

以下是本应用会向本项目自有服务器发请求的全部场景。请求都由你的动作触发（打开面板、点检查更新、点安装、发话题 / 回复、上传），并携带固定的应用标识 UA（如 MTNodeAIO/1.1），不附带姓名、邮箱、设备号或画布内容；例外在本表内注明。

用途地址与发送内容
应用内自动更新http://mt-agent.com/mtnode/updates —— 仅对 latest.yml 等元数据与差分包的 GET 请求。打包版启动 8 秒后检查一次，此后每 6 小时一次，以及你手动点「检查更新」。Microsoft Store（MSIX）版整条更新链关闭，不加载更新器、不设更新源。
应用插件目录/mtnode/plugins/catalog.json 及目录内的 zip：GET 列表与下载包，无用户数据。
扩展目录（插件 / 技能 / MCP 官方源）/mtnode/ext/catalog.json 及其 .tgz 资产：GET 请求，无用户数据。
本地后端与桌宠安装包/mtnode/music3、/mtnode/h3、/mtnode/pet：GET 清单与包文件，在你点安装或检查后端更新时发生。
创意工坊（商店）APIhttp://mt-agent.com/mtnode/store-api，详见第 6 节。
「在线浏览」取回你在画布 / 设置里填写的任意 http(s) 地址，由主进程代取，携带固定应用 UA。

服务器侧的访问日志

mt-agent.com 的 nginx 对所有请求开启访问日志（默认 combined 格式，没有任何路径关闭日志）。记录的字段为：客户端 IP、时间戳、完整请求行（方法 + 含查询串的路径）、状态码、响应字节、Referer、User-Agent；反代到商店服务的路由另外把 X-Real-IP / X-Forwarded-For 传给后端。日志按天轮转并压缩，保留约 14 天后自动删除。

商店服务自身没有逐请求日志，只输出启动行与保存失败记录；其数据文件里不存在邮箱、电话、IP 字段（IP 只出现在上述 nginx 访问日志中）。

当下载 / 更新请求未被本机路由命中时，会转发到阿里云 OSS（mtnode-download.oss-cn-beijing.aliyuncs.com）；OSS 侧日志由阿里云按其条款记录，不在本项目控制范围内。

关于传输加密

本项目的云服务器当前只监听 80 端口（明文 HTTP），未配置 443 与证书。因此访问更新源、商店、讨论区与下载包时，请求内容在网络上是明文可达的。请勿在商店注册时复用你在别处使用过的密码。第三方服务商是否走 HTTPS 由你配置的地址决定。

6. 创意工坊与讨论区：主动上传即公开内容

使用本应用不需要任何账号；只有「创意工坊」的上传 / 点赞与「讨论区」的发话题 / 回复需要账号，且完全可选；讨论区无需登录即可浏览话题与回复。

  • 注册只要三样：用户名（3–24 位字母数字下划线）、密码（6–72 位，服务端以 scrypt + 随机盐哈希存储，不留明文）、昵称（1–32 位）。不采集邮箱与手机号。登录令牌保存在本机 config.json，后续请求以 Authorization: Bearer <token> 携带。
  • 上传的模板与预览图是公开内容：当你把画布（.mtnodes）或技能（SKILL.md 及附件）上传到创意工坊，其标题、描述、标签、预览图与画布正文会向所有用户展示，可被下载。上传前应用会主动清空其中的本机工作目录字段（工作流与节点里的工作区路径置空）以避免泄漏本地路径；但画布正文本身（你写的提示词、参数、素材副本）会按你的意愿公开。请在上传前自行检查，不要上传包含私密内容、密钥或内部资料的画布。
  • 可自行请求删除：模板与技能可由作者本人（或管理员）在商店里删除 —— 删除记录会同时清掉点赞关系、文件与预览图；下载计数随之消失。若你在应用内找不到入口，或希望删除账号、昵称与其他公开内容，请按第 15 节联系我们提出请求（服务端目前没有自助注销接口，需人工执行）。
  • 讨论区：免登录即可浏览话题、状态与回复；登录后可发话题、回复与修改状态。话题内容为标题、正文（≤2000 字）、可选图片（本机先压缩到最长边 ≤1080px、JPEG ≤3MB 再上传）与状态；读取时附带客户端时区偏移 tzOffset（分钟数，仅用于按天分桶显示）。话题长期保留、不会自动过期；你随时可按第 15 节请求删除自己发布的话题或回复。

7. 本地后端：安装会下载依赖与模型

音乐、视频、语音与本地大模型等后端（Music3 / H3 / GPT-SoVITS / llama.cpp / Remotion）需要你主动点「安装」。安装过程会从第三方站点下载 Python / Node 依赖与模型权重，这些请求会带上你的客户端 IP 与 UA；下载到的内容不含你的任何数据，其使用与隐私约束由对应第三方条款管辖：

  • 依赖包：PyPI 国内镜像（清华 / 阿里云）、download.pytorch.org、mirrors.aliyun.com/pytorch-wheels、npm registry、以及你安装 DSH 插件 / Remotion 时涉及的 GitHub 仓库地址。
  • 模型权重：ModelScope（魔搭）modelscope.cn、镜像站 hf-mirror.com，必要时 huggingface.co。
  • 在「扩展能力管理」里在线浏览插件 / 技能 / MCP 时，还会向默认在线源 registry.npmmirror.com 与 data.jsdelivr.com 发检索请求，其中包含你在搜索框输入的关键词。

这些在线源可以在设置里增删；不使用「安装」与「在线浏览」，就不会发生上述请求。

8. Agent 网关：在本机读写文件、执行命令（属功能，不属收集）

本应用的智能节点与助手可以在授权范围内读取和写入本机文件、执行命令。这件事必须讲清楚三点：

  • 它是功能，不是信息收集。Agent 改文件前会把原内容副本写进本机回滚目录（dsh-home/rollback/），命令输出与会话正文也只写本机（dsh-home/sessions/）。
  • 授权由 Agent 预设决定。权限预设可在设置里选择，默认运行在无人值守预设；「纯净模式」会剥掉全部提示与工具、只保留联网搜索。工具是否可读写文件 / 跑命令，取决于你选的预设与具体批准。
  • 数据流向见第 4 节。Agent 读到的文件内容会作为工具结果发往你为该会话选定的模型服务商 —— 请不要在包含机密文件的目录下授予文件与命令权限。

另外两处同类「本机功能，但值得你知道」的：

  • 桌宠插件的全局输入监听：启用桌宠时它会注册系统级键盘与鼠标钩子，但只把按键名与鼠标坐标发给桌宠自己的窗口做动画反应，全部留在本机进程内，不写盘、不出网；不需要时停用或卸载该插件即可。
  • 「网络接收」节点监听 0.0.0.0：运行该节点会在你填写的端口（TCP / UDP）上监听本机全部网卡，局域网内的其他设备可以连入并推送数据。这是你自己开设的数据入口，收发内容不经过任何服务器；不用的时候请停止运行该节点。

9. 崩溃与诊断报告：只写本机，需你手动导出

出现异常时，本应用把错误栈与环境信息追加写入本机日志（logs/error.log 等）与崩溃报告目录（logs/crash-reports/，保留最近 30 份）。环境块包含版本号、Electron / Chrome / Node 版本、平台与系统版本、架构、界面语言、可执行文件路径、数据目录与工作目录。这些信息永不自动上传：崩溃弹窗只提供「导出诊断日志…／打开日志文件夹／关闭」三个本机动作。

只有在你主动点击「导出诊断日志」、并在另存为对话框里选定路径之后（默认落在桌面），才会生成一个 MTNode-diagnostic-*.txt 文件；它由日志尾部与环境块拼成，文件头部两行显式声明 note: API keys and secrets are NOT included. —— 即不收集 API Key 与密钥。这份文件在你自己转发给别人之前，始终只在你电脑上。

请注意一个边界：日志尾部是你自己产生的文本片段（工作流正文、报错消息、命令行输出），而环境块里的路径可能带 Windows 用户名。若你把导出的诊断文件提交给 GitHub Issue 或发给他人，这些信息就会随你的人工动作离开本机 —— 提交前请自行检查并删去不想公开的内容。

10. Cookie 与同类技术

本应用不使用 Cookie。它是桌面程序，不通过 Cookie 或同类技术（如本地共享对象、像素追踪）识别用户或投放广告；界面不加载任何第三方脚本与外链资源，网络请求由主进程发出。创意工坊的登录状态依靠保存在本机 config.json 里的 Bearer 令牌（见第 6 节），不是 Cookie。本隐私政策页面是纯静态单文件，不含脚本、不含统计代码，也不向浏览器写入 Cookie。

唯一与浏览器存储相关的部分，是 Electron / Chromium 运行时自行维护的本机渲染缓存（见第 3 节表格里的「运行环境自带存储」一行），它们不离开这台电脑。

11. 不出售、不共享

我们不向任何第三方出售或共享你的个人信息。本项目的自有服务器与随包代码中不存在把用户数据转给第三方的通路。除以下两类外，不存在任何自动转发：

  • 第 4 节所列由你自己选择并计费的服务商，以及你自己配置的地址（含 MCP、在线浏览目标、依赖与模型的下载源）。
  • 你在创意工坊 / 讨论区主动公开投稿的内容 —— 一经发布即对所有用户可见。

在法律要求的情形下（司法机关或行政机关依法定程序提出的要求、或为应对涉及本项目的诉讼与争议所必需的披露），我们可能披露必要范围的信息；届时会在法律允许的范围内告知你。这是本节唯一的一般性例外。

12. 数据保留与删除

本机侧：删除目录即可彻底清除

13. 未成年人

本应用是面向成人与专业用户的工作流编排与内容生产工具，不提供面向未成年人的功能，也没有年龄验证机制。我们不以未成年人作为目标受众，也不会在知情情况下收集未成年人的个人信息。未成年人使用需在监护人指导下进行；如果你认为我们在知情情况下收集了未成年人的信息，请按第 15 节联系我们，我们会核实并删除。
