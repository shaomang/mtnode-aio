v1.5.6 2026-10-19 Breeze 语音插件功能增强：一站式创建角色，参考音频、样本文字等一次直出

新增

  • 在插件「Breeze TTS 2 本地 TTS」的控制台里新建和管理角色：上传参考音频、填写样本文字与指令，一个角色可以存多组（比如日常、激动、耳语）
  • 新增内置技能「去 AI 味与写作润色」（/humanizer-zh）：用于去除AI味的 Skill

改进

  • Breeze 节点卡片更干净
v1.5.5 2026-10-18 （本版无一句话摘要）

新增

  • 右下角新增点阵图动画，用三种样子表示当前状态
  • 新增内置技能「Breeze 音色设计」、「Breeze 台词规范」

改进

  • 「超级节点」改名叫「节点层」，用法不变

修复

  • 修复展开的节点层里偶尔点不中内部节点的 Bug
  • 修复「Breeze 语音生成」在音色克隆下必报 500 的问题：克隆模板不支持 CFG，以前填着的 cfg_scale 会被原样送去引擎而被拒绝
    • 克隆这一路现在固定用 cfg_scale 1.0，调 CFG 需改用音色导演
v1.5.4 2026-10-16 会话右栏的浏览器实况画面恢复可用，连不上时可手动重连；Markdown 编辑不再吃掉换行，Tab 缩进不再回滚、输入时不再失焦

新增

  • 自动压缩长会话
  • 压缩时机新增「自定义」档：可以填一个触发线，范围 100k 到 500k token

改进

  • 会话输入区新增「压缩上下文」：同时添加手动压缩按钮（以前需要调用Skill /compact）
  • 压缩完出现「查看压缩摘要」（多少条、约多少字、时间等）
  • Markdown 编辑里的 Tab 键修复
  • 行首缩进当成正文内容原样保存（切档、保存、重开都在），不再被清掉
  • 有序列表的编号回到浏览器原生编号
  • Markdown 编辑器不再在空块里自动把 - / 1. / # / > 变成对应的块
  • 顶栏下面那行小字精简，版本号改到右下角显示
  • 画布的面包屑（画布 / 任务 / 壳…）挪到画布左上角，不再和画布标签挤在同一行

修复

  • 修复会话右栏「浏览器活动」的实况画面偶尔不可见的Bug
  • 修复内置浏览器画面偶尔卡在遮罩上不更新
  • 修复在画布界面偶尔点不开左侧栏的Bug
  • 修复 Markdown 编辑器打开后正文被自动重新排版、段落之间与行内的换行被吃掉等问题
  • 修复窗口最小化、被别的窗口整片盖住或不在前台时，任务完成音与提问/审批提示音要等切回窗口才响的问题（现在后台也会当场响，回到窗口不再补响）
  • 修复节点层展开后，里面的节点偶尔拿不出来以及其他Bug
v1.5.3 2026-10-15 Paseo 手机接管上线，会话与语音一批修复

重大更新

  • 新增「Paseo 手机接管」插件，可用手机接管本机会话与审批
  • 插件统一为「安装 / 控制台」两步：安装窗管理安装周期，控制台窗启停与自检等

改进

  • Paseo 后台服务由 MTNode 静默托管
  • 解决 Paseo 移动端不支持 MTNode 询问窗的问题，当前降级成文字询问
  • 会话轨迹的用量明细不再裁剪，同一步的多次调用分别留档
  • 会话历史不再按条数自动丢弃
  • 顶栏「工具库」改用工具箱图标与专属配色
  • 设置里的模型清单可以整行拖动排序

修复

  • 修复语音实时转写不插在光标处、每写一句就抢走输入框焦点
  • 修复会话遇到限流等临时错误直接跳过任务，现在会等待后原样重发
  • 修复 @ 引用标题带空格的节点时会指到别的节点
  • 修复从浏览器发起的请求窗口点提交后没有自动关闭

v1.0 及更早 — v1.0 是 MTNode 的起步形态：把 AI 工作流收束到一张可视化画布上——摆节点、连线、填提示词，运行后拿到文本或图像结果。这一阶段没有留下逐版的用户向更新记录，这里只作概述；从 v1.0.25 开始每版一份文件。

当时已有的能力

  • 画布：节点与连线、框选多选、撤销 / 重做、缩放与平移，工作流本地自动保存
  • 输入节点：文本就地编辑，图像点击选择或直接拖入
  • 处理节点：文本大模型与图像生成，提示词里用 @ 引用上游节点，带参考图自动走图生图
  • 保存节点：输出为 YAML 文本或图像文件，支持自动保存
  • 批量与拆分 / 合并：批量逐条运行或聚合合并，拆分抽取单项、合并汇成批次
  • 动画节点：图像按行列切成帧序列并编码 GIF，支持透明色键
  • 对话节点：气泡式聊天，对话记录随工作流保存
  • 多服务商 API：统一配置服务商与模型，API Key 只存本机
