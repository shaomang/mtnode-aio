四步上手

  1. 装

    下载 MTNodeAIO-Setup-1.3.3.exe（138,039,479 字节），Windows 10 / 11 x64 一键安装。

  2. 接

    接上 AI：每个节点可以各自指定模型、预设档、思考强度与工具许可。

  3. 串

    串成一条链：上游节点的结果交给下游；一族节点收进超级节点（kind: "super"）当成一块用。

  4. 停

    该停的地方停下：长周期任务画成一张状态机图，审批与交付两类环节停下等你，驳回要写理由并退回指定环节重做。

能力矩阵

MTNode 的五项能力与各自对应的硬事实
能力它做什么硬事实
内置 Agent 引擎 一次 AI 协作就是一个会话：有状态、可开关，能读写文件、也能上网搜索。 agent_task 按任务描述读文件、联网、执行命令，结果回填输出。
长周期任务 · 人在环 把整件事画成一张状态机图，由应用替你按图推进，该停的地方停下等你。 状态机 10 种 kind：start / end_ok / end_fail / agent / human / join / fork / map / sub / output
开发节点 把软件项目拆成画布上的一颗颗功能块，逐块让 AI 建目录、写文件、跑验证。 kind: "super" + dev: true；核心文件字段 devFiles 上限 10 条。
音视频生成节点 本机后端驱动的音乐、语音、视频生成，成片写进节点自带的输出路径，不需要再挂保存节点。 八个 kind：music_gen / yue_gen / tts_gen / video_gen / video_upscale / video_interp / remotion / sensenova_gen；音视频任务全局互斥，同一时刻只跑 1 个。
其他节点能力 超级节点把一组节点打包成子图；工具与函数节点把画布变成 Agent 能调用的工具；批量逐条跑，创意工坊里拿模板与技能。 超级节点 kind: "super"；工具配置 toolConfig；函数 fnName + jscode；批量 batchMode。
