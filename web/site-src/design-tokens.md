## 3. 排版与形状 · 实测频次

以下为在 `base.css`（1887 行）内对声明值做的频次统计，代表这套 UI 的**实际手感**，可作为官网版式节奏的锚点。

### 3.1 圆角（`border-radius` 值频次）

| 值 | 出现次数 |
| --- | --- |
| `3px` | 17 |
| `4px` | 4 |
| `8px` | 3 |
| `0 6px 6px 0` | 2 |

**口径**：主圆角 = **3px**（小控件 / 输入框 / 面板）；容器级才到 **8px**；`999px` 只用于胶囊（计数徽等）。**这套系统是「近乎直角」的**。

**口径**：`body` 基准 = **14px**（`base.css` 的 `body { font-size: 14px }`），但**实际信息密度落在 10–12.5px 的半像素刻度上**（`11.5px` / `12.5px` / `10.5px` 合计出现了 30 次）。这是一套**高密度桌面工具的字号体系**，不是营销页的字号体系。

## 4. 使用纪律（从实测里读出来的硬约束）

1. **不要为官网另起一套色**。用户已确认 `DESIGN.md` 走 scan 模式，`base.css` 是唯一视觉真源；官网出现新色 = 双真源。
2. **语义色不得重排分工**。青=读 / 橙=改 / 绿=跑 / 黄=落在哪儿 / 红=失败（`base.css:17` 原文），官网画节点示意时按这套上色。
3. **不要引入「胶囊化」风格**。主圆角是 `3px`，`999px` 只限计数徽这类胶囊元素。
4. **小字尺寸不要照搬应用。** 应用侧的 `10.5px` / `11.5px` / `12.5px` 是**桌面工具高密度界面的手感事实**；官网的**承载信息文字下限是 `11px`**（Impeccable 检测器对现行页面报了 3 处 `undersized-ui-text`，现行 `.meta` 的 `10.5px` 落地即违规）。详见 `DESIGN.md` 的 The Eleven-Pixel Floor Rule 与「Quality Floor 基线」。
5. **深色是默认态**，不是「暗色模式」。`html { color-scheme: dark }` 写在 `base.css` 顶层；工业风与亮色都是**可选主题**（要显式给 `body` 加 `.theme-industrial` / `.theme-light`）。
6. **对比度已经达标，不要再动颜色。** 实测全部前景 / 背景配对 ≥ `4.5:1`：正文墨在近黑底上 `15.57:1`、最差的「弱化墨在抬升面上」也有 `4.63:1`；主橙 `7.50:1`–`8.11:1`，青 `9.95:1`–`10.76:1`。**现行页面的问题在字号与字距，不在色值**——改版时不许为了「更清楚」擅自提亮或压暗令牌。
7. **已知硬编码风险（实测到的既有债，官网别抄）**：`guides/manual/README.md:89-92` 记录了 `base.css` 内三处硬编码深色值没有亮色覆盖——`.app-docs-ask` 背景 `linear-gradient(180deg, #141820, var(--panel))`（`base.css:1612`）、`.app-docs-ask-msg.ai .chat-bubble` 背景 `#1a1f28`（`base.css:1678`）、`.app-docs-article.md img` 背景 `#0d1016`（`base.css:1602`）。**官网一律走 `var()`，不复制这些字面值。**
