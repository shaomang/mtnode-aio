MTNode AI 编排器

把复杂的 AI 工作收束到一张可视化画布：文本 / 图像 / 音视频输入、大模型处理、图像生成、音乐 / 语音 / 视频生成、批量生产、任务规划、对话与智能办事，并用超级节点收纳复杂子图。节点照旧好用，同时自带 Agent 引擎——可读文件、联网搜索、执行命令、调用子代理，完成后交付结果。

💬全屏智能会话

顶栏「编排 / 会话」双视图。多会话按工作目录分组，支持分支、归档、删除；斜杠命令、流式思考与工具轨迹，运行中可随时终止。

✦全局助手 · AI 搭工作流

右侧助手能看全局状态、切换画布、居中节点，也可直接创建 / 连线 / 排版节点；改图与删除工作流会弹窗确认，搭好的管道可继续编辑、一键重跑。

🧩超级节点

把相关节点收纳为子图：展开壳层即可编辑，↪ 进入完整内部画布，支持嵌套、边端子数据隧穿与子文件夹相对路径；边栏树状列表一键进入。

🏗开发节点

把软件项目架构画在一张画布上：模块 → 文件 → 类 / 接口 / 枚举，关系线表达依赖。绑定项目根目录后，「建议 / 开发 / 细化」三个按钮由 AI 只读调研、给出方案或按深度逐层展开子节点。

🗄数据库节点

事实收纳（文件批量导入 + Agent 建表）→ ⚙ 编译生成数据库副本；智能节点接入副本后用 mtnode_db 查询，断言带 [记录id · 标题] 溯源，查不到就答「数据库中没有该信息」。（设置 · 测试版本开启后可用）

🎬音视频生成节点

本地后端：MiniMax Music 3 音乐、SoVITS 语音、MiniMax H3 视频、Remotion 视频。每次运行产出一个文件并写入节点自带输出路径；支持抽卡次数与分辨率档位，全局同一时刻仅 1 个音视频任务。

🖼图像输入 + 视觉模型

图像节点点击选择或直接拖入文件；智能任务接上图像节点后出现「图」徽标，用 @标题 引用。当前模型不支持识图时列出视觉模型候选，确认后记住选择。

🔀任务节点与控制流

任务节点内部是控制流图：固定起点 → 工作 / 子任务 / 判断 → 成功或失败终点；另有需求等待、定时触发器（一次 / 间隔 / Cron）、延时器、序列器、闸门、分发、计数、互斥等控制节点。

🖥网络与执行节点

net_recv / net_send 做跨画布、跨机器文本通道（TCP / UDP · 通道复用 · 逐节点端口）；执行节点绑定 .exe / .bat / .cmd / .lnk，画布上一键启动，可自定图标与主题色。

DeepSeek 官方 · MTNode 自配服务商 · pi-ai 目录统一选择。添加服务商可从目录选 → 填 Key → 自动载入模型与接口；Key 仅存本机，支持视觉模型路由。

🛒扩展商店与应用插件

插件 / 技能 / MCP 三个线上目录，卡片搜索、已安装标记、一键安装卸载，支持自定义源。应用插件含本地 TTS、本地大模型、Music 3 / H3 后端、讨论区与桌宠。

功能特性

  • 输入节点：文本就地编辑、实时保存；图像点击选择或直接拖入。连线后自动继承输入内容，识别 YAML 自动转为批量节点；数据库超级节点内部另有文件节点与表节点。
  • 处理节点：文本 LLM 与图像生成；提示词内 @ 引用已连接节点，@Tag 引用标签分组；带参考图自动走图生图。可预览完整请求、多次尝试、思考强度。
  • 智能任务 / 智能模式：独立「智能任务」节点，或在文本处理上开 🐋 智能、对话节点开「智能助手」；支持 @ 引用、批量 / 聚合、一键扩展为会话并双向同步。
  • 保存节点：输出保存为 .yaml 或图像，支持自动保存；批量链按 {文件名}_{输入节点标题} 命名。媒体生成节点自带输出路径，无需再挂保存。
  • 批量 / 拆分 / 合并：批量按条目并行运行（每条目一次）或聚合合并为一次；拆分节点实时抽取批次单项，合并节点把多输入汇成批次。
  • 超级节点：收纳相关节点为子图，展开壳层或 ↪ 进入完整内部画布，可嵌套；边端子隧穿数据，子文件夹约束内部相对路径。
  • 任务节点与控制流：任务内部为「起点 → 工作 / 子任务 / 判断 → 成功 / 失败终点」，另有需求等待、定时触发器、延时器、序列器、闸门、分发、计数、互斥、判断。
  • 开发节点：软件项目架构画布（模块 → 文件 → 类 / 接口 / 枚举），绑定项目根目录；「建议 / 开发 / 细化」三按钮由 AI 推进，细化按深度逐层下钻。
  • 数据库节点：事实收纳 → ⚙ 编译出数据库副本；智能节点接入后一切事实走 mtnode_db，断言带 [记录id · 标题]，查不到即答「数据库中没有该信息」。
  • 音视频生成节点：MiniMax Music 3 / SoVITS / MiniMax H3 / Remotion 本地后端，每次运行产出一个文件并写入节点自带输出路径。
  • 网络与执行节点：net_recv 监听 host:port 通道转发文本，net_send 推送数据到目标通道（TCP / UDP）；执行节点绑定 .exe / .bat / .lnk 一键启动。
  • 全局节点：只连入不连出，把文本 / 图像源广播给多个消费者；消费者需开启引用（globalRefs）并在提示词写 @源标题。
  • 对话节点：dsh 风格消息流（角色行 + 思考折叠 + 工具 chips），对话记录随工作流保存，可输出整段对话记录；可开「智能助手」走 Agent 引擎。
  • 画布与素材库：多标签工作流、撤销 / 重做 / 复制、框选与组（横竖分别缩放）、节点树边栏、一键居中、统一工作目录；素材库集中管理图像 / 视频等素材。
  • 自动递归执行：每个处理节点只处理直接输入；上游未就绪时自动跑完再继续，链路清晰可溯。
  • 人机互动与内置更新：模型可中途提问（ask_user），权限越界弹出审批；斜杠命令 /new /compact /plan /rename /export /permissions /help；有新版本时右上角差分下载并静默安装。

使用流程

  1. 安装启动：下载安装包一键安装，无需单独安装 Node；启动即恢复上次工作流现场。
  2. 配置服务商：设置 · API/配置 → 从目录选择文本服务商并填 API Key。文本服务商用于 LLM / 智能能力，图像服务商用于生图。
  3. 编排节点：画布空白处右键添加节点，拖线连接，提示词里 @ 引用上游，点 ▶ 自动递归执行。
  4. 批量与保存：开启批量逐条生产或聚合合并，YAML / 图像自动命名落盘；也可放一个智能任务节点，直接描述要办的事（读文件 / 联网 / 写结果）。
  5. 进阶：任务节点做控制流规划，超级节点收纳子图，开发节点搭软件项目架构，数据库节点做有据可查的查询；顶栏「文档」随时查阅手册。

常见问题

需要单独安装 Node 或 Python 吗？

不需要。智能引擎使用随应用内置的 Node（与主程序同版本），引擎随应用启动；只有本地后端插件（本地 TTS / 本地大模型 / MiniMax Music 3 / MiniMax H3）需要各自安装。

智能能力必须用 DeepSeek 吗？

v1.1.1 起，任意带 API Key 的 OpenAI 兼容文本服务商都可以启用智能能力。DeepSeek 官方仍是默认选项之一；识图需选择支持视觉的模型。

数据会上传到 MTNode 服务器吗？

不会。工作流只保存在本机；只有你主动运行节点时，提示词与输入才发给你配置的服务商 API。使用「创意工坊」上传模板时，才会把所选 .mtnodes 与预览图发至工坊服务器（mt-agent.com）。API Key 以密文框保存，不出本机。

Agent 会改我的文件吗？安全吗？

会，这正是智能模式的能力。请指定正确的工作目录。默认「无人值守」允许工作区内读写；可改为逐项审批或只读。运行过程全程可见，可随时终止。

为什么菜单里没有数据库节点？

数据库节点属测试版本能力：在「设置 · 测试版本」开启后才出现。开启后新建数据库超级节点，收纳事实（文件批量导入 + 表节点建表）并点头部 ⚙ 编译，即可生成可供智能节点查询的数据库副本。

数据与隐私

所有工作流数据保存在本机（%APPDATA%\pipeline-console\pipeline-console\save\），不默认上传任何服务器；仅在你主动运行节点时，将提示词与输入内容发送至你配置的服务商 API。使用「创意工坊」上传时，会将你选择的 .mtnodes 模板与预览图发至工坊服务器（mt-agent.com）。
