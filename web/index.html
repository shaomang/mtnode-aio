功能特性

  • 输入节点：文本就地编辑、实时保存；图像点击选择或直接拖入。连线后自动继承，识别 YAML 自动转为批量节点。文本节点 📄 可导入参考文件。
  • 处理节点：文本 LLM 与图像生成；提示词输入 @ 引用已连接节点；带参考图走图生图。可预览完整请求、多次尝试、思考强度。
  • 智能任务 / 智能模式：独立「智能任务」节点，或在文本处理上开 🐋 智能、对话节点开「智能助手」。任务描述支持 @ 引用、批量 / 聚合、一键扩展为会话并双向同步。
  • 保存节点：输出保存为 .yaml 或图像，支持自动保存；批量链按 {文件名}_{输入节点标题} 命名。
  • 批量 / 拆分 / 合并：按条目并行运行或聚合一次；拆分抽取批次单项，合并把多输入汇成批次。
  • 动画节点：图像按 列×行 切割为帧序列并编码 GIF，支持透明色键。
  • 对话节点：dsh 风格消息流（角色行 + 思考折叠 + 工具 chips），记录随工作流保存，可输出整段对话。
  • 画布操作：多标签工作流（上限 12）、撤销 / 重做 / 复制、框选与组（横竖分别缩放）、节点树边栏、一键居中、统一工作目录。
  • 自动递归执行：每个处理节点只处理直接输入；上游未就绪时自动跑完再继续，链路清晰可溯。
  • 人机互动：模型可中途提问（ask_user）；权限越界弹出审批。斜杠命令：/new /compact /plan /rename /export /permissions /help。

使用流程

  1. 安装启动：下载安装包一键安装。无需单独安装 Node。启动即恢复上次工作流现场。
  2. 配置服务商：设置 · API/配置 → 从目录添加或手动填写 API Key。文本服务商用于 LLM / 智能能力，图像服务商用于生图。
  3. 编排节点：右键画布添加节点，拖线连接，提示词里 @ 引用上游，点 ▶ 自动递归执行。
  4. 交给 Agent：切到「智能会话」，或放一个智能任务节点，直接描述要办的事（可读文件 / 联网 / 写结果）。也可让全局助手按你的目标搭好节点再运行。
  5. 批量、保存、分享：开启批量或聚合，YAML / 图像自动命名落盘。整张画布可导出 .mtnodes 与他人无损分享。

常见问题

需要单独安装 Node 或 Python 吗？

不需要。智能引擎使用应用自带的 Node（与主程序同版本），开箱即用，引擎随应用启动。

智能能力必须用 DeepSeek 吗？

v1.1.1 起，任意带 API Key 的 OpenAI 兼容文本服务商都可以启用智能能力。DeepSeek 官方仍是默认选项之一；识图需选择支持视觉的模型。

数据会上传到 MTNode 服务器吗？

不会。工作流只保存在本机。仅在你主动运行节点时，把提示词与输入发给你配置的服务商 API。API Key 以密文框保存，不出本机。

Agent 会改我的文件吗？安全吗？

会，这正是智能模式的能力。请指定正确的工作目录。默认「无人值守」允许工作区内读写；可改为逐项审批或只读。运行过程全程可见，可随时终止。

从 v1.0.25 升级会丢存档吗？

不会。旧工作流会自动补齐新字段（智能开关、工作目录、预设、思考强度、会话关联等），原节点行为保持兼容。

数据与隐私

所有工作流数据保存在本机（%APPDATA%\pipeline-console\pipeline-console\save\），不上传任何服务器；仅在你主动运行节点时，将提示词与输入内容发送至你配置的服务商 API。
