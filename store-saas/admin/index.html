本服务进程

主机

只读页：仅在切到本页签时采样一次（点「刷新」再采一次），服务端不留历史、不起定时器，也不提供重启 / 清理类操作。 CPU 使用率取两次 os.cpus() 快照的差值；内存与负载走 os；磁盘看的是数据目录（db.json 与各内容包所在盘）。

上游提供商（Base URL / Key / 超时）

Key 只显示「已配 + 后四位」，明文永不回传页面；留空表示不改，重填即覆盖。 来源标 env 的表示走服务器环境变量兜底（在管理台填一次就会转成库里的 Key）。

模型列表（上架 / 通道 / 上游模型名 / 价目）

只有出现在这里的模型客户端才拉得到；取消勾选 = 立即下架。 价目：文本 = 元 / 百万 tokens（缓存命中 · 未命中 · 输出，高峰按倍率）；图像 = 元 / 张。
「拉取候选」用该上游的地址 + Key 读上游 /models（只读元信息，不消耗 Token）
发一张 30 分钟的 mtr_test_ 短时 Key 打 /relay/v1/*，按真实用量从当前管理员账号扣费（不是 dry-run）。
