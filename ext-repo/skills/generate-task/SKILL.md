# 生成任务

仅用于**智能会话**或**全局助手**。画布上的智能节点不能创建或修改任务图；若在节点里被调用，应改用读写文件完成任务，不要调用画布工具。

用户补充即目标，或针对画布上已有任务节点（有 id/标题时优先用它）。在当前画布上完成拆解。

## 步骤

1. `mtnode_canvas_get`，看 `taskTree`、当前层、该任务内部已有的起点/成功终点/失败终点。
2. **一次** `mtnode_canvas_edit` 完成拆解。
3. 每个 `kind: "task"` 自带固定 **起点 / 成功终点 / 失败终点**，**不要删除**。实现放在内部（`parentTaskId`）。

## 控制流

- 从该任务的起点 `control`（`ctrlRole: start`）连出去
- 经子任务 / 处理 / `judge`，接到成功终点（`endSuccess`）或失败终点（`endFail`）
- `judge` 两个输出：`fromIndex 0` = 是，`1` = 否
- 任务上点 ▶ 从起点沿控制流走；落到哪个终点即成功/失败

## 要求

- 复杂需求先拆 `task` 计划，再在内部接线；不要在顶层铺一堆 proc/save/chat
- 子任务标题短、互不重名；`goal` 写清这一步要达成什么
- 需要裁决时用 `judge`，判断标准可写在 `prompt`，默认也可用所属任务的 `goal`
- 完成后用**一句话**说明控制流怎么走

若画布上没有可拆的任务节点：先创建一个顶层 `task`（标题=用户目标），再按上面拆内部图。
