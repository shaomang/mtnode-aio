# 常见问题

**▶ 没反应 / 一直失败？**  
先看节点上的错误条。最常见：没填 API Key、没连输入、图像任务用了不支持视觉的服务商。用 ◈ 预览即将发送的请求。

**连线拖不出来？**  
要从端子圆形上按下再拖，不要从节点标题开始。输入端子已被占用时需先断开或改用新端子。

**批量只跑了第一条？**  
处理节点可能处于「聚合」。点头部切换为「批量」。

**定时器一点 ▶ 下游立刻跑了？**  
定时器的 ▶ 是**打开闹钟**。到点才会脉冲。立刻跑请用普通处理节点或「执行」控制节点。

**闸门永远不放行？**  
AND 闸门按**配置的输入路数**等待，没接线的端口也算。减少输入路数，或把线都接上。

**超级节点展开后看不到内部节点 / 端子？**  
用标题栏展开图标打开壳层，或点 **↪ 进入** 全屏编辑。内侧端子在壳层左右边缘（进入后在画布左右边缘）。详见 [超级节点](#super-nodes)。

**超级节点里的保存路径跑到画布根目录了？**  
给超级节点设置**子文件夹**；内部相对路径会自动挂到该前缀下。需要其它位置时用绝对路径。见 [工作目录与存档](#workspace)。

**助手搭图时出现两份保存文件？**  
智能助手 / 智能会话改画布期间，保存节点不会落盘；整次任务结束后才统一写入（路径已含超节点子文件夹）。若仍看到旧文件，多半是中途曾手动点过 ▶ 保存。

**智能任务乱改文件？**  
检查工作目录；把审批调到「逐项审批」或关掉不需要的工具许可。

**运行中分不清哪句是思考、哪句是回复？**  
按发生顺序分段：**「◉ 思考 · N 字」** 只折叠模型内部推理（N 只数思考的字数），中间步骤说出来的话以**正常字号正文**逐段显示，**🔧 工具**调用就近插在发生位置。智能任务节点、智能会话、对话节点、全局助手同一套口径；节点上的「思考中」大窗上半是思考、下半是输出。升级前存档的旧会话仍按老样子显示。见 [智能能力是什么](#dsh)。

**文档答疑说不知道？**  
它只读本手册。单节点细节请用右键「节点指南」，或换个问法指向左侧目录里的章节。

**开发节点「建议」要联网跑模型吗？**  
要。它由 AI 做**只读**调研（读项目代码 + 模块进度）后给出 4 条方案；结果缓存，点「查看上次建议」不重跑，「换一批」才重跑。

**智能节点答不上数据库的问题？**  
先确认接入了数据库：把「数据库副本」连到输入端，或在 prompt 写 `!@数据库标题`。已接入却查不到时，按纪律必须回答「数据库中没有该信息」，不会猜。

**音乐 / 视频节点后面要挂保存节点吗？**  
不用。它们自带输出路径（`.wav` / `.mp4`），再挂保存反而会写无关内容。

**网络节点收不到消息？**  
检查三处：协议（TCP / UDP）、通道号、主机端口（默认端口在 设置 · 网络）。接收节点确认处于监听态。

**执行节点怎么运行？**  
双击节点，或连点两下播放键；通过系统默认方式启动绑定的 `.exe` / `.bat` 或任意文件。

**中英文？**  
右上角地球按钮切换。手册与节点指南都有对应语言（缺英译时回退中文）。
