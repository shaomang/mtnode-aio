# 欢迎使用 MTNode AI编排器

MTNode 把复杂的 AI 工作收束到**一张可视化画布**：文本 / 图像输入、大模型处理、图像生成、音乐 / 视频生成、批量生产、任务规划、对话、智能办事，并以**超级节点**收纳复杂子图。

- **音频 / 视频生成**：音乐生成（MiniMax Music 3）与视频生成（MiniMax H3）本地后端节点，每次运行产出一个文件。
- **网络节点**：`net_recv` / `net_send` 做跨画布 / 跨机器文本通道（TCP / UDP）。
- **执行节点**：绑定 `.exe` / `.bat` 或任意文件，画布上一键启动。
- **开发节点**：软件项目架构（模块 → 文件 → 类 / 接口 / 枚举），带「建议 / 开发 / 细化」按钮，AI 只读评估后给出下一步方案。
- **数据库节点**：事实收纳 → 编译数据库副本，智能节点用 `mtnode_db` 做有据可查的查询。
- **永久免费开源**（MIT），无订阅。工作流可导出为 `.mtnodes` 包分享。
- 下载与主页：[http://mt-agent.com/mtnode](http://mt-agent.com/mtnode)
