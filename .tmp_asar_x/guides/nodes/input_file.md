# 文件节点（批量导入任意文件）

在**数据库超级节点**内部使用：把任意文件（csv / txt / json / md / pdf 等）批量导入数据库子文件夹，供「表」节点读取建表。

## 用法
- 只能添加在数据库超级节点内部（右键菜单在数据库内部只提供「文件节点」和「表」）。
- 拖入文件或点选批量添加；文件会**复制**进数据库子文件夹（默认 `db/`），原文件不动。
- 导入后到「表」节点选择文件建表，或直接点数据库节点头部 **⚙ 编译** 入库。

## 端子
- **输入**：一般无
- **输出**：文件信息（文件清单 / 内容），供表节点或智能节点使用

详见手册 [数据库节点](#database-nodes)。
