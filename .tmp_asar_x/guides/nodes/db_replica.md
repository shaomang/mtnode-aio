# 数据库副本

由「数据库超级节点」头部 **⚙ 编译** 自动生成（子节点，随源库刷新）。它镜像源库的事实记录，供智能节点查询。

## 接入方式
- **连线**：把副本节点连到智能节点（agent_task / 智能文本）的输入端；运行提示词会自动注入「数据库接入 · 事实强制约束」。
- **`!@` 引用**：在 prompt / task 中写 `!@数据库标题` 即可引用（无需连线）。

## 智能节点查询纪律（强制）
- 一切事实必须来自 **`mtnode_db` 工具**（list / query / get / calc），禁止凭记忆补全。
- 每次关键断言都要标注溯源 `[记录id · 标题]`。
- 查不到就明确回答「数据库中没有该信息」；数据库未记载的推断要标注「此为推断，数据库未记载」。

## 端子
- **输入**：一般无（作为查询源，连入智能节点输入端）
- **输出**：数据库指针 / 查询结果

详见手册 [数据库节点](#database-nodes)。
