# 超级节点

![diagram](img/super.svg)

把相关节点收纳成子图。可**展开**在壳内编辑，或 **↪ 进入**完整内部画布。外侧 / 内侧边端子隧穿数据；可选 **子文件夹** 让内部相对路径落在工作目录下的子路径。

## 端子
- **外侧输入 / 输出**：收起时连外部
- **内侧桥接（左）/ 汇流（右）**：展开壳层或进入后的画布左右边缘

## 常用操作
- 顶栏「超节点」：框选合并
- 标题栏：子文件夹、进入、展开 / 收起
- 拖入 / 拖出：移入移出
- 边栏「超级节点」树：快速进入并定位

## 两种特殊形态

| 形态 | 开启 | 作用 |
| --- | --- | --- |
| **开发节点**（功能块） | 创建时选「开发节点」，或节点设为 dev | 软件项目架构：模块 → 文件 → 类 / 接口 / 枚举，绑定项目根目录（devPath），头部有「建议 / 开发 / 细化」按钮，元素间用**关系线**（rel）表达依赖 / 调用 |
| **数据库节点** | 设置中开启「测试版本」后右键添加 | 事实收纳：内部放「文件节点 / 表」，头部 **⚙ 编译** 生成「数据库副本」，智能节点用 `mtnode_db` 查询 |

详见手册 [超级节点](#super-nodes)、[开发节点](#dev-nodes)、[数据库节点](#database-nodes)。
