# Database replica

Auto-generated by **⚙ Compile** on a database super node (a child node that refreshes with the source). It mirrors the source’s facts for agent nodes to query.

## How to connect
- **Wire**: connect the replica into an agent node’s (agent_task / agent text) input; the run prompt automatically injects the “database grounding” fact discipline.
- **`!@` reference**: write `!@数据库标题` (database title) in the prompt / task to reference it without wiring.

## Agent query discipline (mandatory)
- All facts must come from the **`mtnode_db` tool** (list / query / get / calc); never fill from memory.
- Cite provenance `[record id · title]` for every key assertion.
- If nothing matches, answer exactly “数据库中没有该信息”; mark inferred facts as “此为推断，数据库未记载”.

## Ports
- **Input**: usually none (acts as a query source, wired into agent inputs)
- **Output**: database pointer / query results
