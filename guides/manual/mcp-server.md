# MCP 扩展与第三方接入

MCP 是一种通用的 AI 工具连接协议。MTNode 在这里既能当「使用者」（把外部工具接进 MTNode 给 AI 用），也能当「提供者」（让 Claude Code、Cursor 等外部 AI 工具连进来操作你的 MTNode 画布）。

## 一、给 MTNode 接入外部工具与技能

点 **设置 → 扩展能力 → 管理…**，可以在同一只面板里统一管理扩展能力：

- **MCP 服务器**：添加外部 MCP 工具（例如数据库、笔记软件、代码仓库等），配置好后智能会话里的 AI 就能直接调用它们。点选任意一台服务器，还可以点「读取资源清单」只读查看它提供的资源并复制引用。
- **内置与自定义技能（Skills）**：把你常用的工作流程写成技能，在会话或助手框里敲 `/` 就能随时呼出。
- **Blender 本地插件（3D 创作）**：如果你想让 AI 直接帮你操作 Blender 建模或渲染，直接在顶栏 **插件** 里安装 **Blender 本地插件** 即可——它会自动下载官方便携版 Blender 并配好 MCP 连接，重启后在智能会话里就能直接让 AI 驱动 Blender，而且不会影响你自己手动打开的 Blender。

## 二、让外部 AI 工具连进 MTNode（内置 MCP 服务端）

如果你平时也在用 **Claude Code**、**Cursor** 或其他支持 MCP 的客户端，可以让它们直接连上本机的 MTNode，帮你读取修改画布、查阅素材库和 AI 事实库、或者把图片交给 MTNode 识图。

### 在哪开启和复制配置

1. 打开 **设置 → 扩展能力 → 管理…**，切到 **服务端** 页签（默认已开启，只监听本机地址，局域网里的其他电脑连不上）。
2. 点一键复制页面提供的 **stdio 客户端配置片段**（通过随包的 `mcp-stdio.js` 桥脚本连接，自带本机访问令牌），粘贴到 Claude Code 或 Cursor 的 MCP 配置里即可。
3. 点页面上的 **自检**，看到全部通过就说明本机链路完全畅通。

### 安全与审计

- **随时开关或重置令牌**：不用时关掉总开关就会立刻停止监听；担心令牌泄露可以随时点「重置令牌」（重置后需重新复制配置给外部客户端）。
- **操作记录可查**：外部客户端什么时候调了哪个工具、改了哪张画布，都会记在面板的「最近调用」审计日志里（日志保存在数据目录的 `mcp-audit/` 下，按天保留 7 天）。
- **优先交给 MTNode 内部完成**：连接后默认推荐让外部客户端通过会话工具把复杂画布任务委托给 MTNode 自己的智能体来做，既省事又不容易把画布改乱。
- **数据安全底线**：所有连接仅限本机访问，不对外网暴露；外部客户端无法绕过你的本地文件权限和审批规则。
