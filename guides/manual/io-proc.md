# 输入 / 处理 / 保存

![数据流](img/io-proc.svg)

## 输入

- **文本**：就地编辑；📄 可导入 txt / md / json / yaml 等（超过 500KB 拒绝）。
- **图像**：点击选择或拖入文件。
- **音频 / 视频**：点击选择或拖入本机媒体文件，节点就地预览，并输出该文件的 `file:///` URL（可连媒体参考端子 / 保存 / `@` 引用）。
- **文件节点 / 表**（数据库超级节点内部）：批量导入任意文件、Agent 建表，见 [数据库节点](#database-nodes)。
- **素材**：内容不在这张画布上，而在**素材库**（本机跨画布共享的仓库，删画布也不会丢），一条内容＝一对端子，见 [素材库与素材节点](#asset-library)。

## 处理

- **文本处理**：提示词 + 输入调用 LLM。可开「🐋 智能」变成任务（见 [智能任务](#agent-nodes)）。
- **图像生成**：文生图；带参考图走图生图。需要视觉时请勾选服务商「支持视觉」（DeepSeek 官方不识图）。标题栏的**透明开关**（单击开/关，开启后变成一圈旋转彩虹边缘）走**双通道差分抠图**：第 1 通道先出**纯黑背景**作为整套抠图的**唯一基准**，第 2 通道把那张基准图当**唯一参考图**（原尺寸下发、不缩放）自动补一张**严格复刻、只换纯白背景**的图，两图按实测背景电平逐像素差分出真实 Alpha，输出即透明底 PNG；过程对用户无感知，但每次要生成 2 张图（约 2 倍 Token），且只有能把基准图下发的服务商（OpenAI 兼容 / Stability 生图）才会抠图，其余**显式跳过并提示**、只交付第 1 通道纯黑原图（不会另画一张凑数），右键开关可调抠图参数，详见[节点指南](#node-guide)。
- **音频生成 / 视频生成**（两个一级子菜单）：音乐 **Minimax Music 3**、语音 **SoVITS 语音生成**（GPT-SoVITS）、视频 **Minimax H3** 与 **Remotion 视频**，都是本地后端 + 自带输出路径，见 [音乐、视频、网络与执行节点](#media-net)。
- **动画**：把图像按网格切成 GIF 帧，可设透明色键。

**▶ 运行 · ◈ 预览完整请求 · API** 选服务商 / 模型 / 温度 / 尺寸。**多次尝试**（1–10）并行抽卡，输出面板用方块 Tab 切换，下游引用当前选中的那次。处理完成后自动跑下游；下游已有内容时询问覆盖或不继续。

输出头上的「浏览 / 复制 / 清空」可大窗查看或重置。

## 保存

指定路径后 ▶ 写出 YAML 或图像。可勾选「输入变化时自动保存」。有工作目录时可用相对路径，见 [工作目录与存档](#workspace)。
