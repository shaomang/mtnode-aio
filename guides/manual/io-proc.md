# 输入 / 处理 / 保存

> 一句话目标：把「输入节点 → 处理节点 → 保存节点」这条最小链路连起来，跑出第一份落盘结果。

![数据流](img/mtnode-flow-01-flow.svg)
*图 1：输入 → 处理 → 保存 的数据流；数据端子走内容，控制线只负责触发*

## 目标

读完这一页，你能在画布上摆出「文本 / 图像 / 音视频进 → LLM 或生图出 → 写进文件」的完整三步，并知道每类输入的真实容量上限、保存节点的落盘规则。参数怎么调、怎么预览请求见下一章。

## 前置条件

- 至少一个带 API Key 的**文本服务商**（文本处理）和 / 或**图像服务商**（图像生成），见 [配置服务商与 API](#providers)。
- 想让保存节点用相对路径，先给这张画布设好**工作目录**，见 [工作目录与存档](#workspace)。
- 知道「画布空白处右键」是加节点的入口，见 [加节点、连线与 @ 引用](#nodes-wires)。

## 步骤

### 1. 加输入节点，把内容放进去

1. **右键画布空白处** → **输入节点** → 文本 / 图像 / 音频 / 视频，选一种。
2. **就地填内容**：文本节点直接在卡片里打字；点 **📄** 可导入 `txt` / `md` / `json` / `yaml`。图像节点点击选择，或把文件拖进来。
3. **记住真实的容量口径**：单条文本超过 **2 MB** 会**截断并保留开头**；超过 **32 MB** **不读入**，节点上只留文件路径。这是拖入与 📄 导入共用的一条口径（旧正文写的「超过 500KB 拒绝」不对）。
4. **音频 / 视频**：选一个本机媒体文件后节点就地预览，输出值是该文件的 `file:///` URL，可直接连给参考端子、保存节点，也能被 `@标题` 引用；接收端会自动把 URL 归一回本机绝对路径，不用手动转换。
5. **要跨画布复用**内容时别复制粘贴，改用素材节点（素材库删画布也不会丢），见 [素材库与素材节点](#asset-library)。

### 2. 加处理节点并连线

1. **右键** → **处理节点** → **文本处理** 或 **图像生成**。
2. **接上输入**：从输入节点的输出端子拖一条线到处理节点的输入端子。文本处理吃文本；图像生成吃提示词，要参考图就再接一条图像线，走**图生图**。
3. **写提示词**：在节点里写要求，可用 `@标题` 引用上游节点的内容。
4. **文本处理可开 🐋 智能**：打开后提示词变成任务，模型能读文件 / 联网 / 执行命令后交付，见 [智能任务与智能会话](#agent-nodes)。
5. **点 ▶ 运行**：处理完成后会自动跑下游；下游已经有内容时会询问**覆盖**还是**不继续**。

### 3. 加保存节点落盘

1. **右键** → **保存节点**，接在处理节点的数据输出上。**不要**把保存节点接在智能节点、或开了 🐋 智能的文本处理后面——它们自己会写文件。
2. **填保存路径**：有工作目录时可用相对路径，否则填绝对路径。
3. **确认扩展名**：保存节点按**真正接出来的那个端子**定型——文本 → 默认 `.md`（YAML 内容同样以 `.md` 落盘）、图像 → `.png`、音频 → `.wav`、视频 → `.mp4`；从图像端子拖出的线会自动把保存节点切成图像保存。
4. **按需勾选「输入变化时自动保存」**：勾上后上游一变就写一次；批量链上每条目一个文件，文件名按 `{文件名}_{输入节点标题}` 追加，见 [批量、拆分与合并](#batch)。
5. **点 ▶ 写出**，产物落在你指定的路径上。

## 结果

- 画布上出现一条可反复重跑的链路：改输入 → ▶ → 新结果 → 自动 / 手动写进文件。
- 保存节点会记住最近一次落盘的路径，节点上能看到已保存文件。
- 后续所有页面都建立在这条三步链上：调参数见 [参数与运行调试](#params-runs)，跑多条见 [批量、拆分与合并](#batch)，出音视频见 [出音乐 / 语音 / 视频](#media-gen)。

## 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 点 ▶ 提示未配置服务商 / 无可用模型 | 没有带 API Key 的服务商 | 到 设置 → 模型服务 添加并填 Key，见 [配置服务商与 API](#providers) |
| 导入的文本只剩开头 | 单条超过 2 MB，被截断保留开头 | 拆成多个条目 / 走批量，或改从文件读取 |
| 导入后节点里只有路径没有正文 | 文件超过 32 MB，不读入 | 减小体积，或改用能按路径读文件的方式处理 |
| 保存报「路径无法解析」 | 用了相对路径但画布没有工作目录 | 给画布设工作目录，或改填绝对路径 |
| 保存出来是 `.md` 不是 `.yaml` | 文本保存的默认扩展名就是 `.md` | 确认来源端子类型；需要 YAML 就让 `.md` 文件承载 YAML 内容 |
| 文本处理提示不识图 | 图像接进了没有视觉能力的文本服务商 | 在该服务商上勾选「支持视觉」，或换多模态模型 |
