# 创意工坊与讨论区

MTNode 的社区就在顶栏，包含 **创意工坊** 和 **讨论区** 两块，共用同一个 MTNode 账号（点右上角登录，支持微信扫码或账号密码）。

## 创意工坊：淘现成工作流，也分享你的作品

点顶栏 **工坊**，可以在「模板（整张画布工作流）」和「技能（Skill）」两栏之间切换，按最新、热度、下载量或「打赏热度」排序浏览：

### 用别人的作品

1. 点开感兴趣的卡片先预览说明，确认合用再点 **下载到本机**。
2. **模板画布**会直接导入成一张新画布；如果原画布用了你电脑上还没配置的模型，相关节点会静默显示为「**无模型**」，等你点 ▶ 运行时再选自己电脑上的模型即可。
3. **技能**下载后会立刻进入你的本机技能列表，在会话或助手里敲 `/` 就能用。后续原作者发了新版需要你手动点更新，不会偷偷覆盖你本地的版本。

### 分享自己的作品

1. 登录账号后点「上传」，选一张本机画布或技能文件，填好标题、简介、标签和版本号即可发布。
2. **上传前记得清掉私密信息**：不要在节点里留着 API Key、客户隐私资料或私有路径（上传模板时系统也会自动剔除你的本机工作目录路径）。
3. 在「我的」里随时查看下载数、点赞数，或者上传新版本。

## 讨论区：提问、报错求助与提建议

登录后，右上角会出现 **讨论** 入口（未登录时不显示入口，退出登录后讨论区窗口也会自动关闭）。讨论区随软件内置，不用额外下载：

- **话题状态清晰**：发帖或回帖可以标记「一般 / 求助中 / 建议 / Bug / 已解决」。作者随时可以改自己帖子的状态；管理员也可以直接把 Bug 帖「标记已解决」或「改回 Bug」。
- **怎么提问最容易得到帮助**：尽量写清四件事——① 你想做什么；② 你点了哪个节点或改了什么设置；③ 实际出现了什么报错（贴完整报错文字或截图）；④ 你已经试过哪些排查办法。

## 打赏与评论

### 用鲸圆币打赏作者

在创意工坊的模板/技能详情里，或者应用中心已上架应用的详情页里，看到**鲸圆币图标**按钮就能打赏支持作者（讨论区只保留评论互动，不提供打赏）：

- **三档固定金额**：100 / 500 / 1000（打赏窗里只写币数，鼠标停在鲸圆币图标上可看说明；余额不足时点按钮可直接跳转充值）。
- **限额与规则**：单笔最高 1000 币、每个账号每月累计上限 1000 币（每月 1 日 0 点重置）；同一作品每天最多打赏一次；**不能给自己打赏**；打赏一旦发出不可退回。
- **作者所得用途**：作者收到的打赏进入账号余额，可用于调用 MTNode 中转模型，**不可提现**。
- **多作者应用按比例分配**：同一个应用如果有多位作者共同维护或二次开发，打赏窗会列出各位作者让你自由分配币数（总和不超过所选档位，自己那份固定为 0）。
- **隐私保护**：大家只能看到作品的累计打赏总额与次数，具体打赏人名单只对作者本人可见。

### 评论与五星评分

- **免登录可看，登录后可发**：工坊条目与应用详情的评论免登录就能浏览，登录后可以发表纯文字评论（最多 2000 字）并回复他人；模板、技能与应用还支持选填 1–5 星评分（删除评论时评分会一并撤销重算）。

## 社区礼仪

- 下载陌生画布后，建议先在空文件夹里试跑一遍，确认无误再用到主力项目。
- 转载或二次修改他人作品请尊重原作者，未获授权的隐私、肖像或版权素材请勿上传。
