# 创意工坊与讨论区

> 一句话目标：用好社区的两条线——创意工坊里浏览、下载（登录后上传与管理）他人公开的模板画布与技能，讨论区免登录浏览、登录后发话题回帖，并知道分享前的清密与安全礼仪。

## 社区总览

### 社区总览

MTNode 的社区由两块组成，入口都在顶栏：

- **创意工坊**（顶栏「创意工坊」）：浏览 / 下载别人公开的模板画布与技能（Skill），登录后可上传与管理自己的条目。
- **讨论区**（右上角「讨论区」）：话题与回复；免登录即可浏览，登录后可发话题、回帖并改状态。

两者共用同一个 MTNode 账户（微信扫码登录，旧账号可用密码登录后补绑）。账户入口在右上角「账户」。

本节：① 工坊 · 是什么 → ① 讨论区 · 是什么 → ① 打赏与评论 → ① 分享流程。

## 工坊 · 是什么

### 创意工坊是什么

一个公开目录：别人上传的模板画布（整张工作流）与技能（Skill，SKILL.md 包），你可以搜索、预览、下载到本机。

### 动线一：我要用别人的东西

1. 顶栏「创意工坊」，在「模板 / 技能」两栏间切换；可按标签、热度（下载量 / 点赞量）、最新排序，也支持搜索。
2. 先只读预览，确认后「下载到本机 / 下载」。
   - **模板** = 一张可导入的画布；导入时若画布引用了本机没有的服务商或模型，不再弹窗询问，这些节点会静默变成「无模型」——点 ▶ 启动时才会提示你去节点设置里重选服务商与模型。
   - **技能** = 下载到本机后，智能节点即可用 / 调用；工坊有新版本需手动更新，本机副本不会自动跟着变。

### 动线二：我要分享自己的东西

1. 先登录（上传需要登录）。
2. 上传模板 = 选一张本机画布；上传技能 = 选 / 粘贴 SKILL.md（可用「使用本机技能」载入已有技能，需含 frontmatter name，kebab-case）。
3. 填标题、介绍、标签、版本；「我的」里管理自己的条目、查看下载与点赞。

- 上传模板会自动去掉画布与本机工作目录相关的信息，不会把你的本地路径带出去。
- 同一技能名只有上传者本人能更新；重选文件会覆盖工坊正文（需填新版本）。

## 讨论区 · 是什么

### 讨论区是什么

MTNode 官方讨论区，用来提问、报错求助、分享作品与提功能建议。

入口：右上角「讨论区」。它是按需下载的组件，不在安装包里，首次点会提示下载。

### 怎么用

- 免登录即可浏览话题与回复。
- 与创意工坊共用同一个账户，登录后可以发话题、回帖、改话题状态。
- 话题长期保留，方便以后搜到同样的坑。

### 提问模板

1. 我想要什么（目标一句话）。
2. 我做了什么（节点标题 / 画布里的那一支、改了哪些参数）。
3. 实际发生了什么（报错原文，别只截一半图）。
4. 已试过什么（排除掉哪些可能）。

带上最小复现，比贴一整段日志有用得多。

## 打赏与评论

### 打赏（用鲸圆币支持作者 · 讨论区没有这条通道）

- 能打赏的对象：工坊的模板与技能、应用中心里**已上架**的应用（都是同一种入口：一枚**鲸圆币图标**按钮）。工坊在详情里就有一枚；**应用中心只在详情正文的「打赏记录」那一条右侧有一枚**（卡片封面右下角没有打赏按钮）。
- **讨论区不提供打赏**：话题详情与回复行都没有打赏按钮，也不显示累计打赏；讨论区只有「评论」页签（见下）。服务端那条打赏通道与历史上的讨论区打赏记录仍留在库里（管理后台照旧可查），只是界面上不再有入口。
- 钱从**你自己的鲸圆币余额**里出，直接转给作者。没有「充值后打赏」这一步：余额不够时按钮会提示「余额不足，去充值」，点一下直接开充值窗。
- 档位固定三档：**100 / 500 / 1000 币**，不能自己填金额。**打赏窗里只写币数**（不折成人民币），币值多少钱只在充值窗看得到。
- 界面上的币数一律「数字 + 一枚**鲸圆币图标**」（金色圆环里是 **DeepSeek 官方 logo**）：**不再写「币」字** —— 把鼠标停在图标上会显示「鲸圆币」。钱包、设置里的中转余额、计费与打赏窗都是这一套图标。
- 限额两道：**单笔 ≤ 1000 币**，且**每个账号每月累计 ≤ 1000 币**（按北京时间每月 1 日 0 点重置）；同一个对象**一天只能打赏一次**；不能给自己打赏。
- 打赏窗里**不显示「本月剩余额度」**（界面上看不到额度这种限制）：真打到当月上限时，按下打赏才会提示「本月打赏额度已用完（每月 1 日重置）」。
- 余额取不到时窗内会分两种说清：**登录已过期**（点那句话直接重新登录，登录成功后余额原地刷新）与**余额暂时取不到**（网络 / 服务端问题，稍后再试）。
- 打赏**不可退**：不提供撤销（管理后台也没有这个入口，已经撤销过的历史记录照旧只读留档）。
- 作者收到的打赏进他的余额，**可用于作者调用 MTNode 中转模型**，**不可提现**。
- 打赏按**整个应用**（原作者那一支为根）统一统计：一个应用不管有多少人二次开发过、你有几个版本，累计额与次数都是**同一份**（界面上按任一分支看都一样）。
- 谁给谁打赏了多少：**条目 / 帖子上所有人都能看到累计金额与次数**；但**打赏人名字只有这个条目的作者本人看得到**（应用有多个作者时，这一族里的作者都算「作者本人」）。你是作者时打赏窗里列出全部名单（对账用）；你不是作者时，窗里只列**你自己打赏出去的那几笔**（写「您已打赏 N · M 次」+ 图标），看不到任何别人的名字；你从没打赏过就只是一行**累计被打赏**合计。
- 打赏窗**没有右上角的 ✕**：关它走底部的「关闭」或 Esc；「确认打赏」是**橙色描边、中间透明**的按钮，排在窗内**下方**（不是左上角）。
- **一个应用有多个作者时按比例打赏**：同一应用族（含别人基于它二次开发出来的分支）由不同人维护时，打赏窗把这一组作者**排成一列**，每人右侧一个输入框填币数（单位就是那枚鲸圆币图标）—— **合计不得超过你按下的那个档位**（超了会按上限自动夹回），**最后一个作者那一格自动补齐剩余**（你改别人它跟着变）。你自己也在这一组里时，你那一份固定为 **0**（不能给自己打赏）。提交的仍是一笔总额，服务端按每位作者的份数分别入账。
- 工坊的排序里多了一档「**打赏热度**」：按累计打赏额排，支持得多的排前面（同额看次数）。

### 评论（评价与讨论）

- 评论出现在四处：工坊条目的详情窗（「评论」页签）、应用详情（「评论」页签）、讨论区话题详情（「评论」页签）、以及每条回复自己的评论小窗。**讨论区只有评论这一种互动**（打赏入口已移除）。
- **免登录可以看评论，发表评论需要登录**；可以对某条评论「回复」（父子引用），跟讨论区的回复同一形态。
- **只有条目评论（模板 / 技能 / 应用）能打五星**，而且**选填**：不选就不计入平均分；讨论区的话题与回复的评论不带星级。同一个人对同一条目只保留最新一颗星。
- 卡片与详情上会显示**平均星（保留 1 位小数）+ 评论数**与累计打赏；没人评分时不显示假分数。
- 删除：评论作者可删自己的，条目 / 话题作者可删自己名下的评论，管理员可删全站的。**评论删掉后它带的星一起不算**，平均分实时重算。
- 评论只支持纯文字、最多 2000 字，**不能传图**；有频率限制（1 条 / 分钟、50 条 / 天）。

## 分享与安装流程

### 分享一条画布（1-2-3）

1. 先把画布里的私密内容清掉：不要含有 API Key、私有路径、客户资料。
2. 顶栏「创意工坊」→ 上传 → 选这张画布 → 填标题 / 介绍 / 标签 / 版本 → 发布（需登录）。
3. 上传时会自动去掉本机工作目录信息；发布后在「我的」里看下载量与点赞，要改就重选文件并填新版本。

### 安装别人的东西（1-2-3）

1. 在工坊里预览确认，再点「下载到本机 / 下载」。
   - **模板** → 导入为一张新画布；**技能** → 写进本机技能目录，智能节点用 / 调用。
   - 插件 / 讨论区这类组件是「按需下载」的，不在安装包里；装完引擎会重启，先等没跑完的任务结束。
2. 导入他人画布后逐项检查：服务商与模型、保存路径、有没有需要本地后端的节点（H3 / Music 3 / TTS / llama）。
   - 画布引用了本机不存在的服务商 / 模型时不再弹窗询问：那些节点静默变成「无模型」（节点头上会写明原来那一份本机没有），点 ▶ 启动才提示重选服务商与模型。
3. 缺插件 / 缺后端的节点会跑不起来——先看节点说明再点 ▶。

### 升级与卸载

- 插件与素材装在应用配置数据目录下，应用升级后会保留。
- 安装 / 卸载插件会先弹确认；卸载只影响该插件，核心能力不受影响，用户插件可以再次挂载。

## 社区安全与礼仪

- 画布先在空目录里试跑，别在主力项目上直接开。
- 报错提问带最小复现，而不是贴一整段日志。
- 别人的作品注明出处，不要当自己的原创发布。
- 涉及他人隐私、肖像、版权的素材，没有授权不要上传。
