# 界面在哪儿

> 一句话目标：认全屏幕上的五个区域，知道「切换视图、新建画布、找节点、叫助手」分别在哪。

![界面分区](img/mtnode-start-01-ui.svg)
*图 1：顶栏 · 中央画布 · 左侧边栏（☰）· 右侧全局助手（✦）· 左下角总览图与运行队列*

## 目标

读完后你能一眼定位：**顶栏**放视图切换与全局开关，**中央**是画布，**左侧 ☰** 是节点树与超级节点树，**右侧 ✦** 是全局助手，**左下角**是画布总览图与运行队列。

## 前置条件

- 已安装并启动 MTNode。首次启动会**恢复上次现场**；上次异常退出时，回到最后一次自动保存或自动备份的状态。
- 不需要配置任何服务商就能打开界面、加节点、连线和排版——只有真正点 ▶ 运行才需要 API Key。

## 步骤

1. **切换视图**：顶栏最左侧在**画布 / 智能会话 / 专家团**之间切换。画布是节点编排；智能会话是常驻的智能任务聊天；专家团按画布管理专家。
2. **认顶栏中段的动作按钮**：撤销 / 重做 / 居中 / 框选 / 组 / 超节点 / 自动排版 / 隐藏线（**隐藏线**是纯视觉开关，把连线压到 95% 透明，不改画布数据、不进撤销栈；正在拖的新连线与选中节点相关的连线仍会亮起）。
3. **用顶栏右段管画布**：新建 / 改名 / 导入 / 导出 / 删除，以及**插件 / 素材库 / 创意工坊 / 设置**。
4. **认右上角一排**：益智、文档（本手册）、讨论区、审批、账户、更新（检测到新版本才高亮）、语言（中 / EN，同时决定智能体的交流语言）。
5. **打开左侧 ☰ 边栏**：上半是**当前画布**的节点 / 标签 / 绘图列表（点一条即居中定位），下半是**超级节点树**（点一条即进入它的内部画布并适配内部节点）。筛选框同时过滤两侧标题与子文件夹。
6. **打开右侧 ✦ 助手栏**：全局助手可以看画布状态；改动画布前会先确认。它的工作范围可切「全局」，用来跨画布干活。
7. **看左下角**：**画布总览图**（拖框快速平移）与**运行队列**（正在跑的节点与会话）。
8. **读底部状态栏**：画布名、节点与连线数量、服务商数、网格、缩放比例与保存状态。

### 弹窗都是常驻的

设置窗、素材库、扩展能力管理、YAML / Markdown 编辑窗，以及节点头部的小参数面板（透明背景抠图参数、画幅锁定补边参数、开发节点的 Agent 设定与颜色面板）都是 **persistent（常驻）**：点窗口外面、点画布空白都**不会**关掉它们，不会把你改到一半的参数弄丢。关闭只有几条明确路径——窗内「取消 / 完成并关闭 / 确定」按钮、面板右上角 ✕、`Esc`，或再点一次打开它的那颗按钮。**例外**只有两类没有待保存输入的瞬时菜单：右键菜单、`@` 引用与 `/` 命令候选，以及图片预览灯箱。

> 💡 技巧：面板开着时仍可照常编辑画布；平移或缩放画布时面板会跟着自己的按钮走，只有节点被删掉才收起。

> 💡 技巧：图片预览灯箱显示的是**原图**——滚轮以光标为心缩放、点图逐级放大、拖拽平移，底栏有「适应窗口 / 1:1」，放大不糊。

## 结果

你能不看手册就说出「新建画布在哪、切视图在哪、找某个节点去哪、叫助手去哪」，并且知道关掉任何浮层该按什么。

## 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 点画布空白，设置窗没关 | 弹窗是**有意常驻**的，防止丢参数 | 用窗内按钮、✕ 或 `Esc` 关闭 |
| 找不到某个节点 | 被 ☰ 边栏的筛选框过滤掉了 | 清空边栏筛选框 |
| 界面上看不到「更新」 | 只有检测到新版本才出现高光按钮 | 正常现象，无需处理 |
| 切换语言后智能体还讲旧语言 | 语言「口味」按每次运行下发 | 切完语言后重新发起一轮 |
| 顶部按钮灰着点不动 | 正在运行 / 正在拖线，或该动作需要先选中节点 | 先停下当前操作、选中目标节点 |
| 进到某层出不来 | 你在超级节点或任务内部画布 | 用工具条上的**面包屑**返回上层 |
