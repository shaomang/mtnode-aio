# AI 事实库（给 AI 读的条例库）

> 一句话目标：事实库分「一般事实库」（人读的 md 文档）与「AI 事实库」（AI 读的极简条例）两套；AI 事实库在专家团左栏有一枚常显入口行，点开即查阅，Agent 建架构 / 工作流时会把关键结论自动沉淀进来，按命中与热度淘汰。

## 事实库分两类

### 一般事实库（团队事实库）

人读的多篇 md 文档 + 审阅记录 + 共享图片目录，由专家在对话中建档维护；入口在专家团左栏「专家」列表末尾那一行。详见「AI 团队与多角色」。

### AI 事实库

给 **AI 读**的极简条例库：一件事一条、一行到几行，只为「快速知道去哪看」，不是给人读的文档。它与一般事实库**并存、互不读写**，两者的文件都待在同一个「团队事实库」目录下。

### 入口在哪

专家团（顶栏「专家团」视图）左栏偏下有一行常显的「**AI 事实库**」，右侧显示已确认条例数：

1. 未选中画布 / 这张画布还没有文件夹时，行上显示占位提示；
2. 点这一行打开查阅弹窗 —— 近乎全屏、可最小化到状态栏、点外部不会自动关闭（改动不会丢）；
3. 条数徽标只统计**已确认**的条例。

## 条例怎么进来

### Agent 自动沉淀

建项目架构、搭 / 改工作流、定下约定与路径之后，Agent 会把关键结论（模块划分、关键文件与路径、约定与来源、端口与数据流、命令入口、已知坑）写成极简条例写进本库。写作纪律是「一条一件事、标题可辨、正文只求信息传达」，命中计数会自然淘汰废话。

### 待确认（AI 提议）

Agent 想记但还没确定的内容先进弹窗顶部的「**待确认**」区：可以逐条「确认 / 驳回」，也可以「全部确认 / 全部驳回」。**待确认的提议不参与查库、不占上限、不参与淘汰**，确认后才收进库并开始计数。

### 手动新增 / 编辑

弹窗里点「＋ 新建条例」手写一条（标题 + 正文，另有可选的类型 / 标签 / 来源三栏供检索与追溯）；行上的「编辑 / 删除」直接改。正文超过约 200 字只是**软提示**，照常保存。

### 检索

弹窗顶部搜索框按标题与正文过滤（中文按 2 字滑窗匹配，英文按词）。Agent 侧走同一份库。

## 计分与淘汰

### 命中计数

只有**真正被查阅**（Agent 的按关键词查 / 按 id 取，以及界面里的检索）才会给条例加命中；列全部、写入、固定、删除都不加。写入与确认一条新条例记半点写分。

### 分数

分数 = 权重 ÷ (1 + 距上次命中的天数)：越久没人查越低。权重来自「读一次 +1、写一次 +0.5」。

### 淘汰规则

- 默认最多 **100 条**（弹窗可调，上限 1000）；
- 超出后先淘汰**分数最低**且未固定、且不在保护期内的条例，削回上限；
- **固定（★）的永不淘汰**；
- **零命中的新条例有 7 天保护期**，期内不淘汰（给新条例被读到的机会）；
- 一旦「固定的 + 保护期内的」已经占满上限，就不再淘汰，超额条目保留；
- 淘汰记录留在弹窗底部「**最近淘汰**」里，可回看。

## 与一般事实库、数据库的分工

| 库 | 谁读 | 定位 |
|----|------|------|
| **AI 事实库** | AI（紧凑索引） | 快速知道去哪看；**不是**权威 |
| **一般事实库**（团队事实库） | 人（专家也读） | 团队约定的书面出处 |
| **数据库副本**（接入 db_replica 节点时） | AI（实时查询、带引用） | 权威事实 |

冲突时：以**现文件**与**数据库**为准，AI 事实库只是可能滞后的索引。Agent 也会遵守这条，并在回答里说明分歧。

## 文件在哪

`<画布文件夹>/团队事实库/AI/ai-facts.json`（单文件，一个画布一份）。

- 与画布绑定：**画布删除后在同一文件夹重建，事实库会立刻载入**，不用重新录入；
- 文件不存在 = 空库，**首次写入才会创建**（只读查询 / 打开弹窗不落盘）；
- 文件被改坏（JSON 非法）时先自动备份成 `ai-facts.json.bak` 再当空库，绝不静默丢数据；
- 弹窗顶部常显完整路径，右上「导出…」可把整库另存成一份 JSON 备份 / 迁移。

## 旧的「长期记忆」去哪了

旧版的长期记忆（状态栏「记忆管理」里的那份）已并入 AI 事实库：旧数据会在**首次载入**本库时按「标题 + 来源」去重后自动导入，原创建 / 更新时间保留、命中计数从零开始，旧数据库文件保留作备份。此后长期记忆的查 / 记只在 AI 事实库里进行。
