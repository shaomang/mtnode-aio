# 名词表

> 一句话目标：把节点、端子、批量项、思考强度这些常用词一次对上号。

## 术语表

- **节点**：画布的主要内容构成单位（输入 / 处理 / 保存 / 控制…）。
- **超级节点**：把一组节点打包成一个「文件夹」，可将内部节点通过边界端子进行连接。
- **智能节点**：会话型节点，自己读写文件、多步干活。
- **开发节点**：带开发标记的超级节点，一般代表程序项目中的一个功能模块。
- **端子**：节点的接口。
- **批量项**：一次运行只处理一条的批量输入；「聚合模式」= 一次输入全部内容。
- **需求等待**：等到某个文件出现才放行下游。
- **思考强度**：模型思考链的长度档位（无 / 轻 / 标准 / 强 / 最强），越高越贵 / 慢，但潜在效果越好。
- **预设档**：通过大模型的系统提示词决定思维链风格。
