# 版本更新

> 一句话目标：发现新版本时一键差分下载、静默安装并自动重启，全程不用走安装向导。

![更新](img/mtnode-app-03-ui.svg)
*图 1：发现新版本后顶栏出现高光「更新」按钮，其余按钮自动左移让位。*

## 目标

MTNode 内置应用内更新（基于 electron-updater + NSIS blockmap 的**差分下载**）。发现新版本时，顶栏右上角会出现高光 **更新** 按钮，点它就能完成「下载 → 静默安装 → 自动重启」整条链路，不需要手动跑安装包，也不会弹出安装向导。

版本号同时显示在顶栏副标题与作者弹窗里，方便你随时核对当前跑的是哪一版。

## 前置条件

- 网络能连到更新源（默认 `http://mt-agent.com/mtnode/updates`，可用环境变量 `MTNODE_UPDATE_URL` 覆盖）。
- 当前不是 **Microsoft Store（MSIX）** 安装版——商店包的安装目录只读，应用内自更新被整条挡在门外（状态会报 `supported:false`）。商店版请走商店更新。
- 下载期间**应用不退出**，可以继续用；但安装阶段进程会短暂退出，先保存好手头的东西。

## 步骤

### 1. 发现高光「更新」

应用在后台检查更新。发现新版本时，顶栏出现高光 **更新** 按钮；此时 **语言** 按钮仍在最右侧，而「**审批 / 插件 / 文档**」会**向左让位**腾出位置。

「更新」按钮的悬停提示就是「发现新版本，点击下载更新」。

### 2. 确认并开始差分下载

点 **更新** 弹出确认：

- 标题 **发现新版本**，正文是「发现新版本 v…，是否下载更新？」；
- 详情说明会做什么：**差分下载更新包（仅变更部分）**，下载期间可继续使用；下载完成后会后台静默安装，安装完毕后自动重新打开应用；并附带**当前版本号**；
- 按钮：**开始下载** / **取消**。

差分的意思是**只拉变更块**，所以包体通常远小于完整安装包。

### 3. 等它下载完

下载期间应用照常可用，可以继续在画布上干活。**不要**在这段时间内反复点「更新」——重复点击不会加速。

### 4. 选择「立即安装并重启」或「稍后」

下载完毕弹出 **更新已就绪**：

> 更新包已下载完毕（v…）。安装会在后台静默进行（不弹出安装向导），安装完毕后会自动重新打开应用。选择「稍后」则下次退出应用时再安装。当前版本：v…

- **立即安装并重启**：进程短暂退出 → 静默 NSIS 安装 → 自动拉起新版本。
- **稍后**：等下次退出应用时再安装。

> 💡 技巧：Windows 下正在运行的 exe 会锁住安装目录，覆盖安装前必须让进程短暂退出——对用户表现为「后台静默安装，完成后自动重新打开」，所以中途画面闪一下属正常。

### 5. 下载失败时重试

若下载失败，先检查网络，然后**再点一次更新**重走第 2 步。更新状态会复位，可从零开始。

### 6. （开发口径）版本号从哪来

版本号的**唯一真源**是项目根目录的 `version` 文件（`x.y.z`）与 `package.json` 的 `version` 字段。**不要手改这两处**，统一用：

```
node version.js        读取当前版本并同步到 package.json，输出版本号
node version.js bump   末位 +1，写回 version 文件并同步 package.json，输出新版本号
```

一次正式发版由 `npm run release` 同时产出 NSIS 安装包与 Store（MSIX）包，**两包版本号必须一致**。

## 结果

- 应用在新版本上自动重新打开，顶栏副标题里的版本号已更新。
- 更新过程没有出现安装向导，也没有让你选安装路径。
- 如果选了「稍后」，更新包已就位，下次退出应用时自动装。

## 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 顶栏一直没有「更新」按钮 | 已经是新版；或当前是 Store（MSIX）安装版 | 商店版走商店更新，应用内自更新对它不适用 |
| 按钮点不动 / 进度停住 | 网络不稳定，或更新源不可达 | 检查网络后再次点击更新；必要时确认更新源地址可达 |
| 下载失败 | 网络中断、代理拦截或更新源暂时不可用 | 换网络 / 关代理后再点一次更新 |
| 安装后应用没自动打开 | 进程未完全退出，或系统拦截了自动拉起 | 手动启动一次应用；版本号已是新的即安装成功 |
| 「审批 / 插件 / 文档」位置变了 | 出现更新按钮后它们左移让位 | 属预期；更新完成后自动复原 |
| 手动改了 `version` 或 `package.json` 导致版本错乱 | 版本号有唯一真源，手改会两边不一致 | 用 `node version.js` 重新同步，`bump` 递增 |
| 想确认当前版本 | 版本号有两处可视化 | 看顶栏副标题，或打开作者弹窗 |
