# 工作流与创意工坊

## 本地工作流

顶栏可 **新建 / 切换 / 改名 / 删除**。默认工作流 id 为 `default`；只有把画布**全部删光**时才会新建一张空的默认画布，删除其它画布不会碰它。编辑后数百毫秒内自动保存；启动恢复上次现场。

此外每 5 分钟会把各工作流自动快照一份到数据目录里独立的 `save-backups/` 文件夹（内容无变化不重复存，每条工作流保留最近 72 份）；设置 →「画布备份」可直接打开该文件夹找回旧版本。

## 切标签页：回到你离开时的那一块

顶栏标签条（或画布下拉框）切换画布时，**每张画布各自记住自己所在的位置**：

- **钻在哪一层就回到哪一层**：正在超级节点 / 工具节点的子画布里、或某个任务的内部图里干活，用标签条切回来看别的画布再切回来，仍然在那一层里（面包屑与「← 返回」照常可用），不会被打回根画布重新钻一遍壳。新建 / 导入的画布则一定从根画布开始。
- **平移与缩放也各存一份**：回到一张画布时，相机停在离开那一刻的位置与倍率，不再被别的画布的平移量带偏。
- **只在本次运行期间记忆**（不落盘）：重启应用后从根画布开始。相机随平移每帧都在变，写盘等于把手感变成磁盘 I/O。
- **切走期间那一层被智能体删了**：自动逐层退到还活着的父层，一层不剩才回根画布——绝不停在已经不存在的层级上，让你对着一片空白。

## 删除画布：只影响当前这一张

删除一张画布**只影响它自己**，不会牵连其它画布——包括默认画布。

- **弹窗打开那一刻就锁定目标**：确认框会显示这张画布的**名称、id 与节点数**，请核对后再点「确认删除」。若弹窗期间切了画布、或有智能体正在后台写入画布，本次删除会被**当场拦下**并要求重新发起，绝不会改成删「此刻恰好打开的那张」。
- **删除后落在哪张画布**：自动切到标签条里原先紧跟其后的那个标签；没有可用标签时切到最近动过的画布。
- **软删进回收站，不物理删除**：画布 JSON 与其图像资产会整体移入 `%APPDATA%\pipeline-console\trash\<时间戳>__<画布id>\`（里面是 `<画布id>.json` 与 `assets\`）。误删时把 `<画布id>.json` 放回数据目录的 `save\`、`assets\` 放回 `assets\<画布id>\`，重开应用即可找回；本版本暂未提供「一键恢复」按钮。
- **智能体请求删除时同样要确认**：确认框里会写明名称、id 与节点数。受限范围的会话只能删自己绑定的画布；全局范围必须显式指定删哪一张（不会默认「删当前」）。主进程还会按 id + 名称与磁盘上的记录二次核对，**对不上直接拒绝**并把原因原样显示出来。

> 想清理磁盘占用，可自行清空 `trash\` 文件夹；应用不会自动删除其中的内容。

## 导入 / 导出

- **导出**：打包为 `.mtnodes`（含节点、连线、提示词与图像资产），或复制 Base64（适合小纯文本画布）。
- **导入**：从文件或粘贴 Base64 还原。他人模板若引用了你没有的服务商，会引导批量替换。

## 创意工坊

顶栏「创意工坊」浏览 / 搜索公开模板并下载。上传需要注册登录，可管理标题、预览图、描述与标签。
