# 保存、导入导出与工坊

> 一句话目标：工作流自动存得住、切得回来、删得安全、导得出去，还能从创意工坊拿模板。

![保存与恢复](img/mtnode-start-04-state.svg)
*图 1：画布落盘位置与启动恢复*

## 目标

读完这一页，你能管理多张本地工作流、理解自动保存与快照的兜底、放心删除画布、把画布导出成文件或在机器之间迁移，并从创意工坊取用模板。

## 前置条件

- 已经有一条能跑的画布，见 [输入 / 处理 / 保存](#io-proc)。
- 想上传模板需要先登录，见 [登录与账号](#account)。
- 想找旧版本备份，需要知道 设置 →「画布备份」。

## 步骤

### 1. 管理本地工作流

1. **顶栏四个动作**：**新建 / 切换 / 改名 / 删除**。
2. **认识默认画布**：默认工作流 id 为 `default`；只有把画布**全部删光**时才会新建一张空的默认画布，删除其它画布不会碰它。
3. **不用手动存**：编辑后**数百毫秒内自动保存**；下次启动**恢复上次现场**。
4. **靠快照兜底**：每 5 分钟把各工作流的当前状态自动快照一份到数据目录里独立的 `save-backups/` 文件夹（内容无变化不重复存），**每条工作流保留最近 72 份**；设置 →「画布备份」可直接打开该文件夹找回旧版本。

### 2. 切标签页：回到你离开时的那一块

顶栏标签条（或画布下拉框）切换画布时，**每张画布各自记住自己所在的位置**：

- **钻在哪一层就回到哪一层**：正在超级节点 / 工具节点的子画布里、或某个任务的内部图里干活，切走再切回来仍在那一层（面包屑与「← 返回」照常可用），不会被打回根画布重新钻一遍。新建 / 导入的画布则一定从根画布开始。
- **平移与缩放也各存一份**：回到一张画布时，相机停在离开那一刻的位置与倍率，不会被别的画布带偏。
- **只在本次运行期间记忆**（不落盘）：重启应用后从根画布开始。
- **切走期间那一层被智能体删了**：自动**逐层退到还活着的父层**，一层不剩才回根画布，绝不停在已经不存在的层级上。

### 3. 删除画布：只影响当前这一张

1. **弹窗打开那一刻就锁定目标**：确认框显示这张画布的**名称、id 与节点数**，核对后再点「确认删除」。
2. **当场拦下异常情况**：若弹窗期间切了画布、或有智能体正在后台写入画布，本次删除会被拦下并要求重新发起——绝不会改成删「此刻恰好打开的那张」。
3. **删除后落在哪张画布**：自动切到标签条里原先紧跟其后的标签；没有可用标签时切到最近动过的画布。
4. **软删进回收站，不物理删除**：画布 JSON 与图像资产整体移入 `%APPDATA%\pipeline-console\trash\<时间戳>__<画布id>\`（内含 `<画布id>.json` 与 `assets\`）。
5. **误删怎么找回**：把 `<画布id>.json` 放回数据目录的 `save\`、`assets\` 放回 `assets\<画布id>\`，重开应用即可；本版本**暂未提供一键恢复**按钮。
6. **智能体请求删除时同样要确认**：确认框里写明名称、id 与节点数；受限范围的会话只能删自己绑定的画布，全局范围必须显式指定删哪一张。

> ⚠️ 危险：想清理磁盘占用，需要**自己**清空 `trash\` 文件夹——应用不会自动删除其中的内容，清理掉就找不回来了。

### 4. 导入 / 导出与跨机迁移

1. **导出**：打包为 `.mtnodes`（含节点、连线、提示词与**图像资产**），或复制 Base64（适合小的纯文本画布）。
2. **导入**：从文件或粘贴 Base64 还原；他人模板若引用了你没有的服务商，会引导**批量替换**。
3. **跨机迁移**：同一应用内用 `.mtnodes` 迁移单张画布最省事；整机搬迁就直接搬 `%APPDATA%\pipeline-console` 数据目录。

### 5. 从创意工坊取模板

1. **打开**：顶栏「创意工坊」。
2. **浏览 / 搜索 / 下载**公开模板，下载后按导入流程落到本机。
3. **上传需要注册登录**，登录后可管理标题、预览图、描述与标签。

## 结果

- 关掉应用再打开，回到上次的画布与上次钻到的那一层。
- 每 5 分钟有一份可回溯的快照，最多保留 72 份。
- 误删的画布能从 `trash\` 手动找回；导出文件可以交给别人或搬到另一台机器。

## 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 切回来不在原来那一层 | 视图记忆只在本次运行期间有效，重启后从根画布开始 | 重启后手动钻回去；那一层被删时会自动退到还活着的父层 |
| 点了「确认删除」却没删掉 | 弹窗期间切了画布 / 后台正在写，本次被拦下 | 回到目标画布重新发起删除 |
| 找不到刚删的画布 | 已软删进 `trash\` | 把 `<画布id>.json` 放回 `save\`、`assets\` 放回 `assets\<画布id>\`，重开应用 |
| 导入模板后一堆节点报无效服务商 | 模板引用了本机不存在的服务商 / 模型 | 按提示逐个批量替换成本机服务商 |
| 找不到备份文件夹 | 不知道入口在哪 | 设置 →「画布备份」直接打开 `save-backups/` |
| 删了很多画布，磁盘还是没变小 | 只在应用内软删，`trash\` 需要手动清 | 自行清空 `trash\` 文件夹（清空后不可恢复） |
