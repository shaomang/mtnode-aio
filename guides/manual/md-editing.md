# Markdown 编辑：换行不再被吃掉，Tab 稳插缩进

> 一句话目标：把你写的 Markdown 原样留住（段落空行、段中换行、行内空格、行首缩进都不动），并让 Tab / Shift+Tab 在四个编辑面上都稳、不跳、不回滚。

## 哪些地方是同一套编辑手感

下面四个编辑面用的是**同一套**规则与快捷键，学会一个，其它三个都一样：

- **文本节点 ✎ Markdown 编辑器**：节点板身右上角铅笔图标打开的那个窗。
- **✎ AI 审阅窗的正文编辑面**：输出框点「审阅」之后改正文的地方。
- **内置 Markdown 阅读器的编辑态**：打开一份 `.md` 文件后点「编辑」。
- **画布节点板身的正文框**：`input_text` 节点展开后直接写正文的那个输入框（只有源码手感，见下）。

## 两个档位：所见即所得 / 源码

- **所见即所得档**：看到的是排好版的样子（标题、列表、表格都渲染出来）。适合改措辞、调结构。
- **源码档**：看到的是 Markdown 原文（`#`、`-`、`|` 都在）。适合精修格式、贴大段内容。
- 两档随时切换，切档不会丢字。上面四个编辑面里，前三个都有两档；板身正文框只有源码这一种手感。

## Tab 与 Shift+Tab

### 所见即所得档

- <kbd>Tab</kbd>：在**光标处插 4 个空格**。
- 选中了多行（跨段落 / 跨列表项）：**每一行的行首各插 4 个空格**，缩进完仍保持选中。
- <kbd>Shift+Tab</kbd>：这一档**不接管**，照旧跳到下一个控件（反缩进请切到源码档，或直接删空格）。
- **代码块里**按 <kbd>Tab</kbd>：同样只是插 4 个空格，光标留在原处。

### 源码档

- <kbd>Tab</kbd>：把**光标所在这一行**整体缩进 4 个空格（选中多行就每行都缩）。
- <kbd>Shift+Tab</kbd>：这一行有缩进就退掉一档（4 个空格）；没有缩进就不接管，照旧跳到下一个控件。

### 缩进是正文，不是排版工具

- 行首那 4 个空格会**原样写进 Markdown**，保存、导出、切源码档都能看到。
- Markdown 里「行首 4 个空格」本身就是代码块的写法 —— 所以别拿 Tab 当排版缩进用；
  想让一段成为代码块，用工具栏的代码块按钮更稳。

## 不再自动成块

早先版本里，在空行敲 `- ` / `1. ` / `# ` / `> ` 会当场变成列表或标题（俗称「即时成块」）。
这套自动改写已经**整体下线**：现在敲进去什么就是什么，编辑器不再替你改 Markdown 结构 ——
不然刚写完的记号被换掉、光标跳位，比省那一次点击麻烦得多。

要插入列表 / 标题 / 引用 / 链接，用工具栏对应的按钮（或直接在源码档里敲 Markdown 原文）。
工具栏**不再提供**「水平线」与「任务清单」两颗按钮：要分隔线就敲 `---`，要待办就写 `- [ ]`；
正文里已经存在的 `---` 与 `- [ ]` 照旧原样显示、原样保存。

## 粘贴

- 从网页 / 文档里复制带格式的内容粘进来：**优先保留原来的结构**（标题、列表、表格、加粗都还在）。
- 复制的是纯文本：按 Markdown 解析后贴进来 —— 一段带 `- `、`## ` 的纯文本会直接变成对应的结构。

## 不会动你正文的三条底线

1. **打开编辑器看一眼，正文绝对不会被重排**：没改动就不回写，段落空行、段中换行、行内多个空格、表格里的换行都原样留着。
2. **段中换行按硬换行保存**：正文里换行的地方，写回后仍是换行（不会和上一行粘成一段）。
3. **列表与任务清单的原样保留**：嵌套的层级、`- [x]` 的勾选态、行首的缩进，保存与导出后都和你在编辑器里看到的一致。

## 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 按 Tab 光标跳到了别的按钮上 | 这一档不接管 Tab（所见即所得档的 Shift+Tab；源码档本行没有缩进时的 Shift+Tab） | 用 Tab 插缩进；反缩进请切源码档后按 Shift+Tab |
| 按 Tab 缩进了，切源码档却看不到 | 早先版本的缺陷（改完没通知宿主，宿主按旧正文重画把缩进吃了） | 本版已修：缩进立刻写回正文，切档 / 保存 / 重开都在 |
| 按 Tab 缩进后再保存，段首多了空格 | 缩进本身就是正文内容，行首 4 空格 = Markdown 代码块 | 只是想要「看着缩进」请删掉空格，用列表按钮代替 |
| 空行里敲了 `- ` 没变成列表 | 自动成块已下线（不再替你改写结构） | 用工具栏的列表按钮，或在源码档直接写 Markdown |
| 想插水平线 / 待办清单，工具栏里找不到 | 这两颗按钮已下线（正文怎么写就怎么存） | 敲 `---` 分隔线、写 `- [ ]` 待办；旧文档里已有的照旧原样保留 |
| 点工具栏按钮，内容没插在光标处 / 按回车光标不往下走 | 早先版本的缺陷（插入前重设了一次选区，回车后的新行被算成上一行末尾） | 本版已修：没改动 DOM 就不再动光标，插入就落在你点的地方 |
| 粘进来变成一大段纯文本 | 剪贴板里没有 HTML，且纯文本里没有换行 | 用 Ctrl+Z 撤销后改用「粘贴并匹配格式」，或先粘进源码档 |
