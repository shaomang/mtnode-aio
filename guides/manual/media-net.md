# 音乐、视频、网络与执行节点

画布右键 → **处理节点** 下有两个一级子菜单：**视频生成**（Minimax H3、Remotion 视频）与**音频生成**（Minimax Music 3、SoVITS 语音生成）。

## 音频生成 › Minimax Music 3（音乐）

本地 MiniMax Music 3 后端（Gradio）。**每次运行只生成一个音频文件**（`.wav`），写入节点自带的**输出路径**——不需要再挂保存节点。

- 端子：端口 0 = 提示词 · 端口 1 = 歌词 · 端口 2 = 控制输入
- 参数：输出路径、抽卡次数（1–10）、种子（每次 +1）
- 注意：全局同一时刻只允许 **1 个音视频任务**（音乐 / 视频互斥），其它排队

## 音频生成 › SoVITS 语音生成（语音）

本地 GPT-SoVITS 后端，由插件「GPT-SoVITS 语音合成」拉起（OpenAI 兼容服务）。**每次运行只生成一个音频文件**（`.wav` / `.mp3`），同样写进节点自带的**输出路径**。

- 端子：输入 端口 0 = 待合成文本 · 端口 1 = 控制输入；输出 端口 0 = 音频 · 端口 1 = 控制
- 参数：输出路径、音色（留空 = 用后端默认音色）、语速（0.5–2.0）、输出格式（wav / mp3）、抽卡次数
- 后端没装 / 没起时，节点会先尝试拉起再合成；安装后端与准备音色都在**插件**面板里做
- 与音乐 / 视频共用同一条**串行链**（同一时刻只跑一个生成任务），但 SoVITS 是独立进程，**不占**主进程的音视频全局锁

## 视频生成 › Minimax H3（视频）

本地 MiniMax H3 后端（ComfyUI）。**每次运行只生成一个视频文件**（`.mp4`），写入节点自带的**输出路径**。

- 端子：端口 0 = 控制输入 · 端口 1+ = 数据槽（参考图 / 文本 / 参考音频 / 参考视频）
- 模式：`fl2va` 首末帧（默认） / `r2v` 多参考图
- 参数：时长 4–15 秒、分辨率（auto / 480p / 720p / 1080p，显存不足自动降档）、4K 超分补帧（24G 建议关）、抽卡次数

### 自建 ComfyUI 工作流

点节点头部 **⚙ 设置** 打开设置窗口 →「工作流来源」选 **自建 ComfyUI 工作流**，就能用自己在 ComfyUI 里搭的图（不再只有首末帧 / 多参考两条内置链）：

- 工作流在 **H3 管理窗口 · 自建工作流库** 导入（拖文件或粘贴 JSON，API / UI 两种格式都认），存成全局库，所有画布共用
- 图里被**提升为节点参数**的字段变成节点端子（端口 1 = 文本 · 端口 2+ = 素材），也可在设置窗口里直接填值——端子优先于直填，都没给就用工作流原值
- 多个 `Save*` 输出时可指定取哪一个当产物；↻ 与工作流最新图同步参数表；「校验节点包」按后端 `/object_info` 查自定义节点缺失（后端未运行则跳过，不阻断）
- 自建模式下内置的时长 / 分辨率 / 采样 / 超分补帧参数失效（由工作流图决定）；抽卡、种子、进度、取消、互斥照常

## 视频生成 › Remotion 视频（动效）

React 动效合成，本地渲染出 mp4，节点本身**不带**输出路径——产物由下游**保存**节点落盘。Remotion 插件未安装时这一项不出现在菜单里。

## 音频 / 视频输入节点（输出文件 URL）

**输入节点**里的「音频节点」「视频节点」各自只有一个数据输出端子，值是你选的那台机器上文件的 `file:///…` URL：可以直接连进 Minimax H3 的参考音频 / 参考视频端子，也能连**保存**节点或被 `@` 引用。接收端会把 URL 归一回本机绝对路径，不需要你手动转换。

## 网络 · 接收 / 发送（net_recv / net_send）

跨画布 / 跨机器文本通道，TCP / UDP：

- **接收**：监听 `host:port` 通道，收到文本异步转发下游（端口 0 = 数据，端口 1 = 控制）；默认自动监听。
- **发送**：把数据输入端文本推到目标 `host:port`（端口 0 = 数据，端口 1 = 控制触发）；末端节点。
- **通道**：同一端口按通道号（0–65535）多路复用；发送与接收同通道即互通。
- 默认端口在 **设置 · 网络**（接收 40999 / 发送 41000），可逐节点覆盖。

## 执行节点（一键启动）

绑定 `.exe` / `.bat` / `.cmd` / `.lnk` 或任何系统可打开的文件，**双击节点**（或连点两下播放键）即通过系统默认方式启动。可设图标与主题色便于定位。没有数据端子。

创建：画布空白右键 → **开发节点（项目架构 · 功能块）** → **执行**。适合把项目的启动脚本放在架构旁边。

## 提示

- 音乐 / 语音 / 视频节点自带输出路径，**不要**在它后面再挂保存节点；Remotion 相反，产物要靠下游保存节点落盘。
- 网络 / 执行节点的详细端子见右键「节点指南」。
