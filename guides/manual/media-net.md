# 音乐、视频、网络与执行节点

## 音乐生成（MiniMax Music 3）

本地 Music 3 后端（Gradio）。**每次运行只生成一个音频文件**（`.wav`），写入节点自带的**输出路径**——不需要再挂保存节点。

- 端子：端口 0 = 提示词 · 端口 1 = 歌词 · 端口 2 = 控制输入
- 参数：输出路径、抽卡次数（1–10）、种子（每次 +1）
- 注意：全局同一时刻只允许 **1 个音视频任务**（音乐 / 视频互斥），其它排队

## 视频生成（MiniMax H3）

本地 H3 后端（ComfyUI）。**每次运行只生成一个视频文件**（`.mp4`），写入节点自带的**输出路径**。

- 端子：端口 0 = 控制输入 · 端口 1+ = 数据槽（参考图 / 文本）
- 模式：`fl2va` 首末帧（默认） / `r2v` 多参考图
- 参数：时长 4–15 秒、分辨率（auto / 480p / 720p / 1080p，显存不足自动降档）、4K 超分补帧（24G 建议关）、抽卡次数

## 网络 · 接收 / 发送（net_recv / net_send）

跨画布 / 跨机器文本通道，TCP / UDP：

- **接收**：监听 `host:port` 通道，收到文本异步转发下游（端口 0 = 数据，端口 1 = 控制）；默认自动监听。
- **发送**：把数据输入端文本推到目标 `host:port`（端口 0 = 数据，端口 1 = 控制触发）；末端节点。
- **通道**：同一端口按通道号（0–65535）多路复用；发送与接收同通道即互通。
- 默认端口在 **设置 · 网络**（接收 40999 / 发送 41000），可逐节点覆盖。

## 执行节点（一键启动）

绑定 `.exe` / `.bat` / `.cmd` / `.lnk` 或任何系统可打开的文件，**双击节点**（或连点两下播放键）即通过系统默认方式启动。可设图标与主题色便于定位。没有数据端子。

创建：画布空白右键 → **开发节点（项目架构 · 功能块）** → **执行**。适合把项目的启动脚本放在架构旁边。

## 提示

- 媒体节点自带输出路径，**不要**在它后面再挂保存节点。
- 网络 / 执行节点的详细端子见右键「节点指南」。
