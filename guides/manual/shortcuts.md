# 快捷键

> 一句话目标：记住三组键——**撤销重做 / 查找替换 / 选择与分组**，其余用到再查表。

## 目标

读完后你不用离开键盘就能完成「撤回一步、找到某个节点、框选一片、收成一组、删掉重来」这一套动作，也能全程键盘操作 `@` 引用候选。

## 前置条件

- 焦点在画布上，而不是正在输入框里打字。节点正文或提示词输入框里有文字选区时，`Ctrl+C` 这类组合键会交给系统的文本操作，不会作用于节点。

## 步骤

1. **先记三组**：撤销重做（`Ctrl+Z` / `Ctrl+Y`）、查找替换（`Ctrl+F` / `Ctrl+G`）、选择与分组（`Ctrl+左键` 框选 / `G` 成组 / `Delete` 删除）。
2. **再记查找的两个范围**：`Ctrl+F` 只在**当前画布**按标题与内容查找（画布顶端出现悬浮框）；`Ctrl+G` 做替换与全部替换。
3. **最后记单个动作**：`Esc` 取消选择或关掉瞬时弹窗，滚轮缩放，点节点标题重命名。
4. **`@` 引用全程键盘**：输入 `@` 后 `↑` `↓` 移动高亮、回车（或 `Tab`）确认当前条目、`Esc` 收起；菜单开着时回车只选条目，不会把节点跑起来；正文换行用 `Shift+Enter`。

| 操作 | 快捷键 |
| --- | --- |
| 撤销 | `Ctrl+Z` |
| 重做 | `Ctrl+Y` 或 `Ctrl+Shift+Z` |
| 查找节点（标题 / 内容） | `Ctrl+F`（画布顶端悬浮框，仅当前画布） |
| 替换 / 全部替换 | `Ctrl+G` |
| 复制选中节点 / 绘制 | `Ctrl+C`（有文字选区时交给系统复制） |
| 删除选中 | `Delete` / `Backspace` |
| 组成组 / 解散组 | `G` |
| 取消选择 / 关闭部分弹窗 | `Esc` |
| 框选 | `Ctrl+左键` 拖拽，或开启顶栏「▭ 框选」后左键拖拽 |
| 缩放画布 | 滚轮 |
| 重命名节点 | 点击节点标题 |
| `@` 引用候选上下移动 / 确认 | `↑` `↓` / 回车（或 `Tab`） |
| 正文换行（`@` 菜单开着时） | `Shift+Enter` |

搜索与替换的完整用法见 [查找、总览与边栏](#canvas-tools)；`@` 引用候选的键盘路径见 [加节点、连线与 @ 引用](#nodes-wires)。

> 💡 技巧：`Ctrl+F` 的悬浮框只搜当前画布；超级节点内部的内容要先 ↪ 进去再搜。

> ⚠️ 危险：`Delete` 删除的是当前选中对象。删画布、删工作流这类重操作走顶栏按钮与确认框，不会因为误按 `Delete` 而执行。

## 结果

你能不看表完成撤回、查找、框选、成组、删除；`@` 引用菜单可以全程键盘操作，不必碰鼠标。

## 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `Ctrl+C` 没复制节点 | 输入框里有文字选区 | 先点空白处取消文本选区，再复制 |
| `Ctrl+F` 搜不到某个节点 | 它在超级节点内部，或不在当前画布 | 先 ↪ 进入那个超级节点，或切换到对应画布 |
| 回车把节点跑起来了 | 期望换行却按了回车 | `@` 菜单开着时回车只选条目；换行用 `Shift+Enter` |
| `Esc` 关不掉设置窗 | 设置窗是常驻弹窗 | 用窗内按钮或 ✕ 关闭 |
| 框选拖成了平移 | 既没按 `Ctrl` 也没开顶栏「▭ 框选」 | 按 `Ctrl+左键`，或先开框选开关 |
| 发送键不符合习惯 | 默认与你的习惯不同 | 在设置里改成「Enter 发送」或「Enter 换行 + Ctrl+Enter 发送」 |
