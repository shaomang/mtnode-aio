# 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 撤销 | `Ctrl+Z` |
| 重做 | `Ctrl+Y` 或 `Ctrl+Shift+Z` |
| 复制选中节点 / 绘制 | `Ctrl+C`（有文字选区时交给系统复制） |
| 删除选中 | `Delete` / `Backspace` |
| 组成组 / 解散组 | `G` |
| 取消选择 / 关闭部分弹窗 | `Esc` |
| 框选 | `Ctrl+左键` 拖拽，或开启顶栏「▭ 框选」后左键拖拽 |
| 缩放画布 | 滚轮 |
| 重命名节点 | 点击节点标题 |

对话 / 智能会话的发送键可在设置里改：**Enter 发送** 或 **Enter 换行 + Ctrl+Enter 发送**。
