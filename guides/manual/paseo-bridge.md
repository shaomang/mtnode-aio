# 用手机接管会话（Paseo）

手机上装 **Paseo** App（[paseo.sh](https://paseo.sh)，开源），扫码配对之后，你就能在手机上
看并接管 MTNode 左栏里的**智能体会话** —— 读消息与工具调用、看实时输出、发消息、中途插话、
终止本轮，以及在手机上回答那些「停下来等人」的卡片（工具审批 / 画布修改确认 / 模型提问）。

手机上看到的就是 MTNode 里那条会话本身：**同一份账** —— 手机上发的消息，电脑左栏里看得到；
电脑上开的会话，手机也能接着聊。

## 一、准备（电脑上，都在插件里）

打开顶栏「**插件**」→「**Paseo 手机接管**」，在它的控制台窗里按顺序做三件事：

1. **认后端**：控制台会先找本机已装的 Paseo（桌面端自带的命令行，或 PATH 里的 `paseo`）。
   找不到就点「**安装后端**」，选一个目录让它装一份独立的后端（独立数据目录，不抢你桌面端那份）。
2. **生成配对二维码** → 手机 Paseo App 扫码配对。旁边也会给出**配对链接**（可以直接复制到手机）。
   想走直连（不开 relay）也可以：手机上「Add host → Direct connection」填 Tailscale IP 与端口 `6767`。
3. **注册到 Paseo** → 打开「**远程连接**」总开关（默认是关的，配对完由你亲手打开）。

> 桥脚本必须用**真 Node** 拉起（控制台里给的就是当前应用在用的那个 Node）。
> 连不上时按控制台上「**桥自检**」的输出逐条对照，它会把数据目录候选与探活结果都列出来。

## 二、怎么用

- 在 Paseo 里新建 agent 时选 **MTNode 会话**；模式里可以选「新建一条」或**接着某条已有会话**。
- **模型也在 Paseo 里选**：桥把电脑上配好的模型清单交给它。手机上选的模型在你**新建**那条会话时
  生效；**已经有会话也能中途换** —— 换完这条会话的模型就变了，**下一条消息**用新模型，历史消息不
  受影响（正在跑的那一轮仍是老模型，这时手机上会出现一句说明）。这与你在电脑上会话菜单里换模型
  是同一件事，不是「假装换成功」。
  控制台的「桥自检」会告诉你手机端到底能选到几个模型、换模型的两条通道在不在、几条已有会话。
- 发消息、插话、终止的语义与电脑上完全一致：
  - 会话正在跑时，你发的消息会**排在后面**（不打断正在跑的那一轮）；
  - 「插话」会优先塞进正在跑的那一轮，塞不进去就自动变成排队消息，一句话都不会丢；
  - 「终止」= 电脑上那个 ■（连排队消息一起清掉）。
- **要你点头的事会推到手机**：写工作区外的文件、跑命令、改画布时，手机上会弹「允许一次 /
  本会话后续都放行 / 拒绝」。电脑上同时也有这张卡，**谁先答算谁的**。
- 手机没网 / 关掉了：MTNode 这边**继续等**，不自动拒绝也不超时；回来接着答就行。
- **电脑上的界面会跟着动**：手机发一条消息时，MTNode 会把那条会话切成当前会话（这样会话
  正文才会落盘），这一轮跑完再切回你原来在看的那条（你中途自己切走了，它就不抢）。

## 三、它不做什么

- **不在手机上直接改画布**：改画布的动作仍由会话里的 AI 发起，你只是替它按了确认按钮。
- 这一版手机上看不到模型的思考过程与用量，也不转发图片、附件（只转发文字）。
- MTNode 不对外开端口：远程通道一律走 Paseo 自己的 relay 或 Tailscale，MTNode 只负责把会话交给桥。

## 四、常见问题

- **控制台说「没找到 Paseo 的命令行」**：本机没装 Paseo；点控制台的「安装后端」装一份，或装官方桌面端。
- **出码时报 relay 没开**：新装的 Paseo 默认不开 relay，点控制台里的「**开启 relay**」即可
  （relay 是端到端加密的中继，不需要你开端口）。
- **Paseo 里看不到 MTNode 会话**：在控制台点「注册到 Paseo」重来一次；也检查 `command` 的第一条
  是不是写成了应用的可执行文件（必须填真 Node，控制台里有现成的路径）。
- **手机上「未检测到 Model」**（没有模型可选）：在控制台点一次「桥自检」，看那行 `models: N`。
  是 0 就说明桥拿不到模型清单 —— 通常是 MTNode 主窗口关着，或还没配置任何服务商；配好后再点
  「注册到 Paseo」让它重新加载，然后在手机上刷新一下。
- **选模型时报 `… does not expose ACP model selection`**：这句来自 Paseo 的选模型流程（`acp` 是它
  记的协议基名，不是某个服务商）。桥现在两条换模型通道都给（`session/set_model` +
  配置项 `category: model`），正常不会再出现；若仍看到，说明手机连的还是**旧的桥脚本** ——
  重新打包 / 让控制台「注册到 Paseo」把 `command` 指到新脚本后 reload。自检里
  `model switching:` 与 `configOptions(model):` 两行能确认这两条通道在不在。
- **手机上看不到已有的会话**：同样先看自检里的 `sessions: M` —— 那个数字就是电脑左栏里能接管的
  会话条数。数字正常但手机是空的，就在手机上刷新一次，或在控制台重开一次 provider。
  （手机上看到的历史消息是桥按正文**回放**的：最近 80 条、单条最多 4000 字。）
- **昨天还能用，今天连不上**：MTNode 的服务端**端口每次启动都会变**。重开一下 Paseo 的
  provider（或重启 daemon）即可；控制台上的「桥自检」会把当前端口探活一遍。
- **手机上发消息没反应**：先看控制台「正在接管 N 条会话」是不是 0（是 0 = 手机没接上），
  再看「远程连接」总开关是否打开，最后看 MTNode 主窗口是不是关着（会话的执行在界面这一层，窗口关了没人干活）。
- **手机答了审批，电脑上卡还在**：那张卡已经失效了（这一轮结束了或别处已经答过），
  手机上会明确提示，让 AI 重新发起一次请求。
- **想作废已经发出去的配对码**：官方没有「撤销配对」这回事，用控制台的「**重置配对凭据**」——
  它会换掉 daemon 密钥并重启后端，**所有已配对设备都会失效**，需要重新扫码。
- **提示 Paseo 版本过低**：本桥声明了最低兼容版本（控制台里能看到）。升级 Paseo 即可。
