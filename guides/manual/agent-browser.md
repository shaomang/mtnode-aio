# 会话的浏览器能力

会话可以自己开一个浏览器干活（调研、登录后抓数据、把结果存成文件），你随时看得见它在做什么、随时可以接手自己操作。

> 这只浏览器**只用在你亲自开的会话里**。画布上的智能节点、智能任务不注册这套工具（没人看着的自动运行不该自己去点网页），纯净模式同样不注册。

## 它是谁的浏览器

- 独立用户数据目录（`%APPDATA%\pipeline-console\browser-profile`），跟你日常用的浏览器互不干扰：这里登录过的账号、留下的 Cookie 只属于这边的会话。
- 用你机器上已装的 **Edge / Chrome** 直驱（不额外下载浏览器内核，不占磁盘）。本机没装这两个才报错，报错会说明该装什么。
- **按需拉起、用完保留**：会话第一次需要用浏览器时才启动；活干完留着（下次直接接手，登录态不丢），你按面板上的「停止」才会关。
- **默认用内部界面，不会在你屏幕上多开一只窗口**：它跑起来时真实窗口自动让位（移出可视区），画面实时出现在会话右边栏的「实况」区里，你在那儿就能看、能点、能滚、能打字。**你亲手点「独立窗口」才是例外**（真窗口恢复可见；点「收回」再回到右栏），而且这个例外只管这一次 —— 浏览器重启或重开应用又回到内部界面。没被调用 / 浏览器没启动时这一整条不显示；**会话第一次用浏览器时它会自己出现**（你亲手收起过就本次运行不再自动弹，点输入区的「浏览器活动」随时可开回）。这条栏**本来就开着**（上次没收 / 重启后按记忆恢复）时也会自动把实况连上，不用你手动点一下。
- **你不在看那条会话时它静默干活**：会话在后台用浏览器时**不会**弹右栏、不切你的界面、也不弹提示，只在左侧会话列表那条会话上留一枚小青标（「浏览器」）—— 你切回去时画面已经在实况区里等着了，不会看到「连接中…」的空窗。
- 一个进程多标签页；同一时刻只让**一条会话**驱动它（另一条会话要用会收到明确提示，而不是排队乱点）。

## 右边栏「浏览器活动」

会话主内容的**右边栏**是这只浏览器的实时流水账；它**不被调用、没启动浏览器、或当前会话压根没碰过浏览器时整条不显示**（不占宽度），会话左栏与对话区与从前一字不差。**会话一动手用浏览器（第一条活动进来）它自己出现**（dock 也才有机会发生；你亲手关过就本次运行不再自动弹）。入口＝输入区那枚「浏览器活动」按钮（再点一次收起，栏头 ✕ 同效）：

- 每一条 = 一次动作或一条结果：打开了哪个网址、点了哪个元素、输入了什么、跑了什么命令、读了 / 写了哪个文件、页面报了什么错、下载与截图落在哪个路径。
- 分类着色：🌐 浏览器 / `>_` 命令 / 📄 文件 / 其它，一眼能分出「它是在上网还是在动我的机器」。
- 面板上直接控制：**打开浏览器**（在后台拉起它，画面进右栏实况区，屏幕上不新增窗口）、**停止**、**接管 / 交还**、**名单**（拦截 / 风险域名与危险动作审批）、**↻ 刷新**、**清空**（默认清当前会话的，勾「含其它会话」才清全部）。
- **这条栏跟着当前会话走**：切到哪条会话，账本就是哪条会话的（每条活动的归属由它发起的那一轮决定，不是「谁最后动手算谁的」）。**当前会话没有浏览器时这一整条收起** —— 没被调用过、也没在驱动这只浏览器的会话，不该白占一块空栏；切回那条用过浏览器的会话，它按记忆恢复、账本也接回原来那份。你亲手开 / 关过一次的会话会记住你的选择（本次运行内），自动判据不会把你的选择顶掉。实况画面只画给**此刻持着浏览器驱动锁**的那条会话：别的会话驱动着浏览器时，本会话的右栏不去拉它的画面（同一时刻只有一条会话能驱动）。
- 勾「含其它会话」＝连别的会话的条目一起看（查全库）；不勾＝只看当前会话。旧版本留下的、归属没盖成会话号的条目也只在这个勾选下才出现。
- **跟随最新 / 停止跟随**（在栏底「清空」左边）：默认跟随 —— 新活动一来列表就停在最新一条。你往上翻看前面的记录时它会**自动停跟随**（键面翻成「跟随最新」，键不再发亮），这时新活动照旧进来，但视线留在你正看的位置、不会被拽回底部；**滚回底部自动恢复跟随**，也可以点那枚键手动切。这个选择会记住，下次打开按上次的状态恢复。往上翻旧记录与「跟随」互不打扰，核对动作链时不用抢时间。

### 右栏里的「实况」画面

面板上半部分的**实况区**就是这只浏览器本身，**默认就用它**（不是另开一只窗口）：

- 画面是实时投过来的（约 10 帧/秒，按需降质），**只走内存、不落库、不进模型上下文**：看画面同样不花 token。
- 直接在里面操作：点、滚、打字都会转给页面（输入法也能用）。要更顺手的场景（比如输密码）就点「独立窗口」换成真窗口。
- **独立窗口 / 收回**：点「独立窗口」= 真实窗口恢复可见（变回独立窗口），面板只提示「已在独立窗口」，画面不再重复解码；点「收回」→ 画面回到右栏。**这个选择只管这一次**：浏览器重启或重开应用又回到内部界面（不会拿上一次的选择推翻默认）。切成独立窗口期间它**不会再自动把窗口收回去**（一直保持独立窗口，直到你自己点「收回」）。万一真窗口没能摆到你看得见的位置，面板上会直接说明，你照旧可以在右栏实况里操作。
- **暂停观察**：临时不想让它解码画面就点一下（再点恢复）；收起右栏、切到画布 / 团队视图也会自动停掉取帧。
- **兜底模式**：个别机器上「窗口移出可视区」后系统不再渲染，这时会自动回落成「窗口停在屏幕上 + 面板照常出帧」，并在实况区标出来（内容以真窗口为准）。
- 这些记录同时**落到本机活动库**（`%APPDATA%\pipeline-console\activity.sqlite`），关掉面板 / 重启应用还能回看；每个会话最多留 4000 条、整库 30000 条，超量自动清理最旧的。
- **活动流不进模型上下文**。它是给你看的账，不是喂给 AI 的材料 —— 所以看流水不会多花一分钱 token。

## 需要你帮忙时：求助卡

会话遇到它自己过不去的事，会在会话里弹一张**浏览器求助卡**（蓝色卡片，带当时的页面截图），按情况给你几件事选：

| 情形 | 卡片会给你 |
| --- | --- |
| 要登录 / 页面要过验证 | 「接管浏览器（我来操作）」——你亲自输入账号密码，**密码不经过会话、不进对话**；输入就在会话右栏的实况区里做（不会另开一只窗口逼你去点它） |
| 一个结果它吃不准 | 「请你验证这个结果」+ 截图，你点「我已处理，继续」它就往下走 |
| 要你补一个信息 / 做个选择 | 选项按钮（如选哪个账号、哪份文件） |
| 危险动作（提交 / 支付 / 删除 / 发送 / 发布） | 「允许这一次」/「拒绝」 |
| 彻底卡住 | 它说明试过什么、需要什么，你回一句话或直接接管 |

接管期间**会话的浏览器动作会被拒绝**（不是排队等着偷偷做），交还后才继续 —— 所以你可以放心地在它手上抢过鼠标。交还后它会先重新看一眼页面再接着做。

## 安全口径（默认就能挡住的几件事）

- **拦截名单**：这些域名一律拒绝访问；**风险名单**：首次访问弹一次确认卡（邮件、网银、政务这类默认在里面）。名单在面板「名单」里改，**下一次动作即刻生效**。
- **危险动作**：提交 / 支付 / 删除 / 发送 / 发布这类点击，默认先弹确认卡（可整档关掉，看面板里的勾选项）。
- **凭据**：会话不会替你输密码；密钥、令牌类入参在活动流里也只记长度不记正文。
- 页面里的控制台报错、失败请求都会进活动流 —— 出问题时你第一眼就能看到原因。

## 长时自治：自动续跑

会话跑完一轮，如果**目标还没达成、还有下一步**，它会自己接着跑下一轮（输入框上方那枚「模式」菜单里的**「自动续跑」开关**是总开关，默认开）：

- 累计状态（已续几轮、跑了多久、累计消耗）挂在同一条「模式」chip 的悬停提示里，token 可算时才显示。
- 停止条件：它自己判定**目标已达成**（答复里明确收工 + 交付清单）、清单全部收口、你按了终止 / 暂停、或到了安全上限（30 轮，防跑飞）。
- **不会因为你跑了很久、花了很多就停下来问你** —— 阀值只做累计显示，你自己盯。想让它停就在「模式」菜单里把这一项关掉。
- 要数小时才能做完、或者要跨重启接着跑的活，它会**建议**你提升为「长周期任务图」（图上带阶段与断点），但不会自己替你改图。
- 每一轮的开头它都会先自查：哪些已带证据完成、哪些还没做、上一步的输出有没有问题；**发现问题先自己修好并重跑**，不会拿可疑结果当定稿，也不会把「我修不了」以外的事推给你。
