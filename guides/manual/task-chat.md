# 任务与对话

## 任务节点

内部是一张控制流图：固定**起点**、若干步骤 / 子任务 / 判断，以及**成功 / 失败终点**。父任务上用格子展示子任务。点 ▶ 点燃起点。细节见 [任务控制流](#task-flow)。

## 超级节点

收纳相关节点的子图画布（不是控制流容器）。可展开壳层或 ↪ 进入；用边端子隧穿数据；可设子文件夹约束相对路径。详见 [超级节点](#super-nodes)。

## 智能节点的会话模式（💬）

「文本对话」节点已移除。想要微信风格的多轮对话（助手左、用户右、历史随画布保存），在**智能任务**节点头部点 **💬** 开会话模式即可；旧画布上的对话节点打开时会自动迁移成这种节点。详见 [智能任务与智能会话](#agent-nodes)。

## 控制 · 执行 / 清空

把控制节点连到若干目标（或把目标连进来），头部切换「执行 / 清空」，▶ 对全部已连接节点同时执行。金色线不是数据。
