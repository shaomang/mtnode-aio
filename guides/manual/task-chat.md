## 目标

把原来挤在这一页的四件事分别接到它们该在的位置，避免和新结构重复。

## 前置条件

- 无。这是一页导航。

## 步骤

1. **看任务节点**：任务内部是一张控制流图（固定起点、若干步骤 / 子任务 / 判断、成功终点与失败终点），见 [控制流与判断](#control-flow)。
2. **看超级节点**：那是收纳相关节点的**子图画布**（不是控制流容器），见 [超级节点（收纳子图）](#super-nodes)。
3. **看会话模式（💬）**：「文本对话」节点已移除；需要微信风格的多轮对话时，在**智能任务**节点头部点 💬 开会话模式，旧画布上的对话节点打开时会自动迁移，见 [智能任务与智能会话](#agent-nodes)。
4. **看控制 · 执行 / 清空**：把控制节点连到若干目标（或把目标连进来），头部切换「执行 / 清空」，▶ 对全部已连接节点同时执行——金色线只传脉冲，不是数据，见 [控制流与判断](#control-flow) 与 [名词表](#glossary)。

## 结果

你被带到了真正讲这件事的页面；旧书签不会停在空白上说「找不到」。

## 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 从旧链接进来发现内容没了 | 本页已拆分合并 | 按上面的「步骤」跳转到对应页面 |
| 找不到「文本对话」节点 | 该节点已移除 | 用智能任务节点的 💬 会话模式 |
| 把超级节点当任务容器用 | 两者定位不同 | 控制流用任务，收纳子图用超级节点 |
