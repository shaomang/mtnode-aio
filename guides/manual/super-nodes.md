# 超级节点

超级节点用于把一批相关节点**收纳**成一块子图，减少主画布噪音。与「任务」不同：任务强调控制流（起点 → 终点）；超级节点强调**结构收纳与数据通道**。

## 创建与合并

- 画布空白处右键 → **超级节点**。
- 框选若干节点后点顶栏 **「超节点」**：按选区外框新建展开的超级节点，并把选中节点收纳进去。
- 创建 / 收纳常需 **canvas_super** 审批（智能会话 / 助手改画布时也会询问）。

## 展开与进入

标题栏右侧（「进入」按钮旁）有展开图标：

| 操作 | 作用 |
| --- | --- |
| **展开 / 收起**（图标） | 在主画布上打开壳层内部舞台，可直接编辑子节点；再次点击收起。展开时内容会尽量贴齐舞台左上角。 |
| **进入 ↪** | 进入完整画布模式，只显示该超级节点内部；面包屑可返回。 |

壳层内可左键拖空白平移、滚轮缩放外层相机、右键添加节点；把节点拖入 / 拖出即可移入移出。超级节点可嵌套。

## 外侧与内侧端子

不再使用内部「输入 / 输出」代理节点，全部用**边端子**隧穿：

- **外侧输入**（收起时）：外部连入超级节点。
- **内侧输入（桥接）**：展开壳层左侧，或**进入**后画布左边缘；从这里拖到内部节点。
- **内侧输出（汇流）**：内部节点连到壳层右侧 / 全屏右边缘。
- **外侧输出**：超级节点连出到外部。

端子右键可移除该端子上的内侧连线。

## 子文件夹与相对路径

超级节点标题栏右侧可设 **子文件夹**（相对顶栏工作目录）。设置后：

- 内部保存 / 音乐 / 视频 / 监视等待等节点的**相对路径**会自动落在 `工作目录 / 子文件夹 / …`（可多层嵌套，取祖先链上全部子文件夹）。
- 移入超级节点、或修改子文件夹时，内部已有相对路径会自动补上前缀；绝对路径不改写。
- 需要指到画布根或其它目录时，请用**绝对路径**。

路径显示在标题栏右侧（不挡标题）；不再在内部画布上画路径提示。

## 排版

顶栏「排版」整理主画布时，若存在已展开或含内容的超级节点，会询问是否**同时排版内部**。

## 左侧边栏

☰ 边栏分为两段：

1. **当前画布**：当前作用域内的节点 / 标签 / 绘图（点击居中定位）。
2. **超级节点**树：按嵌套层级列出；点击即**进入**该超级节点画布并适配内部节点。当前进入项高亮。

筛选框可同时过滤节点、绘图与超级节点标题 / 子文件夹。
