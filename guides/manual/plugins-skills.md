# 插件、技能与 MCP

> 一句话目标：给智能节点装上新的本地后端与外部工具——应用插件、DSH 插件、技能（Skills）、MCP 服务器，四类扩展各就各位。

![扩展能力](img/mtnode-agent-07-ui.svg)
*图 1：设置 · 智能能力 → 扩展能力 → 管理…，三类扩展共用一个对话框*

## 目标

读完这一页，你能用右上角「插件」装上本地后端（语音、大模型、音乐、视频）；能用「设置 · 智能能力 → 扩展能力 → 管理…」这个统一对话框安装 DSH 插件、写自己的技能、接入 MCP 服务器；并在智能会话里用 `/` 把技能调起来。

## 前置条件

- 有网。离线时插件列表会用上次缓存或随包内置列表，新插件装不上。
- 要装本地后端插件（GPT-SoVITS / Llama.cpp / MiniMax Music 3 / MiniMax H3）时，先备好磁盘与显存，并按插件面板里的指引装依赖。
- 接 MCP 需要一条可执行的 stdio 命令，或一个远程 URL。
- DSH 插件安装后**引擎会重启**，先保存好手头的编辑。

## 步骤

1. **打开应用插件**：点右上角 **插件**。列表**从云端目录更新**（`http://mt-agent.com/mtnode/plugins/catalog.json`），所以不升级主程序也能看到新插件；离线时用上次缓存或内置列表，云端目录缺项时随包内置插件会自动合并回来。
2. **下载并运行**：在卡片上点运行 / 卸载 / 更新。新插件可能是**窗口插件**——目录里新增的 zip 包可直接下载安装并运行，无需发新版安装包；若插件类型当前版本不认识，会提示你先升级应用。
3. **打开扩展能力管理**：进 **设置 · 智能能力 → 扩展能力**，这里只显示一行汇总（各有多少），点 **管理…** 打开统一的「扩展能力管理」对话框。
4. **切标签**：对话框顶部有 `DSH / Skill / MCP` 三个标签切换分类；左边是卡片清单、右边是详情与操作，三类共用同一套样式。
5. **搜索与操作**：每个分类顶部都有搜索框；右侧详情里可对每一项**挂载 / 停用 / 移除**。详细卡片也可以在设置里直接搜索、安装、启停、移除。
6. **装 DSH 插件**：在 DSH 标签里直接填 **npm 包名 / GitHub 地址**安装。插件装到**配置目录**（升级后保留），安装后引擎会重启——下一次运行起工具菜单里就多出它。
7. **建技能**：在 Skill 标签点 **＋ 创建技能**，在右侧写**名称、描述与正文**（Markdown 说明书）。
8. **用技能**：在智能会话 / 智能任务 / 开了「🐋 智能」的文本节点里输入 **`/`** 即可选择该技能，运行时**带上该技能全文**。
9. **加 MCP 服务器**：在 MCP 标签点 **＋ 添加服务器**，填名称与 **stdio 命令或远程 URL**；连接后智能节点就获得该服务器提供的工具。
10. **去线上目录找**：点 **🌐 在线浏览** 进线上目录安装；官方扩展目录是 `http://mt-agent.com/mtnode/ext/catalog.json`，在线浏览预置「MTNode 官方」标签，也可「＋ 添加源」自行添加源。

### 应用插件里的本地后端

- **讨论区**：按需下载的聊天窗口，登录创意工坊同一账户后聊天；可运行、卸载、更新。
- **桌宠 BongoChat**：按需下载的透明置顶窗口，可运行、卸载。
- **本地 TTS（GPT-SoVITS）**：本地语音合成后端，训练 / 试听 / 语种策略都在插件面板里；画布上的 **SoVITS 语音**节点（处理节点 › 音频生成）连的就是它。
- **本地大模型（Llama.cpp）**：本地推理后端。
- **MiniMax Music 3 / MiniMax H3**：本地音乐 / 视频生成后端（对应画布「音频生成 / 视频生成」子菜单里的 **Minimax Music 3** / **Minimax H3** 节点）。

### 内置技能

内置技能由应用自带，随引擎自动同步到技能库并带内部标记，因此**不出现在用户技能列表**、也无需安装；AI 侧用 `skill` 工具按名字加载，普通会话里用 `/` 也能选到：

- `mtnode-dev-architect`——开发节点架构扫描与搭建。
- `mtnode-grill-me`——拷问我：把需求映射成决策树、按轮用 MTNode 的询问窗（`ask_user_question`）一次问完整个前沿，每题把推荐项排在第一位，达成共识并经你在询问窗里确认后才动手；开发节点「开发」框的「先拷问需求」开关用的就是它。
- `mtnode-canvas-batch-safety`——批量防 N²。
- `mtnode-canvas-layout-ux`——画布排版。
- `mtnode-db-facts`——事实库纪律。
- `mtnode-media-gen-nodes`——音乐 / 语音 / 视频生成节点。

### 官方目录与本地仓库

- 官方扩展目录：`http://mt-agent.com/mtnode/ext/catalog.json`（在线浏览预置「MTNode 官方」标签）。
- 本地仓库在 `ext-repo/`，用 `npm run ext:sync` 同步到云端。

## 结果

- 右上角「插件」里能直接启动已装后端；画布上出现对应的生成节点。
- 「扩展能力 → 管理…」对话框里三类扩展各自成标签：DSH 插件显示已启用，技能出现在 `/` 候选里，MCP 服务器显示连接状态。
- 装完 DSH 插件后引擎重启完成，智能节点多出新的工具。
- 在线浏览里能看到官方标签下的技能 / 插件 / MCP 条目，点安装即进本地列表。

## 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 插件列表是空的或很旧 | 离线，用的是缓存 / 内置列表 | 联网后重开插件面板刷新云端目录 |
| 装了插件但画布上没有对应节点 | 节点属于「音频生成 / 视频生成」子菜单，或后端未启动 | 到处理节点的生成子菜单里找；确认插件面板里后端已运行 |
| 点了安装，提示插件类型不认识 | 该插件需要更新版应用 | 先升级应用再安装 |
| `/` 里找不到刚写的技能 | 技能没保存，或该节点不是智能节点 | 在扩展能力对话框确认技能已保存；普通节点要开「🐋 智能」才有 `/` 候选 |
| MCP 服务器加了但工具不出现 | stdio 命令不可执行，或 URL 不通 | 换成可执行命令 / 可访问的 URL，检查详情里的连接状态 |
| DSH 插件装完界面短暂不可用 | 引擎正在重启 | 等重启结束再继续操作 |
