# 插件、技能与 MCP

## 应用插件（右上角「插件」）

插件**列表从云端目录更新**（`http://mt-agent.com/mtnode/plugins/catalog.json`），可不升级主程序看到新插件。离线时使用上次缓存或内置列表；云端目录缺项时，随包内置插件会自动合并回来。

- **讨论区**：按需下载的聊天窗口，登录创意工坊同一账户后聊天；可运行、卸载、更新。
- **桌宠 BongoChat**：按需下载的透明置顶窗口，可运行、卸载。
- **本地 TTS（GPT-SoVITS）**：本地语音合成后端，训练 / 试听 / 语种策略都在插件面板里；画布上的 **SoVITS 语音**节点（处理节点 › 音频生成）连的就是它。
- **本地大模型（Llama.cpp）**：本地推理后端。
- **MiniMax Music 3 / MiniMax H3**：本地音乐 / 视频生成后端（对应画布「音频生成 / 视频生成」子菜单里的 **Minimax Music 3** / **Minimax H3** 节点）。
- **窗口插件**：目录里新增的 zip 包可直接下载安装并运行，无需发新版安装包。若插件类型当前版本不认识，会提示先升级应用。

## DSH 插件 / 技能 / MCP

三类扩展已**整合成一个界面**：「设置 · 智能能力 → 扩展能力」只显示一行汇总（各有多少），点 **管理…** 打开统一的「扩展能力管理」对话框；顶部 `DSH / Skill / MCP` 三个标签切换分类，左边是卡片清单、右边是详情与操作，三类用的是同一套样式。

- **DSH 插件**：扩展 agent 能力，安装到配置目录（升级后保留）；安装后引擎会重启。对话框里直接填 npm 包名 / GitHub 地址安装。
- **技能 Skills**：Markdown 说明书。「＋ 创建技能」在同一对话框右侧写名称、描述与正文；智能会话 / 智能任务 / 开了「🐋 智能」的文本节点输入 `/` 即可选择，运行时带上该技能全文。
  - **内置技能**（应用自带，随引擎自动同步到技能库并带内部标记，因此**不出现在用户技能列表**、也无需安装；AI 侧用 `skill` 工具按名字加载，普通会话里用 `/` 也能选到）：`mtnode-dev-architect`（开发节点架构）、**`mtnode-grill-me`（拷问我：把需求映射成决策树、按轮用 MTNode 的询问窗（`ask_user_question`）一次问完整个前沿，每题把推荐项排在第一位，达成共识并经你在询问窗里确认后才动手——开发节点「开发」框的「先拷问需求」开关用的就是它）**、`mtnode-canvas-batch-safety`（批量防 N²）、`mtnode-canvas-layout-ux`（画布排版）、`mtnode-db-facts`（事实库纪律）、`mtnode-media-gen-nodes`（音乐 / 语音 / 视频生成节点）。
- **MCP 服务器**：「＋ 添加服务器」填名称与 stdio 命令或远程 URL；连接后智能节点获得该服务器的工具。

每个分类顶部都有搜索框，右侧详情里可挂载 / 停用 / 移除；「🌐 在线浏览」仍可去线上目录安装。

官方扩展目录：`http://mt-agent.com/mtnode/ext/catalog.json`（在线浏览预置「MTNode 官方」标签；也可「＋ 添加源」自行添加）。本地仓库在 `ext-repo/`，用 `npm run ext:sync` 同步到云端。

详细卡片可在设置里搜索、安装、启停、移除。
