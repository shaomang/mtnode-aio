# 智能节点与画布归属

在 MTNode 里，AI 干活有三个常见入口：顶栏的「会话」、画布上的「智能节点」，以及画布右侧的「全局助手（✦）」。搞清楚它们各自管什么、怎么不互相打架，用起来会非常安心。

## 三种入口怎么选

| 你想做的事 | 用哪个入口最合适 |
| --- | --- |
| 一次固定加工（翻译、改写、总结、出图） | 画布上的普通**文字 / 图像节点** |
| 在工作流里插入一个「自己读文件、查资料、多步做完」的环节 | 画布上的**智能任务节点**（或开了智能模式的文字节点） |
| 搭新画布、改节点连线、自动排版 | 画布右侧的 **全局助手（✦）** |
| 写软件项目、深度调研、多轮连续协作 | 顶栏的 **会话** 视图（或开发节点点「开发」） |

## 会话属于哪张画布

每条会话在**创建的那一刻**就认定了自己所属的那张画布（你当时正看着哪张画布，它就属于哪张；在开发节点上点按钮建的会话，就属于那个开发块所在的画布）。

- **放心切画布干别的活**：会话开始跑之后，你可以随便切到其他画布继续编辑，这条会话读写的节点、工作目录和数据库都会精准落在**本会话所属的那张画布**上，**不会串到你此刻正看着的画布**，也**不会误改、误删你正在编辑的那张**。
- **一眼认出归属**：左侧会话列表里，每条会话标题下方的 `▣` 图标写的就是它的所属画布（画布被删除时会明确标出）。
- **需要跨画布操作时**：单条会话**不跨画布**读写，还可以查看并修改**本会话所属的那张画布**；如果要同时参考或管理多张画布，请打开右侧的 **全局助手（✦）**，把它的工作范围切到「全局」。

## 画布里的智能节点小贴士

- **不用再接「保存」节点**：智能任务节点自己就能把成品直接写进你的项目文件夹，跑完通常会把文件路径返给你。
- **独立设定开关**：每个智能节点都能在自己的设置里单独挑模型、预设档、思考强度和工具权限，互不干扰。
- **先看清楚再放大任务**：第一次跑带写文件能力的智能节点时，建议先给它一个空测试目录试一遍，确认产出符合预期再用到主力项目上。
