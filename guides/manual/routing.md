## 目标

把你带到讲闸门、分发、互斥等控制节点的当前页面。

## 前置条件

- 无。这是一页导航。

## 步骤

1. **认约定**：控制类节点统一**金色外圈**，内部颜色仍表示种类——见 [控制流与判断](#control-flow)。
2. **看闸门**：AND 语义，配置了几路输入就要几路脉冲到齐才放行；**没接线的端口也会挡住**。
3. **看分发 / 序列器 / 计数 / 互斥**：分发一入多出把脉冲送到多路；序列器按顺序依次触发；计数计满 N 次再放行；互斥在多路里按模式只放行一路（先到 / 端口优先 / 随机）。
4. **看需求等待**：监视某个文件出现或变化后再继续。

## 结果

你被带到了涵盖全部控制节点的当前页面；各节点端口顺序以节点指南为准。

## 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 闸门一直不放行 | 配置的输入路数多于实际接线数，空端口也挡 | 改小闸门输入数，或把空端口接上 |
| 互斥只走了一条 | 模式决定只放行一路 | 按需要改成先到 / 端口优先 / 随机 |
| 计数提前放行 | 计数值与脉冲次数不符 | 核对「每 N 次放行」的设置 |
