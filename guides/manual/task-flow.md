# 任务控制流（已并入控制流与判断）

> 一句话目标：这一页已经并入 [控制流与判断](#control-flow)，老链接来这里给你指路。

![任务图](img/mtnode-flow-08-flow.svg)
*图 1：任务内部的固定起点、步骤 / 判断与成功 / 失败终点，现在都在「控制流与判断」里讲*

## 目标

把你带到真正讲任务控制流的页面，避免同一件事在两页各写一半。

## 前置条件

- 无。这是一页导航。

## 步骤

1. **看任务图本身**：每个任务内部固定有**起点**（任务自动创建，不出现在添加菜单）、若干工作步骤 / 子任务 / 判断，以及**成功终点 / 失败终点**——见 [控制流与判断](#control-flow)。
2. **看怎么推**：点 ▶ 从起点沿控制线推进；到达成功终点即成功，走到失败终点或跑不动则失败。父任务格子反映子任务状态。
3. **看判断分流**：判断节点根据「目标 / 标准」和已有结果，让文本模型只答 YES/NO 再分流（只有两个输出：YES 与 NO），需要已配 API Key 的文本服务商。
4. **看定时与其它控制节点**：定时器、延时器、等待文件、序列器、闸门、分发、计数、互斥同样收在 [控制流与判断](#control-flow)。

## 结果

你被带到了涵盖任务图、判断与全部控制节点的当前页面。

## 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 从旧链接进来发现内容变了 | 本页已合并 | 按上面步骤跳转 |
| 找不到「起点」节点怎么加 | 起点由任务自动创建 | 不要试图手动添加，见新页面 |
| 判断节点没有输出 | 没配文本服务商或判据为空 | 补上 API Key 与判据 |
