# 上架应用与多版本管理

应用做好自测没问题后，可以把它上架到云端应用市场，让其他 MTNode 用户直接下载使用，甚至基于你的版本继续二次创作。

## 怎么上架或发新版本

1. 登录你的 MTNode 账号。
2. 进入 **应用中心 → 开发**，选中你的应用，点预览栏上的 **上架**。
   - **首次上架**与**发新版本**用的都是这同一个按钮：第一次会在云端新建条目，之后再点就是给同一个应用追加新版本（版本号默认自动小版本 +1，也可以手改）。
3. **自动填信息 + 你来核对**：打开上架窗时，AI 会先帮你起草标题、简介、标签和版本号；请一定亲自核对修改再提交。没有配置文本模型时直接手填即可。
4. **拍截图当封面**：点 **拍应用窗口** 会自动启动应用并截一张清晰的窗口图，也可以从电脑选图（最多 8 张，可拖动排序，第 1 张默认作封面）。更新版本时，之前传过的截图会自动带回来，没改动的图不用重复上传。
5. **勾选原创与合规声明并提交**：上传前需勾选合规声明确认不含违法或侵权内容，点提交即可完成。

> **关于应用 ID**：应用 ID 默认锁定，用来唯一标识你的应用，这样以后每次更新都会自动归在同一个应用下。只有在你确实想把它发布成一个全新独立应用时，才点「修改 ID」。

## 多版本与二次开发（分支）

- **版本树清晰收纳**：同一个应用的每次更新都会按版本树排好，别人在应用详情里可以一眼看到「最新」与「本机已装」，也可以自由选择下载任意历史版本。更新只替换应用代码，**不会动用户已经保存的数据**。
- **二次开发自动标明来源**：如果你把别人上架的应用复制到开发目录做了改进再上架，系统会自动记录原作者来源并建出你自己的分支；其他用户点「切换分支」就能在原版和你的改进版之间自由挑选，互不覆盖。

## 配额与已上架管理

- **默认免费额度**：每个账号默认最多上架 **5 个应用**（给已有应用追加新版本不占名额），名下所有版本和截图云端总空间上限 **50MB**。上架窗底部会实时显示「已用 / 上限」。空间满了可以在上架窗里勾选删掉不再需要的旧版本，立刻释放配额。
- **管理我上架的应用**：在应用中心左栏 **开发中应用** 的下半块「我上架到云端」里，可以随时：
  - **编辑资料**：改标题、简介、标签、封面图标和截图，保存后立刻生效，不需要重新发版本号；
  - **彻底删除**：输入应用标题确认后，从云端彻底移除你这一条分支的全部版本包与截图（不可恢复；别人基于它派生出来的分支不会受影响，你本机已装的副本也不会被删）。

## 传不上去时先查这四件事

1. **有没有登录**：未登录无法上架，先点右上角登录账号。
2. **有没有勾选合规声明**：必须勾选声明才能提交。
3. **配额是不是满了**：看窗底用量，删掉几个旧版本腾出空间即可。
4. **应用能不能正常启动**：先回「开发」页点一下「启动」，确认入口页完好无报错再上架。
