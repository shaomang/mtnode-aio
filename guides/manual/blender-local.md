# Blender 本地插件：让 Agent 直接操作 Blender

「**Blender 本地插件**」把三件事一次装好：一份**官方** Blender（便携版，装到你选的目录）、
社区事实标准的 **mcp-for-blender** addon、以及它的 MCP 服务端；最后把这个 MCP 服务器写进
MTNode 的 MCP 配置。重启 MTNode 之后，**你的智能体会话里就多出 `blender` 工具** ——
可以直接让 Agent 建场景、摆机位、改材质、渲一张预览图。

## 一、装（一次就够）

顶栏「**插件**」→「**Blender 本地插件**」→「**安装**」。安装窗会按顺序做：

1. **查版本**：读官方 `download.blender.org` 目录，取**最新稳定版**（当前 5.2.x）；
   已装过就跳过下载（**本插件不自动升级**）。
2. **下载**：官方 windows-x64 便携 zip（约 405MB），**sha256 校验**、断点续传。
3. **解压**到你在插件界面里选的位置（默认是插件根目录下的 `blender`）。不写注册表、不要管理员。
4. **uv**：MCP 服务端靠 `uvx` 跑；本机没有 uv 就装官方那份（失败会退回官方 release 包）。
5. **addon**：装进你的 Blender 用户配置，并在 Blender 里**启用、保存偏好**（改前会备份 userpref）。
6. **注册 MCP**：把 `serverName=blender` 写进 MTNode 的 MCP 配置；9876 被占会自动换 9876–9886 里的空闲端口。
7. **冒烟**：真的拉起一次 Blender，等 addon 起服务，再做一次 MCP 握手（拿回工具列表）。
   会短暂弹一个 Blender 窗口，验完自动关掉 —— **只有这一关过了才算装好**。

装完请**重启 MTNode**：MCP 配置只在启动时读取。

装的过程中窗底一直留着「**关闭窗口**」：只关窗、安装继续在后台跑，再打开还能接上看进度；
真要停就点「**取消安装**」—— 它会当场停下（不再继续装 addon / 注册 MCP / 拉 Blender 冒烟），
已经下好的文件保留，点「**重试**」接着装。

## 二、用

- 在会话里直接说「用 blender 建一个立方体、加一盏灯、渲一张图」；Agent 会调 `blender` 工具。
- 顶栏插件卡片上：
  - 「**启用**」= 插件替你拉起一只 Blender 并起好 addon 服务（只在装了之后出现）；
  - 「**停用**」= 关掉**插件自己拉起的**那只 Blender；**你手开的 Blender 不会被碰**；
  - 「**控制台**」= 逐项状态（Blender / addon / uv / MCP / 端口）、日志、**测试连接**、
    **检查更新**（只提示，不自动升级）、**打开安装目录**、**卸载**。
- 想让 Agent 操作**你已经打开的那份工程**：先在那只 Blender 里启用「MCP for Blender」并启动服务
  （侧栏 MCP 面板），端口用控制台显示的那个；或直接让插件拉起新的实例再打开工程。

## 三、装不上时

安装窗会在失败那一步给出中文原因与下一步；同一只窗里的「**交给 mtnode 会话修复**」会带上日志开会话，
按 `blender-local-install` 技能的【自我修复】走。常见几种：

| 现象 | 多半是 | 怎么办 |
| --- | --- | --- |
| 下载一直失败 | 访问不了官方站点 / 代理拦截 | 换网络后重试（会续传）；仍不行看日志里的 HTTP 码 |
| sha256 不一致 | 传输被截断 | 直接重试（坏包已自动删掉） |
| addon 启用失败 | 有 Blender 正开着，占用偏好文件 | 关掉所有 Blender 再重试，或手动在偏好设置里勾选「MCP for Blender」 |
| 冒烟超时（端口没起来） | addon 没启用 / 端口被占 | 看日志里 Blender 的输出；关掉占用端口的程序后点「测试连接」 |
| 重启后会话里没有 blender 工具 | MCP 配置没生效 | 确认重启过 MTNode；设置 → 扩展能力 → MCP 里应能看到 `blender` |
| 控制台顶部显示「MCP 未注册」 | MCP 那一行被删过 / 配置文件被重写 | 点「安装 / 重装」即可，已装时只会补注册这一行，不会重下 Blender |

## 四、卸载

控制台底部「**卸载插件…**」会先给出清单再二次确认：撤掉 MCP 配置、删掉 addon、
**并删掉 Blender 安装目录**（这是本插件的口径：它装的东西归它管）。**保留**：
userpref 备份、本机已装的 uv、以及你自己的 `.blend` 工程文件。

## 五、边界

- Blender 只从**官方** `download.blender.org` 下，且必须过 sha256；没有第三方镜像。
- 不自动升级；要新版本就卸载后重装。
- 只启停**插件自己拉起的** Blender；不动用户实例、不动用户工程。
- 依赖源：Blender 官方；uv / PyPI 官方优先，失败自动回退国内镜像（日志会写明用了哪个）。
