# 输入补全（边打字边预测）

开启输入补全后，你在 MTNode 里打字停顿一下，光标后面就会浮出一段半透明的「接下来可能想写什么」；觉得合适按 `Tab` 就能直接采纳，省去不少重复敲字。

## 在哪开关和设置

入口在窗口**底部状态栏最左边**的图标（几行字加一个加号），也可以随时按 **`Ctrl + Tab`** 快速开关总开关。

点开设置面板，里面只有几项简单设置，改完立刻生效：

- **总开关**：默认已开启；关掉后不会发送任何补全请求。
- **触发方式**：支持「自动补全（边打字停顿一下自动提示）」和「按 `Tab` 手动补全（按第一下出建议，按第二下采纳）」两项独立开关，按你的习惯勾选。
- **服务商 / 模型**：可以选任意可用的文本模型，列表里响应最快、最省钱的 `flash` 模型会标出「推荐」。
- **触发延迟与最大长度**：觉得弹得太勤就把延迟调大一点；想补得更长就把最大补全长度调高。
- **费用报告**：点面板里的「费用报告」，能清楚看到一共调用了多少次、采纳了多少次、花了多少 token。

## 怎么用最顺手

1. 在任意普通输入框（会话输入框、节点提示词、表单、研究笔记、以及你用应用中心做的独立应用窗口）里正常打字。
2. 稍微停顿片刻（或按 `Tab` 手动触发），光标处就会浮出预测内容：
   - **单行建议**：直接以半透明文字接在光标后面。
   - **多行建议**：以一张清晰的卡片浮在光标行下方，不会挡住你正在看的正文。
3. **采纳或放弃**：
   - 按 `Tab` 直接把建议写进去；
   - 按 `Esc` 丢掉；
   - 继续打字或移开光标，建议会自动消失，完全不打扰思路。

> **和缩进冲突吗？** 屏幕上没有补全建议时，`Tab` 就是原本的缩进或切换焦点；只有屏幕上正显示补全建议时，`Tab` 才会先用来采纳建议。如果正好想缩进，先按一下 `Esc` 收掉建议再按 `Tab` 即可。

## 隐私与安全说明

- 输入补全需要把**光标附近的一小段文字**发给你选定的模型服务商来生成预测，不会发送整篇文档或其它窗口的内容。
- **密码框、只读框，以及中文输入法正在打拼音选词的时候**，绝不会触发补全，也不会发任何请求。
- 关掉总开关后，正在显示的补全会立刻收起，此后不再发任何请求。
