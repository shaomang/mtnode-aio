# FIM 补全：打字时先给你一句「接下来写什么」

> 一句话目标：任何输入框里停一下，光标后面浮出一段半透明的预测文字，按 <kbd>Tab</kbd> 采纳、按 <kbd>Esc</kbd> 丢掉；不想要就关掉开关，一个请求都不发。

## 开关在哪里

- **入口在画布底部状态栏最左边那一颗按钮**（图标是几行字加一个加号），点一下打开「输入补全」设置面板，再点一次（或按 <kbd>Esc</kbd> / 点面板右上角 ✕）关掉。
- 面板是**常驻浮层**：点到画布或别的地方不会自己关，改完的每一项当场生效、当场记住。
- 面板里就五行东西：

| 行 | 作用 |
| --- | --- |
| 启用输入补全（在输入框里按 <kbd>Tab</kbd> 采纳） | 总开关，**出厂是关的**；不勾就一个请求都不发 |
| 服务商 / 模型 | 补全走哪一家、哪一档模型（模型只列 flash 档，见下） |
| 触发延迟（毫秒） | 停手多久才发一次请求，缺省 350 |
| 最大补全长度（token） | 一次最多补多少个 token |
| 本次统计 | 这一趟运行发了多少次请求、你采纳了多少次 |

## 哪些地方能补

- **所有真文本框**：会话输入框、节点参数面板里的格子、设置窗里的输入框、Markdown 编辑器的源码档、代码编辑框、研究笔记的正文框……不用逐个登记，装上就对全部输入框生效。
- 多行框能补多行；单行框只补光标所在那一行。
- **这些地方不会触发**：密码框、只读框、禁用状态的框、富文本编辑区（<kbd>contenteditable</kbd>），以及输入法还在组词的时候（打拼音、选候选字的这一段时间不发请求）。

## 怎么用

1. 在一个输入框里停手（缺省约 350 毫秒），光标后面会出现一段**半透明字** —— 那就是它猜的后续内容。
2. <kbd>Tab</kbd> 采纳（插进去、光标落到末尾）；<kbd>Esc</kbd> 丢掉；继续打字、挪光标、离开输入框也会自动收掉。
3. 位置贴不准时（字体或换行复刻不上、光标不在可视区里），它会降级成光标旁边一个「Tab 补全」的小气泡：照样按 <kbd>Tab</kbd> 采纳，只是不再假装能画在你正打字的位置上。
4. 3.2 秒没回来就静默放弃，不弹错误、不打断输入。

### 和 Tab 缩进的关系

- **没出现半透明字时，<kbd>Tab</kbd> 还是原来的 <kbd>Tab</kbd>**（在 Markdown 编辑器里就是缩进，在弹窗里就是跳到下一个控件）。
- **只有在出现半透明字时，<kbd>Tab</kbd> 才会被「采纳」先用掉**。想缩进却已经被补全挡住：按 <kbd>Esc</kbd> 收掉再按 <kbd>Tab</kbd>，或直接接着打字。
- <kbd>Shift</kbd> / <kbd>Ctrl</kbd> / <kbd>Alt</kbd> + <kbd>Tab</kbd> 任何时候都不接管。

## 支持的服务商，与为什么只认 flash

- **服务商**：下拉里列出你这台机器上能派给 Agent 的那几家 —— DeepSeek 官方，以及你自己配的 DeepSeek 中转（名字或接口地址里带 deepseek 的那些）。
- **模型**：只列这一家里名字带 flash 的模型。同一家的其它模型照样显示在下拉里，但是灰的，后面写着「（不支持补全）」；这一家一只 flash 都没有时会提示「（该服务商没有 flash 模型）」，去「设置 → 模型服务」给它补一个带 flash 的模型即可。
- **只给 flash 的理由**：补全这活儿一次只补一两行，要的是**快、便宜、不打断手**。补全请求发出后你还在打字，慢半秒出现的内容已经跟不上光标了；而大模型单价高、延迟长，为一行字等两秒，不如自己写。所以这条链路只挂在各家最轻的那一档上，别处再聪明也不用。
- 换一家服务商时会自动切到这一家的 flash 档，不用手动再选一次。

## 隐私：你会被发出去什么

- **打开补全之后，你输入的内容会离开本机**，发给你在上面选定的那家服务商。面板底部那句「输入内容会发往所选服务商」就是这个意思。
- 发出去的**只有光标附近那一段**：光标前最多约 2000 字符、光标后最多约 500 字符，两端都按整行裁齐（单行框只取光标所在那一行）。文档其余部分、别的会话内容、别的输入框内容都不会跟着发。
- 密码框、只读框、禁用的框、富文本编辑区、输入法组词期不触发，所以那些地方一个字都不会出去。
- **总开关关掉之后不再有任何请求**：正在显示的那段半透明字会立刻收掉，之后打字也什么都不发。
- 补全请求只走你已经配好的那家服务商直连，不经过 MTNode 的服务器，也不会把这些内容写进画布或本机文件。

## 计费：按次消耗所选服务商的 token

- 每一次真实补全 = **一次很短的模型请求**，按你所选服务商的 token 单价计费（批量折扣、免费额度都按该服务商自己的规则走）：输入最多约 2500 字符，输出上限几十个 token。
- **停手才会发**：打字过程中不发请求，停一下才发一次；连续敲键会把还没发出去的那一次直接作废。
- **同一段上下文再问一次不重复计费**：光标前后内容与模型都没变时直接命中内存里的缓存，不再发请求（缓存只在本次运行里有效，退出应用即清空）。
- **超时就取消**：3.2 秒没回来会主动取消这次请求；服务商那边是否已经计了这一次，按它自己的规则算。
- 想知道到底花了多少次：打开面板看「本次统计」里的**请求 / 采纳**两个数 —— 请求数就是真实发出去的次数，采纳数是你按 <kbd>Tab</kbd> 用掉的次数。两个数差得远说明补全不太合你的写法，可以先调大「触发延迟」或干脆关掉。

## 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 开了开关，打字什么也不出现 | 这家服务商没有 flash 档模型；或当前输入框是密码框 / 只读 / 富文本 | 面板里看模型那一行是否灰着，去「设置 → 模型服务」补一个 flash 模型；换一个普通文本框试 |
| 补全出来了，但位置偏了一行 / 跑到框外 | 输入框的字体或换行没法完全复刻（自定义样式、缩放、自动增高） | 它会自动降级成「Tab 补全」小气泡，照样能采纳；也可把窗口缩放调回 100% |
| 想缩进，按 Tab 却把补全插进去了 | 半透明字在场时 <kbd>Tab</kbd> 优先给采纳 | 先按 <kbd>Esc</kbd> 收掉再按 <kbd>Tab</kbd>，或继续打字让它自己消失 |
| 一直不出现补全 | 触发延迟调得太大；或模型回得太慢（超过 3.2 秒就放弃） | 把「触发延迟」调小，换更快的 flash 档 |
| 不想让它发任何请求 | — | 关掉面板里的总开关；关掉后正在显示的补全也会立刻消失 |
