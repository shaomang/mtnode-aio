# 数据库节点与事实纪律

> 一句话目标：把散落的事实收进数据库超级节点，编译成副本交给智能节点，让 AI 只能「有据可查」地回答。

![数据库节点](img/mtnode-agent-11-flow.svg)
*图 1：文件 / 表节点收纳事实 → ⚙ 编译 → 生成数据库副本 → 接进智能节点做查询*

## 目标

读完这一页，你能建起一个数据库超级节点，把 csv / txt / json / md / pdf 等文件导入并按表单建成 SQLite 表，点 ⚙ 编译产出**数据库副本**，再把副本接给智能节点；同时明白接上副本之后，AI 回答事实的方式只剩一种——查库、引用、查不到就说查不到。

## 前置条件

- 在设置里开启「**测试版本（Beta）**」——数据库超级节点是 Beta 功能，开关打开后才会出现在右键菜单里。
- 准备好要入库的文件（csv / txt / json / md / pdf…），或一份已经建好的信息节点。
- 有一个可用的智能节点或智能会话（见 [智能任务与智能会话](#agent-nodes)）来消费这份数据。
- 已了解 [超级节点](#super-nodes)：数据库节点是一种超级节点（`db:true`），对外只暴露边界端子。

## 步骤

1. **开 Beta**：进设置开启「测试版本（Beta）」。
2. **建库**：画布空白处右键 → 添加「**数据库**」节点（默认子文件夹 `db/`）。
3. **导入文件**：在数据库节点**内部**右键 → **文件节点**：拖入或选择文件，文件会被**复制**进数据库子文件夹；内部右键只提供这两种节点。
4. **建表**：内部右键 → **表节点**（读取文件 · Agent 建表）：选文件 → Agent 抽取字段 / 类型 / 主键等元数据 → **你确认表单** → 建表（SQLite / FTS5）。
5. **放事实**：信息节点也可以直接在数据库内部当作「事实」输入；编译后一并入库。
6. **⚙ 编译**：点节点头部 **⚙ 编译**（**仅手动触发**、增量）：索引子文件夹文件 + 内部信息节点，生成 / 刷新**数据库副本**子节点（`db_replica`，镜像源数据库，带 `dbNodeId` / `dbName` / 编译时间）。
7. **接进智能节点**：两种方式任一即可——
   - **连线**：把「数据库副本」连到智能节点输入端，运行提示词会自动注入「数据库接入 · 事实强制约束」。
   - **`!@` 引用**：在 prompt / task 里写 `!@数据库标题`，无需连线。
8. **切换形态调试**：节点头部 **▤ / ▦** 在两种形态间切换——**超级节点形态** ↔ **数据库形态**（内嵌查询 / calc / 检查更新等调试控制台）。

### 两种形态（画布式 / 控制台）

- **画布式（超级节点形态）**：像普通超级节点一样在内部摆文件节点 / 表节点 / 信息节点，连线看清楚数据从哪来。
- **控制台（数据库形态）**：内嵌查询框、`calc` 计算与检查更新按钮，用来手动验证一条断言、核对一条记录，不用把库接到智能节点上跑一整轮。

### 查询纪律（强制，引擎注入）

- 一切事实来自 **`mtnode_db`** 工具（list / query / get / calc），**禁止凭记忆补全**。
- 关键断言必须带溯源 `[记录id · 标题]`；输出里每一个数字、每一条结论都要能指回一条记录。
- **数字计算用 `calc`**，不要心算、不要用模型口算替代。
- 查不到 → 明确回答「**数据库中没有该信息**」；需要推断 → 标注「此为推断，数据库未记载」。

> 纯文本（非智能）节点引用数据库只拿到「【数据库：标题】」指针占位，不注入内容、也不调用工具。想让 AI 真正查库，必须用智能节点 / 智能会话。

### 编译与维护

- 副本头部会显示**编译时间与记录数**，一眼看出这份副本是不是最新。
- 编译是**增量**的：只索引新增 / 变更的内容，重复编译代价小。
- 删除源数据库后副本失效（可以删掉它）。
- 编译**不会自动发生**，改完文件记得再点一次 ⚙。

## 结果

- 画布上多了一个数据库超级节点，内部有文件节点与按表单建出的表。
- 副本子节点头部显示编译时间与记录数；把它连到智能节点后，提示词里自动带上「数据库接入 · 事实强制约束」。
- 智能节点回答里的事实都带 `[记录id · 标题]` 溯源；库里没有的问题，它会直说「数据库中没有该信息」。
- 切到数据库形态可以手动 query / calc 验证一份数据。

## 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 右键菜单里没有「数据库」 | 设置里没开「测试版本（Beta）」 | 去设置打开 Beta 开关 |
| 建表后查不到刚放进来的内容 | 只导入了文件、没点 ⚙ 编译 | 点节点头部 ⚙ 编译，生成 / 刷新副本 |
| 副本上的记录数不更新 | 编译是手动触发的 | 每次改完文件 / 信息节点后重新编译 |
| 智能节点开始凭印象回答 | 没接副本，或只连了普通文本节点 | 把副本连到**智能**节点输入端，或写 `!@数据库标题` |
| 回答里没有溯源 | 提示词里没强调纪律 | 确认节点是智能节点且副本确实接上了；引擎会自动注入强制约束 |
| 删了源数据库，副本报错 | 副本依赖源库 | 一并删除失效副本，或重建数据库节点后重新编译 |
| 数字算错了 | 没用 `calc` | 要求它以 `calc` 计算并给出结果，不要接受口算 |
