# 数据库节点（事实收纳 → 副本 → 查询）

把「事实」收进**数据库超级节点**，编译成**数据库副本**，让智能节点用 `mtnode_db` 工具做**有据可查**的查询。

## 创建

数据库超级节点在设置里开启「**测试版本（Beta）**」后，画布空白右键即可添加「数据库」节点（默认子文件夹 `db/`）。

## 内部结构

数据库超级节点内部右键只提供两种节点：

1. **文件节点**（批量导入任意文件）：拖入或选择文件，**复制**进数据库子文件夹（csv / txt / json / md / pdf…）。
2. **表节点**（读取文件 · Agent 建表）：选文件 → Agent 抽取字段 / 类型 / 主键等元数据 → **你确认表单** → 建表（SQLite / FTS5）。

## 编译与副本

- 节点头部 **⚙ 编译**（仅手动触发、增量）：索引子文件夹文件 + 内部信息节点，生成 / 刷新**数据库副本**子节点。
- 信息节点也可以直接在数据库内部当作「事实」输入；编译后一并入库。

## 智能节点接入

两种方式（任一）：

- **连线**：把「数据库副本」连到智能节点输入端，运行提示词自动注入「数据库接入 · 事实强制约束」。
- **`!@` 引用**：在 prompt / task 里写 `!@数据库标题`，无需连线。

## 查询纪律（强制，引擎注入）

- 一切事实来自 **`mtnode_db`**（list / query / get / calc），禁止凭记忆补全。
- 关键断言带溯源 `[记录id · 标题]`；数字计算用 `calc`。
- 查不到 → 明确回答「**数据库中没有该信息**」；需要推断 → 标注「此为推断，数据库未记载」。

> 纯文本（非智能）节点引用数据库只拿到「【数据库：标题】」指针占位，不注入内容、不调用工具。

## 调试与维护

- 节点头部 **▤ / ▦** 切换形态：超级节点形态 ↔ **数据库形态**（内嵌查询 / calc / 检查更新等调试控制台）。
- 副本头部会显示编译时间与记录数；删除源数据库后副本失效（可删除）。
