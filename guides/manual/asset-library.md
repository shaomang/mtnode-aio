# 素材库与素材节点

> 一句话目标：把常用的文本 / 图像 / 音频 / 视频按分类存进一座跨画布共享的素材库，再用素材节点喂给任意一张画布。

![素材库](img/mtnode-share-01-ui.svg)
*图 1：素材库的左右两栏（左＝分类 + 素材一体树、右＝所选素材的内容详情），以及画布上绑定该素材的素材节点。*

## 目标

**素材库**是本机上一座**跨画布共享的内容仓库**：把常用的文本、图像、音频、视频按**分类**打包成一个个「**素材**」，画布上用「**素材节点**」引用它们。

内容存在素材库根目录里，**不属于任何一张画布**——**删画布**、删节点，素材都还在；反过来，在库里**改内容**，所有引用它的画布下次读取就跟着变。

入口：顶栏 **素材库**（工具库旁边的分层托盘图标）。想弄清素材节点和输入节点的分工，先看 [输入 / 处理 / 保存](#io-proc)。

## 前置条件

- 已安装并启动 MTNode（见 [第一次使用](#first-run)）。
- 准备好一个用来放素材库的**项目文件夹**；库会落在它下面，之后由应用自动维护。
- 想在画布上用素材节点，画布本身不要求设置工作目录——素材库根目录与工作目录是两件事（见 [工作目录与存档](#workspace)）。

## 步骤

### 1. 指定素材库根目录

第一次点「素材库」会让你**选一个文件夹作为素材库根目录（项目目录）**。没指定根目录前素材库不会打开，节点上会提示「还没有指定位置」，指定后自动接上。

这个目录**之后不建议改动**：更换根目录会**重新扫描**，新目录里没有的素材在画布上会变成「素材失联」。真要换也可以——对话框头部有 **更改根目录…**（会二次确认并说明后果），**旧目录里的文件不会被删除**，换回去就重新认得。

### 2. 用左右两栏管理分类与素材

| 位置 | 内容 |
|---|---|
| **左栏＝分类 + 素材一体树** | 素材库根目录下的文件夹层级（**显示名称与素材数**），分类行前的 **▸/▾** 可展开：展开后在该分类下列出**素材行**（显示名 + 内容数），点素材行＝右栏看它的内容。点 **＋ 新建文件夹** 在当前位置下建分类；右键分类：**新建子文件夹 / 重命名 / 删除 / 在资源管理器中打开**。分类可无限嵌套，另有 **全部素材（根目录）** 一行收拢根目录下的素材 |
| **右栏＝所选素材的内容** | 选中左树里的素材时，右栏顶部是**素材名 / 描述 / 文件夹相对路径**，右上动作行固定为 **设置 / 复制到画布 / 删除 / 打开文件夹**（在文件资源管理器中打开该素材夹）；正文是该素材的**内容条目列表**，可直接**改标题、编辑文本 / 更换文件 / 上传文件、删除条目、＋ 文本 / ＋ 图像 / ＋ 音频 / ＋ 视频 加内容、⠿ 拖动或 ▲▼ 重排**（改的是库，引用它的画布下次读取即生效） |
| **右栏（未选素材时）** | 没有点开具体素材时，右栏＝当前分类的素材卡片：**显示名 · 内容数 · 类型摘要（如「文本 2 · 图像 1」）· 描述**，下面是 **设置 / 插入到画布 / 删除**；右键卡片还能 **移动到分类…** 与 **重命名** |
| **工具条** | **新建素材**（建一个空素材）· **上传为新素材**（选本机一个文件夹，按文件类型自动变成内容条目）· **刷新**（重新扫描目录） |

默认**右侧是空的**——素材要你亲手新建或上传，扫描只会认出**带标记文件的文件夹**（标记文件 `.mtnode-asset.json`）。

你也可以在**资源管理器里直接整理**这座库：把素材夹在分类之间挪动、给分类改名都没问题（标记文件别删、别改），回到应用点「刷新」即可。

### 3. 在画布上放下素材节点

创建方式三选一：

1. 素材库右栏里点 **复制到画布**（未选素材时的卡片上是「插入到画布」，两者同一入口，直接带上绑定）；
2. 画布空白处右键 → **输入节点** → **素材节点（绑定素材库 · 内容条目即端子）**（建出来是未绑定空壳）；
3. 从别的节点输出端子把线拖到空白处，在落点菜单里选**素材节点**，再绑定。

未绑定的节点上有两个入口，这就是**上传本机文件的两条途径**：

- **绑定…**：打开素材库（同一个左右栏界面，改成选择模式），挑一个**库里已有**的素材接上——库是现成的，不用重复上传。
- **上传…**：选本机一个文件夹 → 整体收进素材库成为一个**新素材** → 自动绑定。素材库不收的文件类型会跳过并告诉你跳过了几个。

### 4. 按「一条内容 = 一对端子」接线

**每个内容条目对应一对端子**（同名同号）：左边连入＝写回这条内容，右边输出＝读出这条内容。类型必须对上——文本端子只收文本来源，图像端子只收图像来源，音频 / 视频端子只收媒体来源。

输出值的口径按内容类型分：

- **文本 → 字符串**：下游拿到的是正文本身，可以直接拼接、改写、再喂给模型。
- **图像 → 本机绝对路径**：进参考图时按下发顺序认成「第 N 张」。
- **音频 / 视频 → `file:///` URL**：可连进媒体参考端子，也可被 `@` 引用。

输出端子接进下游处理节点后，那条内容会自动进它的**背景信息**（块标题＝内容条目标题，与端子同名）；同一个素材节点的多条内容分别连线时，各条都会独立注入，不会互相顶掉。

提示词里引用素材内容：素材节点**本身不再作为 `@` 候选**，打 `@` + **内容条目标题**（＝端子名）只引用**那一条**内容；**只有已经连线接进本节点的端子可以被引用**，没接线的条目即使属于同一素材也引不到。

### 5. 让写库这一步安全可控

- 库里这一条**还空着** → 运行到这一步**自动写进库**（提示几条已同步，可**撤销**）。
- 库里这一条**已有内容** → 只有连进来的与库里那份**不同**时，条目上的 **⟳ 才亮起**，**点一下才更换**。跑流程绝不会悄悄覆盖你攒下的素材。
- **Ctrl+Z 连素材库一起回滚**：每次覆盖前，库里被换掉的那份先进该素材的 `.versions` 目录（每条内容留最近 5 份），**撤销**时贴回旧内容，重做再贴回新内容。

### 6. 改名、重排与删除

左树点开一个素材，右栏就是它的内容详情，**改标题、编辑 / 更换 / 上传文件、增删与重排条目都直接在这里做**（与「设置」框同一套写库口径）；下面的「设置」框是同一份操作的另一处入口。

点节点头部 **⚙**（或素材库右栏顶部的 **设置**）打开**素材设置**：改**显示名称**与**描述**；**＋ 文本 / ＋ 图像 / ＋ 音频 / ＋ 视频**加内容条目——**文本也一样能上传本机文件**（「＋ 文本」里选「上传本机文本文件…（可多选）」，一个文件一条内容；想再改改就选「手写一条空正文…」，表单里那颗 **上传文件…** 会把正文读进框里）。

每行可改**端子名**（＝端子标题）、用 **⠿ 拖动**或 **▲▼** 调整**顺序**（＝端子顺序）、**编辑文本 / 上传文件 / 更换文件**、**✕ 删除条目**。

改名与重排**不会甩线**（连线跟着那条内容走）；删除条目会让那一对端子消失、挂在上面的线一并断开——**Ctrl+Z 可复原**。

删素材 / 删分类 / 删内容条目，实体一律进**素材库根目录的 `.trash/<时间戳>__<名字>`**，**不会真的删掉**；需要时在资源管理器里手工找回。**非空分类不允许直接删除**（连子分类里的素材一起计数）：先把素材移到别的分类。

## 结果

- 素材库里出现了带标记文件的素材夹，画布上的素材节点接上了绑定，端子按内容条目成对出现。
- 库内容与画布解耦：**删画布不丢素材**，改库内容所有引用画布下次读取即生效。
- 导出 `.mtnodes` 时**不含素材库**：画布包只带画布自己的图像等资产，素材库独立于画布、始终留在本机根目录里。跨机迁移时把素材库根目录一起带走，或在新机器上**重新绑定**。

## 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 节点上写着「素材**失联**」 | 素材库根目录换了位置，或素材夹被删 / 改名，库里已找不到它 | 把素材夹放回根目录后点「刷新」；或在节点上 **重新绑定素材库…** 另选一个素材（连线按标题保留） |
| 素材库打不开 | 还没指定根目录 | 首次打开时选一个文件夹作为素材库根目录 |
| 上传时提示「跳过了 N 个文件」 | 素材库不收该文件类型 | 只把受支持的文本 / 图像 / 音频 / 视频放进待上传文件夹，其余另行保管 |
| 端子连不上线 | 内容类型与端子类型不匹配（例如把图像连进文本端子） | 把线接到同名同类型的端子上，或在设置里改成对应类型的内容条目 |
| 跑完发现库里那份没变 | 库里已有内容时不会静默覆盖 | 点条目上亮起的 **⟳** 手动更换；或先删掉库里那条内容 |
| 分类删不掉 | 非空分类不允许直接删除 | 先把子分类 / 素材移到别的分类，再删 |
| 「素材库正在回滚，请稍等一下再撤销 / 重做」 | 上一次撤销正在回写库内容 | 等提示消失后再按 `Ctrl+Z` / `Ctrl+Y` |
| 库内容被覆盖后想退回 | 被换掉的那份已进 `.versions/` | 按 **Ctrl+Z** 连库一起回滚；超出最近 5 份之后需在资源管理器里手工找回 |
