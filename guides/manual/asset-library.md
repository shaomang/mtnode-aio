# 素材库与素材节点

> 一句话目标：认识画布之外的仓库——素材从哪来、如何复用与引用（素材本身不是 @ 候选），让品牌图 / 立绘 / BGM 一次导入到处复用。

## 素材库总览

### 素材库

上方菜单栏「素材库」可打开素材库配置窗口。

素材库是画布之外的「仓库」，放你的图片、音频、视频等原始材料；生成节点做好的图、音、视频也可以回流进去反复使用。

素材库的项目路径是独立于画布、项目的，可跨项目、画布使用。

## 素材库 · 导入

### 导入素材

- 在素材库界面中设置根目录文件夹，并创建新素材。

### 引用素材

- 把本机文件拖进画布。
- 拖动连线在下游节点通过「@」来引用。
- 素材库内按名称 / 类型检索，选中后可放置到画布中供引用。
- 路径固定，画布或项目被删除也不会丢失文件。

具体使用方法请参考 B 站中的演示。
