# 素材库与素材节点

**素材库**是本机上一座**跨画布共享的内容仓库**：把常用的文本、图像、音频、视频按**分类**打包成一个个「**素材**」，画布上用「**素材节点**」引用它们。内容存在素材库目录里，**不属于任何一张画布**——删掉画布、删掉节点，素材都还在；反过来，在库里改一份内容，所有引用它的画布下次读取就跟着变。

入口：顶栏 **素材库**（工具库旁边的分层托盘图标）。

## 第一次使用：指定根目录

第一次点「素材库」会让你**选一个文件夹作为素材库根目录（项目目录）**。

- 这个目录**之后不建议改动**：更换根目录会**重新扫描**，新目录里没有的素材在画布上会变成「素材失联」。
- 真要换也可以：对话框头部有 **更改根目录…**（会二次确认并说明后果）；**旧目录里的文件不会被删除**，换回去就重新认得。
- 没指定根目录前素材库不会打开；节点上会提示「还没有指定位置」，指定后自动接上。

## 左右两栏

| 位置 | 内容 |
|---|---|
| **左栏＝目录** | 素材库根目录下的文件夹层级，**只显示名称与素材数**（不带图标）。点 **＋ 新建文件夹** 在当前位置下建分类；右键分类：**新建子文件夹 / 重命名 / 删除 / 在资源管理器中打开**。分类可无限嵌套 |
| **右栏＝素材** | 当前分类里的素材卡片：**显示名 · 内容数 · 类型摘要（如「文本 2 · 图像 1」）· 描述**，下面是 **设置 / 插入到画布 / 删除**；右键卡片还能 **移动到分类…** 与 **重命名（文件夹）** |
| **工具条** | **新建素材**（建一个空素材）· **上传为新素材**（选本机一个文件夹，按文件类型自动变成内容条目）· **刷新**（重新扫描目录） |

默认**右侧是空的**——素材要你亲手新建或上传，扫描只会认出**带标记文件的文件夹**。

你可以在**资源管理器里直接整理**这座库：把素材夹在分类之间挪动、给分类改名都没问题（标记文件 `.mtnode-asset.json` 别删、别改），回到应用点「刷新」即可。

## 素材节点：一条内容 = 一对端子

创建方式三选一：

1. 素材库卡片上点 **插入到画布**（直接带上绑定）；
2. 画布空白处右键 → **输入节点** → **素材节点（绑定素材库 · 内容条目即端子）**（建出来是未绑定空壳）；
3. 从别的节点的输出端子把线拖到空白处，在落点菜单里选**素材节点**，再绑定。

未绑定的节点上有两个入口：

- **绑定…**：打开素材库（同一个左右栏界面，改成选择模式），挑一个**库里已有**的素材接上。
- **上传…**：选本机一个文件夹 → 整体收进素材库成为一个**新素材** → 自动绑定。素材库不收的文件类型会跳过并告诉你跳过了几个。

每个内容条目对应**一对端子**（同名同号），左边连入＝写回这条内容，右边输出＝读出这条内容；类型必须对上（文本端子只收文本来源，图像端子只收图像来源）。细节、失败提示与排错见 [节点指南](#node-guide) 里的**素材节点**。

输出端子接进下游处理节点后，那条内容会自动进它的**背景信息**（块标题＝内容条目标题，与端子同名）；提示词里打 `@素材节点标题` 会把这个素材接进该节点的**每一条**内容一起带上——图像端子进参考图，音频 / 视频端子进 `file:///` 地址。同一个素材节点的多条内容分别连线时，各条都会独立注入，不会互相顶掉。

## 同步与撤销：写库这一步是安全的

- 库里这一条**还空着** → 运行到这一步**自动写进库**（提示几条已同步，可撤销）。
- 库里这一条**已有内容** → 只有连进来的与库里那份**不同**时，条目上的 **⟳ 才亮起**，**点一下才更换**。跑流程绝不会悄悄覆盖你攒下的素材。
- **Ctrl+Z 连素材库一起回滚**：每次覆盖前，库里被换掉的那份先进该素材的 `.versions` 目录（每条内容留最近 5 份），撤销时贴回旧内容，重做再贴回新内容。

## 设置：改的是库里那一份

点节点头部 **⚙**（或素材库卡片上的 **设置**）打开**素材设置**：改**显示名称**与**描述**；**＋ 文本 / ＋ 图像 / ＋ 音频 / ＋ 视频**加内容条目——**文本也一样能上传本机文件**（「＋ 文本」里选「上传本机文本文件…（可多选）」，一个文件一条内容；想再改改就选「手写一条空正文…」，表单里那颗 **上传文件…** 会把正文读进框里）；每行可改**端子名**（＝端子标题）、用 **⠿ 拖动**或 **▲▼** 调整**顺序**（＝端子顺序）、**编辑文本 / 上传文件 / 更换文件**、**✕ 删除条目**。

改名与重排**不会甩线**（连线跟着那条内容走）；删除条目会让那一对端子消失、挂在上面的线一并断开——**Ctrl+Z 可复原**。

## 删除与找回

- 删素材 / 删分类 / 删内容条目，实体一律进**素材库根目录的 `.trash/<时间戳>__<名字>`**，**不会真的删掉**；需要时在资源管理器里手工找回。
- **非空分类不允许直接删除**（连子分类里的素材一起计数）：先把素材移到别的分类。
- 素材被删后，画布上的节点不会消失，只是变成「素材失联」；找回素材夹或**重新绑定**即可继续。
