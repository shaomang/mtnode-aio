# 配置服务商与 API

> 一句话目标：让画布上的节点真的能调用模型——加一个带 API Key 的文本服务商，图像 / 视觉能力另加对应服务商。

![填 Key 后模型列表载入](img/mtnode-start-02-demo.svg)

## 目标

配好之后，处理节点、智能任务节点、智能会话与全局助手都会从全局配置里取服务商与模型；节点头部的 **⚙ 设置** 可以把某一步改成别的模型。

## 前置条件

- 一个 OpenAI 兼容服务商的 API Key（例如 DeepSeek 官方、pi-ai 等目录里的服务商）。
- 若要跑图像生成或识图，另外准备**支持图像 / 支持视觉**的服务商——**DeepSeek 官方不识图**。

## 步骤

1. **打开服务商设置**：点顶栏 **设置 · 模型服务**。
2. **从目录添加**（推荐）：在服务商目录里选一家 → 填入 **API Key** → 模型列表与接口地址自动载入。
3. **或手动配置**：选「手动」，填 OpenAI 兼容的 **Base URL（接口地址）** 与模型名，多个模型用英文逗号分隔。
4. **按需要勾选「支持视觉」**：勾上之后图像才能作为多模态输入送进模型；不勾时图像只作为参考图或附件处理。
5. **排列模型优先级**：在设置里拖动模型列表调整顺序，节点上的模型下拉按这个顺序展示。
6. **到节点上验证**：点任意文本处理节点头部的 **⚙ 设置**，确认能选到刚配的服务商与模型。
7. **收好 Key**：**API Key 只存本机**，不随工作流导出、也不随创意工坊上传。

> ⚠️ 危险：不要把 API Key 写进提示词、保存节点的输出或画布标题里——工作流导出（`.mtnodes`）与工坊上传会把这些正文一起带走。

> 💡 技巧：文本、图像、识图可以配成**三家不同的服务商**：用便宜快速的跑批量，用最强的跑智能任务，互不影响。

## 结果

设置里能看到服务商卡片与模型列表；任意处理节点的 **⚙ 设置** 弹窗里都能选到这些模型；▶ 运行时不再报「未配置服务商 / 缺少 Key」。

## 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 模型列表是空的 | Key 无效、Base URL 写错，或该服务商不提供模型列表接口 | 核对 Key 与 Base URL 后改用手动填写模型名 |
| ▶ 运行报鉴权失败 | Key 过期 / 额度耗尽 / 粘贴时带了空格 | 重新粘贴 Key，确认没有前后空格 |
| 图片送进去模型说看不懂 | 该服务商没勾「支持视觉」，或本身没有视觉能力 | 换成支持视觉的服务商，或另配一个识图服务商 |
| 节点里选不到新加的服务商 | 节点保存的是旧配置 | 重新打开节点 **⚙ 设置** 再选一次 |
| 改了设置但正在跑的节点没变 | 运行中不重读参数 | 等这一轮结束再重跑 |
| 工坊下载的模板提示服务商缺失 | 模板引用了你没配的服务商 | 按提示批量替换成自己的服务商 |
| 请求偶发超时 | 服务商限流或网络抖动 | 智能运行会自动重发；普通节点重跑一次即可 |
