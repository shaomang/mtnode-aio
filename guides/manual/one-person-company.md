# AI 团队与多角色

> 一句话目标：给一张画布配一队 AI 专家——人设四段式 + 模型 + 预设档 + 思考强度 + 工具许可，手动或一句话自动招聘，单聊与 2–6 人圆桌，收敛出的建议卡按 advice/ 与 decisions/ 采纳落盘。

## 专家团总览

### 专家团总览

给一张画布配一队 AI 专家，围绕这张画布展开单聊或群聊，让多位专家各说一遍再形成汇总建议。

### 入口

顶栏「专家团」视图。团队绑定当前画布，标题显示当前画布名，切画布即自动换团队上下文。

### 使用方法

1. 专家拥有一份完整的智能体身份：人设（身份 / 目标 / 约束 / 输出格式）+ 模型 + 预设档 + 思考强度 + 工具许可。
2. 单聊可以一问一答；圆桌（群聊）让 2–6 位专家各跑一轮，最后由主持人「收敛出建议」，产出一张建议卡。
3. 建议卡在采纳前不写任何文件；你点「采纳并生成待办 / 采纳为决策记录」才会落进 advice/ 或 decisions/。

## 专家团 · 是什么

### 专家团的意义

专家团允许你赋予 AI 多个身份，并站在该身份的立场和知识体系与你对话。同一个问题给不同的专家往往会有完全不同的回答，比一般性的问答涵盖面更广。

### 和智能会话、开发节点的区别

- **全局助手**：单个会话，适合任务流水线和画布编排。
- **开发节点**：按模块拆分、迭代项目，适用于程序开发。
- **专家团**：同一件事让多个不同“人格”提出建议。它默认只读写文本，不干涉项目或画布。

### 功能补充

- **会话留痕**：讨论收敛后可以归档为事实库，该事实库可由专家进行构建，并由用户进行修订。
- **有据可查**：专家回答事实性问题也会先查本团队的事实库。
- **给 AI 读的极简条例**：左栏「AI 事实库」是另一套给 AI 读的紧凑索引（一件事一条），Agent 建架构 / 工作流时会把关键结论自动沉淀进去，按命中与热度淘汰；详见「AI 事实库（给 AI 读的条例库）」。
- **收敛成建议**：在群聊（圆桌会议）收集信息和建议后，可点击右上方「收敛成建议」按钮，由 AI 主持人将整个会议内容撰写为文档。

## 专家团 · 组建与调用

### 招聘专家（手动）

1. 进顶栏「专家团」视图 → 左栏上方点 ＋ 招聘。
2. 从模板库选一个（内置 39 个预置角色，如研究分析师 / 代码评审员 / 产品经理 / 财务顾问），或从空白开始。
3. 填名称、岗位、图标。
4. 右侧「模型」区选服务商 / 模型 / 思考强度 / 预设档 / 温度。

### 招聘专家（自动）

在对话框里用一句话说清用人需求，例如「我要一个盯现金流的财务顾问」；HR 会生成一张严格 JSON 角色卡，本地校验（必填 / 长度 / 禁写项 / 工具许可 / 图标合法）通过、你点「确认录用」才写入。校验失败或取消都不落库；录用后会顺手存进模板库，下次一键套用。该人格卡为根据需求完全重新生成，不会套用现有模板。

### 提示词四段式

身份 Identity / 目标 Goal / 约束 Constraints / 输出格式 Output。

### 调用

- **单聊**：左栏点一位专家直接对话；角色行右侧 ＋ 给他新开一段对话。
- **圆桌**：会话区 👥 新建群聊，选 2 位以上参与者，不建议一次性选太多人，避免 Token 浪费。

### 默认权限

读文件、写文件、联网搜索、反问用户；逐项审批：执行命令。

### 跨画布

标题右侧「复制」把当前画布的团队增量复制到另一张画布：只追加，不删除、不覆盖目标画布已有内容。

## 专家团 · 圆桌与建议卡

### 圆桌（群聊）

- 新建群聊，可选 2 位或以上专家。
- 每一轮由每位专家依次独立发言，各自用自己的模型。第 1 轮互不可见，避免互相锚定、复读。
- 可以 @某位专家 定向提问，避免大家重复同一个观点。

### 收敛出建议

点「收敛出建议」，由主持人只做结构化聚合、不新增观点，产出一张「建议卡」：

结论 / 理由 / 依据 / 少数意见（原文保留）/ 未收敛分歧 / 待验证假设 / 下一步。

### 采纳与落盘

- **采纳并生成待办** → 追加到 `<工作区>/advice/TODO.md`
- **采纳为决策记录** → 写 `<工作区>/decisions/DEC-YYYYMMDD-NN.md`（状态 = 已确认）
- **仅存档** → 不写任何文件

讨论过程中的建议文件落在 `<工作区>/advice/ADV-*.md`。

## 专家团 · 团队事实库

### 事实库是什么

事实库保存这个项目的「事实来源」，让专家回答事实性问题时有据可查。入口不在画布上，而在专家团视图左栏「专家」列表末尾那一行。

### 怎么用

1. **新建文档**：点库行常显的 ＋ 新建文档；专家在对话中发现稳定事实也会自动建档 / 改档，即时出现在左栏。
2. **清单**：下方列出文档名与更新时间；点一行打开审阅窗。

### 专家怎么查阅事实库

事实库内容会自动把每篇文档的名称与路径告诉专家，由专家自行决定是否查阅。一般来讲顺序是：先读最相关的事实库文档 → 不够再查项目内容 → 仍不够会以「事实库中没有该信息」为由请求补充。

### 事实库文件在哪

`<画布项目文件夹>/团队事实库/`，每篇文档三个文件：`<文档名>.md`（正文）、`<文档名>.review.json`（审阅记录）、共享 `assets/`。删除移入系统回收站，可在资源管理器还原。
