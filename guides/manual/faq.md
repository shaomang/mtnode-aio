# 常见问题与名词速查

遇到卡壳先在这里扫一眼，大多数常见问题一分钟就能对上号。

## 常见问题速查

| 遇到什么情况 | 常见原因 | 怎么解决 |
| --- | --- | --- |
| **点 ▶ 没反应** | 没填 API Key、上游没内容、或者被「等待文件」节点挡住 | 去「设置 → 模型服务」检查 Key 是否有效且未停用；看上游节点有没有输出 |
| **结果没保存成文件** | 普通处理节点后面忘了接「保存」节点 | 文本/图像普通节点需在后面接「保存」节点；智能节点自己写文件，不用接保存 |
| **改了上游，下游没跟着变** | 提示词里直接粘了死文字，而不是用 `@标题` 引用 | 删掉死文字，敲 `@` 重新选中上游节点标题 |
| **音视频或数字人一直排队不动** | 本地音视频插件共享显卡，同一时间只跑一个 | 等前一个任务跑完（看底部「AI 工作中」进度）；显存紧张时降低分辨率或开启顶栏「简略」 |
| **批量运行花了很多钱** | 把整批 N 条内容又全塞进了每次运行 | 逐条处理用「批量模式」；只有需要 AI 一次看完所有内容做总汇时才用「聚合模式」 |
| **导入别人的画布后节点标着「无模型」** | 对方用的服务商或模型你本机没配 | 点开该节点的 **⚙ 设置**，换成你自己电脑上可用的服务商和模型即可 |
| **报错看不懂怎么办** | 参数或网络异常 | 把报错全文发给右侧全局助手（✦），或者点手册右上角「答疑」直接问 |

## Windows 提示「已保护你的电脑 / 未识别应用」怎么办

新版本刚发布时，Windows SmartScreen 偶尔会弹出蓝色拦截提示，这是系统对新签名的常见提醒，按下面三步即可正常打开：

1. 在蓝色弹窗里点击文字链接 **更多信息**。
2. 弹窗下方会出现新按钮 **仍要运行**，点击它即可启动。
3. 放行一次后，同一版本以后打开就不会再拦了。

## 磁盘占用大怎么办

MTNode 提供两处一键清理入口，都能安全释放空间而不删你的重要作品：

- **清理全局临时缓存**：打开 **设置 → 存储占用与清理**，先看清各类缓存占了多少空间，勾选不需要的临时项再清。
- **清理插件产出物缓存**：打开顶栏 **插件**，点插件卡片右上角的 **ⓘ**，在「产出物缓存」里选「保留最近 7 天」或「全部清理」，不会删模型权重和运行环境。

## 常用名词速查（白话版）

- **节点**：画布上的一个个功能方块（输入、处理、保存、控制等）。
- **端子（接口）**：节点左右两侧的小圆点，左边进数据、右边出数据，连上线就能自动传内容。
- **节点层**：把一堆节点收进一个壳里的「收纳盒」，双击钻进去看里面，外面保持清爽。
- **智能节点**：自带 AI 代理能力的节点，能自己读文件、多步思考、写结果，适合复杂任务。
- **开发节点**：专为软件开发设计的节点层，用来把代码项目拆成模块、文件和类来协作开发。
- **思考强度**：控制 AI 回答前「想多深」的档位（无 / 低 / 中 / 标准 / 高 / 最强），越高通常越细，但也越慢、越费 token。
- **预设档**：决定 AI 说话与干活风格的档位（默认「极简模式」，少废话直接给结果），不会改变思考强度。
- **批量模式 / 聚合模式**：收到多条输入时，批量模式是「一条一条分别跑」，聚合模式是「打包在一起一次性跑」。
- **鲸圆币**：MTNode 账户里的站内币，可用于调用 MTNode 中转模型和在工坊/应用中心打赏支持作者。
