# 常见问题

> 一句话目标：用一张「现象 → 原因 → 处理」表，把使用中最常撞上的坑一次性对上号。

![常见问题](img/mtnode-app-05-ui.svg)
*图 1：FAQ 覆盖画布、批量、控制流、素材、媒体、网络、智能能力与中文 / 英文界面八大类现象。*

## 目标

把此前散在各页的问答收成一张可扫读的表，再给一份**错误码 / 现象索引**，让你从屏幕上看到的那句话直接跳到对应章节。

如果你要的是「怎么从头做一件事」，请走左侧目录对应章节；这里解决的是「本来应该能跑，为什么没跑起来」。

## 前置条件

- 先看**节点卡片上的错误条**——大部分现象它已经说清楚了。
- 拿不准发给服务商的到底是什么请求，用节点上的 **◈ 预览**。
- 想深挖的话准备好本机数据目录路径（见 [工作目录与存档](#workspace)）。

## 步骤

按现象查表。

### 画布与操作

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 点 ▶ 没反应 / 一直失败 | 没填 API Key、没连输入、图像任务用了**不支持视觉**的服务商 | 看节点错误条逐项排除；用 ◈ 预览即将发送的请求（见 [服务商与 API](#providers)） |
| 连线拖不出来 | 从节点标题开始拖，而不是从端子圆形按下 | 从端子圆形上按下再拖；输入端子已被占用时先断开或改用新端子（见 [节点、端子与连线](#nodes-wires)） |
| 超级节点展开后看不到内部节点 / 端子 | 还停在收起态 | 用标题栏展开图标打开**壳层**，或点 **↪ 进入** 全屏编辑；内侧端子在壳层左右边缘（见 [超级节点](#super-nodes)） |
| 超级节点里的保存路径跑到画布根目录了 | 超级节点没设子文件夹 | 给它设**子文件夹**，内部相对路径会自动挂到该前缀下（见 [工作目录与存档](#workspace)） |
| 助手搭图时出现两份保存文件 | 智能助手 / 智能会话改画布期间保存节点**不落盘**，整次任务结束后统一写入 | 若仍看到旧文件，多半是中途手动点过 ▶ 保存；清掉多余那份即可 |
| 「中英文怎么切」 | 界面语言跟顶栏地球按钮走 | 点右上角地球按钮切换；手册与节点指南都有对应语言，缺英译时回退中文（见 [设置总览](#settings)） |

### 批量与控制流

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 批量只跑了第一条 | 处理节点处于**聚合**模式 | 点头部模式切换，改成「批量」（见 [批量、拆分与合并](#batch)） |
| 定时器一点 ▶ 下游立刻跑了 | 定时器的 ▶ 是**打开闹钟**，到点才脉冲 | 要立刻跑请用普通处理节点或「执行」控制节点（见 [控制流与判断](#control-flow)） |
| 闸门永远不放行 | AND 闸门按**配置的输入路数**等待，**没接线的端口也算** | 减少输入路数，或把线都接上 |
| 分不清哪句是思考、哪句是回复 | 显示口径按发生顺序分段 | **「◉ 思考 · N 字」**只折叠模型内部推理（N 只数思考字数），中间步骤的话以正常字号正文显示，🔧 工具调用就近插在发生位置（见 [智能能力是什么](#dsh)） |

### 素材、媒体与网络

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 素材节点显示「素材失联」 | 素材库根目录换了，或素材夹被删 / 改名 | 放回原目录后点「刷新」，或重新绑定（见 [素材库与素材节点](#asset-library)） |
| 跑完发现库里那份没变 | 库里已有内容时不会静默覆盖 | 点条目上亮起的 **⟳** 手动更换 |
| 音乐 / 语音 / 视频节点后面要挂保存节点吗 | 不需要 | Minimax Music 3、SoVITS 语音与 Minimax H3 都自带输出路径（`.wav` / `.mp3` / `.mp4`），再挂保存反而会写无关内容；**Remotion 视频例外**，需要下游保存节点落盘（见 [音乐、视频、网络与执行节点](#media-net)） |
| 网络节点收不到消息 | 协议、通道号、主机端口三处之一对不上 | 逐项核对 TCP / UDP、通道号、主机端口（默认端口在 设置 · 网络）；接收节点确认处于**监听态** |
| 执行节点怎么运行 | 它是本机程序启动器 | 双击节点，或连点两下播放键，通过系统默认方式启动绑定的 `.exe` / `.bat` 或任意文件 |

### 智能能力与数据库

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 智能任务乱改文件 | 工作目录不对，或审批档位太松 | 检查工作目录；把权限调到「逐项审批」或关掉不需要的工具许可（见 [审批与权限](#approvals)） |
| 文档答疑说不知道 | 答疑助手**只读本手册** | 单节点细节请用节点右键「节点指南」；或换个问法指向左侧目录里的章节（见 [节点指南索引](#node-guide)） |
| 智能节点答不上数据库的问题 | 没接入数据库 | 把「数据库副本」连到输入端，或在提示词里写 `!@数据库标题`；已接入却查不到时，按纪律必须回答「数据库中没有该信息」，不会猜（见 [数据库节点](#database-nodes)） |
| 开发节点「建议」要联网跑模型吗 | 要 | 它由 AI 做**只读**调研（读项目代码 + 模块进度）后给出 4 条方案；结果缓存，点「查看上次建议」不重跑，「换一批」才重跑（见 [开发节点](#dev-nodes)） |
| 助手说「需要先关掉与画布无关开关」 | 全局助手开了「与画布无关」档，本轮不注册任何画布工具 | 关掉该开关后重跑（见 [智能任务与智能会话](#agent-nodes)） |

## 结果

- 你能从屏幕上的一句话定位到「是哪一项没配 / 哪一步没跑 / 哪个开关没关」。
- 需要细节时，表格每一行都指到了对应章节，可以顺着读下去。
- 仍然查不到的问题，去 [排错与诊断](#troubleshoot) 跑三个只读诊断工具。
