# 常见问题

> 一句话目标：把常见的「没反应 / 没落盘 / 花多倍钱」现象对上原因，并知道去哪求助与反馈。

## 常见问题速查

- 点了 ▶ 没反应：看上游有没有输入、是否被「需求等待」挡住、服务商与 Key 是否配好。
- 结果没落盘：保存节点只接在普通节点后面；智能节点自己写文件，不要接保存。
- 下游没跟着更新：提示词里粘的是正文而不是 @标题，上游重跑不会更新它。
- 生成多张图 / 花了多倍钱：文生图每次只出 1 张；要多张就一个批量项一张，或调高抽卡次数。
- 音视频卡住：音、视频共享同一把显存锁，同一时间只能跑一个。
- 批量任务特别贵：检查是不是把整批 N 条又塞进了每次运行（≈N² 次调用）；要一次看全部才用「聚合模式」。
- 报错看不懂：把报错原文 + 节点标题发给右侧栏助手，它能读画布直接定位。

## 求助与反馈

### 画布里的疑问

直接问右侧栏助手（✦）：它能看你眼前的画布，也能直接改。

### 想省事

一句话描述「输入 → 处理 → 产物格式 → 存哪」，让助手把节点搭好，你再改参数。

### 提需求 / 报 bug 的四件套

1. 环境：系统、显卡、显存、内存；本地后端还是要 API。
2. 你想要的结果。
3. 实际发生了什么（报错原文 / 截图）。
4. 已经试过什么。

### 写教程时

每节保持同一形式：总览 + 节点说明 + 多种用法 + 可重跑示例，后续迭代只改正文，不动结构。
