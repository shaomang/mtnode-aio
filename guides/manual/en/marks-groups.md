# Box, groups, layout

> One-sentence goal: pack a set of nodes into one group that moves as a whole, and re-run the nodes that need it with one click over control wires.

## Groups, zones and one-click re-run

- Press `G` to group: pack a set of nodes so the whole group moves and scales together.
- One-click re-run: use control wires to connect the control node (▶) straight to every node that should re-run.
- Zone boxes and groups are canvas annotations and do not affect execution.
