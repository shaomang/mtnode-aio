# Approvals

> One-sentence goal: see which tools tool permissions allow, and which actions raise their own confirmation dialog.

## Tool permissions and approvals

- **Tool permissions**: which tools are allowed — file read/write, web search, canvas editing, asking questions, image reading. For ordinary jobs it is worth turning image reading off, otherwise the AI may keep taking screenshots to confirm things and waste tokens.
- **Approvals**: canvas changes, canvas deletion and plugin installation raise their own confirmation dialogs; workspace file writes and web search go through according to the current preset.
