# 框选、组与排版

> 一句话目标：把散在画布上的节点收拾干净——框选一片、收成一组、一键排版、必要时用绘制做标注。

![框选到排版](img/mtnode-canvas-03-flow.svg)
*图 1：框选一片节点 → 收成组（整体拖动 / 分轴缩放）→ 一键自动排版*

## 目标

读完后你能选中一片节点、把它们归成一个可以整体搬动的组、给画布做分区标注，并把乱掉的布局一键铺开。

## 前置条件

- 画布上已经有若干节点。空画布没有任何可框选的对象。
- 需要「超节点」式收纳时，走 [超级节点（收纳子图）](#super-nodes)——组只是视觉容器，超节点才是真正的子图。

## 步骤

1. **加绘制标注**：右键空白处 → 绘制（箭头 / 框体 / 说明文字）。它们只是标注，不参与运行；可改颜色、线宽、字号，`Ctrl+C` 能复制绘制。
2. **框选一片**：`Ctrl+左键` 拖空白，或先打开顶栏「▭ 框选」再直接拖。框内的节点与绘制会一并选中，可一起移动 / 删除 / 复制。
3. **组成组**：选中多个节点后按 `G`，或点顶栏「◫ 组」并输入标题。虚线圆角框可整体拖动；框边缘的把手可以**横竖分别缩放**。
4. **解散组**：再按一次 `G`，或点组按钮解散；**节点本身保留**。
5. **自动排版**：点顶栏「自动排版」，按连线方向把节点铺开、减少重叠。
6. **处理超节点内部的排版**：若画布里有已展开或含内容的超级节点，排版时会询问是否**同时排版内部**。
7. **只看布局**：按「隐藏线」把连线压到 95% 透明，检查版式，再按一次恢复（纯视觉，不改数据、不进撤销栈）。

> 💡 技巧：给画布分区时，先用框体绘制画几个区域，再用说明文字标上「输入区 / 处理区 / 输出区」，最后把节点摆进去——比一堆裸节点好认得多。

> ⚠️ 危险：组被解散或删除时节点会保留，但**删除组内的节点**和删除普通节点一样不可逆（只能靠撤销）。批量操作前先确认选中的范围。

## 结果

画布按区域排布、重叠明显减少；一组节点可以整体拖动；画布上留下可读的箭头与说明文字。

## 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 拖出了一个框却没选中东西 | 用了普通左键拖，变成平移画布 | 按 `Ctrl+左键`，或先开顶栏「▭ 框选」 |
| 组被拖散了 | 拖的是组内节点而不是组框 | 拖动虚线框本身；组内节点可单独选中移动 |
| 排版后更乱了 | 连线方向不明确（只有一个节点或没有连线） | 先补连线，或用绘制手排 |
| 超节点内部没被排版 | 排版询问时选了「只排主画布」 | 再点一次排版并选「同时排版内部」 |
| 绘制挡住了节点 | 绘制框盖在节点上方 | 改绘制颜色 / 线宽，或把绘制移到节点下方 |
| 想把组当子图用 | 组只是视觉容器 | 改用 [超级节点](#super-nodes) |
