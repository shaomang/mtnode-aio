# 加节点、连线与 @ 引用

> 一句话目标：会用右键加节点、用端子连线、在提示词里用 `@` 引用上游，并看懂线的三种类型。

*图 2：三种线——**数据线**传值、**金色控制线**只传脉冲、**关系线**只表达依赖。*

![拖动与连线动效](img/mtnode-canvas-02-demo.svg)
*图 3（循环动效，约 6 秒）：拖动节点 → 从输出端子拉线 → 落入输入端子（成功变绿 / 落空变红）→ 落在空白处就地生出新节点；静态回退见 `img/mtnode-canvas-02-demo-static.svg`。*

## 目标

读完后你能加对节点类型、把线连对（含连不上时知道为什么）、用 `@` 精确引用上游内容，并分清「浏览态」与「编辑态」。

## 前置条件

- 有一张画布。连线本身不花钱，只有 ▶ 运行才调用服务商。

## 步骤

1. **加节点**：在画布**空白处右键**，展开节点大类菜单，选一个类型。控制类节点带**金色外圈**。
2. **改标题**：点节点标题即可改名。标题是 `@` 引用的依据，起个能认出来的名字。
3. **连线**：从上游**输出端子**（右侧圆点）拖到下游**输入端子**（左侧圆点）。**不能成环**；输入端子默认 1 个，连上后常会自动再空出一个。
4. **连不上就看端子类型**：数据端子按类型匹配（文本 / 图像 / 音频 / 视频各不相同），不匹配时线拖不过去或落点变红。
5. **落在空白处松手 = 就地新建并连入**：从输出端子向外拉、在空白处松手，会弹出菜单，只列出这条线**真的连得上**的节点类型（图像线不会出现只吃文本的 Minimax Music 3）。选一项即在该处建好节点并连上；按 `Esc` 或点别处取消。落在某个节点身上不算，视为瞄着那个节点。
6. **写 `@` 引用**：在提示词里输入 `@`，候选只列出**已连接**的节点（若左上角彩虹图标已开，还包括全局节点连入的来源）。继续打字即筛选（标题包含匹配，前缀命中排前面），`↑` `↓` 移动高亮、回车（或 `Tab`）确认、`Esc` 收起——**全程不必碰鼠标**。`Shift+Enter` 仍是正文换行，菜单开着时回车只选条目、不会把节点跑起来。
7. **区分三种线**：**数据线**沿连线把上游结果作为输入传下去；**控制线是金色的**，只传脉冲（定时、闸门、执行 / 清空），不当作数据输入；**关系线**只表达依赖（开发节点用得多），不参与执行。
8. **打开 / 关闭引用来源**：文本处理 / 图像处理 / 智能任务 / 判断节点**点击左上角类型图标**开启引用（图标变彩虹）；拖动图标只移动节点，不会误开。

### 浏览态与编辑态

- 节点**未被选中时是浏览态**，正文只读：有 Markdown 信号走 **Markdown**、成规模的 `key: value` 走 **YAML**（保留缩进与配色），拿不准就按纯文本显示；`@标题` / `@标签` 按引用色高亮。图像铺满节点。此时只有头部那排小按钮可点（▶、参数、浏览…）；滚轮在正文上是翻阅，按住正文拖动则移动节点。
- **点选节点即回到可编辑形态**：正文换回输入框，光标落到主输入框末尾；点空白处或改选别的节点又回到浏览态。
- 参与浏览态的只有输入（文本 / 图像）、文本处理、图像处理、智能任务、对话、保存；控制 / 判断 / 任务 / 超级 / 开发 / 数据库 / 媒体 / 网络类节点**恒为编辑形态**。

> 💡 技巧：端子旁的参数名平时按宽度省略，鼠标移到节点上就放开显示完整——工具 / 函数节点的参数名、素材节点的条目标题都是全文。

> ⚠️ 危险：控制线（金线）不是数据线。把金线接到一个需要数据的输入端子，节点拿不到任何内容；反之把数据线当控制线，也不会触发下游。

## 结果

你能从零搭出「输入 → 处理 → 保存」这条最短管道，并说清每一根线的类型与作用；`@` 引用可以精确指到某个上游节点。

## 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 线拖不过去 / 落点变红 | 端子类型不匹配或会成环 | 换成能吃该类型的节点，先断开成环的那条线 |
| 输入节点改不动了 | 它已连上上游，内容变成**只读并继承上游** | 断开连线即可恢复可编辑 |
| `@` 菜单里没有想引用的节点 | 它没连到当前节点 | 先把线连上，或开启左上角彩虹图标纳入全局来源 |
| 写了 `@` 但运行没注入 | 只开彩虹没写 `@`，或写了 `@` 没开彩虹 | 全局来源要两个条件同时满足，见 [全局节点广播](#global-broadcast) |
| 端子文字互相遮挡 | 以为名字在端子排内 | 端子名一律写在节点外侧、与端子同一水平线 |
| YAML 文本自动变成多条 | 内容被判定为 YAML 批量条目 | 这是预期行为；想当纯文本就调整内容格式 |
