# 节点、端子与连线

![数据管道](img/nodes-wires.svg)

## 添加节点

画布空白处右键：输入、处理、保存、对话、智能、任务、**超级节点**、控制流、绘制等分类。控制类节点带**金色外圈**。

节点很多时，用 [超级节点](#super-nodes) 收纳子图；框选后也可点顶栏「超节点」一键合并。

## 端子与连线

- 从**输出端子**（右）拖到**输入端子**（左）。不能成环。
- **拖到空白处松手 = 就地新建并连入**：从输出端子向外拉、松手在画布空白处，会在松手位置弹出菜单，只列出这条线**真的连得上**的节点类型（图像线不会出现只吃文本的 Minimax Music 3）。选一项即在该处建好节点并把线连进它的输入端子；按 `Esc` 或点别处即取消。落在某个节点身上不算（视为瞄着那个节点）。
- 端子旁的**名字一律写在节点外侧**：输入侧标在左边，输出侧标在右边，与端子同一水平线——端子上下只隔 12px，文字放上面就会盖住相邻端子。端子排上**没有**「输入 / 输出」这两个额外标题（谁进谁出看端子上的参数名即可）。
- **名字平时按宽度省略，鼠标移到节点上（或选中高亮）就放开显示完整**——工具 / 函数节点的参数名、素材节点的条目标题都是全文，不会再看到切一半的字。
- 输入端子默认 1 个，连上后常会自动再空出一个。
- **控制连线是金色的**，只传脉冲（定时、闸门、执行/清空），不当作数据输入。
- **全局节点**只连入、不连出。文本处理 / 图像处理 / 智能任务 / 判断节点**点击左上角类型图标**开启引用（图标变彩虹）；拖动图标只移动节点，不会误开。

## 继承与自动运行

输入节点一旦被连上，内容变为**只读并继承上游**；断开即可再编辑。YAML 文本会自动变成批量条目。

点 ▶ 时，若上游尚未处理，会**自动递归执行**直到就绪。处理节点完成后会**自动执行下游**；若下游已有输出，会询问是覆盖还是不继续。

## @ 引用

在提示词中输入 `@`，只列出**已连接**节点（若左上角彩虹图标已开，还包括全局节点连入的来源）。运行时输入进入「背景信息」，提示词进入「内容」。图像引用作为参考图。

继续往下打字就是筛选（按标题包含匹配，前缀命中排前面），**`↑` `↓` 移动高亮、回车（或 Tab）直接确认当前条目**、`Esc` 收起——全程不必碰鼠标；`Shift+Enter` 仍是正文换行。菜单打开时回车只选条目，不会把节点跑起来。

全局节点的来源**只有被明文 `@` 命中才会进入输入**：只开彩虹不写 `@`，本次不注入任何全局内容；写了 `@` 但没开彩虹同样不生效。

## 浏览态与编辑态

- 节点**未被选中时是浏览态**，正文只读：文本按内容自动判定渲染方式——有 Markdown 信号走 **Markdown**，成规模的 `key: value` 走 **YAML**（保留缩进与配色），拿不准就按**纯文本**原样显示换行；`@标题` / `@标签` 引用一律按引用色高亮。图像**铺满节点**并保留完整画面。此时节点上**只有头部那一排小按钮可点**（▶、参数、浏览…），正文不再接收输入——滚轮在正文上是翻阅内容，按住正文拖动则移动节点。
- **点选节点即变回可编辑形态**：正文换回输入框，光标自动落到主输入框末尾，可直接打字；点空白处或改选别的节点，就又回到浏览态。
- 参与浏览态的只有输入（文本 / 图像）、文本处理、图像处理、智能任务、对话、保存；控制流 / 判断 / 任务 / 超级 / 开发 / 数据库 / 媒体 / 网络等节点**恒为编辑形态**。
- **批量条目在浏览态的读法**：条目竖向逐条排列，每条 = 一行**条目标题**（等宽青色小字，超长以省略号收尾）+ 其下的**条目内容**；内容若是文本同样按 Markdown / YAML 渲染，若是图像则显示该条缩略图，条目之间以细分隔线区分。条目过多时在节点内部滚动（滚动条默认隐去，悬停节点时淡显），空内容显示为「（空）」。
