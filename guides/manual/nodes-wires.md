# 加节点、连线与 @ 引用

> 一句话目标：掌握画布操作技巧——进出节点层、缩放平移、跑这一支与拖入文件。

## 画布操作技巧

- 双击节点层：打开看里面的内容，再双击空白处回到上层。
- 滚轮缩放、拖动空白平移。
- 节点上的 ▶：按连线顺序跑这一支；上游跑完下游会自动跟随（可在设置里关掉）。
- 连线即数据流：上游改完重跑，下游跟着更新。
- 拖文件进画布即成输入节点；拖图片到图像输入节点可换图。
- 节点提示词里输入 @ 引用上游：↑↓ 选择、回车（或 Tab）直接确认、Esc 取消。
- 使用「节点层」将多个节点进行归类，有助于提升画布渲染速度。
- 顶栏「节点层」一键框选合并；选中单颗节点层时再点一次 = 拆开它（内部内容按原位置移到外层，空壳删除）。

## 参数端子：用一份 JSON 覆写节点配置

插件节点与所有带 ⚙ 设置窗的节点，输入端**最末位**都多一颗「参数」端子。建一个「输入文本」节点写一份 JSON 对象，连到这颗端子上：运行那一刻按 JSON 改掉该节点的配置，跑完自动还原，**画布上的值一个不动**。

```json
{ "savePath": "out/今日海报.png", "model": "gpt-image-2-vip", "size": "1536x1024" }
```

- **写什么键**：节点的配置字段正式名（`savePath` / `outputPath` / `size` / `model` / `duration` / `temperature`…），**区分大小写**，下划线或短横线写法不再识别（写错按未知键处理）。要点开节点 ⚙「参数覆写」小节右上的文档按钮：那里列出这个节点的**全部参数 + 一句话说明**（含类型、默认值、当前值）。
- **相对路径**：路径类键（`…Path` / `workspace` / `dir`）写相对路径就按画布工作目录算，绝对路径原样使用。
- **多条参数线**：按接线顺序合并，同一个键后面的覆盖前面的；嵌套对象逐层合并、数组整体替换；某个键写 `null` = 恢复默认值。
- **看不到效果时**：⚙ 里的明细表列出「键 / 节点当前值 / 本轮生效值 / 来源」，右上的文档按钮给出每个参数的说明。默认宽松——写错的键回退并提示；勾上「参数严格校验」后改成一票否决：整份拒绝，这个节点不运行。
- **服务商也能覆写**：`providerId` / `provider` 在本机找不到时，会按名称唯一匹配、再按模型归属自动换成本机可用的服务商（写回画布、可撤销）；仍找不到就保留原样，并在运行时跳过该节点。
- **只能接线，没有第二种写法**：Agent 也一样 —— 要给参数就建一颗「输入文本」写 JSON、连到「参数」端子。Agent 不再能直接把参数写进节点（那样会压住你设置窗里的值，导致你改不动自己的参数）。
- 顺带一提：这份 JSON 直接写在「输入文本」节点里时，卡片会自动显示成表单项（一行一个键，可加减行），右上角「JSON」随时切回源码。
