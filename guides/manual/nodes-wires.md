# 画布基础：节点、连线与排版

画布是 MTNode 最直观的玩法：每个方块是一个「节点」，节点之间的线代表「数据往哪流」。把复杂的事拆成几个节点连起来，改哪一步就重跑哪一步，不用每次从头跟 AI 重复讲要求。

## 添加节点与查看说明

- **加节点**：在画布空白处**右键**，或者用画布底部的**建造条**，挑一个节点放上去。
- **看不懂节点是干嘛的**：每个节点右上角都有一枚 **?** 按钮（鼠标移开 1 秒自动消失，可在设置里隐藏），点一下看一句话说明；右键节点选 **节点指南** 可以看完整用法。
- **拖动与缩放**：按住画布空白处拖动平移，滚轮缩放；节点太多找不到时按 `Space` 或点顶栏 **居中** 一键归位。
- **按标题快速找**：按 `Ctrl + F` 或点顶栏 **查找**，可以直接搜索当前画布上的节点、历史会话、项目文件和本手册。

## 连线与 `@` 引用

把上一个节点的右侧输出口，拖到下一个节点的左侧输入口，就算接通了。

- **在提示词里精准引用**：在文字处理或图像生成节点的提示词框里输入 `@`，会弹出上游已连入的节点列表，用方向键选中并回车就能插入 `@节点标题`。以后上游内容改了，下游会自动拿到最新内容。
- **数据线 vs 控制线**：数据线传内容（文字、图片、音频等）；控制线只传「轮到你跑了」的信号。给一条链的开头接一个 **控制节点（▶ 开始）**，点它就能按顺序一键重跑整条链。
- **表单节点（`表单输入`）**：如果你每次运行都要填好几个字段（比如标题、受众、配图、参考视频），可以用表单节点先定好字段，再像填问卷一样填进去或拖入素材；图片和视频还支持写描述、打标签、框选标注。双击表单节点可以展开大面板编辑。
- **用参数端口批量覆写**：不少处理节点都带有一个「参数」输入口，接一份 JSON 进去就能动态覆盖节点里的模型、尺寸、步数等配置，适合批量跑不同参数组合。

## 整理大画布：组、节点层与排版

画布上节点一多，可以用下面几个工具保持清爽：

- **框选与复制**：按住拖出选框一次选中多个节点；按 `Ctrl + D`（或点顶栏 **复制**）原地克隆选中的节点和它们之间的连线。
- **组（分区框）**：选中几个节点点顶栏 **组**，给它们套一个带标题的背景框。拖框的标题栏可以整块一起挪动，视觉上分区很清楚。
- **节点层（收纳盒）**：选中一堆节点点顶栏 **节点层**，把它们折叠收进一个大卡片里，双击就能钻进去看内部细节，点画布左上角的 **← 返回** 回到外层。
- **自动排版与隐藏线**：点顶栏 **排版** 自动把节点理顺；连线太密遮挡文字时，按 `D`（或点 **隐藏线**）可以暂时藏起连线。
- **简略模式**：画布上图片和视频很多、要腾出显存给本地视频模型用时，点顶栏 **简略**，画布会暂时不加载图片/视频预览缩略图，省显存又流畅。

## 撤销、重做与历史回滚

- **日常撤回**：`Ctrl + Z` 撤销、`Ctrl + Y` 重做（或点顶栏撤销/重做按钮）。画布上的移动、删改、连线、甚至助手帮你搭的节点都可以一步撤回。
- **防丢草稿**：输入框里写到一半没提交的草稿，关掉软件再开也会自动保留。
- **节点内版本回滚**：如果你用了 [AI 审阅](#ai-review) 改稿，每一版修改都会完整保留在审阅记录里，随时可以回到之前的任意一版。
