# 审批与权限

> 一句话目标：搞清楚右上角「审批」里的两个开关各管什么，知道什么时候会弹卡片、哪些操作一定会被拦下来。

![审批与权限](img/mtnode-agent-05-ui.svg)
*图 1：右上角「审批」面板——上半是权限预设，下半是工具许可*

## 目标

读完这一页，你能为一次任务挑对权限预设：日常让 AI 自己跑就用默认的无人值守，碰真实代码或重要文件时切成逐项审批；能按类别勾掉不该给的能力；能看懂越权时弹出的审批卡片怎么点；也知道哪几类操作不论预设多松都会被硬拦。

## 前置条件

- 已能跑起智能节点或智能会话，见 [智能任务与智能会话](#agent-nodes)。
- 先想清楚这次要它碰什么：只读资料、改工作区文件、跑命令、联网、还是识图。
- 注意这两组设置是**全局**的，改完会影响之后所有运行，不只是当前这一轮。

## 步骤

1. **打开面板**：点顶栏右上角的 **审批**。
2. **选权限预设**：面板上半是「权限预设」，四选一：
   - **无人值守（工作区读写 · 不询问，默认）**——工作区里读写文件，不弹窗。
   - **工作区读写 · 逐项审批**——能读写工作区，需要越权时逐项问你。
   - **只读 · 逐项审批**——只读，越权逐项问你。
   - **完全放行（不限目录 · 不询问）**——不限目录、不询问。

> ⚠️ 危险：「完全放行」把沙箱与询问一起放开，Agent 可以写工作区以外的路径。只在一次性、可丢弃的环境里用它。

3. **勾工具许可**：面板下半按类别列出 Agent 可用的能力。它与权限预设**互相独立**——那边管沙箱与「越权要不要问」，这边管「允许调用哪些能力」。
4. **另存一份**：工具许可可勾选修改当前预设，或点 **＋ 新建** 把当前勾选**另存成自定义预设**，之后可切换、重命名、删除（内置默认预设不能重命名 / 删除）。
5. **改完跑一次任务**：设置从**下一轮任务**起生效，不用重启应用。

### 工具许可的类别

- **画布类**：节点与连线、控制、绘图、排版与成组、应用操作（状态 / 列表 / 重命名 / 选中 / 撤销重做）、删除画布。
- **基础能力（引擎）**：读文件、写文件、终端命令、联网、子代理任务、目标与任务清单、后台命令与子代理的收流 / 终止、向用户提问。
- **识图**：识图子代理。

每一类的取值是**批准**（直接可用）或**拒绝**（硬拦截）；按所选产品口径也可能是「询问＝调用前确认」。勾选改动只影响**下一次任务起**写入系统提示的那份许可，画布 / 应用 / 识图会直接拒绝未授权调用，读文件 / 终端 / 联网等基础能力则写入系统提示约束。

> 💡 技巧：拿不准就先用默认的「无人值守 + 默认工具许可」跑一轮，看它实际调了哪些工具，再决定放宽或收紧——比一开始就想全要准得多。

### 预设怎么选（速查）

- 只是读资料 / 写文档，不需要动系统：**无人值守（默认）**。
- 要改真实项目的代码、跑命令：**工作区读写 · 逐项审批**。
- 只想让它看、不想让它动：**只读 · 逐项审批**。
- 一次性沙箱环境：**完全放行**（见上面的风险提示）。

### 逐项审批时会发生什么

选了「工作区读写 · 逐项审批」或「只读 · 逐项审批」后，任务一旦用到越权工具，屏幕会弹出**审批卡片**：卡片写清这次要做什么，给你 **允许一次 / 拒绝** 两个按钮。

![审批卡片](img/mtnode-agent-05-demo.svg)
*图 2：审批卡片从右侧滑入 → 点「允许一次」→ 卡片收起、任务继续跑（约 4 秒循环动效；静态回退图 `img/mtnode-agent-05-demo-static.svg`）*

拒绝不会让任务崩掉：模型会收到失败回执，然后换一条不越权的路继续，或在回复里说明它需要什么权限。

### 硬拦截项

**画布修改、应用级危险操作、识图**是硬拦截：即使预设较松，这类调用也会确认或直接拒绝——它们改的是你正在编辑的东西（画布、应用状态），或会把你的图片发给外部模型。若智能任务报 `mtnode_vision` 失败或被禁用，可在识图许可里点「始终允许」或「本会话允许」；无人值守预设不会弹工具审批，需要逐项确认就改用「工作区读写 · 逐项审批」。

### 模型向你提问

任务中途模型还可能**向用户提问**：屏幕下方弹出「🐋 模型等待你的回应」询问窗，一次列出本轮全部问题，每题给候选项（**选项下方那一行小字就是模型给的理由**，推荐项排在第一位并标「（推荐）」），也可在「其他（自定义回答，选填）」里写自己的答案。

- 点 **回答** 后本轮继续跑。
- **稍后（终止本轮）**：暂时不答并停掉这一轮。
- **中断任务**：明确放弃这次提问（模型收到失败回执，不会拿空答案硬往下走）。

需求拷问（内置技能 `mtnode-grill-me`）走的就是这个询问窗。

## 结果

- 右上角「审批」的当前预设一眼可见：日常脚本跑无人值守，改真实项目时切逐项审批。
- 越权工具会弹卡片让你点「允许一次 / 拒绝」，拒绝后任务会自行绕路而不是报错退出。
- 画布修改、应用级危险操作、识图这几类无论如何都会确认或拦截。
- 你自定义的预设留在列表里，随时切换。

## 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 任务报「当前工具预设不允许：…」 | 该类能力在工具许可里被拒 | 到右上角「审批」里改工具许可，或换一个预设 |
| 逐项审批时任务卡住不动 | 审批卡片在等你点按钮 | 卡片上点「允许一次」或「拒绝」，任务才会继续 |
| 识图一直失败 | 识图许可未放行，或无人值守档不弹卡片 | 识图许可点「始终允许 / 本会话允许」，或改用「工作区读写 · 逐项审批」 |
| 觉得太吵，到处弹窗 | 选的是逐项审批档 | 换成默认的「无人值守（工作区读写 · 不询问）」 |
| 想删掉某个自定义预设，按钮是灰的 | 内置默认预设不允许重命名 / 删除 | 复制成新预设再改，或只切换不删除 |
