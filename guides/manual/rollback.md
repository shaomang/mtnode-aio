# 撤销与回滚

> 一句话目标：用快捷键撤销 / 重做画布改动，并记住切图与大改前的保险习惯。

## 撤销 / 重做 / 回滚

- Ctrl+Z / Ctrl+Y：撤销、重做画布改动（改标题、连线、位置都算）。
- Ctrl+F 打开全局搜索功能；焦点正在某个输入框里时，它改成打开「输入框内查找」小条，
  在**这个输入框内部**高亮并定位文字（Enter 下一个 / Shift+Enter 上一个 / Esc 关闭）。
- 删除节点、删除画布这类动作会先弹确认。
- 撤销栈只属于你眼前这张画布；切到别的画布，撤销不会跨图。
- 保险习惯：大改之前先复制一份画布，或者把输入正文另存一份。
