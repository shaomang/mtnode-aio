# 需求等待

![diagram](img/wait_file.svg)

盯住一个文件路径：文件还没生成就挡住下游，生成了才放行。它不输出文件内容，下游自己去读约定路径。

## 端子
- **输入**：无
- **输出**：控制（连到下游，避免下游提前跑）

## 设置
- 在节点头部 **⚙ 设置** 打开的设置窗口里改；**监视路径（待生成的文件）**：绝对路径，或先设工作目录后写相对路径
- **轮询间隔（秒）**：多久检查一次，1–60，默认 2
- 「浏览 / 位置」是节点上的动作按钮，不在设置窗口里

## 用法
- 用「浏览」挑一个已有文件，或直接在设置窗口里填还没生成的那个路径
- 「位置」在文件夹里显示监视路径（文件还不存在时可能定位不到）
