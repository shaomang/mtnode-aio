# 函数节点（JS 计算）

在画布上写一小段**纯 JS**，把输入算成输出。参数即端子，所以它能像普通节点一样连线、级联、批量、保存。

创建：右键 → **其他节点** → **函数（JS 计算 · 自定义入参出参）**。

## 端子
- **输入**：端子 0 = 控制入（固定）+ 每个输入参数一颗（文本 / 图像 / 视频 / 音频）；勾了数组的参数可挂多条数据线
- **输出**：每个输出参数一颗（0..n-1）+ 末位控制出（固定）；输出恒为一号一值

## 设置
节点头部 **设置** 打开的设置窗口里改，卡片上只留「入参 / 出参」两行只读摘要：

- **函数名 fnName**：可选，仅备注。
- **描述 description**：给人看的一句说明。
- **输入参数类型 / 输出参数类型**：文本 / 图像 / 视频 / 音频，每条 = 一颗端子。文本值是字符串；图像 / 视频 / 音频值是 `{kind, path, text}` 路径对象，`path` 是本机绝对路径。
- **数组 · 可接多条线**：只在输入参数行出现，见下。
- 参数行可拖 ⠿ 或点 ▲▼ 调顺序；顺序即端子顺序，已连的线跟着参数走。
- **参数**（9001）：可写一份默认 JSON，运行时会与接进 9001 的 JSON 深合并（对象逐层合、数组整体替换、`null` 保留），整份进 `input.params`。JSON 写错默认只警告并跳过该来源；勾上**参数严格校验**则直接拒绝这次运行。

## 用法
- **数组输入端子**（一条线不够用，就像图生图要多张参考图）：给输入参数勾上「数组 · 可接多条线」，同一颗端子就能连多条线，端子变成可增长的槽位组。代码里这个参数**恒为数组**——没挂线是 `[]`，挂一条也是长度 1，可以无条件 `for` / `map`。数组只改形状不改类型，元素顺序 = 连线顺序。
- **写代码**：直接在节点上编辑（默认有注释模板）。代码不在画布进程里跑，每次运行主进程单独起一条执行线程（`fn-runtime.js`），界面不卡；超时默认 10 分钟，结束 / 停止 / 超时都会连同它拉起的外部进程树一起回收。
- **入参对象 input**：`input.params`（9001 注入）、`input.$1` / `$2`…（按端子序号）、来源标题 / 参数名、`input.values`（按接线顺序）。`return` 即输出；返回普通对象且键命中输出参数名时，按键名分发到各输出端子。
- **`mtnode` 桥**：线程里没有 `window` / `document`，落地到本机全用它 —— `mtnode.exec(程序, 参数, {cwd})` 隐藏启动并等退出、`spawn` / `wait` / `kill` / `processes`、`sleep`、`log` / `progress`、`readText` / `writeText` / `readFile` / `fileInfo`、`join` / `abs` / `cwd` / `platform`、`readPdf` / `pdfInfo`、`subtitle`（音视频转字幕）、`screenList` / `windowList` / `screenShot`（拍屏幕 / 窗口）、`ai(提示词)`（用本节点「AI 调用」选的模型真发请求）。
- **AI 调用**：节点头部 🤖 选模型 / 预设 / 思考强度，选中后在代码里 `await mtnode.ai(...)`；没选过会返回 `ok:false`，不会静默空跑。

## 注意
- **没被选中时只显示内容**（函数名、描述、入参 / 出参、代码、上次结果）；点一下节点才出现可编辑代码块。
- 返回值归一：字符串 / 数字 / 布尔 → 文本；`{kind, path}` → 对应媒体；其余对象 → JSON 文本；每个输出端子还会按自己声明的类型再归一一次（图像端子拿到路径会补成图像值）。
- 函数节点没有独立测试台，点 ▶ 真跑一次看各端子结果；图像 / 视频 / 音频输出各带只读预览。
- 「开发」按钮绑定一条会话，只改这一个函数节点的代码与参数表；动了参数表要回画布复核连线（端子可能移位）。
