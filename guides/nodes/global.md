# 全局节点（广播）

只连入、不连出：把文本 / 图像源**广播**给任意多个消费者，避免重复连线。

## 引用方法（两步，缺一不可）
1. 把源节点连进全局节点（可多个源）。
2. 在消费者节点（文本处理 / **图像处理** / 智能任务 / 判断）上**点击左上角类型图标**开启引用（图标变彩虹 = 已开启），并在提示词 / 任务里写 **`@源节点标题`**（或该来源身上的 `@标签`）。

> 只开引用或只写 `@` 都不生效。开了彩虹也**只有被明文 `@` 命中的全局来源**才会进入本次输入，未点名的不注入（`@` 菜单仍列出全部来源供点选）。不能把控制节点连进全局节点。

## 端子
- **输入**：文本 / 图像源（多个）
- **输出**：无
