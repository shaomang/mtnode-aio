# 全局节点（广播）

只连入、不连出：把文本 / 图像源广播给任意多个消费者，省掉重复连线。

## 端子
- **输入**：多个文本 / 图像源（控制节点不能连进来）。
- **输出**：无。

## 设置
- 无设置项：节点头部没有 **⚙ 设置** 窗口，行为全由接线和消费者上的彩虹开关决定；点节点 body 空白处可看全部连入内容。

## 用法
- 把源节点连进全局节点（可多个）。
- 在消费者上**点击左上角类型图标**开启引用（图标变彩虹），再在提示词 / 任务里写 **`@源节点标题`**（或该来源的 `@标签`）。只开引用或只写 `@` 都不生效，两样都要。
- 可用消费者：文本处理 / **图像处理** / FLUX 3 / Qwen Image / 智能任务 / 判断。

## 注意
- 开了彩虹也**只有被明文 `@` 命中的全局来源**才进入本次输入，没点名的不注入（`@` 菜单仍列出全部来源供点选）。
- 一个都没命中时会提示「已开启全局引用，但提示词未 @ 引用任何全局来源」，不是静默生效。
- 不能把控制节点连进全局节点。
