# 表单节点（结构化 JSON · 卡片墙填内容 · 图像 / 视频描述与注释）

画布空白处右键 →「输入节点」→「表单节点」，或在节点搜索里搜「表单」。

节点本体是**一份设计好结构的 JSON**：先定好有哪些字段（叫什么、什么类型、必填不必填、
选项是什么、默认值 / 自动计算、什么时候显示），再照着填 / 把素材拖进去。填完的内容
既能顺连线交给下游，也能被 `@` 引用给 AI 直接看见。

## 填写的入口

- **板身就是一面卡片墙**：只显示「项」和「内容」，没有一行一字段的输入框，也不写「表单 N 项 / 必填已填齐」
  这类状态文案（必填没填只在卡角点红点）。
  - 媒体（图像 / 视频 / 音频 / 文件）= **方形卡**：缩略图 + 文件名，角上标类型、描述 / 标注数量。
  - 文字 / 数字 / 开关 / 单选 / 多选 = **16:9 卡**（约占两个方卡宽）：卡面直接显示值，超出自动截断。
  - 列表 = **每行一张卡**：行里有素材就用那份素材当方卡，没有就是 16:9 文字卡；末尾一张「＋ 追加」。
  - 空着的项也出占位卡（未填的必填项在卡角点一个红点），点开就能填。
- **点卡 = 就地编辑**：在节点旁弹出这一项的浮层 —— 字段值 / 列表行的各子字段 / 素材的预览、描述、
  标签、标注、识图都在里面。浮层跟着节点走，**点窗外不会关**，只走 ✕ 或 Esc；浮层里还有「在面板中编辑」。
- **大面板 = 全屏编辑模式**：双击板身空白处，或点「更多设置」打开 —— 字段定义、模板、逐行编辑、
  写描述、框选 / 时间点标注、识图、看 JSON 都在这里。面板是**常驻的**：点窗外不会关，只有 ✕、Esc 才关；
  改一处存一处，右下角写着落盘路径。
- **卡片在板身里自己滚**：节点高度固定一档，内容再多也不会把节点顶高；卡片区左右各让出 24px
  端子栏通道，任何情况下都不压到左右端子与接线排。你手动拉过高度就听你的。
- **缩略图懒加载**：卡片滚进视野才取图（图像走缩略图协议，视频取首帧，音频 / 文件给图标），
  几十份素材的表单也不卡。
- **字段多时才有搜索框**：可见字段 ≥ 9 个时顶栏出现「搜字段 / 文件名」，平时不占地方；
  「全部折叠 / 更多设置 / 刷新」在板身底部一排。

## 卡片上能做什么、到哪为止

- **文字 / 数字 / 开关 / 单选 / 多选**：点卡开浮层改；浮层里失焦才规范化并标记改动（数字 / 日期时间会按类型收口），
  回车等于失焦。**自动计算（算式）字段在浮层里是只读的**；开关 / 单选 / 多选点一下就生效。
- **列表**：卡面是这一行的摘要（各子字段拼一行）；点卡改这一行的每个子字段；「＋ 追加」加一行，
  浮层底部有「删除这一行」。逐格批量编辑仍去大面板。
- **媒体**：卡面只管「是哪份素材」；描述、标签、标注、识图都在浮层里（也可以去大面板）。
- 板上改的是同一份 `node.values`，与浮层 / 大面板 / `.json` 是同一份数据，不是两套副本。

## 折叠 / 展开

- 点组头左边的**字段名**即可折叠 / 展开这一组；折叠后整组变成「标签：值摘要」一行。
- 板身底部有「**全部折叠 / 展开全部**」，尾部还有「还有 N 组」，点一下把折起来的都展开。
- **第一次打开时默认只展开前 3 组**，其余先折起来（只折一次，之后完全听你的记录）。
- 折叠只改**显示**：字段、取值、JSON、`@` 引用一律不变，折叠也不写进 `.json`。
- 折叠状态记在节点上，关掉画布再打开还是你上次的样子。

## 字段类型

单行文字、多行文字、数字、下拉单选、多选（标签点选）、开关、**图像、视频、音频、任意文件**、
日期时间、**列表**（一列可增删的行，每行再含若干子字段，适合多镜头 / 多素材清单）。

- **必填**只是提示，不拦人：没填会在卡角点红点、`@` 引用里写「未填必填」，照样能往下跑。
- **默认值 / 自动计算**支持受限表达式（`sum(len(素材列表))`、`now()` 之类），算式字段在界面上
  只读；**显示规则**是可视化的「当字段 X 等于 Y → 显示 / 隐藏 / 必填」。被隐藏的字段保留值，
  但不进 `@` 引用摘要。

## 素材：拖进来就有描述和注释

- 图像 / 视频 / 音频 / 文件字段本身就是一块**拖放区**：点空卡选文件、往里拖、或直接把多个文件
  拖到板身空白处（自动追加成「素材列表」的行）。
- **卡上落文件 = 换这份素材**：拖到媒体方卡上，第一份写进这张卡，多出来的追加进素材列表；
  拖到**板身空白**处 = 全部追加进素材列表。文字卡不接文件；类型对不上的（比如图片拖进视频卡）不写、也不报错。
- **从左栏文件树拖进来和拖系统文件是同一条路**，落点语义同上。
- 拖入是**追加**语义，不去重：同一份文件拖两次就是两行，拖进卡里就是再覆盖一次。
- 拖进来的东西里**必须有一份带路径的文件**：只拖一段选中的文字不会触发表单接手（那段文字由浏览器 / 输入框自己的默认行为处理）。
- **图像会复制进工作流资产**（跟着画布走，换盘不丢）；视频 / 音频 / 任意文件只记原始绝对路径
  （文件可能很大，不复制）。
- 每份素材可写**描述**与**标签**；图像还能**框选标注**（拖出矩形 + 一句注释，坐标按 0~1 归一化，
  缩放不会偏），视频能按**时间点 / 起止段**记注释。卡角的 `✎` / 数字就是「有描述 / 有几条标注」。
- **识图补充**：单个素材在浮层或面板里点「识图补充」，或按「一键补充全部」，让识图模型看图写描述
  （视频自动抽 3 帧概括）。拖入时**不会**偷偷跑模型，运行工作流时也不会 —— 只有你点才会。
- 描述与注释就是给 AI 的上下文：每次 `@引用` 这个节点，Agent 都能看到并复用。

## 从别的节点连一条线进来：算一次引用，然后线就没了

表单是**一次性引用**：把上游节点的文本 / 媒体输出连到表单的输入端子，落线那一刻就把上游**当前**
的内容抄进表单，紧接着**把这条线摘掉**。

- **抄进哪里**：文本 → 自动建一个「引用内容」多行字段（已存在就往后追加，空一行分隔）；
  图像 / 视频 / 音频 / 文件路径 → 素材列表的行（没有素材列表就当场建一张；存储口径同拖入，
  图像复制进资产、其余记绝对路径）。
- **「引用内容」就在板身上**：它是一张正常的卡（跟别的字段一样可点开、就地改），大面板里也照常显示；
  内容同时进 JSON 与 `@` 引用摘要，下游和 Agent 都读得到。
- **断线之后上游再变，这份拷贝不会跟着变** —— 要新的就再连一次（再连一次就是再抄一份，会追加在后面）。
- **落不进内容的部分不会丢**：列表里没有能收这类文件的子字段时，这条退到节点的 `refs[]`，
  `@` 引用里仍然看得见；JSON 类输出也走 `refs[]`。
- **上游这一刻是空的**：不断线，只提示一次「上游还没有内容：线先留在端子上，等它有值了自动复制进
  本表单」。之后上游一有值（跑出结果 / 被填上），表单**自动**抄一份并摘线 —— 不用再拖一次线。
- **幂等**：线一摘就没了，同一条线不会被吸收第二次，不会重复追加同一份内容。一次落线只吸一次
  （画布重绘 / 面板重绘 / 等值的那只看门表都不会重复触发）。
- **撤销**：写入的值与摘掉的线是**同一步撤销**，按一次 Ctrl+Z 两条一起回退。
- 复制是「当时那一刻的快照」：表单里的是可编辑副本，与上游是两份数据。

## 对外给什么

- **1 个输出端子** = 整份 JSON 文本（字段结构 + 值 + 素材路径 / 描述 / 标签 / 注释），
  可直接接下游节点的文本端子，或接「参数」端子（9001）当运行期配置。
- **1 个输入端子（标题「引用」）** = 一次性吸收入口（见上一节）：连进来就抄一份、然后断线，
  上游当时还是空的就先留着线、等它有值了自动抄；不是常驻的数据通道。
- **`@` 引用**给的是**紧凑摘要**（字段: 值，素材给路径 + 描述 + 标签 + 注释），并附上那份
  `.json` 的绝对路径 —— 长表单不会把上下文撑爆，要全文的 Agent 直接读那个文件。
- 数据落在 `<工作目录>/mtnode-forms/<表单名>-<节点 id 后四位>.json`，每次编辑自动写盘；
  这个文件也可以**手改**：面板打开时与点「刷新」时按修改时间比对，**新的那份赢**（值**和**
  字段结构都读回来；结构不合法就整份拒收，不会把你的表单改坏）。

## 模板

内置 5 份：素材清单 / 角色设定 / 分镜镜头 / 产品图集 / 通用参数表。套模板只换结构，
同名（同标签）字段的值会尽量保留。也可以「存为我的模板」，跨画布复用（只存结构，不存值）。
