# 表单节点

画布空白处右键 →「输入节点」→「表单节点」。一份有结构的 JSON：先定字段，再照着填 / 把素材拖进去。

## 端子
- **输入**：固定 1 个，标题「引用」——连进来的内容抄一份进表单后线立刻断开（一次性引用；上游还没值就先留着线，有值自动抄）
- **输出**：固定 1 个 = 整份 JSON 文本（结构 + 值 + 素材路径 / 描述 / 标签 / 注释），可接文本端子或「参数」端子

## 设置
- 没有 ⚙ 设置窗：字段定义、模板、逐行编辑、JSON 都在大面板里（双击板身空白处，或点头部的展开图标）；面板常驻，点窗外不关，只走 ✕ / Esc。

## 用法
- 板身是卡片墙：点卡就地改，空项也有占位卡；必填没填在卡角点红点，但不拦运行。
- 字段类型：单行 / 多行文字、数字、下拉单选、多选、开关、图像、视频、音频、任意文件、日期时间、列表（列表每行一张卡，末尾「＋ 添加行」）。
- 媒体卡是拖放区：拖文件进去，图像复制进工作流资产，视频 / 音频 / 任意文件只记绝对路径；拖入是追加，不去重。
- 每份素材可写描述与标签；图像能框选**标注**（坐标按 0~1 归一化），视频能按时间点 / 起止段记注释；点「识图补充」才让识图模型写描述，不会偷偷跑。
- 可见字段 ≥ 9 个时顶栏出「搜字段 / 文件名」；头部三颗小图标是 全部折叠 / 展开（占满画布）/ 刷新。
- 内置 5 份模板：素材清单 / 角色设定 / 分镜镜头 / 产品图集 / 通用参数表；也能「存为我的模板」（只存结构）。

## 注意
- 第一次打开默认只展开前 3 组，其余折起（只折一次，之后听你的）；折叠只改显示，不动值。
- 连进来的内容只抄一次：断线后上游再变，表单里的副本不跟着变；要新的就再连一次。
- 数据落在 `<工作目录>/mtnode-forms/<表单名>-<节点 id 后四位>.json`，改一处存一处；手改这个文件后点刷新，时间新的那份赢，结构不合法会整份拒收。
- `@` 引用给的是紧凑摘要 + 这份 `.json` 的绝对路径，长表单不会撑爆上下文。
