# PDF生成

把上游的**文本 / Markdown** 排版成一份 PDF 落盘：标题层级、列表、表格、代码块、图片都会排版，公式会画成真正的数学式子。入口：画布空白处右键 →「处理节点」组里**鼠标悬停** **文本生成** 展开二级菜单 → **PDF生成**。

## 端子
- **输入**：文本，可接多条（单份 PDF 里按顺序拼起来，中间用分隔线隔开）；图像 / 音频 / 视频接不了。
- **输出**：1 个数据端子 = **本次生成的 PDF 落盘地址**；还没生成过时回落成上游输入的内容。它只是落盘回执，接不接线都要点 ▶ 才生成。

## 设置
- 在节点头部 **⚙ 设置** 打开的设置窗口里改：
  - **保存路径**：相对工作目录或绝对路径，后缀固定 `.pdf`（写错会自动纠正）；留空 = 用**输入节点**的标题命名（上游是「文本节点 2」就得到 `文本节点 2.pdf`）。卡片上的「文件名」框也能改，清空即回到这套默认命名。
  - **PDF 版面**：**页面尺寸** A4（默认）/ A3 / A5 / Letter / Legal；**横向**（宽表格、宽公式更合适，默认关）；**页边距** 无 / 窄 / 标准（默认）/ 宽；**正文字号** 小 / 中（默认）/ 大；**显示页码**（页脚居中「当前页 / 总页数」，默认开）；**文档标题**（留空不加，填了在正文顶部加一行居中大标题）。

## 用法
- 接上文本来源（文本节点 / 文本处理（LLM）/ 智能任务 / 素材节点文本条目 / 函数输出）→ 按需要调版面 → 点 ▶ 生成。
- 节点头部的 **PDF 图标小按钮**用系统默认 PDF 阅读器打开已生成的 PDF；还没生成时点它只提示先按 ▶。

## 注意
- **连上不会自动生成**，也没有「自动保存」开关：接线、上游更新都不落盘，只有点 ▶（或控制节点指挥）才生成。
- 公式支持 `$…$`、`$$…$$`、`\(…\)`、`\[…\]`，与画布预览同一套渲染器；围栏代码块与行内代码里的 `$` 不当公式。
- **批量**：每个条目一份，命名 `文件名_条目标题.pdf`；**聚合**：全部合成一份，每个条目标题当小标题（`## 标题`）。
- 内置工具「Markdown 转 PDF」共用同一套排版内核，但回的是**文件路径 + 字节数**、版面固定（A4 · 标准页边距 · 中号字 · 带页码）。
