# 交付节点（deliver）

长周期任务在**主画布**上的人工落点：机器做完了，下一步需要有人把东西递进来才继续。只有启用中的长周期任务会创建它（带固定 **uid** 和绑定目录），节点列表 / 右键菜单 / 拖线落点 / 全局搜索里都没有它的类型入口。

## 端子
- **输入**：清单里**每个还没交的文件 = 一个输入端子**，端子标签就是文件名（如 `分镜表.md`）。文件交掉后该端子消失，剩下的按顺序补位，已连的线按文件项身份重绑。文本 / 选项确认类条目不占端子。
- **输出**：没有。

## 设置
- 没有 ⚙ 设置窗口，清单就在节点上改：
  - 板身顶部是一张 Markdown 表（文件名 / 内容说明 / 必填选填 / 格式或大小要求 / 交付状态）；表上方 **▤ 预览 Markdown** 用应用内预览器打开整份清单。
  - **＋ 添加文件** 加条目，每个端子后面可删除。改过之后以画布为准：系统只补新增项，不拿图里的旧清单盖掉你的改动，改完会写回图定义与 `交付清单.md`。

## 用法
- 交件两条路任选：把上游节点（文件 / 图像 / 视频 / 音频 / 保存）连到对应端子（真拿得到文件就自动记为已交付、文件复制进交付目录）；或点端子的 **⬆ 上传** 选这个文件。
- 交齐后到顶部条带的人工卡上点 **确认交付完成** 才往下跑 —— 收齐 ≠ 放行。

## 注意
- 文件名对不上、格式或大小不符都只提示不拦（红字标出，随时「撤回」重传）；**撤回**只清已交标记，交付目录里的文件不删。
- 必填没交齐也能放行：确认窗逐条列出缺项并要求写交付说明（可留空，会记成「（未填说明）」），留痕进 `manifest.json` 的 `releases` 与《交付清单.md》的「未交付说明」段，之后的 Agent 环节读得到。
- 交付目录固定在 `<画布工作目录>\mtnode-deliverables\<uid>\`（含 `manifest.json` 与 `交付清单.md`）；工作目录不可用时退回 `%APPDATA%\pipeline-console\longtask\deliver\<uid>\`。**uid 不要自己改**，改了就不对账。
- 可以删（下次跑到那一环按同一 uid 重建），但**不能复制**；重跑同一环节算新一轮，端子全部回来。长任务或 run 删掉时交付目录不会被自动删。
