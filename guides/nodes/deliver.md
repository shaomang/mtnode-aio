# 交付节点（deliver）

长周期任务在**主画布**上的人工落点。它长得很像文件节点，但它不是给你手动添加的：
只有启用中的长周期任务会创建它，创建时系统给它一个固定的 **uid** 和一个绑定的固定目录。

## 它是干什么的

长周期任务里有一类**人工任务 · 内容交付**：机器做完了，但下一步必须有人把东西递进来
（一份定稿、一批配图、一个确认）才能继续。这类人工任务在主画布上就表现为一个交付节点。

### 一个端子严格对应一个文件

这是这个节点最要紧的一条：**清单里每一个还没交的文件，就是节点上的一个输入端子**。

- 端子的标签**就是那个文件名**（例：`分镜表.md`）——连到时候一眼看得出这条线喂的是哪个文件。
- 节点板身顶部有一张 **Markdown 表**，逐行写明每个端子对应的文件是什么：

  | 文件名 | 内容说明 | 必填/选填 | 格式或大小要求 | 交付状态 |
  | --- | --- | --- | --- | --- |
  | 分镜表.md | 每个镜头的景别 / 时长 / 台词 / 运镜 | 必填 | 仅 .md · ≤ 2 MB | 待交付 |

  表上方有一枚 **▤ 预览 Markdown**：点它就用**应用内的 Markdown 预览器**打开整份清单 ——
  交付目录里已经落盘的 `交付清单.md`（完整人读文档）优先；还没落盘时开的就是板身这张表本身。
  预览器自带「复制全文」，想贴给一起干活的人看，也在那个窗里取（节点上不再单设复制按钮）。
- **文件交掉之后，它对应的端子就消失**，剩下的端子按顺序往上补；已经连好的线会跟着它
  对应的那个文件走（按文件项的身份重绑），不会错指到别的文件上。
- 文本 / 选项确认类条目不占端子（它们没有文件），在条带上就地填。

### 两处都能改清单，画布优先

- 清单的初始内容来自长任务图里那个人工任务（`human.deliver.items`）；
- 你也可以直接在节点上改：点「＋ 添加文件」填**文件名 / 内容说明 / 必填选填 / 格式或大小要求**，
  每个端子后面还能「删除」；
- **改过之后以画布上的为准**：系统只往里补新增项，不会拿图里的旧清单把你的改动盖掉。
  改动会同步写回图定义、`manifest.json` 与`交付清单.md`。
- **回写的图定义就是下一次的起点**：画布侧（节点上、条带卡片上）的增删改都会回写任务图里的清单，
  所以**下次启用 / 重跑不再读旧清单**（切画布、重开画布恢复现场时也会补齐），也不会拿图里的旧条目
  把你改过的清单盖回去。只有**正在跑的这一轮**仍用启用那一刻的快照。

### 节点上显示什么

- 头部显示**交付清单进度**（`已交付 3/5`），以及一句「到条带上处理这个人工任务」。
- 若这一环是**带着没交齐的项**继续的，进度条下面会挂一条**放行横幅**：还有几项必填未交、
  是哪几项、人工写的交付说明、放行时间（逐轮记录在交付目录的《交付清单.md》「未交付说明」段）。
- 中间是上面那张 md 表；表下面是**端子行**（每行 = 一个待交付端子 + 它的上传钮与删除钮）；
  再下面是**已交区**（交过什么、从哪来的、什么时候交的），每条都能「撤回」。
- 交付目录由系统生成：`<画布工作目录>\mtnode-deliverables\<uid>\`，里面有一份
  `manifest.json`（机器读的真源）和一份`交付清单.md`（给人看的）。工作目录不可用时
  自动退回 `%APPDATA%\pipeline-console\longtask\deliver\<uid>\` 并提示一次。

## 文件怎么进来（两条路，任选）

1. **端子连线（会自动收下，不必再点按钮）**：把上游节点（文件 / 图像 / 视频 / 音频 / 保存节点）
   连到某个端子上。只要这一件**真拿得到文件**（上游已经产出、且文件在磁盘上），
   系统就会**自动**把这一项记成「已交付（连线）」、把文件复制进交付目录、让该端子消失 ——
   不需要你在条带右栏再点一次「从画布连线取」。收线在看三处发生：接线的那一刻、任务每跑完
   一步之后、打开 / 切回画布与条带每次重绘时，所以「连好线却还是待交付」不会发生。
   连了线但上游**还没产出 / 拿不到文件**时，这一项照旧待交（系统绝不凭空算已交），
   由你补交或让上游先跑完。
2. **逐个上传**：每个端子后面点「⬆ 上传」，选的就是**这个端子对应的那个文件**——
   文件名要跟端子标签对得上；对不上会红字提醒，但**照样收下**（交付是人的事，系统只提示不拦），
   选错了随时「撤回」重传。文件会被复制进上面那个固定目录，原件不动。

「格式或大小要求」也**只提示不阻止**：写了 `仅 .md · ≤ 2 MB`，传了 `.txt` 或超限会标出来，
但不会把你挡在门外。

### 没有文件名 / 没交齐也能确认交付，但要写清原因

交付以文件为单位，文件项要有一个**带后缀的文件名**（例 `分镜表.md`）。没写文件名、或只拿一句
描述充数，节点与条带卡片都会显式标**「文件名待补」**——那句描述**不会被当成文件名收下**
（端子标签、清单表第一列、上传对齐、写回状态都按这个判据）。

**必填项没交齐、或必填文件还没定下文件名时，点「确认交付完成」不再被拦住**：先弹一只确认窗，
逐条列出没交的条目（「没交」/「没定下文件名（含后缀）」）并给你一格**交付说明**——
为什么有些没交付、哪些需要额外交付（**一件都没交也允许继续**，说明也可以留空）。
窗里两个出口：**「继续任务」**放行并往下跑；**「返回补齐」**什么都不提交，说明留在草稿里，
你回去继续交。空说明不会被当成没写——交付目录里会显式记成「（未填说明）」。

放行的代价是留痕，三处同源：共享状态键 `deliver_note` / `deliver_missing`（下游读得到）、
run 里的逐轮放行记录、以及交付目录 —— `manifest.json` 的 `releases` 与《交付清单.md》的
**「未交付说明」**段（含轮次 / 时间 / 未交清单 / 你的说明）。放行过的条目在清单里标
**「未交付·已放行」**，节点板身上也会挂一条放行横幅（还有几项必填未交、说明是什么）。
交付环节**之后**的 Agent 环节会在提示词里读到这段说明。

必填项全部交付完时节点显示**就绪**，但**这一环不会自己往下走**：怎么放行只有一条路 ——
你在条带卡片上点**「确认交付完成」**（从这里往下跑）。连线交齐的件只是已经自动记为已交付
（不必再去收一次线），**收齐 ≠ 放行**。**缺件时同样由你决定**：点「确认交付完成」会先弹确认窗
把没交的条目逐条列出来、要你写清原因才放行；系统不会自己把交付判成完成，也不会因为缺件而判失败。
**撤回**只把「已交」标记去掉、端子放回来，交付目录里的文件一律不删。

重跑同一环节算**新一轮**：清单重施注入，所有端子都回来，需要重新交一遍（上一轮的文件仍在
交付目录里，可以随时回看）。


## 关于 uid

uid 形如 `lt8位编号-环节短名`，它是这个人工任务的身份：目录名、清单文件、条带卡片都靠它
对齐。**不要自己改**——改了下游就找不到交付物。

## 能不能删

- 可以删。你删掉之后，该环节会被标成「交付节点需重建」，下次跑到那一环时系统会重新建一个
  （uid 不变，目录沿用）。
- **不能复制**：右键复制、Ctrl+C / Ctrl+D、以及智能体建图都不允许复制或新建这个类型；
  它是状态机某个环节的唯一落点，复制出第二个就对不上账了。
- 长任务或 run 被删除时，交付目录只会在「交付目录体检」里被报告成无主目录，**绝不会被自动删除**。

## 看不到这个节点的类型入口？

对——节点列表、右键菜单、拖线落点候选、全局搜索的创建入口里都不会出现它。这不是遗漏：
它只能由长周期任务系统创建。要开始用，展开画布上方那条细线，新建一个长周期任务，
在里面放一个「人工任务」并把类型选成「内容交付」，然后点「启用并绑定」。
