# 数据库副本

由「数据库节点层」头部的 **⚙ 编译** 自动生成、随源库刷新；它镜像源库里的真实记录，供智能节点查询。

## 端子
- **输入**：0 个（它只作查询源，连到智能节点的输入端）。
- **输出**：1 个 = 数据库指针 / 查询结果。

## 设置
- 无设置项：本节点没有 **⚙ 设置** 窗口，内容全取自源数据库；要更新就回数据库节点层点 **⚙ 编译（增量）**（仅手动触发）。

## 用法
- 连到智能节点（智能任务，或开了智能助手的文本处理）的输入端，运行提示词会自动注入「数据库接入 · 事实强制约束」。
- 不想连线就在 prompt / task 里写 `!@数据库标题` 直接引用。

## 注意
- 一切事实必须走 **`mtnode_db`** 工具（list / get / query / write / delete / calc），每个关键断言标 `[记录id · 标题]`；查不到就答「数据库中没有该信息」，推断要标「此为推断，数据库未记载」。
- 纯文本（非智能）节点只拿到「【数据库：标题】」指针占位，不注入库内容、也不调用工具。
- 源数据库删了 → body 显示「源数据库已删除：副本失效」，本节点可删；源库没编译 → 提示回数据库节点点 **⚙ 编译**。
