# 工具节点（Agent 可调用）

把画布上的一段流程（文本处理 / 智能任务 / 函数 / 保存等任意子图）打包成 **Agent 可直接调用的工具**：给它工具名、用途描述和入出参数，会话里的模型就能像调函数一样调用，参数从端子进出，结果回传会话。

创建：右键 → **其他节点** → **工具（Agent 可调用 · 入参出参端子）**。

## 端子
- **输入**：端子 0 = 控制入（固定）+ 每个输入参数一颗
- **输出**：每个输出参数一颗（0..n-1）+ **末位控制出**（固定）
- **组**：另有 **参数** 端子（9001），是内部图的共享参数，工具内的函数节点会自动继承（自己写的同名键优先）
- 每个数据端子都带声明类型（文本 / 图像 / 视频 / 音频）；断开连线不重排、不自动增减；Agent 调用只走数据端子

## 设置
节点头部 **设置** 打开的设置窗口里改，卡片上只留名称 / 描述与入参 / 出参摘要：

- **工具名 name**：也是 Agent 的调用名；标题默认跟随它，手动改过标题后两者独立。
- **描述 description**：写清「做什么 / 何时用 / 注意什么」，Agent 据此判断是否调用。
- **输入 / 输出参数类型**：每条 = 一颗端子；出参也要声明类型，标成「图像」就是图像端子。增删参数 = 增删端子，删参数时对应连线一并失效。
- **描述自足六格**：用途、每个入参说明、每个出参说明、可选性（勾「可选」；二选一写进「至少给一个」）、调用示例（键 = 参数名的最小 JSON）、限制与失败情形。描述 / 示例 / 参数说明里可写 `{{outDir}}`，调用时替换成本机可写的用户输出目录。
- 缺格时卡片出现黄字「描述不自足（缺 …）」，只提醒，不阻挡保存与运行。

## 用法
- **内部图决定行为**：工具执行的是它的内部子图。外侧输入端子自动成为内部节点的取值来源，内部输出接回外侧输出端子；写回时按输出端子声明的类型归一（图像端子拿到路径会补成图像值）。
- **运行**：点 ▶ 先补跑上游，再按拓扑执行内部全部可运行节点，结果写回输出端子并继续下游。下游拿到什么类型看输出端子——图像端子接保存节点会自动按 `.png` 保存。批量走内部或下游节点的 batchMode（每次只处理单条）。
- **开发**：卡片下方「开发」绑定一条会话，只改这一个工具节点：可改 `toolConfig` 的 name / description / inputs / outputs，也可在工具内部增删节点与连线；动参数表会在回复里提醒你复核连线。
- **跨画布复用**：顶栏 **工具库**（按钮用的就是程序自己的图标）列出**已保存的工具 / 函数包**与**应用内置条目**（内置条目带灰徽「内置」，可插入 / 试跑，但不能改名或删除），建节点仍走上面的右键菜单。保存即存下节点 + 内部图快照；「插入」可反复克隆到任意画布；「会话随时可调用」开关（默认关）打开后，无需画布副本也能在会话里调用。

## 注意
- 描述不自足只影响 Agent 一次调对的概率，不是错误；内置工具都按六项写全，旧副本打开画布时会自动刷新描述与参数说明（个数与顺序不动）。
- 内部节点失败、或内部没有可执行节点时，工具显示 ✕ 并给原因；Agent 调用失败以错误文本回执，不中断会话。
