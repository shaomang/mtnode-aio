# 工具节点（Agent 可调用）

把画布上的一段处理流程（文本处理 / 智能任务 / 函数 / 保存等任意子图）打包成 **Agent 可直接调用的工具**：给它一个工具名、用途描述和入出参数，智能会话里的模型就能像调用函数一样调用它，参数从端子进出，结果回传会话。

工具节点 = **类超级节点的容器形态**：把要执行的处理流程作为它的**内部子图**（子节点挂在本节点下，机制与超级节点一致），点 ▶ 或 Agent 调用时按拓扑执行；配置统一存在 `toolConfig`（`name` / `description` / `inputs` / `outputs`）。

创建：画布空白处右键 → **工具** → **工具（Agent 可调用 · 入参出参端子）**。

## 设置（参数即端子）
点头部 **「设置」** 打开设置窗口（参数全部在窗里改，工具卡片上只留名称 / 描述与「入参 / 出参」只读摘要）：

- **工具名 name**：也是给 Agent 的调用名。标题默认跟随工具名；手动改过标题后两者独立。
- **描述 description**：写清楚「做什么 / 何时用 / 注意什么」——Agent 据此判断是否调用本工具。
- **输入参数类型（文本 / 图像）**：每一条 = 一个输入端子，参数名即端子名；文本端子的值是字符串，图像端子的值是 `{kind:"image", path}` 路径对象。
- **输出参数类型（文本 / 图像）**：每一条 = 一个输出端子，**出参和入参一样要声明类型**——把某个输出结果改成「图像」，它就是一条图像端子（值 = 图片路径）。

增删参数 = 增删端子；删参数时对应连线一并失效；改类型 = 改端子类型（端子会重新着色、下游按新类型取数）。
**调整参数顺序**：拖动参数行左侧的 ⠿ 把手可把该参数插到任意位置，或用行尾 ▲▼ 逐格移动——参数顺序即端子顺序，已连的数据线会跟着参数一起移位（不会漂到别的参数上）。

## 开发（绑定该工具的会话）
工具节点同样支持**「开发」**（卡片下方按钮，与函数节点同一机制）：

- 点「开发」→ 弹窗展示现状（工具名 / 描述 / 入出端子 / 内部子图 / 会话工作区），填写本次要改或扩展的内容；
- 确认后新建一条**绑定该工具**的会话并后台运行（标题「开发 · 工具名」· 工作区 = 画布目录）；
- 会话只改**这一个工具节点**：可改 `toolConfig` 的 name / description / inputs / outputs（参数即端子，动参数表要提醒你复核端子连线），也可在**工具内部**新建 / 删除 / 调整节点与连线来重建行为——工具的行为就是它的内部子图；
- 会话清单 / 左下角队列可看进度，改完点卡片再「开发」可接着上一轮要求继续迭代。

## 端子类型有什么用（用户可见收益）
端子声明的类型是**连线校验、保存选型、连线着色**的唯一依据：

- **从图像输出端子把线拖到保存节点，会自动按图像保存（扩展名自动变 `.png`）**；从文本输出端子拖过去则按文本保存（`.yaml`）。不必再手动挑「文本保存 / 图像保存」。
- 图像线只能接进图像端子、文本线只能接进文本端子；接错了会直接点名「哪个端子是什么类型、去哪儿改」，不会把图像悄悄塞进文本端子（真拿图像值喂文本端子时按路径取文本，并在节点摘要上提示一句）。
- 图像端子与图像连线单独着色，一眼看出哪条线走的是图片。

## 端子排布
- **输入**：端子 0 = 控制入（固定），之后每个输入参数一个端子。
- **输出**：每个输出参数一个端子（0..n-1），**末位 = 控制出**（固定）。
- 每个数据端子都带声明类型（文本 / 图像）；控制端子不带类型，仍按实际值判定。
- 端子固定排布：断开连线不重排、不自动增减；Agent 调用时只走数据端子，控制口不动。

## 内部图（决定工具做什么）
工具执行的是它的内部子图（子节点挂在本节点下）：

1. 准备内部子图——壳层形态（超级节点 + 工具变体）下像超级节点一样展开 / 进入内部画布编排；从工具库**插入**的工具自带内部图，展开即可查看调整。
2. 外侧输入端子（含控制入）自动作为内部节点的取值来源——接线方式与超级节点的内外侧桥接一致。
3. 内部节点的输出接回外侧输出端子（内侧汇流），运行后写回对应输出参数——值会**按该输出端子声明的类型**归一：图像端子拿到路径文本会补成图像值，文本端子拿到图像则按路径取文本（节点摘要上会提示一句，数据不丢）。外侧输出端子上的徽标 / 颜色与内侧汇流端子的提示同一口径。

## 运行
- 点 ▶（或控制 ▶ 触发）：先补跑上游，再按拓扑执行内部全部可运行节点（proc / 智能 / 函数 / 保存等，含级联），结果写回输出端子并继续执行下游。
- 工具节点整体可被下游 @ 引用 / 全局广播（文本口径照旧）；**接给下游什么类型看的是那个输出端子**：图像输出端子连到保存节点会自动按图像保存（`.png`），见上文「端子类型有什么用」。批量请走其内部或下游节点的 batchMode（batch 模式每次运行只处理单条输入）。

## 跨画布复用与「随时可调用」
顶栏 **工具库**（按钮用的就是程序自己的图标）打开的对话框**只列已保存的工具 / 函数包**，不在这里建节点（建节点走上面的右键菜单）：

- **保存到工具库**：把本节点连同内部图快照存成工具包（名称 / 描述 / 入出参数（含每个参数的类型）+ 内部图 JSON）。
- **插入**：任意画布可重复插入该工具包（克隆为新 id，内部父子与连线按新 id 重建）。
- **会话随时可调用**（默认关）：开关打开后，Agent 会话里**无需画布副本**即可直接调用本工具；画布上的工具节点默认就在可用清单里。改名 / 覆盖保存会保持同一份库记录，开关随之延续。

## 工具运行出错
内部节点失败、或内部没有可执行节点时，工具节点显示 ✕ 错误并给出原因；被 Agent 调用失败时以错误文本回执，不会中断会话。
