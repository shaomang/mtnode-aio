# Database replica

Generated by **⚙ Compile** on a database node layer and refreshed with the source; it mirrors the source's real records for agent nodes to query.

## Ports
- **In**: none (it is a query source — wire it into an agent node's input).
- **Out**: 1 = database pointer / query results.

## Settings
- No settings: there is no **⚙ settings** window here, everything comes from the source database. To refresh, go back to the database node layer and click **⚙ Compile (incremental)** (manual only).

## Usage
- Wire it into an agent node's input (Agent task, or Text process with assistant mode on); the run prompt then injects the mandatory database grounding rules.
- Or skip the wire and write `!@数据库标题` (database title) in the prompt / task.

## Notes
- Every fact must come from the **`mtnode_db`** tool (list / get / query / write / delete / calc); cite `[record-id · title]` for each key assertion; if nothing matches, answer exactly “the database has no such information”, and label inferences “inference — not in the database”.
- A plain (non-agent) node only gets a database pointer placeholder — no content is injected and no tool is called.
- Source database deleted → the body says “Source database deleted: this replica is stale, you can delete it”; source not compiled → “Not compiled yet: expand the database node and click ⚙”.
