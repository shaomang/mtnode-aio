# Splitter

![diagram](img/splitter.svg)

One in, many outs: after a pulse it fires **all** lanes at once — the parallel version of the sequencer.

## Ports
- **In**: control
- **Out**: 2–8 lanes

## Settings
- In the settings window opened by **⚙ Settings** in the node header; **Output count (2–8)**: default 3
- The node shows only a one-line summary
