# Execute node (one-click launch)

Bind an executable or any system-openable file (`.exe` / `.bat` / `.cmd` / `.lnk`, or documents / scripts) and **launch it from the canvas** in one click. No data ports — a standalone tool node.

Create: right-click empty canvas → **Dev node (project architecture · feature block)** → **Execute**; or right-click a feature block → “New Execute Node Inside” to keep the launcher inside that module.

## How to use
1. Pick the file to bind (absolute path).
2. Optional: set an icon (`execIcon`) and body color (`execColor`) to spot it fast.
3. **Double-click the node**, or **click the play button twice**, to launch it through the OS default handler.

## Ports
- **Input**: none
- **Output**: none

Great for keeping “start a local tool / open a folder / run a script” actions on the canvas next to docs and notes.
