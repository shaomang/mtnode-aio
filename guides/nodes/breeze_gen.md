# Breeze 语音生成（Breeze TTS 2）

![diagram](img/breeze_gen.svg)

画布右键 → **处理节点 › 音频生成 › Breeze 语音生成**。把文本合成成**语音**：后端是插件「Breeze TTS 2 本地 TTS」在本机拉起的管理服务（默认 `127.0.0.1:8772`）+ 官方 `breeze_infer.api` 推理引擎（`127.0.0.1:8773`，**按需拉起**）。**每次运行只生成一个音频文件**（`.wav` / `.flac` / `.mp3`），写入节点自带的 `outputPath`。**输出路径也可以留空**：把它的**数据输出**接到下游的「保存」节点，路径就归那个保存节点管 —— 产物先落**应用托管目录**（应用数据目录下的画布资产 / 临时区），再由那个保存节点落盘到你填的保存路径；数据只落你选的安装目录与 `%APPDATA%\pipeline-console`。

## 端子
- **输入**：端口 0 = 待合成文本 · 端口 1 = 参考音频（音频文件 URL）· 端口 2 = 参考文稿（文字，或音频 / 视频输入节点）· 端口 3 = 指令 instruction · 端口 4 = 控制输入
- **输出**：端口 0 = 语音音频（下游可试听 / 保存）· 端口 1 = 控制输出

## 两个文本框（卡片上直接编辑）
- **第一个框 = 待合成的文本**（端口 0）：**端口 0 有输入时这个框只读回显**，端口空着才可编辑（存节点上的 `srcText`，随节点持久化）。
- **第二个框 = 参考文稿**（端口 2）：同一条规则，**端口 2 有输入时只读回显**，端口空着才可编辑（存节点上的 `refText`）；选了音色库音色而这个框留空时，合成会用音色库自带的那份参考文本。
- 框上不写标题行、也不挂状态标签：**鼠标悬停**就能看到这个框归谁（「端子为空时，这个框里的文字就是本次要合成的内容」/「端口 0 有输入时这里只读」）。
- 这个框**只显示文字**：端口 2 接的若是音频 / 视频输入节点，显示的就是**该节点端口 1 的转写输出**（它自己转好的文字）—— 接到的是它的**音频输出口（端口 0）**时，那一路是音频本身，框里空着，绝不把那条 `file:///…` 路径当参考文字；还没转写过也是空着，节点状态行会指路「去那只音频节点点转录」。端子给的是音频 / 视频文件（音频 URL、`E:\…\ref.wav` 这类本机路径，来自保存节点 / 生成节点 / 把路径当文本给的节点都算）时，这个框**一样只读且空着**，绝不把那条路径当参考文字显示 —— 那一路音频由节点当**参考音频**取走，参考文本要另外给：在框里填，或把音频节点的**转写输出**接到端口 2。
- 两个框都是**端子优先**：接上输入的那一刻框就变只读，断开又归你改。本节点**不做转录** —— 参考文本要自己填，或从端口 2 接进来（转录在音频 / 视频输入节点上做，见它们的指南）。

## 角色（音色预设）
想固定用某个声音、又不想每次接参考音频，就用**角色预设**：一个角色 = **1 个基础音色 + N 个备选音色**，每组 = **一段参考音频 + 与它逐字一致的台词 + 一句指令 +（可选的）场景标签**。角色在**这个节点上建**：节点头部的 👤 按钮 → 角色跳窗（音频由宿主复制进数据目录，不引用你原来的文件，**换画布照样能选**）。

- **三步向导**（每步都能回头改）：
  1. **声线设定** —— 两个入口：
     - **声线设计（AI 造声线）**：只填「角色名 + 一句声线设定」（如「三十岁出头的女声，音色偏暖，语速慢」）。点「AI 优化提示词」由**默认文本模型 + 内置技能**把它扩成一句可直接用的 instruction；候选台词也由模型按声线设定现写（中文约 40~70 字 / 英文 25~45 词 ≈ 8~15 秒），每条都不一样。模型下拉可临时换（记在插件配置里，留空 = 跟随默认）。
     - **音频参考（我有现成音频）**：自己选一段音频 + 填与它**逐字一致**的台词（+ 可选指令）→ 直接存成角色。
  2. **候选挑选** —— 按你选的数量（3~6）生成候选，**每条独立随机 seed、随机 cfg（3~5）**；台词 / seed / cfg 都能手改，可单条重抽、追加一条、生成中取消（已出的候选留着）。
  3. **确认音色** —— 挑一条当**基础音色**（可填组名 / 场景），保存后直接用到这个节点。
- **后续加备选音色**：角色窗里「＋ 添加备选音色」走同一个三步向导（同角色、按场景 / 情绪重调提示词，走「音色导演」= 基础音色的音频 + 新指令），用来做生气 / 温柔 / 旁白等不同演法。
- **改一切**：角色名、声线设定、指令、每组的台词 / 组名 / 场景都能改后「保存修改」；组能删、角色能删，备选音色可「设为基础音色」。
- **选择**：节点上方菜单条里那颗 **👤** 按钮 → 角色跳窗：左边挑角色，右边逐组给出 **波形播放器**（直接试听）、台词与指令，点「**用这一组**」即生效（关窗并把角色写回节点）。
- **选好之后**：端口 1 / 2 在卡片上隐藏，也**不参与合成** —— 参考音频与台词都来自那一组；卡片上只剩「待合成文本」一个框。
- **指令**：端口 3 或节点设置里的指令**非空就覆写**那一组的指令；留空则用组里自带的那句（默认什么都不用填）。
- **能力档**：选了角色就走「音色导演」（音频 + 指令同给），设置窗里的能力 / 音色两行不再出现；`cfg_scale` / `seed` 仍可调。
- **没选角色 = 老口径**：端子优先，端子空了才用音色库，行为与以前一模一样。
- **插件控制台**只剩后端启停、日志与**手写指令的临时试听**，不再维护角色。

## 参数
点节点头部 **⚙ 设置** 打开设置窗口来改；改完即时生效，节点卡片上只显示一行当前摘要。

- **角色**：上方菜单条那颗 🎭 选的角色 / 第几组（见上一节）
- **音色**：音色库 id（安装目录 `voices/<id>/{ref.wav, ref.txt}`），留空 = 用端子给的参考音频；**选了角色时这一行与下面的能力档都不出现**
- **能力**：自动判定 / 音色克隆 / 音色设计 / 音色导演
- **指令 instruction** / **cfg_scale**（默认 4）/ **seed**（默认 42）
- **克隆模式的 cfg_scale 恒为 1.0**：引擎的克隆模板（有参考音频、没有导演指令时走的那条 `ref_clone_tata`）没有负向提示词，只接受 `cfg_scale=1.0`，别的值会被引擎直接拒绝（HTTP 500）。所以这一路节点只下发 1.0，设置窗里填的值不下发，卡片摘要行显示「cfg 1（克隆固定）」；**要调 CFG 就填一条「指令」改用音色导演**（那个模板支持负向提示词），音色设计（无参考音频）也照常支持 CFG。管理服务在收到「克隆 + cfg≠1」时会把值钳制回 1.0 并写进控制台日志，不再让整次合成失败。
- **输出格式**：`.wav` / `.flac` / `.mp3` · **输出路径**：保存位置（相对工作目录 / 节点层子文件夹）；**接了保存节点就可以留空** —— 那时路径归那个保存节点管，产物先落应用托管目录、再由它落盘（见「保存」节点指南）。没接保存节点时必填，留空点 ▶ 会提示「未设置输出路径时无法启动生成」。
- **抽卡次数**：多次尝试（1–10），取其中一次结果

- **许可**：推理代码 Apache-2.0；**模型权重、衍生模型与自托管输出受 BreezeBlue Research and Non-Commercial License 约束，仅限研究与「非商用」用途** —— Apache-2.0 不授予商用权，付费订阅只覆盖 breezeblue.ai 托管平台的输出、不覆盖自托管；禁止未授权语音克隆与冒用。
- **参考源优先级**：选了**角色**就用那一组（端口 1 / 2 不参与）；没选角色时端子的「参考音频 / 参考文本」优先，端子为空时才用节点设置里选的音色（音色库在 **插件 › Breeze TTS 2 本地 TTS** 的控制台里维护，一条 = 安装目录 `voices/<id>/` 下的参考音频 + 文稿；旧音色首次打开控制台会自动迁成单组角色，原目录保留）；**参考音频两个口都认** —— 端口 1（音频文件 URL）与端口 2（音频 / 视频输入节点，取它自己的音频文件），两边都接了就取端口 1；**给了参考音频就必须同时给参考文本**（官方接口要求成对：在「参考文本」框里填，或把音频节点的**转写输出**接到端口 2 —— 音频节点还没转录就先去它上面点「转录」），否则节点在本地拦下并给明确指路，不白跑一趟引擎。节点状态行会写明本次实际用了哪个源。
- **三种能力（官方口径）**：有参考音频且无 instruction = **音色克隆**；有 instruction = **音色导演**；无参考音频 = **音色设计**。
- **mp3 需要 ffmpeg**：wav / flac 由 soundfile 封装，mp3 走安装目录 `tools/ffmpeg/`（安装脚本会下便携 ffmpeg）；缺失时节点给明确中文指路，建议改用 wav / flac。
- 与音乐 / 视频走同一条**串行链**（同一时刻只跑一个生成任务）**并持全局音视频互斥锁** —— 引擎 eager 就要约 7.7GB 显存，会和音乐 / 视频抢显存；本机只有这一个语音后端，不持锁的独立语音进程（SoVITS / `tts_gen`）已随该插件移除。
- 需要 **NVIDIA GPU，12GB 显存起步**（eager 约 7.7GB）；Windows 原生可跑（官方 README 只写 Linux，本插件走默认 eager 路径，不启用 CUDA Graph fast 路径）。
- **后端常驻**：管理服务与引擎是常驻单例，**不随 MTNode 退出**，关掉控制台窗也不影响后端；要停服务 / 释放显存，点插件卡片主按钮「**停止**」（会连托盘一起退），或用托盘菜单「**停止服务并退出**」。卡片上那颗「**控制台**」只是显式打开控制台窗；后端状态与日志点**封面右上角那颗 ⓘ**（卡片本体不再响应点击）就能在内嵌只读 console 里看（后端主动求助不再自动弹窗）。
- **后端报错会弹窗**：装坏 / 跑挂时主窗口会弹一份**错误报告**（错误码、错误正文、console 日志尾部、出问题的节点），并问你要不要「**🤖 自动修复**」——新建一条你看得见的会话，按安装技能 `breeze-tts-local-install` 的【自我修复】模式在**本插件的 INSTALL_DIR** 里修，修好后**自动重启后端**并刷新本节点状态。主动取消、正在安装中、磁盘不够、没 N 卡、驱动太旧、安装目录不合法这几类**只报告不自动修**（详见手册「插件报错弹窗与自动修复」）。
