# FLUX 3 Image Klein（本机图像生成 / 编辑）

画布右键 → **处理节点 › 图像生成 › FLUX 3 Image Klein**（节点类型 `flux3klein_gen`，插件 id `flux3-klein-local`）。
本机独立 ComfyUI 后端（默认端口 **8197**），官方 **FLUX 3 Image Klein 5.6B 蒸馏**权重，两档精度：**INT8**（默认）与 **BF16**。

能力对齐云端「图像生成」节点（`proc_image`）：**文生图 · 多参考图编辑（≤10 张）· 蒙版重绘 · 抽卡 / 种子 · 比例桶 · 透明背景**。
不支持的功能已按共识移除：没有「输出路径」（产物落应用托管目录，路径交给下游保存节点）、没有补边 / 画幅锁定、没有联网参考图 URL。

## 端子
- **输入**：端口 0 = **提示词**（文本，可接文本节点）· 端口 1 = **参考图**（图像，**可多接**，最多 10 张）· 端口 2 = **控制输入**
- **输出**：端口 0 = **图像**（`save_image` / 图像预览 / @ 引用直接复用）· 端口 1 = 控制输出

## 三种用法
1. **文生图**：提示词直接写在节点 body（或接文本节点），不接参考图 → 只跑文生图。
2. **参考图编辑**：接 1–10 张参考图 + 写「要改什么」（例：把天空换成黄昏，其余保持不变）→ 走官方编辑路径
   （`ModelSamplingFlux` 编辑档 + `ReferenceMultiLatent` 多参考）；参考图会先缩放到节点「比例」参数对应的尺寸，输出**跟比例参数一致**。
   蒙版重绘时输出跟随第 1 张参考图尺寸（同尺寸才做像素回贴）。
3. **蒙版重绘**：节点头部蒙版按钮打开编辑器（涂抹 = 只重画这一块）→ 未涂抹处尽量保持原图。
   蒙版底图取**端口 1 的第 1 张参考图**，所以蒙版用法必须先连一张参考图。

## 参数（⚙ 设置）
- **比例**：`1:1` 1024² · `16:9` 1344×768 · `3:2` 1248×832 · `4:3` 1152×896 · `2:3` 832×1248 · `3:4` 896×1152 · `9:16` 768×1344（长边 1024，全部是 16 的倍数）。
- **精度**：`INT8 蒸馏`（5.6GB 扩散 + 4.9GB 文本编码器，8G 卡起）· `BF16`（11.1GB + 8.9GB，建议 24G 卡，细节更好）。
  两档权重可同时装在机器上，切换只换加载的文件。
- **采样步数**：默认 **16**（蒸馏档），CFG **1.0**，采样器 `euler` + `simple`。
- **种子 / 抽卡（每次执行种子 +1）**：抽卡 N 次 = N 张图；开透明背景时 = **2N 张**（双通道）。
- **透明背景**：Flux 没有「直出 Alpha」参数，走**两遍差分**（先黑底出基准 → 再把基准当唯一参考图、换成纯白 → 两图像素差分出 Alpha），
  另有「抠图噪点地板 / 边缘羽化 / 自动对齐两通道」三个旋钮。它适合**主体清晰、背景干净**的画面；复杂背景会有毛边。

## 运行口径
- **全局同一时刻只允许 1 个音视频 / 图像生成任务**：与音乐、语音、视频、SenseNova、InfiniteTalk、SoulX 节点共用一把媒体大锁；抢不到锁时状态行会写明被谁占着。
- 点 ▶ 会自动拉起后端（ComfyUI），**跑完不自动关**（下次直接复用；也可在控制台手动停止）。
- 安装建议预留 **≥40GB** 磁盘（ComfyUI + CUDA torch + 两档权重；只装 INT8 可省约 19GB）。
- 显存：INT8 在 **8GB** 卡上可用（1:1 / 1024²）；BF16 与 2048 长边建议 **24GB**。装不下时把精度切回 INT8 / 降比例桶。
- 卸载插件**不删**已生成的图（图在画布资产目录里，自己清理）。

## 排错
- 节点 body 顶部出现「插件未安装」警示条 → 到「插件 · FLUX 3 Image Klein」里设安装目录并点安装。
- 生成失败会给出错误码 + 后端日志尾部，并弹「自动修复」入口；主动取消 / 正在安装 / 没有 N 卡不自动修。
- 控制台（插件卡片「控制台」）里有状态、显存读数、安装与生成日志、试生成，问题现象先看那里。
