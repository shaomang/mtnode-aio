# 网络 · 接收

监听指定 `host:port` 的通道（TCP / UDP），收到文本后**异步转发**给下游——是异步数据源，没有数据输入。

## 端子
- **输入**：无
- **输出**：端口 0 = 数据（收到的文本）· 端口 1 = 控制（收到消息时脉冲）

## 设置
协议 / 端口 / 通道 / 启动即监听都在节点头部 **⚙ 设置** 打开的设置窗口里改（改端口 / 通道 / 协议会自动重启监听）；「开始监听 / 停止 / 清空 / netdebug」是动作按钮，留在节点上，节点里只显示一行当前设置摘要。

## 参数
- **协议**：TCP / UDP
- **通道**：同一端口上按通道号（0–65535）多路复用；`net_send` 发往同通道即被本节点收到
- **主机 / 端口**：默认端口取全局设置（设置 · 网络，默认 40999），可逐节点覆盖
- **自动监听**：默认随工作流启动自动进入监听态

## 典型用法
两台机器 / 两个画布互通：一处 `net_send` 推送到 `主机:端口`，另一处 `net_recv` 同通道接收后接处理节点。
