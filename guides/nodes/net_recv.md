# 网络 · 接收

监听一个 `主机:端口` 通道（TCP / UDP），一收到文本就往下游送，并能同时触发控制线；它不接上游数据，是纯数据源。

## 端子
- **输入**：无
- **输出**：端口 0 = 信息（收到的文本）· 端口 1 = 控制（每收到一条脉冲一次）

## 设置
- 在节点头部 **⚙ 设置** 打开的设置窗口里改：
- **监听端口**：0–65535，新建时 40999；填 0 = 用全局端口（设置 · 网络，默认 40999）
- **通道号（16bit）**：0–65535；同一端口按通道分流，`net_send` 发到同一通道才收得到
- **协议**：TCP / UDP（默认 TCP）
- **启动时自动监听**：默认开；打开 MTNode 或切回本画布就自动监听
- 改端口 / 通道 / 协议会立刻重启监听；卡片上留「▶ 开始监听 / ■ 停止监听 / 清空 / netdebug」动作与一行当前设置摘要

## 用法
- 开着自动监听就不用点：对端 `net_send` 一发，这里存下文本、顺着数据线静默跑下游，并从控制端口 1 触发控制连线

## 注意
- 收的是 MTNode 自己的帧（2 字节通道 + 4 字节长度 + UTF-8 正文），裸文本发不进来
- 端口被别的程序占了会「监听失败」并在节点里给原因；同一端口同一协议的多颗接收节点共用一份监听，靠通道号区分
- 通道号和协议两样都得对上，只对上一样收不到
