# 图像生成

![diagram](img/proc_image.svg)

按提示词生成图像。可接文本或图像输入；支持尺寸、质量 / 背景直传参数、透明背景、蒙版局部重绘、与首参考图保持一致长宽比（画幅锁定）等。

## 设置
**服务商 / 模型 / 尺寸 / 质量 / 背景**在节点头部 **⚙ 设置** 打开的设置窗口里改，改完即时生效；节点卡片上只显示一行当前摘要（服务商 / 模型 / 尺寸，另加你显式设过的质量 / 背景 / 蒙版）。头部 **◈** 是预览（看运行时真正发出去的请求），与设置窗口分开放。提示词属于内容，仍写在节点里。

## 质量 Quality / 背景 Background（gpt-image-2 直传参数）
两项都在 **⚙ 设置** 里选，默认「不传」（交给服务商按 auto 处理）：

- **Quality**：`low` / `medium` / `high` / `xhigh` / `max` / `auto`，只接受这六个官方枚举值。旧版 DALL·E 的 `standard` / `hd` 不要用——不同渠道下会 400 或**被静默忽略按 auto 计费**。
- **Background**：`transparent`（透明）/ `opaque`（不透明）/ `auto`，默认不传。
  - 选 **透明** 时：请求带 `background=transparent` 并强制 `output_format=png`，接口**直出带 Alpha 通道的 PNG**。同时运行会在提示词末尾自动补一段「背景必须是真透明通道」的要求（成对 ASCII 标记包裹，重跑不会越叠越长），并**禁用头部的差分透明算法按钮**——接口已经给透明了，再跑双通道差分纯属多花 2 倍 Token。
  - 注意：编辑接口的透明是「**重绘去背**」，不是精确抠像（主体边缘可能有背景残渣）。要像素级抠图，把背景改回「默认 / 不透明」，再用下面的**双通道差分抠图**。
  - 与**差分抠图**互斥：背景选透明会自动关掉差分抠图，其按钮置灰不可点（工具提示写明怎么恢复）。

## 蒙版局部重绘
标题栏的**蒙版小按钮**（方框 + 涂抹 + 透明圆）默认关闭。

- **单击 = 开 / 关**：首次开启（还没有蒙版）会直接打开**蒙版编辑器**，涂抹并「确定并启用」后开关自动打开；已有蒙版时单击直接开关（不会重复画）。
- **右键 = 打开蒙版编辑器**（随时重画 / 微调）。
- 编辑器**近乎全屏**，右下角可拖拽调整大小（最小宽度 ≥50vw）。工具：**画笔**（左键涂抹、按住右键抹除）、**方形**、**圆形**（左键拖出区域，右键拖 = 从标记里减去）、**撤销**、**清空**、**画笔尺寸**、**羽化半径**；**Esc** 或 ✕ / 取消关闭，**确定并启用**才写回节点。
- 涂抹过的地方显示为**透明绿**——它对应服务端的 Alpha 语义：**透明区域 = 允许模型重绘，不透明区域 = 尽量保留原图**（参考 [蒙版局部重绘指南](https://docs.apiyi.com/api-capabilities/gpt-image-2/mask-editing)）。导出时程序把涂抹区抠成透明、其余填满不透明，所以你不必理解 Alpha。羽化半径作为模糊作用在边缘上，让接缝更自然。
- 运行时会发送 **image + mask + prompt**（`/images/edits`）：
  - `mask` **只对第 1 张 image 生效**，且必须与原图**同尺寸**（编辑器就是按首张输入图的原始像素画的，程序按同一缩放口径下发，不会错位）。
  - **出图画幅跟着首张参考图的像素尺寸走**：带蒙版时程序把请求里的 `size` 钉成首张图的像素尺寸（命中接口自定义尺寸约束就原样，否则退回 `auto`），**节点自己选的尺寸这一轮不生效**。服务端按 `size` 出图，`size` 一旦与蒙版像素不一致，它会先把输入图重排 / 缩放，蒙版按原图像素画出的空间对应关系立刻失效——实测表现就是「蒙版没生效」：整张主体被重绘。想换画幅请先关蒙版。
  - 因此**必须连入图像输入**：首张图即蒙版背景。没连图就开启会提示，运行会直接报错。
  - 服务商须为 **OpenAI 兼容图像服务商**（gpt-image-2 的 `/images/edits`）；其它类型运行会报错说明。
  - 提示词只写「要改成什么」，例如：`仅修改蒙版透明区域，把涂抹区域里的水杯换成一束白色郁金香，其他区域保持不变，保持原有光线、视角与摄影风格。`
  - 蒙版**不是硬裁剪**：官方口径是「基于提示词的引导式编辑」，蒙版外的阴影 / 光照可能联动，蒙版边界附近有过渡。把标记比目标物体**稍微放大一圈**（覆盖边缘、阴影）更稳。
- 与**画幅锁定**同时开启时**以蒙版为准**（补边会改写第 1 张参考图，蒙版就与原图错位），运行会跳过补边并在 **◈ 预览**里写明。
- **◈ 预览**里能看到 `mask` 字段（就是蒙版文件的**纯路径**，与 `image` 一样不做任何包装）与上面的说明。
- **◈ 预览 = 真正下发的输入**：`/images/edits` 这类 multipart 请求，预览逐条列出**实际要发出去的表单字段**（字段名 · 文件名 · 实际像素尺寸 · 字节数 · 纯路径），用的是与真正发请求同一份分片实现；不再打印内部的 `{ __multipart: … }` 伪 JSON（那份里的 image / mask 只是本地路径数组，字段名与文件名跟线上对不上，容易被误读成「路径不对 / 蒙版没传」）。非 multipart 请求（文本 / 文生图）照旧按 JSON 原样回显。

## 透明背景（双通道差分抠图）
标题栏的**透明开关**（灰白格小方块）默认关闭。

- **单击**开 / 关；开启后按钮不再显示图标，改为一圈**旋转的彩虹边缘**动效。
- 开启后每次生成实际会出 **2 张图**（纯黑基准 + 纯白复刻），Token 与耗时约 **2 倍**，请慎用。
- 工序（顺序不可颠倒；全程在内部完成，你只需正常写提示词）：
  1. **第 1 通道（基准）· 纯黑背景**：程序在提示词末尾自动注入「背景必须是均匀纯黑 #000000」并生成。这一张是整套抠图的**唯一基准**，也是最终前景色的权威，请按成品标准画好主体；
  2. **第 2 通道 · 纯白背景**：自动剥掉黑底注入段、换上「除背景颜色外与参考图逐像素完全一致」的纯白 #FFFFFF 注入段，并把**第 1 通道那张原图当唯一参考图**下发——你原本的参考图不再混进来（同时收到两张语义冲突的图，模型会照原参考图重画，第 2 通道就跟基准对不上）。这张基准图**按原尺寸下发，不走普通参考图的 1080 缩放**（压小再让模型放大 = 主体尺度必漂），请求尺寸也钉成基准图实际像素对应的档位，保证两通道**同宽同高**；
  3. 两图按 `α = (bgRange − 白 + 黑) / bgRange` 逐像素解出 Alpha，`bgRange` 是两张图上**实测**到的背景色差（模型交的常常是 250 / 8 这种伪黑白，按理想 255 / 0 硬算会给整幅画蒙上一层薄雾）；再做前景包围盒对齐、边缘羽化与非预乘还原，输出带透明通道的 PNG。
- **只有能把基准图当参考图下发的服务商（OpenAI 兼容 / Stability 生图）才会抠图**；其余服务商**显式跳过**并提示原因，本次只交付第 1 通道（纯黑背景）这一张，**不会另画一张凑数**——两张独立生成的图必然错位，差分在不一致处给出中间 Alpha，画面上就是满屏虚影。
- 与色键抠图不同：**白色或黑色的主体不会被误抠掉**，半透明边缘（发丝、运动模糊、玻璃）也能保留真实 Alpha。
- **右键**该开关打开参数面板：噪点地板（压掉生图噪声）、边缘羽化（只平滑 Alpha 通道）、自动对齐修正（按前景包围盒与边缘吻合度对齐第 2 通道），以及「用已存的两通道重算抠图」（改参数后不必再花一次 Token）。
- 第 2 通道失败时不会中断流程：交付第 1 通道（纯黑背景）原图并提示原因。
- **◈ 预览**给出第 1 通道（纯黑背景 · 唯一基准）请求，并写明运行时会补发第 2 通道严格复刻；该服务商无法锚定时，预览会直接写明「运行时将跳过抠图」。
- 预览区在开启后自动垫上灰白格，便于检查透明边缘。

## 与首参考图保持一致长宽比（画幅锁定）
标题栏的**画幅锁定开关**（虚线画幅里嵌一块小图的按钮）默认关闭，单击开 / 关，**右键**打开补边参数。目的是「出的图能和参考图对得齐」——换背景、改材质、局部重绘这类活儿最常用。

开启后每次生成自动做三件事（提示词照常写，不必自己算尺寸）：

1. **复制并补边**：把**第 1 张参考图**等比缩放（不拉伸、不裁切）居中贴进目标画幅，四周补出一圈填充带，写一份临时副本；原参考图文件只读，不改写。
2. **拿副本去生图**：请求尺寸钉成目标画幅，并在提示词末尾自动追加一段「填充区是可自由延展的缓冲区、主体不得移动缩放」的说明（成对 ASCII 标记，重跑不会越叠越长）。
3. **出图后裁回**：按同一矩形把补边带裁掉，输出的长宽比 = 首参考图长宽比；服务商把图出成别的分辨率时，矩形按比例映射，依旧裁得准。

要点：

- **必须连入至少一张参考图**，纯文生图时自动跳过（会提示原因，不会报错中断）。
- 参考图比例本来就等于某一档画幅时**不补边也不裁回**，不产生多余文件。
- **不多花一次出图**（与透明背景那种双通道不同），只多一次本地读写。
- 右键面板里可选：目标画幅（**自动**挑最贴近参考图比例的档位 / **跟随节点「尺寸」**）、补边填充方式（边缘延展 / 镜像翻转 / 纯白 / 纯黑 / 自定义色）、以及「**输出还原为参考图的原始像素尺寸**」（默认关：保留生图分辨率，只保证长宽比一致）。
- 与**透明背景**可同时开：先按补边画幅做双通道抠图，最后统一裁回。
- 裁回失败时退回整幅原图并提示，绝不把已经花钱出的图丢掉。
- **◈ 预览**里会写明「补边到哪个画幅、裁回哪个矩形」，发请求前先确认一遍。
