# 网络 · 发送

把数据输入端的文本推送到目标 `host:port` 的通道（TCP / UDP）。末端节点，没有输出。

## 端子
- **输入**：端口 0 = 数据（要发送的文本）· 端口 1 = 控制输入（触发发送）
- **输出**：无

## 设置
目标地址 / 端口 / 通道 / 协议都在节点头部 **⚙ 设置** 打开的设置窗口里改；「发送 / 清空 / netdebug」是动作按钮，留在节点上，节点里只显示一行当前设置摘要。

## 参数
- **协议**：TCP / UDP
- **通道**：同一端口上按通道号（0–65535）多路复用；对端 `net_recv` 监听同通道即可收到
- **主机 / 端口**：目标地址；端口 0 表示用全局默认（设置 · 网络，默认 41000）

## 典型用法
与「网络 · 接收」配对做跨画布 / 跨机器文本通道：处理节点 → `net_send` →（网络）→ `net_recv` → 下游。
