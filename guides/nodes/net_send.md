# 网络 · 发送

把上游给的文本按帧推到 `主机:端口` 的某个通道（TCP / UDP）；末端节点，没有输出。

## 端子
- **输入**：端口 0 = 信息（要发的文本）· 端口 1 = 控制（触发发送）
- **输出**：无

## 设置
- 在节点头部 **⚙ 设置** 打开的设置窗口里改：
- **目标地址**：默认 127.0.0.1，可填远端 IP
- **目标端口**：0–65535，新建时 41000（与监听端口分开，便于同机双向调试）；填 0 = 用全局端口（设置 · 网络，默认 40999）
- **通道号（16bit）**：0–65535；对端 `net_recv` 监听同一通道才收得到
- **协议**：TCP / UDP（默认 TCP），要和对端一致
- 卡片上留「▶ 发送 / 清空计数 / netdebug」动作与一行当前设置摘要

## 用法
- 端口 0 接上游（文本 / 素材），点「▶ 发送」或由端口 1 的控制线触发

## 注意
- 端口 0 没接上游会报「未连接信息输入」，上游内容为空也不发
- 发的是 MTNode 自己的帧（2 字节通道 + 4 字节长度 + UTF-8 正文），不是裸文本
- TCP 连不上对端时，约 4 秒后报「发送超时」
