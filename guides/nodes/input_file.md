# 文件节点（批量导入任意文件）

只在数据库节点层内部用：把任意文件批量导入数据库子文件夹，供「表」节点读取建表。

## 端子
- **输入**：1 个数据端子 + 末位控制端子（内容来自导入的文件，一般不接线）
- **输出**：1 个 = 文件信息（文件清单 / 内容），供表节点或智能节点使用

## 设置
- 没有 ⚙ 设置窗：添加与清空在板身上；编译在数据库节点头部 **⚙**。

## 用法
- 展开数据库节点层，在里面右键 →「文件节点」（内部菜单只有「文件节点」和「表」）。
- 点「＋ 添加文件」多选，或把文件拖到节点上；文件复制进数据库子文件夹（默认 `db/`），原文件不动。
- 到「表」节点选文件建表，或点数据库节点头部 **⚙ 编译** 入库。

## 注意
- 节点层没设工作目录 / 子文件夹时，导入会提示失败。
- 「清空」只清节点里的清单，已复制进子文件夹的文件不删。
