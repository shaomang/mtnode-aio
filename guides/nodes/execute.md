# 执行节点（一键启动）

绑定一个可执行文件或任意可被系统打开的文件（`.exe` / `.bat` / `.cmd` / `.lnk`，或文档 / 脚本等），在画布上**一键启动**。没有数据端子，是独立工具节点。

创建：画布空白右键 → **开发节点（项目架构 · 功能块）** → **执行**；或在开发功能块上右键 →「在内部新建执行节点（启动器）」，把启动器直接放进该模块。

## 用法
1. 节点上选择要绑定的文件（绝对路径）。
2. 可选：设置图标（`execIcon`）与主题色（`execColor`）便于在画布上快速定位。
3. **双击节点**，或**连点两下播放键**即可运行（通过系统默认方式打开 / 启动）。

## 端子
- **输入**：无
- **输出**：无

适合把「启动本地工具 / 打开目录 / 运行脚本」这类高频动作放进画布，和文档、流程说明放在一起。
