# 执行节点（一键启动）

绑定一个可执行文件或任意系统可打开的文件（`.exe` / `.bat` / `.cmd` / `.lnk`，或文档 / 脚本），在画布上**一键启动**。没有数据端子，是独立工具节点。

创建：画布空白右键 → **开发节点（项目架构 · 功能块）** → **执行**；或在功能块上右键 →「在内部新建执行节点（启动器）」，把启动器放进该模块。

## 端子
- **输入**：无
- **输出**：无

## 设置
没有 **⚙ 设置** 窗口，全部在节点卡片上操作：

- **绑定可执行文件…**：选要绑定的文件（绝对路径）。
- **更换图标…**：默认「默认」启动器图标，可选火箭 / 齿轮 / 终端 / 播放 / 闪电 / 扳手 / 文件夹 / 文件 / 电源等。
- **更换颜色…**：默认无色，可选青绿 / 蓝 / 紫 / 橙 / 红 / 粉 / 绿 / 棕 / 灰蓝，改变卡片底色便于定位。

## 用法
1. 绑定文件；没绑定时点执行会提示「先绑定可执行文件」。
2. **点一下播放键**即可运行（也可**双击节点**）—— 走系统默认方式打开 / 启动，一次点击就执行，不用点第二下。

## 注意
- 只认绑定那一刻的路径：文件被移走 / 删掉会报「文件不存在」。
- 不参与运行：执行引擎不会跑到它，也不能被连线喂数据。
- 适合把「启动本地工具 / 打开目录 / 运行脚本」这类高频动作放进画布，和文档、流程说明放在一起。
