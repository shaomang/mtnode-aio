# 产出节点（ltout）

长周期任务留下的**可编辑产出落点**：每个环节生成的信息与文件内容都会同步写进这颗节点，不用等整件事跑完。它不是手动加的 —— 只有启用中的长周期任务在环节跑出东西时创建它（标题形如 `产出 · 起草`），并放进**该环节的节点层子壳**里（壳被删过就回落主画布层）。

## 端子
- **输入**：没有。
- **输出**：没有。它不参与连线，是给人看、给人改的落点。

## 设置
- 没有 ⚙ 设置窗口：能改的就是正文本身 —— 板身上直接改，或点节点头部的 **✎** 用内置 Markdown 编辑器改，保存即写回节点。
- 正文下方是只读的文件引用清单：这一环落盘的文件（文件名 + 大小，鼠标悬停看全路径）。

## 用法
- 边跑边看这一环的产出；觉得不对就直接改正文。
- 改完不用通知谁：后续环节会用你改后的内容继续。

## 注意
- 你改的内容算数：正文变了、或文件被动过（时间 / 大小对不上）→ 后续环节用改后的内容，不拿旧版盖回去。
- 核对不上（产出节点被删、文件读不到、这一环还没登记过产出）→ 条带上出现「产出判不准，请确认」人工卡，答完并确认才接着跑。
- 一个环节只有一颗产出节点：重跑 / 回跳都复用它（按 `ltTaskUid + ltPath` 认人），删了下次跑到会补回来。
- 不能复制、也不能手动新建（右键、复制粘贴、模板、全局搜索、智能体建图都拒绝）；建它不进撤销栈。
