# 产出节点（ltout）

长周期任务留下的**可编辑产出落点**。它不是给你手动添加的：只有启用中的长周期任务
会在环节跑出东西时创建它——创建时系统把它和「哪个任务、哪个环节」绑死（标题形如 `产出 · 起草`），
并把它放进**该环节的超级节点子壳**里（见 `super.md`：每条长任务在主画布上有一颗
「长任务 · <任务名>」壳，每个环节在壳内占一颗子壳，**任务创建时壳就已摆好**；壳被删过就回落主画布层）。

## 它是干什么的

长任务跑到一半，**每个环节生成的信息与文件内容都会同步写进这颗节点**：不用等整件事跑完，
你随时能在画布上查阅。这解决了「跑了两小时，只能干等」的问题——过程产出一直摆在你眼前。

## 怎么改、改了会怎样

- **正文可直接编辑**：在节点板身上直接改，或点节点头部的 **✎** 用内置 Markdown 编辑器改
  （保存即写回节点）。
- **节点下方是只读的文件引用清单**：这个环节落盘的文件（文件名 + 大小，鼠标悬停看全路径）。
- **你改的内容算数**：后续环节接着跑之前会核对产出有没有被你改过——
  - 正文变了、或文件被改动（时间 / 大小对不上）→ **后续环节会用你改后的内容**继续，不拿旧版覆盖你；
  - 一切对得上 → 照常往下跑；
  - **核对不上**（产出节点被删了、文件读不到、这一环还没登记过产出）→ 系统不猜：条带上出现一张
    「产出判不准，请确认」的人工卡，你答完并点确认它才接着跑。

## 关于身份与去重

一个环节只有一颗产出节点：重跑 / 回跳都复用它（靠 `ltTaskUid + ltPath` 认人），
你把它删了、下次跑到那一环会按同一身份补回来。产出节点与画布一起存盘，关掉应用再打开还在。

## 能不能删、能不能复制

- **可以删**：下次跑到那个环节会补回来（节点正文会重新写成最新产出）。
- **不能复制、也不能手动新建**：右键菜单、复制 / 粘贴、模板、全局搜索、智能体建图都不允许创建
  或复制这个类型；它只能由长周期任务系统创建，建它时**不进撤销栈**（在画布上按 Ctrl+Z 不会把它撤掉）。
- 它没有输入 / 输出端子，不参与连线——它是给人看、给人改的落点，不是流水线里的一环。

## 看不到这个节点的类型入口？

对——这不是遗漏：它和交付节点一样只由长周期任务系统创建。要开始用，展开画布上方那条细线，
新建一个长周期任务（**创建即显示，不必先启用**）：对应的超级节点父壳与各环节子壳在创建时就已经摆在画布上，
跑到有产出的环节时，产出节点就出现在那一环的子壳里（壳被删过的话，系统会按任务身份当场补建）。
