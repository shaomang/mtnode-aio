# 素材节点（绑定素材库 · 内容条目即端子）

**素材节点**是画布通向**素材库**的那道门：它绑定素材库里的一个「素材」，把这个素材打包的每一份内容变成节点上**一对端子**（左边连进＝写回这条内容，右边输出＝读出这条内容）。

节点上**不存内容**，只存「绑定」。所以：

- **改内容＝改库**：在节点里编辑文本、更换图像，改的就是素材库里那一份，所有引用它的画布一起跟着变。
- **删画布不丢**：删掉节点、删掉整张画布，素材库里的文件一行都不会少。

创建：画布空白处右键 → **输入节点 → 素材节点（绑定素材库 · 内容条目即端子）**；或在顶栏「**素材库**」里对着素材卡片点 **插入到画布**。

## 三种状态

| 状态 | 什么时候 | 能做什么 |
|---|---|---|
| **未绑定** | 刚建出来的空节点 | 点 **绑定…** 从库里挑一个素材；点 **上传…** 选本机一个文件夹整体收进库并绑定；点 **打开素材库** |
| **正常** | 已绑定且库里找得到 | 逐条看内容、就地编辑、点 ⟳ 同步、点 ⚙ 设置 |
| **素材失联** | 素材在库里被删了，或素材库根目录换过 | **端子与连线原样保留**（不清空、不甩线）：点 **重新绑定…** 接另一个素材，或找回素材夹 / 换回原根目录后点 **重新扫描** 自动接上 |

节点**永远不会被自动删除**——失联只是「暂时读不到」，把库接回来就复原。

## 端子：一条内容 = 一对端子

- 端子名就是**内容标题**，端子顺序就是素材设置里的**内容顺序**。
- 第 i 个输入端子和第 i 个输出端子是**同一条内容**：从左边连进去的东西写进这条内容，右边输出这条内容。
- **类型必须对得上**：文本端子只收文本来源，图像端子只收图像来源（音频、视频同理）。接错了会点名是哪条线、哪个端子、去哪儿改。
- 一个输入端子**只挂一条线**；要接别的内容，请另加一条内容条目（或先把线挪到别的端子）。
- 素材节点是**纯内容源**：没有控制端子，不吃 ▶ 控制线，也不参与批量 / 聚合。

### 各类型输出什么

| 内容类型 | 输出值 | 能直接连去哪儿 |
|---|---|---|
| 文本 | 字符串 | 文本处理、智能任务、保存·文本 |
| 图像 | 该文件的 `file:///` URL | 图像生成（参考图）、保存·图像 |
| 音频 | 该文件的 `file:///` URL | 音乐生成、语音合成的参考音频、保存·音频 |
| 视频 | 该文件的 `file:///` URL | 视频生成参考、保存·视频 |

下游节点会把接进来的这份内容当作**已连接的输入**自动带上（与输入节点连进来时同一机制）。

把素材**单个内容端子**连进输入节点（文本 / 图像 / 音频 / 视频）时，该输入节点只继承、展示、转发**这一条**内容（与直接读到这条内容等价），素材的**其它条目不会跟着整份带进来**。

库里那条内容还没读到（首次打开、失联、文件缺失）时，端子按「**没有输入**」处理——不猜旧值，读到后自动接上。

## 在节点上直接改内容

- **文本**：就地输入，**离开输入框（失焦）才写进库**——库是全应用共享的，不能每个键落一次盘。不想手打就点下面的 **选择文本 / 更换文本**，从本机挑一个 `.txt` / `.md` / `.json` 等纯文本文件，正文整份读进来顶掉这条（旧那份自动留进版本目录）。
- **图像 / 音频 / 视频**：**选择/更换** 该类型 = 从本机挑一个文件**复制进库**（旧那份自动留进版本目录）；**在文件夹中显示** = 跳到资源管理器看实体文件。
- 文本条目在库里**恒为 `.txt`**：源文件叫 `.md` / `.yaml` 也一样，只取正文内容，扩展名不跟着漂。单个文本文件上限 **16 MB**（撤销回滚要把整份内容搬进搬出，超限直接拒绝并说明）。
- 内容条目多时，节点 body 内部**可以下拉滚动**，一条一行、按顺序排列。
- 每条内容上方的 **⟳** 是同步按钮（见下）。

## ⟳ 同步：把画布产出写回库

把某个节点的输出连到素材节点的**输入端子**上，就有两种行为：

1. **库里这条还空着** → 运行到这一步**自动写进库**，并提示「n 条已自动同步（Ctrl+Z 可撤销）」。
2. **库里这条已经有内容** → 只有当连进来的和库里那份**不是同一份**（主进程按字节比对）时，**⟳ 才亮起**；**点一下才更换**，不点绝不动库里那份。

也就是说：跑流程不会悄悄覆盖你攒了很久的素材，但空着的位置会被自动填上。

## 撤销会连素材库一起回滚

任何一次写库（编辑文本、更换文件、点 ⟳、自动同步）之前，应用都会把**库里被覆盖的那份**留进该素材的 `.versions` 目录（每条内容保留最近 5 份），并把这笔账记在撤销快照上：

- **Ctrl+Z**：画布复原 **＋ 库文件贴回旧内容**（提示「素材库内容已回滚 n 项」）。
- **Ctrl+Y**：再回到新内容。
- 万一某项回滚失败（文件被占用等），提示会告诉你旧内容仍在那个素材的 `.versions` 目录里，可手工找回。

## 设置（⚙）：改名称、加内容、排序、删条目

点节点头部 **⚙**（或素材库卡片上的 **设置**）打开**素材设置**：

- **显示名称 / 描述**：只影响库里的这个素材。
- **＋ 文本**：两条路并列 —— **上传本机文本文件…（可多选）** 直接挑 `.txt` / `.md` / `.json` 等文件入库（每个文件一条内容），或 **手写一条空正文…** 开表单（表单里也有一颗 **上传文件…**，选完正文填进框里、还能接着改）。**＋ 图像 / ＋ 音频 / ＋ 视频**：从本机选文件复制入库（可多选），每个文件一条内容。
- 每行＝**⠿ 把手**（拖到任意位置重排）· **▲▼**（逐格移动）· **端子名**（＝端子标题）· 类型 · `⇄n` 当前端子号 · 库内文件名 · **编辑文本 / 上传文件 / 更换文件** · **✕ 删除**。
- **改标题**＝改端子名，连线跟着走；**重排**＝改端子顺序，连线跟着走；**删除条目**＝这一对端子消失、挂在它上面的线一并断开（**Ctrl+Z 可复原**），实体文件进素材库根目录的 `.trash`（**不实删**）。

## 素材库怎么用（顶栏按钮）

1. 第一次点顶栏「**素材库**」会先让你**选一个文件夹作为素材库根目录（项目目录）**。这一步之后**不建议改动**：更换根目录会触发重新扫描，新目录里没有的素材会变成「素材失联」，需要手动重新绑定（旧目录的文件不会被删，改回去即可再次识别）。
2. 打开后是**左右两栏**：
   - **左栏＝目录**（只显示名称，不带图标）。点 **＋ 新建文件夹** 建分类，右键分类可 **新建子文件夹 / 重命名 / 删除 / 在资源管理器中打开**。分类可以嵌套。
   - **右栏＝该分类下的素材卡片**：**设置 / 插入到画布 / 删除**，右键还能 **移动到分类…**（端子序号不受影响）与 **重命名（文件夹）**。
   - 工具条：**新建素材**（建一个空素材）· **上传为新素材**（选本机一个文件夹 → 按文件类型自动变成内容条目）· **刷新**（重新扫描）。
3. 默认分类是空的：**素材**是要你亲手建的（新建或上传），不是扫描出来的。
4. 你也可以**直接在资源管理器里整理**：一个文件夹里放了标记文件（`.mtnode-asset.json`）就是**素材**，没有的普通子目录就是**分类**；重开素材库会自动认出来。
5. **删除一律不实删**：分类、素材、内容文件都先进根目录的 `.trash/<时间戳>__<名字>`，在资源管理器里可手工找回。非空分类不允许直接删（先移走素材）。

## 在提示词里引用素材内容

- 把素材的**内容端子连线**到处理节点（文本 LLM / 图像生成 / 智能任务）后，该节点运行时会自动把这条内容写进**背景信息**，块标题就是**内容条目标题**（与端子上的名字一模一样）。
- 同一个素材节点可以有几条内容分别连进同一个处理节点，**每条都会各自进背景**（不会只留第一条）。
- 想在提示词里点名引用：素材节点**本身不再作为 `@` 候选**；打 `@` + **那条内容的标题**（＝端子名），只引用**某一条内容**，不会把整份列表全带上。`@` 候选列表里列出的就是这些内容条目。
- **只有已经连线接进本节点的内容条目才可引**：某条内容想被 `@` 到，先把它的端子连到那个处理节点；没接线的条目即使属于同一素材也引不到。
- 图像端子进**参考图**（`@` 时写成「第 N 张参考图」），音频 / 视频端子进该文件的 `file:///` 地址文本。
- 前提：库里那条内容得**读得到**（未绑定 / 素材失联 / 空条目 → 没有内容可注入）。带 Tag 的素材节点与聚合模式同样吃素材节点的内容条目。

## 与其他节点的区别

- 与**输入节点**（文本 / 图像 / 音频 / 视频）的区别：输入节点的内容属于**这一张画布**（删画布即丢），素材节点的内容属于**素材库**（跨画布共享、独立存活）。
- 与**工具 / 函数节点**的区别：那两类的端子是**参数表**；素材节点的端子是**内容条目**。相同点是「端子名＝条目名、端子顺序＝条目顺序」。

## 本轮限制

- 智能会话（Agent）**暂时不能直接读写素材库**，也不提供「素材」相关的网关工具；素材只能从素材库界面或素材节点操作。**下一轮**再接入。
- 素材库界面**没有搜索框**，也**不能跨分类拖拽**素材（请用右键「移动到分类…」）。

## 排错

| 现象 | 怎么办 |
|---|---|
| 提示「素材库还没有指定保存位置」 | 顶栏「素材库」→ 按引导选一个文件夹作根目录 |
| 节点显示「素材失联」 | 素材在库里被删 / 换了根目录：找回素材夹或换回根目录后点**重新扫描**；或点**重新绑定…**选一个别的素材 |
| ⟳ 一直不亮 | 连进来的和库里那份是**同一份**（字节相同），或库里那条为空（会在运行时自动同步），或这个端子此刻没连线 |
| 连线被拒绝「只接受 ×× 来源」 | 端子类型与来源不符：改接同类来源，或在素材设置里换一条同类内容 |
| 处理节点里 `@` 不到素材内容 | `@` 只找**已连线**的内容条目：先把该素材的那条内容端子连到那个处理节点（或把素材连进全局节点并开启全局引用）；`@` 素材节点标题已不再命中，要打 `@` + 内容条目标题 |
| 背景信息里没有那条内容 | 库里这条内容还读不到：节点显示「素材失联」／条目为空／正文刚改还没落库（点 ⟳ 或先离开输入框） |
| 撤销后库没变回来 | 该次写库前旧内容没能进 `.versions`（文件被占用等）；到该素材的 `.versions` 目录手工找回 |

详见手册 [素材库与素材节点](#asset-library)。
