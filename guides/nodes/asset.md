# 素材节点（绑定素材库 · 内容条目即端子）

画布通向**素材库**的那道门：绑定库里一个素材，把它的每条内容变成一对端子 —— 左边连进 = 这条内容有候选可写回，右边输出 = 读出这条内容。节点只存绑定、不存内容，所以改内容就是改库，删节点 / 删画布也不会丢库里的文件。

## 端子
- **输入**：每条内容一对输入端子（第 i 入 ↔ 第 i 出），端子名 = 内容标题；一个输入端子只挂一条线，类型必须对口（文本端子只收文本来源）。连入**不会写库**。
- **输出**：同样数量的输出端子；文本给字符串，图像 / 音频 / 视频给该文件的 `file:///` URL。
- 没有控制端子：不吃 ▶ 控制线，不参与批量 / 聚合。库里的内容读不到时，端子按「没有输入」处理，不猜旧值。

## 设置
- 在节点头部 **⚙ 设置**（或素材库卡片上的「设置」）打开的**素材设置**窗里改；**显示名称 / 描述**：只影响库里这个素材。
- **＋ 文本 / ＋ 图像 / ＋ 音频 / ＋ 视频**：从本机选文件复制入库，每个文件一条内容（可多选）。
- 每行 ＝ ⠿ 拖动排序 · ▲▼ 逐格移动 · 端子名 · 类型 · `⇄n` 端子号 · 库内文件名 · 更换文件 · ✕ 删除（这一对端子消失、线一并断开，Ctrl+Z 可复原，实体文件进 `<根>/.trash`）。
- 文本条目在库里恒为 `.txt`（源文件是 `.md` / `.yaml` 也只取正文），单个文本文件上限 **16 MB**。

## 用法
- 右键空白处 → **输入节点 → 素材节点**；或顶栏 **素材库** → 卡片上 **插入到画布**。
- 刚建出来还没绑定时，节点给三颗入口：**绑定…**（从库里挑一个素材）、**上传…**（把本机一个文件夹整体收进库并绑定）、**打开素材库**。
- 在节点里编辑文本：**离开输入框（失焦）才写库**。
- 要把连进来的内容写回库：点该条目的 **覆盖** 并在二次确认里确认 —— 跑流程不会替你写盘。

## 注意
- 写回只有两个入口：就地编辑（失焦写库）、点「覆盖」并确认。每次写库前旧内容进该素材的 `.versions`（每条保留最近 5 份），**Ctrl+Z** 会连库文件一起回滚。
- 库里找不到（被删 / 换了根目录）= **素材失联**：端子与连线原样保留，点 **重新绑定…**，或找回目录后点 **重新扫描**。节点永远不会被自动删除。
- `@` + **内容条目标题**只引用**某一条内容**；素材节点标题本身不是 `@` 候选，没接线的条目也引不到。连线接进处理节点的条目会自动写进**背景信息**，块标题就是条目标题。
- 智能会话暂时不能读写素材库；素材库界面也没有搜索框、不能跨分类拖拽（用右键「移动到分类…」）。
