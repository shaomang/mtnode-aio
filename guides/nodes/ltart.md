# 产物节点（ltart）

长周期任务留下的**产物落点**：一件产物 = 一颗节点。它不是给你手动添加的 ——
只有启用中的长周期任务会在**每个环节跑完时清点这次跑出来的东西**，把其中**你该读 / 该收的
关键文件**摆在这里（标题形如 `产物 · 文本 · pilot.md`），并放进**该环节的超级节点子壳**里
（与产出节点同一层；壳被删过就回落主画布层）。

## 它是干什么的

长任务的成果散在工作目录里（`output/shots/01.mp4`、`assets/script/shotlist.md`…），
翻文件夹很费劲。产物节点把**这一环这次产出的关键文件逐件摆到画布上**：跑完就能看见，不用等整件事结束。
只有值得你读 / 收的那几件会占画布（口径见下一节），中间件不铺上来 —— 画布留给结果，不留给过程。
产物节点挂在同环节「产出节点」的右侧，按空位网格排列，不压住既有节点。

## 怎么用

- **看**：图片直接出缩略图（点开可看大图、可另存为）；文本 / Markdown / 表格给一段摘要；
  其它类型给路径 + 打开入口。
- **编辑保存**：文本类产物的头部多一枚 **✎**，点它直接进应用内可编辑阅读器（.md 走 Markdown
  阅读器、其它文本走行视图，都能改），**保存即写回这件产物文件**，节点上的体积与摘要随即刷新；
  要看全文也在这一枚里（阅读器自带 Markdown 渲染，读完顺手就能改）。
- **打开**：节点头部那枚 **⇢** 用系统默认程序打开这件产物；节点底部一行是完整路径
  （鼠标悬停可看全）。
- **打开所在文件夹**：头部紧挨着 ⇢ 的 **📁** 直接在资源管理器里定位到这件产物所在的文件夹
  （并选中它）—— 想在产物目录里接着翻同一批文件时，不用先打开文件再退一级。
- **挪 / 删**：可以自由拖动、改名、删除；系统下一次跑到同一环、同一件产物时**复用同一颗节点**
  （按「任务 + 环节 + 文件路径」认人），不会每跑一轮就堆一片新的。你删了，下次跑到会补回来。
- **不连线**：它没有输入 / 输出端子 —— 它是给人看的东西，不是流水线里的一环。

## 什么产物会被摆上来

清点范围 = 本环节**自己写出来的**、且在跑的那一刻真的读得到的文件。清点走三条路，谁命中都算：
本环节写文件工具（write / edit）落盘的路径（**工作区相对路径也算**，按本画布工作目录解析）、
写回本环节状态里能抽出来的路径，以及（前两条都空手时）本环节时间窗内工作目录里变过的文件。
上游环节交下来的输入文件不会再摆一遍，避免每个下游环节都把上游的图重复铺一屏。

清点出来之后还会**挑一道**（画布只摆你该读 / 该收的关键文件）：

- **摆**：报告与文档（`.md` / `.pdf` / `.txt` / `.html` / `.docx` / `.pptx` / 字幕…）、
  数据表（`.csv` / `.xlsx`…）、成品图（`.png` / `.jpg` / `.webp`…，画布上就是缩略图）。
- **不摆**：视频与音频（不是拿来「读」的东西，画布上只会多出一堆它自己的播放器）、
  日志与配置文件、中间件（分镜 JSON、抽帧图之类）、依赖锁、源码 / 脚本 / 归档 / 数据库 / 可执行文件。
- 这些文件**没有丢**：仍在工作目录里，产出节点的文件引用清单也一件不少，需要时从那里找。
- 单次最多摆 32 件；交付环节里**你亲手确认过的交付件**照旧全摆（那是你已经挑过的东西）。

## 看不到这个节点的类型入口？

对——和产出节点、交付节点一样，它只由长周期任务系统创建：右键菜单、复制 / 粘贴、模板、
智能体建图都不会创建或复制这个类型（`LT.LOCKED` 名单里）。要开始用，展开画布上方那条细线，
新建并启用一个长周期任务；跑到有产出的环节时，对应环节的超级节点子壳里就会出现它。
