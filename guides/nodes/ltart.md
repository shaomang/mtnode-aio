# 产物节点（ltart）

长周期任务留下的**产物落点**：一件产物 = 一颗节点。只有启用中的长周期任务会在每个环节跑完时清点这次跑出来的关键文件，把该读 / 该收的摆到画布上（标题形如 `产物 · 文本 · pilot.md`），并放进**该环节的节点层子壳**里（壳被删过就回落主画布层）。

## 端子
- **输入**：没有。
- **输出**：没有。它是给人看的东西，不参与连线。

## 设置
- 没有 ⚙ 设置窗口，动作都在节点头部那排按钮上：
  - **✎**：文本类产物进应用内可编辑阅读器，**编辑保存**即写回这件产物文件，节点上的体积与摘要随即刷新。
  - **⇢**：用系统默认程序打开这件产物。
  - **📁**：在资源管理器里定位并选中这件产物。

## 用法
- 跑完直接看：图片给缩略图（点开可看大图、可另存为），文本 / Markdown / 表格给一段摘要，其它类型给路径 + 打开入口。
- 可以自由拖动、改名、删除；系统下一次跑到同一环、同一件产物时**复用同一颗节点**（按「任务 + 环节 + 文件路径」认人），不会每跑一轮堆一片新的。

## 注意
- 只摆关键文件：报告与文档、数据表、成品图会摆；视频与音频、日志与配置、中间件、源码 / 脚本 / 归档 / 数据库不摆。文件没丢，仍在工作目录与产出节点的文件清单里。
- 单次最多摆 32 件；交付环节里你亲手确认过的交付件照旧全摆。
- 上游环节交下来的输入文件不会再摆一遍。
- 不能复制、也不能手动新建（在长任务的锁定名单里）；删了下次跑到会补回来。
