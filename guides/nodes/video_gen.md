# Minimax H3（视频生成）

![diagram](img/video_gen.svg)

画布右键 → **处理节点 › 视频生成 › Minimax H3**。本地 MiniMax H3 后端（ComfyUI）。**每次运行只生成一个视频文件**（`.mp4`），写入节点自带的 `outputPath`，不需要再挂保存节点。

## 端子
- **输入**：**端口 0 = 控制输入（固定放在第一个端子，与视频超分 / 补帧 / Remotion 同构）** · **R2V** 模式：端口 2–10 = 参考图 I1–I9、端口 11–13 = 参考视频 V1–V3、端口 14–16 = 参考音频 A1–A3（三组端子一次排全）· **FL2VA** 模式：端口 2–3 = 首帧 F / 末帧 L · **提示词 = 端口 1** · 开了**分段衔接**再多一个 **↩ 上一段视频**（FL2VA = 端口 4 · R2V = 端口 17，见下节）。数据端口号与面板 / 文档里的「端子 N」（数据槽号）**完全同号**，与后端 `ref_image_0..8` / `ref_video_0..2` / `ref_audio_0..2` 一一对应；数据线连端口 0 会被挡下（那颗是控制开关）
- **输出**：端口 0 = 视频（下游可试看）· 端口 1 = 控制输出

## 参数
点节点头部 **⚙ 设置** 打开设置窗口来改；改完即时生效，节点卡片上只显示一行当前摘要。

- **输出路径**：`.mp4` 保存位置（相对工作目录 / 超级节点子文件夹）
- **生成模式**：`fl2va` = 首末帧（默认）；`r2v` = 多参考（参考图 / 参考视频 / 参考音频）
- **时长**：4–15 秒（默认 5）
- **分辨率**：auto（按比例默认）/ 480p / 720p / 1080p（显存不足自动降档）
- **后处理**：本节点**不再**跑超分 / 补帧——需要时另建 **视频超分** / **视频补帧** 节点单独运行
- **抽卡次数**：多次尝试（1–10）

## 分段衔接（长视频无缝衔接）

H3 单次最长 **15 秒**；要出更长的片子就分段生成、段间衔接。设置窗口的「生成」段里开 **分段衔接**（内置 `fl2va` 与 `r2v` 两种模式都支持，默认关；**自建 ComfyUI 工作流模式不提供**——端子由那张图自己决定）。

- 开启后节点多一个 **↩ 上一段视频** 输入端子（控制输入仍固定在端口 0 不动）：把**上一段成片**接进来即可，本段自动以它衔接。
- **引导帧数**（1–60 · 默认 22）：取上一段**末尾 N 帧**作段间引导，锁定构图、角色位置与场景连续性。
- **重绘幅度**（0–1 · 默认 1）：`0.3–0.6` 为推荐的「**引导加重绘**」区间——在锚定构图的同时对引导区域重绘，重置画面状态、避免段数一多就背景裂化 / 人物饱和度异常。填 `0` = 退回纯引导（只吃末帧引导，不重绘）；填 `1` = 不加引导重绘，沿用内部 denoise。
- **`fl2va`（首末帧）模式**：↩ 端子排在首 / 末帧之后（**数据槽 4 · 端口 4**）；节点没有首帧输入时，上一段的末帧会兜底充当首帧（锚定构图）；**首帧端子接了图则以你接的首帧为准**。
- **`r2v`（多参考）模式**：该模式没有 `first_frame` 入参，衔接的锚只能是**一路参考视频**——上一段末尾 N 帧直接占一个 `<Video N>`（官方语义里 `<Video N>` 本就含 *video continuation* / 续写起点）。
  - ↩ 端子排在参考图 / 参考视频 / 参考音频**三组之后**（**数据槽 17 · 端口 17**），不侵占 I1–I9 / V1–V3 / A1–A3。
  - 参考视频**上限仍是 3 路**：没连满时衔接接在最后一路（V1→V2→V3）；**连满 3 路则顶掉最后一路 V3**，你原来那条参考视频本段不进图——占用了第几路会在节点状态行与 H3 控制台里写明，不会静默丢。
  - **自动补写续写声明**（默认开）：运行时在提示词末尾自动补一句 `Continue seamlessly from <Video N> as the starting point; keep subjects, scene and camera continuity.`，告诉模型按那一路续写；自己已经写过类似要求可以关掉。
  - 衔接这一路只喂**画面帧**、不喂音轨（窗口只有 N 帧，配整段音轨会音画长度不匹配）。
- 提示词衔接技巧：角色外观与场景描述**每段保持一致**（`r2v` 尤其要写全，否则外观漂移）；动作注意上一段**结尾**→下一段**开头**的连续；要切镜就在段与段之间换，一镜到底则保持运镜描述连续。
- 用法：第 1 段正常生成 → 第 2 段起把上一段输出接到 **↩** 端子 → 重复到目标时长 → 在剪映 / PR 里按顺序拼接、检查衔接点。衔接视频文件不存在时只记日志跳过，不影响本段正常生成。

## 自建 ComfyUI 工作流（可选）

节点默认走内置 H3 链（首末帧 / 多参考）。想跑**自己搭的 ComfyUI 图**：点节点头部 **⚙ 设置** 打开设置窗口 → 「工作流来源」选 **自建 ComfyUI 工作流**。

- **库**：工作流存在本机全局库（`<数据目录>/h3-workflows/`），在 **H3 管理窗口 · 自建工作流库** 里导入（拖 JSON 文件 / 粘贴 JSON），ComfyUI 的 **API 格式**与 **UI 格式**都能识别（UI 格式自动转 API 格式，自动丢掉 Reroute / Note / 常量原语等前端节点）。「管理」按钮直接打开那个窗口。
- **打开**：库里每条模板右侧都有「打开」，点一下就在**内嵌的 ComfyUI 编辑器**里编辑这一条（后端没跑会先问一句再拉起）。这只是「拿出去改」，**不会覆盖库里的模板**——改完想回到库里 / 上画布，仍然只有 ComfyUI 里「导出 (API)」→ 回管理窗口「导入 JSON」这一条路。
- **端子**：图里被「提升为节点参数」的字段会在设置窗口里各占一个数据端子——**数据端子 1 = 文本 · 2+ = 素材（图 / 视频 / 音频）**（端口号与数据槽号同号，**端口 0 = 控制输入**），顺序就是参数表顺序，可用 ▲▼ 调整。默认参数表取扫描建议（提示词 / LoadImage / 种子…），可增删改名。
- **直填值**：每个参数都可在设置窗口里直接填值；**端子接了数据时端子优先**，端子没接才用直填值，都没有就沿用工作流 JSON 里的原值。素材填本机绝对路径，生成时自动上传到 ComfyUI。
- **输出节点**：图里有多个 `Save*` 时指定取哪一个当本节点的产物；留空 = 最后一个视频产物。
- **失效与校验**：↻ 会把参数表与库里最新的图重新同步（图上改掉的落点标「落点已失效」，不静默删）；「校验节点包」按后端 `/object_info` 比对自定义节点是否装了（后端没运行则跳过，**不阻断生成**）。
- 种子沿用节点上的 **种子 / 摇数**：一次执行把该种子统一下发到图里**所有** `seed` / `noise_seed` 类字段。
- 自建模式下 **时长 / 分辨率 / 采样等内置参数一律失效**（由工作流图自己决定，设置窗口里也不再出现这些项），也不做 24G 钳制；抽卡、进度、取消、输出路径与全局互斥照常。

## 注意
- 全局同一时刻只允许 **1 个音视频任务**（音乐 / 视频互斥）。
- **本节点只出原生片**：超分 / 补帧已拆成独立节点（处理节点 › 视频生成 › 视频超分 / 视频补帧），按需单独运行，也可串联 **H3 → 视频超分 → 视频补帧**。
- 24G 显存上限会限制分辨率档位；超分 / 补帧的显存建议见对应节点指南。
- 参考图 / 参考音频 / 参考视频都可以直接连**图像输入**、**音频输入**、**视频输入**节点：媒体端子给的是 `file:///…` URL，本节点会自动归一回本机路径。
- **Sage Attention（可选加速 · 约 1.5–2×）**：要 `triton-windows` 与**和本机 venv 配套的** `sageattention` 预编译 wheel 成对装上（只装一个等于没装）。**缺包不报错**：每次生成前插件在 venv 里自检，缺就自动不带 Sage 节点，只慢一点。自检与补装都在 **H3 插件窗 →「Sage 加速」按钮**（宿主按本机 Python / torch / CUDA 大版本自己挑轮子，装完立刻按同一口径复检）。
- **后端报错会弹窗**：H3 需要在你本机装环境，装坏 / 跑挂时主窗口会弹一份**错误报告**（错误码、错误正文、console 日志尾部、出问题的节点），并问你要不要「**🤖 自动修复**」——点了就是新建一条你看得见的会话，按安装技能 `minimax-h3-install` 的【自我修复】模式在**本插件的 INSTALL_DIR** 里修，修好后**自动重启 H3 后端**并刷新本节点状态。主动取消、正在安装中、磁盘不够、没 N 卡、驱动太旧、安装目录不合法这几类**只报告不自动修**（详见手册「插件报错弹窗与自动修复」）。
- **这些不是故障，别当问题修**：分辨率被钳到长边 ≤1280（24G 安全红线）、生成完没有 4K / 没有补帧（后处理已拆成独立节点）、`--cpu-vae` 默认关闭（开了 VideoVAE 解码必报 dtype 崩）、EasyCache 档位被夹在 0.08 / 0.30 / 0.90。
