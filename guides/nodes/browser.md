# 浏览器工具（会话能力）

会话自己的浏览器：不随包发浏览器内核，直驱本机已装的 Edge / Chrome，用独立用户数据目录（登录态单独一份）。这一族工具**只在会话里注册** —— 画布上的智能节点 / 智能任务不注册（没人看着的自动运行不该自己去点网页），纯净模式也不注册。

手动入口（不用写命令）：会话输入区那枚 **浏览器活动** 按钮打开会话主内容右边栏（不被调用或没启动浏览器时整条不显示）。原来那排「打开浏览器 / 停止 / 接管 / 名单 / ↻」已下架；**真窗口**在右栏实况区头部那枚常态小键「用真窗口打开 / 收回」；**接管**不再有界面按钮 —— 登录类求助由网关自动接管、用户答完那一问自动交还。

## 工具一览

| 工具 | 做什么 | 关键参数 |
| --- | --- | --- |
| `browser_launch` | 按需拉起浏览器（已有就复用，不重开） | — |
| `browser_snapshot` | **首选**的看页面方式：标题 / URL / 可点元素清单 / 可见文本 / 页内报错 | `textLimit`（默认 4000 字符） |
| `browser_navigate` | 打开网址（域名层不再拦，见下「安全闸」） | `url`、`waitMs` |
| `browser_click` | 点元素（危险动作先弹确认卡） | `selector` 或 `text` |
| `browser_type` | 往输入框打字（**禁止代填凭据**） | `selector`、`text`、`submit` |
| `browser_key` | 按键（`Enter` / `Escape` / `Tab` …） | `key` |
| `browser_eval` | 页内执行 JS 取数据（返回结构化摘要，不返回整页 HTML） | `expression` |
| `browser_wait` | 等元素 / 等文本出现，或直接等一会儿 | `selector` / `text` / `ms` |
| `browser_screenshot` | 截图落盘（按需才用，**模型默认只看摘要**） | `fullPage` |
| `browser_tabs` | 列标签页 / 切换 / 新开 / 关闭 | `action`、`targetId` |
| `browser_network` | 看页内请求（方法 / 状态 / URL），排查失败接口 | `limit` |
| `browser_help` | **向用户求助**（**只用于与浏览器 / 当前页面有关的事**：登录墙、验证码、页面上的验证与选择、被网站拦住、页面上的危险动作；与浏览器无关的询问一律走 `ask_user_question`，网关会**拒绝**越界的调用）：卡片与 `ask_user_question` 的询问卡是同一张（题面 + 选项 + 自定义回答 + 「回答」键），回执是 `answers[]`。`kind` 只作语义与标题（`login` 自动接管、答完自动交还）；用户「稍后 / 中断」时本工具以**失败**收场 | `kind`、`questions[]`（旧写法 `message` + `options` 仍收，自动折成一道题）、`screenshotPath`、`note` |
| `browser_release` | 交还驱动权（会话告一段落时用） | — |

## 使用口径（写给会话自己的纪律）

- **先 `browser_snapshot`**：看页面就靠结构化摘要，别一上来截图（截图贵，且只在真需要「看长什么样」时才用）。
- **凭据不进对话**：遇到登录、验证码、付款，调 `browser_help`（`kind:"login"`，题面里说清要你做什么）请用户亲自操作；**绝不要**用 `browser_type` 填密码。默认这只浏览器 dock 在会话右边栏（窗口让位、面板里可操作）；用户也可以在右栏实况区头部点「用真窗口打开」换成真实窗口 —— 两种形态下都是用户自己动手。
- **求助只用在该用的地方**（本次需求 · 用户口径）：`browser_help` 只用于**与浏览器 / 当前页面有关**的事 —— 登录墙、验证码、页面上的验证与选择、被网站拦住、页面上的危险动作。共识确认、方案与范围选择、补充信息、可否开工这类**与浏览器无关**的询问一律用 `ask_user_question`：网关会直接拒绝越界的 `browser_help`（工具以错误文本收场并提示改用 `ask_user_question`，**不弹卡**）。判据是「这一轮你调用过任何 `browser_*` 工具，或本条会话正驱动着这只浏览器」。
- **求助就当作 asking**：`browser_help` 的参数与回执与 `ask_user_question` 同形（`questions[]` → `answers[]`），写法照那个工具的习惯来（推荐项排第一并标「（推荐）」、每题 `description` 写一句理由）。用户答完卡就等于作答；他点「稍后 / 中断」时这次求助会**失败**，那是「没人回应」，不是默许 —— 别把空答案当结论往下做，等他下一条消息或稍后重新求助。
- **危险动作先问**：提交 / 支付 / 删除 / 发送 / 发布这类点击会自动弹确认卡；被拒绝就停下换方案，不要绕路重试同一下。
- **接管期间停手**：用户在窗口里自己操作时（登录类求助自动进入接管），你的浏览器动作会被**拒绝**（不是排队）—— 收到拒绝就等他那张求助卡答完（作答即交还），或先用 `browser_help` 说明你需要什么。
- **留痕**：每次动作与结果都进活动流（会话右边栏「浏览器活动」+ 本机活动库），并写进你的交付说明（页面状态、下载与截图路径、跑过的命令），让用户能自己复核。

## 安全闸（默认值）

- **域名名单已下线**（本轮需求）：不再有拦截名单 / 风险名单，也不再有风险站点的首次访问确认卡；访问哪个站点按任务需要自行判断。
- **危险动作审批**：恒开（提交 / 支付 / 删除 / 发送 / 发布这类点击每次都会弹确认卡，没有开关）。
- **用户数据目录**：`%APPDATA%\pipeline-console\browser-profile`（独立、跨会话保持登录态）；截图 / 下载另有自己的目录。
