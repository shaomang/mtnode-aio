# 浏览器工具（会话能力）

会话自己的浏览器：不随包发内核，直驱本机已装的 Edge / Chrome，用独立用户数据目录（登录态单独一份）。这一族工具**只在会话里注册**——画布上的智能节点 / 智能任务不注册，纯净模式也不注册。

手动入口：会话输入区的 **浏览器活动** 按钮打开右栏活动流（没调用或没启动浏览器时整条不显示）。**真窗口**在右栏实况区头部的「用真窗口打开 / 收回」；**接管**没有按钮——登录类求助由网关自动接管，答完自动交还。

## 端子
- **输入**：无（不是画布节点，是会话工具族）
- **输出**：无

## 设置
没有 **⚙ 设置** 窗口；下面这些是固定口径：

- **用户数据目录**：`%APPDATA%\pipeline-console\browser-profile`（独立、跨会话保持登录态）；截图 / 下载另有自己的目录。
- **危险动作审批**：恒开（提交 / 支付 / 删除 / 发送 / 发布这类点击每次都弹确认卡，没有开关）。
- **域名名单已下线**：没有拦截 / 风险名单，也没有风险站点首次访问确认卡，访问哪个站点按任务需要判断。

## 用法
- 看页面先 **`browser_snapshot`**：标题 / URL / 可点元素 / 可见文本 / 页内报错，`textLimit` 默认 4000 字符。截图贵，只在真需要「看长什么样」时用 `browser_screenshot`。
- 其余工具：`browser_launch`（按需拉起，已有就复用）、`browser_navigate`（`url`、`waitMs`）、`browser_click`（`selector` 或 `text`）、`browser_type`（`selector`、`text`、`submit`）、`browser_key`（`key`）、`browser_eval`（`expression`，回结构化摘要）、`browser_wait`（`selector` / `text` / `ms`）、`browser_tabs`（`action`、`targetId`）、`browser_network`（`limit`）、`browser_release`（交还驱动权）。
- **`browser_help` 向用户求助**：只用于与浏览器 / 当前页面有关的事（登录墙、验证码、页面上的验证与选择、被网站拦住、页面上的危险动作）；与浏览器无关的询问走 `ask_user_question`，网关会**拒绝**越界的调用。参数 `kind`、`questions[]`（旧写法 `message` + `options` 仍收）、`screenshotPath`、`note`，回执是 `answers[]`；`kind:"login"` 自动接管、答完自动交还。

## 注意
- **凭据不进对话**：登录 / 验证码 / 付款一律请用户亲自操作，**绝不要**用 `browser_type` 填密码。
- 用户点「稍后 / 中断」时本次求助以**失败**收场，那是「没人回应」不是默许——别把空答案当结论。
- 用户在窗口里自己操作（接管）时，你的浏览器动作会被**拒绝**（不排队）：等求助卡答完，或先用 `browser_help` 说明你要什么。
- 每次动作与结果都进活动流和本机活动库，并写进交付说明（页面状态、下载与截图路径、跑过的命令），让用户能复核。
