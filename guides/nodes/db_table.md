# 表节点（读取文件 · Agent 建表）

放在**数据库节点层**里用：读连入的文件节点，Agent 抽元数据 → 你确认表单 → 按表单建表，每个文件 = 一行。

## 端子
- **输入**：文件节点（或文件数据），可多接；每个文件建一行。
- **输出**：1 个，不往下游传数据；建好的表随数据库编译进副本，由智能节点用 `mtnode_db` 查。

## 设置
- 无设置项：节点头部没有 **⚙ 设置** 窗口。建表走节点 body 上的 **📋 建表**；建好后 body 显示列 / 行预览，并给 **重新建表** 与 **打开数据文件**。

## 用法
- 展开数据库节点层，放进「文件节点」并导入文件；再把文件节点连到本节点。
- 点 **📋 建表**：Agent 出字段 / 类型 → 在「确认表单（建表元数据）」里改 → **确认并建表**。
- 回数据库节点层头部点 **⚙ 编译（增量）**，表才进副本。

## 注意
- 一张表建在哪个数据库层，看你在哪一层的里面加了本节点；表结构 / 数据写成该库子文件夹里的 `表_<标题>.schema.yml` 与 `.table.csv`。
- 数据库层没设工作目录 + 子文件夹时这两个文件不落盘（建表照样能出结果，但不进副本）。
- 图像文件会先问「需要内容说明，是否进行识图处理？」，识别结果填进内容说明列；没认就是「(未识别)」。
