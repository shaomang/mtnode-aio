# 表节点（读取文件 · Agent 建表）

在**数据库超级节点**内部使用：读取「文件节点」导入的文件，由 Agent 抽取元数据 → **你确认表结构表单** → 按表单建表（SQLite / FTS5）。

## 用法
1. 先有「文件节点」导入的文件。
2. 添加「表」节点，选择要建表的文件。
3. Agent 生成字段 / 类型 / 主键等元数据，弹出**确认表单**；调整后确认建表。
4. 建好的表随数据库超级节点 **⚙ 编译** 进入副本，供智能节点用 `mtnode_db` 查询。

## 端子
- **输入**：文件节点（或文件数据）
- **输出**：表数据（查询结果）

详见手册 [数据库节点](#database-nodes)。
