# 文件节点（上传任意文件）

画布空白处右键 →「输入节点」→「文件节点」。新建出来的节点里只有一颗**上传文件**按钮：
不用先想清楚「我这个文件该进哪种节点」，选完文件，应用按文件类型把它**就地**变成对应的输入节点。

- 图片（png / jpg / webp / gif …）→ **图像节点**（图片复制进工作流资产，**按原尺寸保留**：
  不改像素宽高、不重编码，节点右下小字显示的就是原图的真实尺寸）
- 文本与代码（txt / md / json / yaml / csv / js / py …）→ **文本节点**（正文读进节点）
- PDF → **文本节点**（走 PDF 解析编排，正文是解析出来的 Markdown）
- 音频（mp3 / wav / m4a …）→ **音频节点**（输出该文件的 `file:///` URL）
- 视频（mp4 / mov / webm …）→ **视频节点**（同上）
- **解析不出来的文件**（压缩包 / Office / 可执行程序 / 无扩展名的二进制…）→ **只保留文件路径**：
  不硬读成文本、也不转成文本节点，节点上是这条本机绝对路径，唯一的输出端子给出的就是它。

文件框的默认类型是**全部文件（\*.\*）**：任意后缀都能选，选完再按上面的规则落地。

也可以**不上传**，直接手动指定要变成哪一种：点节点头部（菜单栏）那颗 **文本 / 图像 / 音频 /
视频** 小按钮，或在这个节点上右键 →「转换为输入节点」——两条入口用的是同一份目标清单。

## 三条要注意的

1. **转换后不再退回**：变成文本 / 图像 / 音频 / 视频节点之后，它就是一颗普通输入节点，
   没有「转回文件节点」的入口（Ctrl+Z 撤销这一步仍然有效）。
2. **没上传之前它连不了线**：此时它还没有任何内容，也就没有端子可连；
   转成具体输入节点后端子才出现。**只保留路径**时它有一个输出端子（值 = 那段路径）。
3. **仅保留路径 = 下游只拿到路径**：接进下游、或用 `@文件节点` 引用时，给的都是这段
   本机文件路径（不读文件内容），下游据此去调工具 / 读盘 —— 这正是「以此触发工具」的用法。
   文本后缀的文件若读出来其实是二进制（或编码不是 UTF-8），同样只保留路径，不会把乱码装进正文。

## 兼容说明

文本 / 图像 / 音频 / 视频四种输入节点**本体全部保留**：老画布照旧能打开、能运行、能连线；
把文件直接拖到画布空白处，也照旧按类型直接建出对应节点。这次只是把右键菜单里的四条
合成一条，不再要求新手先选类型。

## 端子

- **上传文件之前**：无输入、无输出（它还没有内容）
- **只保留路径**：无输入、**1 个输出端子**（值 = 那段本机文件路径，可被下游引用 / 接线）
- **转换之后**：随目标节点类型而定 —— 文本 / 图像 / 音频 / 视频节点都是「仅输出」一个内容端子
