# 文件节点

画布空白处右键 →「输入节点」→「文件节点」。节点上只有一个「上传文件」按钮，选完文件按类型就地变成对应的输入节点。

## 端子
- **上传前**：无输入、无输出（还没有内容，连不了线）
- **只保留路径**：无输入，1 个输出 = 那段本机文件路径
- **转换后**：跟随目标类型 —— 文本 / 图像各 1 个内容输出；音频 / 视频是 2 个（URL + 转写）

## 设置
- 没有 ⚙ 设置窗：转换入口在节点头部的 文本 / 图像 / 音频 / 视频 小按钮，或右键「转换为输入节点」。

## 用法
- 点「上传文件」选文件（对话框默认「全部文件（*.*）」）。
- 图片 → 图像节点（复制进资产，按原尺寸保留）；文本与代码 → 文本节点；PDF → 文本节点（正文是解析出的 Markdown）；音频 / 视频 → 音频 / 视频节点（输出 `file:///` URL）。
- 解析不出来的（压缩包 / Office / 可执行程序 / 二进制）只保留路径，下游拿到的就是这段路径，可据此去调工具。

## 注意
- 转换后没有退回文件节点的入口（Ctrl+Z 撤销这一步仍然有效）。
- 文本后缀的文件若读出来是二进制或不是 UTF-8，同样只保留路径，不把乱码装进正文。
- 认不出类型且大于 1 MB 的文件不整份读入，直接只保留路径。
