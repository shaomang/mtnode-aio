# MTNode AI编排器

将复杂 AI 工作流收束于一张可视化画布的桌面工具：文本 / 图像输入、LLM 文本处理、图像生成、批量处理、拆分合并、图转 GIF 帧动画、AI 对话，皆以节点自由编排。

## 下载与主页

- **下载页面**：[http://mt-agent.com/mtnode](http://mt-agent.com/mtnode)（Windows 安装包与源码包）
- **主页**：[http://mt-agent.com/mtnode](http://mt-agent.com/mtnode)

## 功能特性

- **输入节点**：文本就地编辑、实时保存；图像点击选择或直接拖入文件；连线后自动继承输入内容，识别 YAML 自动转为批量节点。
- **处理节点**：文本 LLM 与图像生成；提示词内输入 `@` 引用已连接节点；带参考图自动走图生图接口。
- **保存节点**：输出保存为 `.yaml` 文本或图像文件，支持自动保存；批量链上按 `{文件名}_{输入节点标题}` 自动命名。
- **批量 / 拆分 / 合并**：批量逐条运行或聚合合并；拆分节点实时抽取批次单项，合并节点多输入汇成批次。
- **动画节点**：图像按 `列×行` 切割为帧序列并编码 GIF 动画，支持透明色键。
- **对话节点**：微信风格聊天气泡，对话记录随工作流保存，可输出整个对话记录。
- **多服务商 API**：统一配置服务商与模型，API Key 仅存本机。
- **工作流管理**：本地 JSON 自动保存，启动自动恢复现场；支持撤销 / 重做 / 复制节点。
- **自动递归执行**：输入含未处理的上游节点时自动递归执行直至就绪。

## 使用流程

1. **安装启动**：从[下载页面](http://mt-agent.com/mtnode)获取安装包，一键安装后启动。
2. **配置服务商**：在「设置 · API/配置」填写服务商与 API Key。
3. **编排节点**：右键画布添加节点，拖线连接，提示词内输入 `@` 引用上游，点击运行。
4. **批量与保存**：开启批量逐条生产或聚合合并，YAML / 图像自动命名落盘。

## 从源码运行

```bash
npm install
npm start
```

## 构建与发布

```bash
npm run dist        # electron-builder 构建安装包（需要 node_modules 完整依赖）
```

版本号由源码目录 `version` 文件管理（格式 `x.y.z`），每次构建末位 +1。

## 数据与隐私

所有工作流数据保存在本机（`%APPDATA%\pipeline-console\pipeline-console\save\`），不上传任何服务器；仅在你主动运行节点时，将提示词与输入内容发送至你配置的服务商 API。
