# MTNode AI编排器

将复杂 AI 工作流收束于一张可视化画布的桌面工具：文本 / 图像输入、LLM 文本处理、图像生成、批量处理、拆分合并、图转 GIF 帧动画、AI 对话，皆以节点自由编排。

**永久免费开源**：MTNode 永久免费，源码开放（MIT License），随版本提供源码包下载，无任何收费或订阅；工作流可导出为 `.mtnodes` 包无损分享或整体开源。

## 下载与主页

- **下载页面**：[http://mt-agent.com/mtnode](http://mt-agent.com/mtnode)（Windows 安装包与源码包）

## 功能特性

- **输入节点**：文本就地编辑、实时保存；图像点击选择或直接拖入文件；连线后自动继承输入内容，识别 YAML 自动转为批量节点。
- **处理节点**：文本 LLM 与图像生成；提示词内输入 `@` 引用已连接节点；带参考图自动走图生图接口。
- **保存节点**：输出保存为 `.yaml` 文本或图像文件，支持自动保存；批量链上按 `{文件名}_{输入节点标题}` 自动命名。
- **批量 / 拆分 / 合并**：批量按条目并行运行（每条目一次）或聚合合并为一次；拆分节点实时抽取批次单项，合并节点多输入汇成批次。
- **动画节点**：图像按 `列×行` 切割为帧序列并编码 GIF 动画，支持透明色键。
- **对话节点**：微信风格聊天气泡，对话记录随工作流保存，可输出整个对话记录。
- **控制节点**：用小按钮切换「清空 / 执行」，一点 ▶ 对所有已连接节点清空输出或运行。执行时有数据依赖的先跑上游，互不依赖的并行，避免排队。另有「需求等待」：监视文件路径，无输入端子，仅用输出控制线阻塞后续节点，不输出内容；浏览选路径时只读选取，不改写文件。
- **内置更新**：有新版本时右上角高光「更新」；确认后差分下载（blockmap 只拉变更），装完自动重启。发布说明见 [`scripts/UPDATES.md`](scripts/UPDATES.md)。
- **多服务商 API**：统一配置服务商与模型，API Key 仅存本机。
- **工作流管理**：本地 JSON 自动保存，启动自动恢复现场；支持撤销 / 重做 / 复制节点。
- **自动递归执行**：输入含未处理的上游节点时自动递归执行直至就绪。
- **工作流导入 / 导出**：一键导出整张画布为 `.mtnodes` 工作流包（含节点、连线、提示词与输入），或复制为 Base64 分享；导入端一键还原、跨机器无损迁移。内容生成工作流可整体开源，社区可发布「剧本人设框架」类模板，由大家填充创意角色（如 DeepSeek娘）。
- **创意工坊**：顶栏「导出」右侧进入公开创意工坊；可按标签浏览 / 搜索并下载 `.mtnodes` 模板。上传需注册登录（用户名 + 密码 + 昵称），可管理自己的模板（标题、可选 640p 预览图、描述、标签），并统计下载与点赞。
- **智能 Agent 能力（1.1.0，DeepSeek Harness 植入）**：智能任务节点与「智能会话」由 DeepSeek Harness agent 引擎驱动——模型可读文件、联网搜索、执行命令、调用子代理与后台任务后完成任务；支持提问（ask_user）、权限审批、斜杠命令、权限预设、dsh 风格指标统计与会话管理。智能助手还可在当前画布上**创建并排版节点**（改标题、连线、@引用），用于按指示搭出可再编辑、可再运行的工作流（例如物品配置生成并写入配置表）。Agent 会话沿用 dsh 的透明消息流，思考过程与工具调用轨迹逐条可查，**一切日志与操作可追溯**。

## 使用流程

1. **安装启动**：从[下载页面](http://mt-agent.com/mtnode)获取安装包，一键安装后启动。
2. **配置服务商**：在「设置 · API/配置」填写服务商与 API Key。
3. **编排节点**：右键画布添加节点，拖线连接，提示词内输入 `@` 引用上游，点击运行。
4. **批量与保存**：开启批量逐条生产或聚合合并，YAML / 图像自动命名落盘。

## 从源码运行

```bash
npm install
npm start
```

## 构建与发布

```bash
npm run dist        # electron-builder 构建安装包（需要 node_modules 完整依赖）
```

版本号由源码目录 `version` 文件管理（格式 `x.y.z`），每次构建末位 +1。

## 数据与隐私

所有工作流数据保存在本机（`%APPDATA%\pipeline-console\pipeline-console\save\`），不默认上传任何服务器；仅在你主动运行节点时，将提示词与输入内容发送至你配置的服务商 API。使用「创意工坊」上传时，会将你选择的 `.mtnodes` 模板与预览图发至工坊服务器（`mt-agent.com`），下载为公开拉取。

## 版本更新

### 1.1.10（当前版本：工作流分享以及大量QoL改进）

- **工作流导入 / 导出 / 社区云分享**：整张画布一键导出为 `.mtnodes` 工作流包（或复制为 Base64），无损分享、开源、跨机器导入；内容生成工作流可整体开源，社区共创可复用模板（如「剧本人设框架」，由社区填充 DeepSeek娘等创意角色）。

### 1.1.0（大版本更新：植入 DeepSeek Harness 获取 Agent 能力）

本次更新为 MTNode 植入了 **DeepSeek Harness（dsh）** agent 引擎（随应用自带统一 Node 运行时，无需单独安装），智能节点与智能会话从「单次生成」升级为「完整任务执行」：

- **Agent 引擎**：模型可读文件 / 联网搜索 / 执行命令 / 调用子代理与后台任务，完成任务后返回结果；引擎网关随应用启动，dsh 升级只影响网关一层（解耦设计，见 `dsh/DESIGN.md`）。
- **智能任务节点**：提示词成为任务描述，可 `@` 引用已连接节点；参数面板（预设 / 供应商 / 模型 / 思考强度）与智能会话完全一致，节点与会话内容双向同步、一键扩展为会话。
- **智能会话**：多会话管理（按工作目录分组、归档、分支 fork）、dsh 风格透明消息流（思考过程 / 工具调用轨迹）、上下文用量统计与分布弹窗、中断。
- **模型提问（ask_user）**：任务中途模型可通过提问弹窗征求确认 / 选择 / 补充信息，回答后继续执行。
- **权限审批（approval）**：权限预设切到「逐项审批」档位时，工具越权操作会弹出审批卡片（允许一次 / 拒绝）。
- **斜杠命令**：`/new` `/compact` `/plan` `/rename` `/export` `/permissions` `/help`。
- **权限预设**：无人值守（默认）/ 工作区读写·逐项审批 / 只读·逐项审批 / 完全放行，沙箱模式 + 审批策略热切换。
- **多服务商目录**：DeepSeek 官方 + MTNode 自配服务商 + pi-ai 目录（opencode 等 36 家）统一选择；添加服务商时**从目录选择**（选服务商 → 输入 Key → 自动载入模型列表），API Key 隐藏显示；智能能力永久启用。
- **扩展商店**：App Store 式弹窗（插件 / 技能 / MCP 三个标签），列表**拉取于线上**（npm registry + GitHub 官方仓库），一键安装 / 卸载；已安装插件列表默认收纳；任务完成音效可替换自定义音频文件并试听。
- **会话管理**：会话侧边栏支持分支 / 归档 / **直接删除**（提示确认）；智能任务节点与会话**标题、内容双向映射**；删除节点时其关联会话一并删除（先提示）。
- **插件 / 技能 / MCP**：dsh 风格插件清单与安装、Skill 文件系统技能、MCP 服务器管理。
- **体验**：10 款主题色（默认 Industrial）；任务运行超过 5 分钟完成时短促音效提示（可关闭）。

- **1.0.23**：文本处理与对话节点新增「思考强度」（effort：无/低/中/高，默认低）。
