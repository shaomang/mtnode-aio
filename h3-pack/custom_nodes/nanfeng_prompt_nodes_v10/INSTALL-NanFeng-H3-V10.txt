# 南风 H3 V10 公开版（已禁用二采）

本包节点：`NanFengH3MultiReferenceGeneratorV10`（显示名：`南风H3 V10 多参视频生成`）。

## 公开版限制

- V10原有主生成、参考素材、音频锁定、智能分镜、Sigma、LoRA、实时预览等代码保留。
- **所有二采执行入口已强制关闭**：潜空间放大二采、旧高清二采、旧双采样即使由历史工作流传入`true`，运行时也会被强制改为`false`。
- V10界面不显示“H3潜空间放大二采”面板。
- 本限制只存在于这个桌面发布包，不修改你机器中正在运行的V10/V11。

## 安装

1. 解压后，把唯一根目录 `nanfeng_prompt_nodes_v10` 放入：
   `ComfyUI/custom_nodes/`
2. 删除或移走目标环境里旧的同名目录，避免重复注册。
3. 安装该节点原工作流所需依赖节点（KJNodes、VideoHelperSuite及MiniMax H3相关节点）。
4. 不含模型、LoRA、参考素材、API密钥或本机配置。模型需要放到目标ComfyUI对应模型目录。
5. 如需API功能，参考`.env.example`在本机自行建立配置；不要把真实密钥上传或分享。
6. 重启ComfyUI后按`Ctrl+F5`。若旧画布缓存了控件位置，请删除旧节点并重新添加V10节点。

## 校验

包内`SHA256SUMS.txt`记录每个文件的SHA256，可用于确认文件完整性。
