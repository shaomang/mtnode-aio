# 场景与对白参考表

供 `SKILL.md` 引用：场景类型、对白手术清单、人物卡、契诃夫结构样板。

## 一、六种对白场景形态（类型名保留英文）

| 形态 | 信息分布 | 适用 | 写法要点 |
| --- | --- | --- | --- |
| balanced | 双方掌握的信息量相当 | 摊牌、谈判、夫妻争吵 | 每回合交换一次攻防；不许一方连说三句 |
| comic | 一方不知道观众知道的事 | 喜剧、讽刺 | 让不知情者认真，知情者配合；笑点落在第三拍 |
| asymmetric | 一方知道得多 | 审问、试探、上下级 | 弱势方靠提问夺回主动；强势方用沉默施压 |
| indirect | 双方都不说真事 | 家庭、政治、办公室 | 谈物件、谈第三方、谈程序；真事只露一次 |
| reflexive | 人物谈论「说话」本身 | 元叙事、编剧题材 | 只用于一次；第二次就变成炫技 |
| minimal | 台词极少，靠动作与停顿 | 诀别、和解、反高潮 | 一场不超过 12 句；沉默要占一整行 |

## 二、对白手术清单（改稿时逐条划掉）

1. 删掉所有问候与告别（除非问候本身是攻击）。
2. 删掉「你知道的」「我不是说过吗」「听我说」。
3. 删掉解释人物关系的句子；关系靠称呼与动作交代。
4. 删掉形容自己情绪的台词（「我很生气」）；改成动作或反话。
5. 一句里只留一个信息点；两个信息点拆成两句，删掉次要的。
6. 删掉所有人都会说的那句话；留下只有这个人会说的。
7. 把最重的词放到句尾；把最重的句子放到场尾。
8. 每场只允许一句「直接说出想要什么」；其余全部潜台词。
9. 长独白只允许全片一段；超过 8 行就拆给两个人。
10. 读一遍，凡是念着拗口的地方，改字不改意。

## 三、人物卡（三维＋可演细节）

```
姓名／年龄／职业：
生理：外貌、健康、习惯动作、随身物
社会：阶层、家庭位置、职业身份、称呼别人的方式
心理：想要什么（具体可见）／怕什么／错误信念（他坚信正确，因为曾经救过他）
口头禅：
语法习惯（句长、爱用哪类词、是否打断别人）：
对主题的态度：
与主角的关系向量（他按主角哪个按钮）：
本季可失之物：
```

- 编排检查：把主要人物对主题的态度列成一列，出现两个同型就合并或改写。
- 对手卡另加三行：他的自辩（三段）／他最想被谁认可／他最后一张牌。

## 四、契诃夫式结构样板（可复用骨架）

以「家庭成员离开／丧亲」为例，六段可套：

| 段 | 功能 | 写法 |
| --- | --- | --- |
| 1 旁观者的框 | 用外人的一句羡慕定调 | 「真有福气啊」 |
| 2 到达 | 期待落空，只给一句不评论的观察 | 「还以为会更热闹一点」 |
| 3 第一次被放下 | 让孩子替老人发怒 | 不写老人委屈 |
| 4 被外包 | 用电话与委托推进 | 观众看见推诿 |
| 5 唯一真诚的招待 | 借来的酒、外卖 | 越简陋越真 |
| 6 中点自评 | 用笑说出最痛的话 | 「到底变成无家可归的了」 |
| 7 平行的两个夜晚 | 交叉剪辑，两人整晚不在一起 | 观众替他们拼话 |
| 8 死亡预告三次 | 每次被笑着打断 | 病只用一个动作暗示 |
| 9 事件在空镜里 | 不拍死亡 | 只拍 afterward |
| 10 葬礼 | 悼念与算计同桌 | 俗语先当玩笑后当悔恨 |
| 11 物件传递链 | 照片→被子→手表→贴耳听 | 最后一个物件被「听」 |
| 12 结尾递减 | 社交空间→家→无人空镜 | 回到旁观者一句「又冷清了啊」 |

## 五、契诃夫化自检（十二条的展开）

| # | 检查 | 不合格的表现 |
| --- | --- | --- |
| 1 | 分幕是否偶数、每幕一个情调词 | 每幕都在吵同一件事 |
| 2 | 最大事件是否在画外 | 高潮靠一场打架／车祸 |
| 3 | 幕尾是否停顿／否决／独白 | 每幕都留悬念钩 |
| 4 | 每人一件随身物＋一句口头禅 | 口头禅只是重复，结尾没有反用 |
| 5 | 是否没有反派 | 有一个纯恶角色推动一切 |
| 6 | 正确答案是否第一幕说出并被拒 | 主角到最后一刻才想明白 |
| 7 | 对话是否偏移半格 | 每句都精准回答上一句 |
| 8 | 哲学后是否接日常动作 | 人物站着讲道理 |
| 9 | 最痛的话是否最短 | 用长独白抒情 |
| 10 | 环境声是否有来源 | 气氛音乐代替现场声 |
| 11 | 预告的事是否没发生 | 所有伏笔都被兑现 |
| 12 | 是否坚持它是喜剧 | 演成了苦情戏 |

## 六、场景诊断表（打印出来逐场打勾）

| 问题 | 是／否 | 修法 |
| --- | --- | --- |
| 这场删掉，后面是否需要补一句解释？ | 否→可删 | 删，把信息并进相邻场 |
| 开场价值与结尾价值是否相同？ | 是→废场 | 重设冲突或降为过场 |
| 是否有一个人物全程被动？ | 是 | 给他一个自己的目标，哪怕很小 |
| 转折是否靠电话／外人消息？ | 是 | 改成在场人物的选择 |
| 最关键的台词是否被说满？ | 是 | 砍掉后半句，留动作 |
| 观众是否比人物早太多知道？ | 是 | 缩短延宕，或加一次误判 |
| 地点是否可随意替换？ | 是 | 换成只有这里才成立的场所 |
| 道具是否只出现一次？ | 是 | 要么删，要么安排三次递进 |
