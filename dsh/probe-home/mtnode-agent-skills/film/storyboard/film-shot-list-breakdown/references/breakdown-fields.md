# 拆解字段字典

正文 `film-shot-list-breakdown` 引用本文件。每个字段给「必须含什么 / 好例子 / 坏例子」，以及会把它判死的观察信号。

## 一、节拍七条判据（不满足就不是节拍）

1. **进态 ≠ 出态**。写不出两个真正不同的短语，就把这行并进邻居。
2. **每个变化都有施压者**。自己的身体、别人、物件、画外声、截止时间。「气氛变了」没有施压者。
3. **摄影机不是节拍**。「推近他的脸」是第 7 步的决定；真节拍换三种拍法都成立。
4. **换地点不是节拍**。走到门口只有「到达改变了压力」才算，否则是路程，并进相邻拍。
5. **同时发生的第二条线另起一个字母**（`B1`、`B2`），不是「然后」。
6. **一拍只推一件事**。一拍里两个目标 = 两拍。
7. **可计时**。每拍给秒数；秒数加起来要落在场景目标时长 ±15%。

节拍行写法：

```
B3 | 进态：她以为他只是迟到 | 施压者：他递出的收据 | 出态：她知道他昨晚不在加班 | 3.5s
```

## 二、22 字段字典

### 身份泳道（9）

| # | 字段 | 必须含 | 好 | 坏 |
| ---: | --- | --- | --- | --- |
| 1 | `scene_shot_id` | 场号-镜号，项目内唯一且稳定 | `SC07-04`，后拆为 `SC07-04a` | `镜头4（原3）` |
| 2 | `location` | 资产 id + 第几个 setup | `loc_landing / 门侧低机位` | `楼道` |
| 3 | `time_of_day` | 时段 + 光源状态 | `夜，走廊灯管半坏，隔 4s 闪一次` | `晚上` |
| 4 | `characters` | `@tag@version(状态变体)`，含朝向 | `@lin@v3(湿发, 外套右肩破损, 面朝门)` | `林、老张` |
| 5 | `props` | 版本 + 在哪只手 + 状态 | `@envelope@v2（右手，边角折起）` | `一个信封` |
| 6 | `description` | 3–5 句可见事实 | `门只开一条 15cm 的缝；他的左眼在缝里；信封贴着他的小腿` | `气氛紧张，很有电影感` |
| 7 | `dialogue` | 原文逐字，标说话人 | `林：「谁在那儿？」` | `林问是谁` |
| 8 | `running_time` | 秒，精确到 0.5 | `3.0s` | `约三秒` |
| 9 | `complexity` | low / mid / high | `mid`（单人 + 手部接触 + 反光地面） | `正常` |

`complexity` 判定（用于排重试预算）：`low` = 单人、无手部特写、无镜面、无文字；`mid` = 两人同框或手部特写或一次运镜；`high` = 三人以上 / 肢体接触 / 动物 / 儿童 / 快速动作 / 镜面反射 / 需要口型对位。`high` 每镜按 3–6 次生成预留。

### 导演泳道（6）

| # | 字段 | 必须含 | 好 | 坏 |
| ---: | --- | --- | --- | --- |
| 10 | `shot_goal` | 这一镜替观众完成什么 | `让观众先于他看见楼梯口的影子` | `表现紧张` |
| 11 | `task` | 动词开头，一镜一个 | `逼他跨出门槛` | `情绪铺垫` |
| 12 | `dramaturgy` | 在场景中的位置与赌注 | `B3 之后，赌注从「迟到」升为「有人来过」` | `剧情推进` |
| 13 | `blocking` | 起位 → 移动 → 终位，带米数与朝向 | `门内 0.4m 侧身 → 前探 0.2m → 停在门槛外，面朝楼梯` | `他犹豫地站着` |
| 14 | `acting` | 肌肉级指令 | `吸气 0.5s，眉毛内侧抬起，下唇内收 2mm，眼睛不移开缝隙` | `害怕` |
| 15 | `style_device` | 借用的一条手法 | `前景遮挡：门框占左侧 25%` | `电影感` |

### 摄影 / 剪辑泳道（7）

| # | 字段 | 必须含 | 好 | 坏 |
| ---: | --- | --- | --- | --- |
| 16 | `size` | 六级阶梯之一 | `MCU` | `半身偏近` |
| 17 | `movement` | 一个主运动 + 距离 + 时长，或 `locked` | `slow dolly-in, 20cm over 3s` | `缓慢推进，有呼吸感` |
| 18 | `lens` | `##mm` + 机距 | `85mm，距脸 1.2m` | `长焦` |
| 19 | `angle` | 高度 + 角度 + 轴线侧 | `1.55m，A 侧 35°，水平` | `低角度` |
| 20 | `cut_type` | 硬切/叠化/跳切/匹配切/黑场 | `硬切（同轴跳两级）` | `正常切` |
| 21 | `pace` | 段落里的节奏角色：等/压/爆/收 | `压` | `适中` |
| 22 | `transition` | 出点接什么 + 靠什么成立 | `接 SC07-05 的手部特写，靠纸边摩擦声搭桥` | `自然过渡` |

## 三、风险分档

| 档 | 判定 | 处理 |
| --- | --- | --- |
| 绿 | 单人、静态、无手部特写、无文字、无镜面 | 直接生成，1–2 次 |
| 黄 | 双人同框 / 一次运镜 / 手持物 / 需要口型 | 先出关键帧锁身份，再图生视频，2–4 次 |
| 红 | 三人以上肢体接触 / 打斗 / 动物 / 儿童 / 奔跑 / 镜面或玻璃反射 / 需要精确文字 | 纸面上先拆成两个镜；或改机位回避；预算 3–6 次并准备退路方案 |

红线不加预算就开拍，是最常见的烧钱方式：一条红档镜头失败 6 次，等于整场黄档镜头的预算。

## 四、文字任务表

| 字段 | 填法 |
| --- | --- |
| `text_id` | `T01` |
| `scene_shot_id` | `SC07-04` |
| `exact_text` | 原文，含换行与标点 |
| `placement` | 画内位置：`门牌，画面右上 1/5，正对镜头` |
| `appearance` | 出现帧与持续：`第 12–48 帧，随门开露出` |
| `typography` | 字体倾向 + 颜色 + 是否描边 |
| `method` | `后期贴` / `实拍道具` / `生成时留空位` |

生成侧只保留占位描述：`a blank metal nameplate, no lettering`。

## 五、时间轴与装配

- 分镜表 `时长` 列相加 = 目标时长（±15%）。拼接命令按此顺序：

```bash
printf "file '%s'\n" clip1.mp4 clip2.mp4 > list.txt
ffmpeg -y -f concat -safe 0 -i list.txt -c copy joined.mp4
```

- 需要统一转码时：`ffmpeg -y -i joined.mp4 -crf 23 -preset medium out.mp4`（CRF 18–28 常用，23 为默认；越低越清晰、文件越大）。
- 单条 clip 生成耗时可到 5 分钟，轮询间隔 10 秒；三条以上并行排，不要串行等。
