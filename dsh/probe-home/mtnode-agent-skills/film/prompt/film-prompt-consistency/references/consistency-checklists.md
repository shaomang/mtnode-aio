## 二、单镜自检（每镜生成前跑）

- [ ] 本镜用到哪些资产，ID 与版本写清
- [ ] 身份块是本版本原文，未改写
- [ ] 场景拓扑与上一镜同侧（门/窗/主光方向）
- [ ] 参考编号映射未变
- [ ] 不在场的参考对象已写排除句
- [ ] 本镜新增状态已登记（谁脏了、谁受伤、道具在谁手上）
- [ ] 台词文本来自脚本，未沿用音频参考里的即兴内容
- [ ] 时长能让本镜动作做完（≥所需秒数）

## 三、跨镜对照（成片前逐项看）

| 检查项 | 判据 | 不合格的处理 |
| --- | --- | --- |
| 脸 | 眼距、鼻梁、下颌线、痣/疤位置一致 | 撤掉多余角度图；补 `no face morph`；重出该镜首帧 |
| 发型 | 分缝方向、长度、碎发走向一致 | 身份块补分缝方向；统一湿度状态 |
| 服装 | 版型、主色、扣子/拉链、磨损位置一致 | 服装单独参考 + 禁改主色句 |
| 体型 | 肩宽、头身比一致 | 身份块写身高与体型；避免不同焦段混用 |
| 场景 | 门窗位置、家具相对关系、地面材质一致 | 用场景板重出；写拓扑句 |
| 光 | 主光方向、K 值、对比度一致 | 全片固定 K 值；每镜重复光源方位 |
| 道具 | 形状、材质、磨损一致；持握的手一致 | 道具特写图 + `same geometry`，并登记换手 |
| 色彩 | 主色/辅色/禁用色一致 | 风格块写色值；禁改句 |
| 画幅 | 全片同一比例与分辨率 | 统一归一化后再生成 |
| 节奏 | 每镜 2–3.5s，动作有起承 | 拆镜或加时长（上限见主技能） |

## 四、序列/续写失败图谱

| 现象 | 机制 | 处置 |
| --- | --- | --- |
| 第二段像重拍第一段 | 复制了整段描述或死贴尾帧 | 只写「结束状态 + 新动作」，换景别接 |
| 第二段开场人物位置错 | 没有登记上一段结束位置 | 续写模板必填「上一段结尾状态」 |
| 道具在两人之间跳 | 换手没登记 | 状态表记录持有者，并在下一段首句写明 |
| 光线从白天变傍晚 | 没固定时间与 K 值 | 全片时间线表：每段对应时刻 + K 值 |
| 服装越来越新 | 磨损状态只在首段写过 | 状态表按段递增（第 3 段起加灰、第 5 段起破口） |
| 说话人串音 | 音色参考没有绑定到具体角色 | `@Audio1 as voice identity for [角色] only` |

## 六、参考集体检（生成前最后一道）

1. 参考总数是否超过模型上限（2.0：9 图 + 3 视频 + 3 音频 = 12；2.5：≤30 图 / ≤10 视频 / ≤10 音频 / 总 ≤50）。
2. 是否有两张参考在对同一个属性「投票」（两张不同年龄的脸、两个不同版本的走廊）。
3. 是否有参考携带了不需要的信息（广告牌文字、路人、水印）。
4. 视频参考的总时长是否在平台上限内（Runway 上限 30s）。
5. 音频参考是否只含一个用途（对白与音乐不要放同一条）。
