# 关键帧构图与交接

## 一、首帧、中段帧、尾帧的分工

| 帧 | 承担什么 | 不该承担 |
| --- | --- | --- |
| 首帧 | 建立身份、空间、光、动作起始态 | 剧情高潮、极限角度、完成态动作 |
| 中段帧（关键帧 3+） | 动作转折、姿态峰值、构图重构 | 与首帧矛盾的外貌或服装 |
| 尾帧 | 交给下一段继续的落点状态 | 全新角色、全新空间（除非明确转场） |

Seedance 2.5 的首尾帧只在 `omni_reference` 模式合法；关键帧 3+ 只能用提示词形式表达（平台无对应输入位），所以第 3 帧之后要靠「角色映射 + 逐镜描述」实现。

## 二、可延伸的构图公式

```
主体位置 + 运动方向留白 + 前中后景分层 + 光的可延续性 + 动作中间态
```

- **主体位置**：单人近景落三分线，避免正中（正中适合「被注视/仪式」，但 i2v 容易原地不动）。
- **留白**：运动方向留出画面宽度 25–35%（**通用经验值**）；不要两侧都堵死。
- **分层**：前景虚化物（门框、叶、肩）+ 中景主体（实）+ 背景纵深（虚）。三层都有，运镜才有视差。
- **光的可延续性**：写清光源位置（`screen-left window`），下一镜同侧继续，观众才不会觉得换了场地。
- **动作中间态**：抬手到一半、转身过半、正要推门。完成态只能靠「表情变化」撑 4 秒。

## 三、四视图卡布局

```
┌─────────┬─────────┬─────────┬─────────┐
│ 正面     │ 3/4 侧  │ 正侧     │ 背面     │
│ 全身     │ 全身     │ 全身     │ 全身     │
└─────────┴─────────┴─────────┴─────────┘
          统一中性站姿 / 统一表情 / 统一 5600K 柔光 / 灰底 / 细分隔线
```

硬规则：

- 一张卡 = 一个身份 + 一套服装；不同身份、互斥的伤情/服装必须分卡。
- 卡是**基础资产**，不是戏剧首帧：不要用它直接开视频，先裁出需要的单视图。
- 卡里不要写场景、道具、文字，否则每张下游图都会带上它们。
- 出卡后先自己检查：脸、侧脸轮廓、服装背面构造、人体比例、左右不对称细节（如单侧耳饰）是否一致。**版式不能证明身份一致**，要逐项看。
- 修卡只改失败的字段，不要整张重出。

## 四、安全区与裁切

下表的百分比与像素为**通用经验值**（平台无硬规范）。

| 项 | 建议 | 说明 |
| --- | --- | --- |
| 主体离边缘 | ≥5% 画宽 | 防裁切切手切头 |
| 头顶留白 | 8–10% 画高 | 同时留给字幕/台标 |
| 字幕区 | 下 12–15% 保持低信息 | 避免文字压在脸上（**通用经验值**） |
| 画幅归一化 | 先裁后喂 | 16:9 → 1280×704；9:16 → 704×1280 |

裁切命令（等比铺满 + 居中裁切）：

```powershell
ffmpeg -y -i "<原图>" -vf "scale=1280:704:force_original_aspect_ratio=increase,crop=1280:704" "<项目>/assets/img/<name>_16x9.png"
```

## 五、面板 / 分镜图 → 视频的镜头推断

起手用静态分镜时，按面板类型推断镜头（这是最省事的一组默认值）：

| 面板类型 | 推断镜头 | 视频里的动作 |
| --- | --- | --- |
| 大特写（脸） | 推近 | 轻微 `Dolly In`，焦点在眼睛 |
| 标准镜头（腰以上） | 中距 | 轻微平移或稳定持机 |
| 中景（全身） | 后退 | `Dolly Out` 露出环境 |
| 全景（地点） | 远距 | 不动，或极缓无人机拉远 |
| 斜角 / 极端角度 | 旋转 | 旋转到与面板一致的视角 |
| 细节插画 | 横移 | 缓慢平移扫过细节，不切 |

单面板可扩成 2–4 秒；多面板（2–9 格）要让模型推断格间过渡，必须写清：**阅读顺序**（左到右 / 右到左 / 竖排）+ 故事弧一句话 + 过渡方式（平滑 / 硬切 / 特效）。

## 六、交接给视频提示词的删除清单

从图像提示词搬到视频提示词时，删掉这些：

- 已经能看见的外貌与服装细节（保留 1–2 个身份锚点即可）
- 已经确定的光位与色温（只写「延续首帧的光」）
- 构图落点（首帧已经定死，重复描述会让模型重新构图）
- `no text, no watermark` 这类图像卫生句

保留并新增：

- 运动（谁、往哪、多快、几秒完成）
- 新信息（谁进入、什么被拿起、什么被打破）
- 情绪变化（肌肉级描述）
- 声音意向

## 七、素材卫生

- 参考图必须是成片质感：线稿、黑白分镜、厚涂概念图会把画风带进成片。
- 人脸参考用清晰大头照，不要过度美颜——「过于完美就假」，这是「五毛特效感」的第一大来源。
- 分辨率不足 1500px 宽的图不要当身份参考，模型会自己补细节并补歪。
- 同一角色的多张参考要同光同年龄段，混龄混光会拉平身份。
