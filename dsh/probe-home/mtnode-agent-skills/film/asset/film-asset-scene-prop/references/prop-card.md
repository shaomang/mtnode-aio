# 道具卡扩展：设计次序、视图矩阵、跨视图一致性、设定板版式

## 1. 从设计理由到可见形体

1. 定用途：这件东西怎样被携带、握持、放置或操作。
2. 定识别：哪个特征承担「一眼认出」与剧情作用。
3. 定轮廓与体块比例（先整体，再局部）。
4. 定构件连接与操作方式（铰接、旋钮、开口、握持区）。
5. 定材料与工艺（每面 2–4 个材质属性）。
6. 定有作用的局部细节（承力、密封、防滑、标记）。
7. 跨视图冻结数量：按键数、刻槽数、铆钉数一旦选定，所有视图一致。

禁止的做法：先想好「一枚红键、五枚黑键、三道槽」再倒推成设计；那是装饰不是形制。风格来自轮廓、比例、连接、材料分界的相互关联，不是给通用商品换色、加划痕。

## 2. 按用途选图（不统一套商品照）

| 用途 | 图要回答的问题 | 张数与版式 |
| --- | --- | --- |
| 造型探索 / 概念主图 | 轮廓、比例、时代、性格；主要材料怎么共同形成它 | 1 张，主形占 60% 以上画幅 |
| 外观确认 | 主要面与侧面怎么连接；什么使它可辨 | 正 + 侧，2 张 |
| 完整设定板 | 用必要整体视图 + 正交或近正交视图 + 结构/材料局部讲同一个设计 | 3–5 格一板 |
| 局部细节图 | 该部位在哪、什么材料、怎么连接或使用 | 1–2 张微距 |
| 剧情使用参考 | 与人物的尺度与接触是否成立 | 1 张，含手或环境参照 |
| 会翻倒 / 滚动的物件 | 底面从未被看见的那一侧 | 补 1 张底面（undercarriage） |

版式纪律：主形足够大；辅助角度只补真正缺失的面；局部围绕有意义的连接与材料组织。不是所有物件都要正反侧顶，也不是所有设定板都无字。用户要求无字时用位置／视图对应表达，不加广告口号，不编造工程性能。

## 3. 材质契约（每个面 2–4 个属性）

| 属性 | 可选值 | 示例 |
| --- | --- | --- |
| 基底 Base | metal / glass / fabric / ceramic / wood / leather | 拉丝不锈钢 |
| 粗糙度 Roughness | matte / satin / glossy / mirror | 缎面 |
| 瑕疵 Imperfection | 划痕 / 灰尘 / 磨损 / 指纹 / 铜绿 | 使用留下的细划痕 |
| 边缘 Edge | beveled / sharp / rounded / chamfered | 圆角软边 |

样例：哑光陶瓷瓶，发丝细裂纹与淡铜绿，圆润软边，置于粗刨橡木上。

材质落地口径：

- 金属写拉丝 / 氧化 / 划痕 / 冷凝。
- 布料写织物、缝线、压褶、磨损。
- 地面写颗粒、湿度、接触痕迹。
- 接触必须有压力、遮挡、阴影与相应变形。
- 禁止穿模、粘连、漂浮、重复物、方向错误。

## 4. 道具卡完整模板

- 剧情作用: 被藏进袖口，S11 抽取药液
- 握持: 右手，拇指推杆

- 轮廓: 细长圆柱，头部略粗，尾部推杆外露 3cm

- 材料: 筒身玻璃（glossy，细水痕）；推杆塑料（satin，边缘 chamfered）
- 颜色: 筒身透明，刻度深蓝 #1C3A5E，针座 #B8860B

## 5. 跨视图一致性检查

- [ ] 部件总数一致（按键、刻槽、铆钉、铰链）。
- [ ] 连接方式一致（哪面接哪面，铰接在哪侧）。
- [ ] 材料边界一致（金属与塑料的分界线位置）。
- [ ] 左右手性一致（握持侧、开口朝向不镜像）。
- [ ] 磨损与标记位置一致（划痕在哪个面）。
- [ ] 状态一致（同一镜头里不同时存在「已开裂」与「完好」）。
- [ ] 与人物、环境的接触关系成立（手握得住、放得进兜）。
- [ ] 允许透视与可见数量变化，但不允许实体部件漂移。

主图六枚按键、正对同一区域的局部变七枚 = 一致性错误。不能把「文字约束存在」当成通过，也不能从错误局部反向改写基准。

## 6. 剖面与拆解的边界

- 需要说明隐藏连接、开合或内部构造、且设计依据充分时，可出说明用剖面／拆解。
- 剖面不等于剧情当前可见状态；交付时注明用途。
- 不为「丰富细节」给未设定道具加秘密机关。
- 不因为拒绝一切标注与拆解，让设计无法解释。

## 7. 只修问题格

- 已认可的设定板只要求更细时，保留表达方式，先查重要部位是否因占比过小、焦点或高光遮挡而难辨。
- 针对接缝、密封边、接口、铰接、握持、挂接等适用部位改善展示尺度与材质区分。
- 不默认把已认可设计重新概念化；不把增加磨损、螺钉、细线当细节提升。
- 纯裁切能保留原有细节，但不会创造更多真实细节；未见侧面需要其他参考或明确候选补设计。

## 8. 用图后的分级判定

| 判定对象 | 通过标准 |
| --- | --- |
| 文字自洽 | 卡内字段互不矛盾，尺度与检查表能对上 |
| 外形表现 | 主形可读，轮廓与比例成立 |
| 局部一致 | 跨视图部件数、连接、材料边界不漂 |
| 结构可用 | 可解释的装配与操作，不出现无法成立的连接 |
| 用户接受 | 用户明确认可 |

漂亮的设定板仍可能存在无法装配的部件、错误标注或跨视图漂移，不能称已具备工程制造精度。
