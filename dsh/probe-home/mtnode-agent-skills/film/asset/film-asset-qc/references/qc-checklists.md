# 可勾选质检表

用法：复制对应段落到护照或交付说明，逐项打勾；`✗` 必须写「位置 + 现象 + 修法」，
不写「再打磨一下」。整段未勾完不得改 `locked`。

## A. 护照完整性（9 段）

- [ ] 标题行含 tag 与 version
- [ ] `Status` 为 draft 或 locked，且与登记表一致
- [ ] `Type` 为 character / location / prop 之一
- [ ] `Scenes` 与分场表逐个对齐
- [ ] `Seed files` 有路径或明确写 pending
- [ ] `Canonical descriptor` 是完整散文，无简写版
- [ ] `Reference-sheet prompt` 逐字包含描述原文
- [ ] `Reference files` 全是版本化路径，无虚构路径
- [ ] `Stress test` 有矩阵与结果（未跑则留空，不写「通过」）
- [ ] 登记表有对应行，列齐全（tag · type · version · seed file · scenes · status）

## B. 角色逐项核对（每行一次测试结果）

- [ ] 脸：脸型、五官关系与参考一致
- [ ] 发：长度、分缝、发尾位置一致（侧脸与背面也成立）
- [ ] 年龄线索：细纹、手背血管、发际线没有被抹平或加剧
- [ ] 体形：身高比例、肩宽、重心一致
- [ ] 皮肤：瑕疵位置与数量一致（左颊/右眉尾这类位置必须对）
- [ ] 服装：层数、版型、颜色一致，没有换面料
- [ ] 鞋：出现在画面内时型号与磨损一致
- [ ] 随身物：持握/佩戴侧一致
- [ ] 识别细节：疤、耳环、表等一眼认人的特征在
- [ ] 变体状态：湿/伤/换装与护照写的可见变化一致，不变项未被改
- [ ] 双人镜头：两个身份都成立，没有互串脸
- [ ] 同框群像：没有出现同一张脸的克隆队

角色门槛：**10 行全 pass**。任一行 miss → 保持 draft。

## C. 地点逐项核对

- [ ] 布局：出入口、墙段、门窗数量与位置一致
- [ ] 地标：固定锚点在位、朝向未变
- [ ] 材质：地面颗粒/湿度、墙面、金属处理一致
- [ ] 色板：主/辅/强调色与内置影调一致
- [ ] 光特性：光源位置、色温、光比与场次表一致
- [ ] 尺度：门高、层高、家具尺寸与人物比例成立
- [ ] 风化：损坏与污渍位置一致，没有随机新增
- [ ] 反打不是水平翻转，画面左右按几何重算
- [ ] 成组板曝光已归一化，剪接点上不读成换天气
- [ ] 未看见区域仍标未知/候选

地点门槛：矩阵跑完 + 用户显式通过。

## D. 道具逐项核对

- [ ] 形制：轮廓与比例一致
- [ ] 尺度：与人物手部/环境的接触关系成立
- [ ] 材料：每面材质与表面处理一致
- [ ] 标记：刻字、贴纸、编号位置与内容一致
- [ ] 磨损：划痕、胶痕、缺口位置一致
- [ ] 部件数：按键/刻槽/铆钉数量跨视图不变
- [ ] 可动件：开合状态与镜头表一致
- [ ] 可见面：该镜头需要的那一面有对应参考格
- [ ] 手持/放置：持有人与持握侧一致
- [ ] 无穿模、粘连、漂浮、重复物、方向错误

道具门槛：矩阵跑完 + 用户显式通过；道具**不做**运动测试。

## E. 角色动画 QA（六层）

| 层 | 勾选项 |
| --- | --- |
| 1 结构 | [ ] 角色设定 / 绑定计划 / 姿势库 / 时间线四份数据齐全并互相引用 |
| 2 静态资产 | [ ] 引用的部件、背景、参考图全部存在且可解析 |
| 3 浏览器预览 | [ ] 预览页在 1280×720 下加载完成（`waitUntil: "networkidle"`） |
| 3 浏览器预览 | [ ] 截图已保存，console 无未处理错误 |
| 4 运动 | [ ] 抽帧覆盖开头/中段/结尾，差异非平凡（不是静帧） |
| 4 运动 | [ ] 无断肢、层错、出画、抖动穿模 |
| 5 成片 | [ ] ffprobe 时长与分镜一致 |
| 5 成片 | [ ] 分辨率与交付规格一致 |
| 5 成片 | [ ] 音轨存在、采样率正确、无爆音 |
| 6 人眼 | [ ] 表情可读（每镜只有一个主表情） |
| 6 人眼 | [ ] hold 帧存在，表演不是持续滑动 |
| 6 人眼 | [ ] 画面内文字无乱码、无错字 |
| 6 人眼 | [ ] 道具接触有压力、遮挡与阴影 |

判定：技术全过且表演可读 = `pass`；可修的绑定/时间线问题 = `revise`；
缺资产、空渲染、运行失败、运行时长错误 = `fail`。

## G. 返修单模板

```markdown
| # | 位置 | 现象 | 分级 | 修法 | 复查 |
| 1 | S07-03 面部 | 左眉尾疤缺失 | P1 | 回护照补「左眉尾 1cm 疤」→ 换正脸参考 → 整批重生成 | pass |
| 2 | S07-09 道具 | 按键 6→7 | P1 | 以主图为基准，只重生成该局部 | pending |
| 3 | S11-02 暗部 | 死黑不可读 | P2 | 局部提亮暗部，保留高光 | pass |
```

分级：

- **P0** 缺资产、空渲染、运行失败、时长/分辨率错 → 阻断交付。
- **P1** 身份漂移、断肢、层错、出画、同框串脸 → 阻断该场。
- **P2** 表情不可读、文字乱码、塑料感、暗部死黑 → 不阻断，记入待修。
- **P3** 构图偏好、颗粒度偏好 → 只记录。
