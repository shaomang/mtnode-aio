# 角色资产与一致性锚点

## 何时用

- 剧本已经定了人物，要开始出静态参考图，或要把一个人物锁定成后续所有镜头共用的资产。
- 跨镜头「同一个人越拍越不像」：脸型漂移、发型变、服装换色、身高比例变。
- 要交付角色卡／人物设定／character sheet／角色三视图／表情板。
- 同一角色的不同状态（湿透、受伤、换装、年龄跳跃）要拆成独立资产。
- 要接 Soul ID、@ 参考图、种子这类一致性锚点，但不知道该给多少张图、权重给多少。
- 不适用：只要一句人物描述进单张抽卡（不需要资产）；服装设计探索本身（先做完探索再回来锁卡）；已锁定资产的质检与返修（用 `film-asset-qc`）。

## 核心原则

1. **先读剧本，再设计**。通读人物出现的场次，理解身份、关系、时间线；只搜名字或读摘要不算通读。只有片段时明说覆盖范围，未给剧本时按当前描述设计并标注「推定」。
2. **一个角色 = 一张卡 + 至少两张图**。一张脸部特写锁脸 + 一张全身正/背锁体型，是硬底线；禁止只交一张图就宣布角色可用。参考图统一中性灰底，全项目只钉一个 hex（人 `#8a8a8a`，生物 `#7f7f7f`，道具中灰）。
3. **一张卡只描述「另一个提示词作者无法猜」的事实**。脸型、发型、体态、服装、磨损、识别细节必须写到可复述；写「气质独特」「很有故事感」等于没写。
4. **提示词必须分两块**：Identity Block 只放静态外观，Motion Block 只放动作、运镜、时间；脸和核心特征**不再重复描述**（有 Soul ID／参考图时重复描述会让模型边读脸边算动作，脸在中途变形）。
5. **一个状态一个资产**。`@lin`、`@lin_wet`、`@lin_blood` 各自独立编号、独立护照、独立参考板；状态差异在基准卡上「改」是禁止的。
6. **参考图数量按角色量级给**：主角 10–20 张、配角按需、道具 3–5 张；每张必须有说明「从这张取什么」，只「觉得好看」的图不许进板。
7. **一致性锚点必须写进交接**：用哪套（Soul ID／参考图／种子）、几张、权重多少、参考图承担什么职责（只锁身份，不锁光线与姿势）。
8. **没过压力测试不许开拍**。角色需 10/10 通过（十次测试全不漂移），任何一次 miss 都保持 draft，且不得用「另几张好看」平均掉。

## 工作流

1. **读本与记录**。输入：剧本或人物描述。动作：标出该角色出现的全部场次、每场状态（时间、天气、伤势、服装）、与谁同框。产出：一句设计依据 + 场次列表（写进卡头 `场次` 字段）。
2. **建卡**。输入：上一步。动作：逐字段填「关键参数与模板」里的角色卡，缺的字段标 `待定` 而不是留空或编造。产出：`Cxx` 编号的角色卡（draft）。
3. **出最小图组**。输入：角色卡。动作：一次生成 3×2 六格（16:9）：正面脸、3/4 脸、侧面、全身正、全身背、可选道具格；或分两次出「脸部特写 + 全身正背」。灰底、均匀光、中性表情、单人、无遮挡。产出：2–6 张基准图。
4. **做表情板与姿势库**。输入：基准图。动作：按情绪组出 9 个核心表情（中性／喜／怒／哀／惊／惧／厌／疑／决心），再按戏补 10 个扩展；动作姿势按 `neutral / attention / emotion / action / mouth` 五类建库。产出：表情板 + 姿势清单（见 `references/character-card.md`）。
5. **建参考图集**。输入：全部已认可图。动作：按槽位归档（正脸、3/4、侧、背、全身、表情、手部、服装细节、磨损细节），每张写一行「取什么」；淘汰重复角度与低分辨率图。产出：10–20 张（主角）参考图集与说明表。
6. **绑锚点**。输入：参考图集。动作：选锚点组合（见 `references/consistency-anchors.md`），记录 seed、参考图槽位顺序、权重、参考职责。产出：卡内 `## 锚点` 段。
7. **压力测试**。输入：角色卡 + 参考图。动作：按 `film-asset-qc` 的矩阵跑 10 条（角度 × 景别 × 实际场次光 × 同框配对），逐条判 pass/miss。产出：测试记录；不满 10/10 回第 2 步改卡或换参考，不改测试。
8. **登记与交接**。输入：通过记录。动作：状态改 `locked`，把卡与参考图整理到资产目录，输出给下游的只有「Identity Block 逐字文本 + 参考图路径 + 锚点参数」。产出：交接包。

## 关键参数与模板

### 1. 角色卡字段（必须逐项有值或标 `待定`）

| 字段 | 写什么 | 判定标准 |
| --- | --- | --- |
| 编号 / tag | `C01`–`C99`，配 `@name` | 已确认编号不得复用 |
| 脸型 | 轮廓（椭圆／方／长／心形）+ 颧骨 + 下颌 + 下巴 | 画师能据此画侧脸 |
| 五官 | 眼型（单／内双／双）、眼距、鼻梁、唇厚、眉形 | 至少 4 项 |
| 发型 | 长度、分缝、发尾走向、发色 hex | 侧面与背面也成立 |
| 年龄线索 | 年龄段 + 2 个可见线索（法令纹、手背血管、发际线） | 不写具体岁数也行，但要可画 |
| 皮肤 | 冷暖、瑕疵（雀斑／疤／痣）与位置、数量 | 位置写到「左颊」「右眉尾」 |
| 体态 | 身高 cm、肩宽感、重心、步态特征 | 至少 3 项，含一个不对称特征 |
| 服装 | 每层（外／内／下装／鞋）材质 + 颜色 hex + 版型 | 3 层起，鞋必须写 |
| 磨损与使用痕迹 | 具体到部位与形态（鞋头横划痕、袖口起球） | ≥2 处，禁止「有点旧」 |
| 识别细节 | 一眼认人的 1–2 个特征（疤、项链、缺角耳环） | 必须有，且不与别人重复 |
| 随身物 | 物件 + 持握／佩戴侧 | 与道具资产编号对应 |
| 口音／声音 | 口音标签 + 语速（字/秒）+ 音色 | 语速用「克制 2.5–3.2 字/秒、自然 3.5–4.2 字/秒」定档 |
| 性格 | 一句行为倾向 + 一个矛盾点 | 矛盾点要能演出来 |
| 状态变体 | 变体 tag + 与基准的可见差异 + 不变量 | 每个变体独立编号 |

### 2. 最小交付视图（按用途选，不补套餐）

| 用途 | 视图组合 | 说明 |
| --- | --- | --- |
| 锁脸 | 正面特写 + 3/4 特写 | 均匀光、中性表情、单人 |
| 锁体型 | 全身正面 + 全身背面 | 同尺度、同光位、同灰底 |
| 完整角色资产 | 正面 / 3/4 / 侧面 / 背面 / 特写 | 参考板五视图，与护照一致 |
| 一次成板 | 3×2 六格 16:9 单次生成 | 身份比多步拼装更稳；比逐张生成少漂移 |
| 换装不漂脸 | 分栏板：左「幽灵模特」服装 + 右「与输入脸 100% 一致」特写 | 服装改、身份不改 |
| 同框群像 | 多角色 lineup 并声明为「多样参考」 | 单人参考直接扩群会出克隆脸 |

### 3. 参考图集与锚点参数

| 项 | 主角 | 关键配角 | 说明 |
| --- | --- | --- | --- |
| 参考图张数 | 10–20 | 按同框次数定，≥4 | 图集少于 4 张不足以覆盖角度 |
| 送进生成的参考张数 | 2–3 | 2 | 正面 / 3/4 / 侧面；漂移时改用整张角色板当 `@Image1` |
| 表情数 | 9 核心 + 10 扩展 | 9 核心 | 见 `references/character-card.md` |
| 角色锚点块 | 10 属性 | 10 属性 | 身份、画面位置、景深层、占画比、朝向、姿势、视线、接触点、状态锁、表情 |

**参考图权重（按模型给值）**

| 模型／手段 | 数值 | 效果 | 数值来源 |
| --- | --- | --- | --- |
| Midjourney `--cref` + `--cw` | `--cw 80`（服装+面部）／`--cw 0`（仅面部） | 80 会连衣服一起锁；只要脸时用 0 | 通用经验值 |
| SD / Flux IP-Adapter 类 | 0.6–0.8 | 低于 0.6 脸开始自由发挥，高于 0.9 把参考图的姿势、构图一起锁死 | 通用经验值 |
| 图生图改状态 | denoise 0.25–0.4 | 只动头或手，房间不动；不同 UI 的「参考强度」方向相反，先在一帧上试 | 通用经验值 |
| 种子 | 首图定 seed 后全程复用；换角度才换 seed | 同 seed + 同描述 = 同脸同光位 | 通用经验值 |

> 以上四行是模型无关的操作经验，不是上游实测值；上游只给了「参考送 2–3 张」「整板当 @Image1」这两条硬规则。

### 5. 提示词骨架（Identity / Motion 分离）

```
[Identity Block]  （粘贴角色卡原文，一字不改）
[Motion Block]    她推门进来，停两步，看向桌面。
[Camera]          固定机位，中景，平视。
[Light]           场次 S07：窗光为主，光比 6:1，色温 3200K。
[Refs]            @lin（身份），light_ref（光位，不锁姿势）。
[Negative]        不要换脸、不要改发型长度、不要加帽子。
```

- 正向描述优先；负向只写真实风险（本片实际出过的错），不抄长串禁用词。
- 完整字段表、表情词表与姿势库骨架见 `references/character-card.md`；锚点组合、换脸与多状态做法见 `references/consistency-anchors.md`。

## 常见坑

1. **一张图就宣布角色可用** → 后续每个镜头自己猜体型与背面 → 至少补一张脸部特写 + 一张全身正背，灰底同光位。
2. **角色板上有多张脸** → 视频模型「不知道该抓哪张脸」→ 中途换脸 → 板面只留一张可读的脸，其余头抹掉。
3. **提示词里重复描述五官，同时写动作** → 脸在动作中变形 → 拆 Identity / Motion 两块，有参考图时只写差异。
4. **服装靠文字「变湿」** → 模型自由发挥，脸跟着糊 → 状态变体提前单独出板，湿透、受伤、换装都在资产阶段解决。
5. **参考图权重给到 0.9 以上** → 每个镜头都复刻参考图的姿势与构图，运镜没得选 → 0.6–0.8 保身份放姿势，只在必须锁姿势时上调。
6. **同框多人各用单人参考** → 出克隆军团 → 建一张多角色 lineup 并声明为「多样参考」，或在提示词里逐人给不同识别细节。
7. **只给「专业、电影感」这类词** → 出通用脸 → 换成具体形制：下颌线、发缝、鞋型、磨损位置。
