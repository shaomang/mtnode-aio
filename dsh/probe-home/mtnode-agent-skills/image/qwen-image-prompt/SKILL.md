# Qwen Image 2.1 提示词

**本技能是应用内置技能。** 用户要写 / 改 **Qwen-Image-2.1** 的出图提示词（文生图、图像编辑、多图参考、信息图、分镜）时使用。

依据：[Qwen-Image-2.1 提示词写法指导手册](https://www.modelscope.cn/posts/436932)（该手册以官方案例库 40 余个真实案例的提示词为蓝本拆解，第一至九章为官方范式；附录里「非官方·经验补充」的条目本技能已单独标注）。

MTNode 口径：「Qwen Image 2.1」节点（`qwenimage_gen`）—— 端口 0 = 提示词、端口 1 = 参考图（**最多 10 张，接了就是图像编辑**）、端口 2 = 控制入；节点另有 `negative`（负面提示词）、蒙版局部重绘、透明背景开关、7 种比例桶（默认 2K 档）/ INT8 40 步 · Turbo 8 步。

## 一、动笔前先定三件事

1. **模式**：端口 1 没接图 = 文生图（从零描述一整张画面）；接了 1–10 张 = 图像编辑（在给定素材上做指定改动，按接线顺序说「第 1 张图 / 第 2 张图…」）。
2. **详略**：官方文档里有「智能改写（Prompt Extend）」开关，**MTNode 本机后端没有这一档**，提示词原样下发给 `TextEncodeQwenImage21`。所以一律按官方「关闭改写」那一支写：**把画面信息说尽，逐元素逐字锁定**。不要给「一句话大纲」期待模型自己扩写 —— 本机不会扩。
3. **排除项写在哪**：官方把否定约束写在正文里（「无文字、无 logo、无水印」「不出现任何人物」）。节点有 `negative` 字段也可以放，但**正文里的排除句是主路径**，两边不要互相依赖。

## 二、通用骨架（所有场景共用）

顺序固定，越靠前权重越高：

1. **一句话定身份**：`这是一张【品类/风格】的【横/竖版】图`（例：`为专业跑步品牌拍摄的高品质运动鞋广告编辑摄影作品`）。
2. **主体**：外观、姿态、数量、朝向（可感知的名词，不写「好看 / 高级 / 有氛围」）。
3. **环境**：所处空间、前景与背景元素。
4. **光照**：方向、时段、冷暖、光比（例：`日落黄金时段从右后方约 45 度角照射的暖色自然光，在面部左侧形成伦勃朗式三角光影`）。
5. **材质与纹理**：`浅原木色木纹餐桌` `带猫眼光泽的棕黄色虎眼石圆珠` 这类颗粒度。
6. **构图**：视角、机位高度、焦段与景深、主体占比与位置。
7. **收束**：整体风格质感（日系二次元 / 偶像剧电影感 / CCD 直出 / 印象派油画）+ 排除项（`无文字、无 logo、无水印` `不要拼贴`）。

需要比例、尺寸、刻度时直接给数值（`近似 9:16 竖条` `0/10/20/30m 比例尺`）。**像素尺寸不要写进提示词**：画幅由节点的比例桶决定（1:1 / 4:3 / 3:4 / 3:2 / 2:3 / 16:9 / 9:16，默认 2K 档），提示词里只写「竖版 / 横版 / 竖长条」这类比例语气。

## 三、文字密集型画面（信息图 / 试卷 / 海报 / App 界面 / 科普卡）

- **逐字锁定文案**：画面里要出现的每个字都写进提示词（状态栏时间、卡片标题、评分、价格、坐标轴刻度、表格每行数值、图注），不让模型自由发挥。
- **先划区再填空**：按上下左右或 (a)(b)(c) 分区编号，逐区说明放什么、放在哪（`左上角徽章+标题、主体大插画居中、右侧竖栏信息、底部图例与剖面`）。
- **字体族与层级**：`标题用粗黑体、正文用宋体印刷、注意事项用楷体`。
- **防乱码三件套**（含中文文案必备收尾）：`文字逐字准确、清晰可读、无错字无乱码`；`不要生成任何未指定的多余文字`；`不要添加未要求的口号或标语`。

## 四、图像编辑（端口 1 接了图）

1. **点名输入图与角色**：单图用「输入图片 / 第 1 张图」，多图按顺序写「第 1 张图…第 N 张图」，并说清每张图承担什么（谁是场景、谁是物品、谁是人物身份）。
2. **「保持不变」清单**：逐项列死必须不动的东西（瓶身材质、泵头、每一行 logo 文字、链宽比例、扣上刻字、底布与刺绣）。涉及人物时固定表述：`严格保持面容、五官、气质不变`。
3. **移除 → 新增 → 光影统一**：先写移除什么，再写新增 / 替换成什么并逐元素描述，最后统一到同一套光影（光源方向、接触阴影走向、景深）。**漏写光影统一是画面显假的头号原因。**
4. **只改局部**：用节点的**蒙版局部重绘**开关（透明区域 = 允许编辑区），提示词只描述蒙版内要变成什么 —— 「其余不变 + 光影融合」的约束节点会自动追加，**不要自己再抄一遍**，也不要在提示词里描述框线 / 掩码颜色（本机没有圈选标注这层，写了等于让模型把框画出来）。
5. 收尾固定句：`画面其余部分与输入图一致，不重绘、不重新构图`。

## 五、多参考图协同（最多 10 张）

- **多人合照**：每张脸当身份参考，逐人指派服装、姿态、站位，并锁易漂移的细节（`保持第 1 张图的发型完全不变——同样金色盘发、刘海与蓬松度，不得改成披肩长卷`），再用一个统一场景与光把所有人组织进同一张合影。
- **换装 / 配饰**：直接下动作指令 —— `让第 1 张图的模特换上第 3 张图的鞋、拿第 4 张图的包、戴第 5 张图的帽，保持姿势与背景不变`。要点是「图号—物品—穿戴动作」一一对应。
- **多物布置**：一张空场景为底，其余图作物品参考，逐件写「取哪张图的什么物、放在何处、朝向、遮挡关系」，补一句 `只取物体本身、忽略其原背景`，最后统一到场景原有光照与接触阴影。

## 六、分镜 / 故事板 / 时间轴

- **格数与排布写死**：`恰好 6 格、等宽、单横排 1 行 6 列、每格竖长条、不是网格也不是两行、绝不把任何一格再拆成上下两块`；编号补防错句 `每格一个数字徽标，不重复、不跳号、不缺号`。不给这些约束，模型会自作主张改分格。
- **角色一致性锚定**：先声明外观基准（`以第 1 张图的正面/侧面/背面三视图为准：发型、服饰、身材比例全程一致`），再明确 `只改变姿势、表情、动作与所处场景`，并强调 `每一格都必须画出角色本人、占画面主体，严禁只有背景的空格`。
- **逐格脚本化**：每格写清场景与动作（`第 1 格清晨窗边捧杯、第 2 格街头回眸…`）；叙事类可用镜头顺序（全景—中景—近景—特写）或时间轴分段（`对峙 0—20s、开战 21—50s…`）。

## 七、人物一致性与真实摄影质感

- **以原图为身份基准**：`以输入图片中这位女性为身份基准，五官、发型、耳饰沿用原图不变，仅重建画面其余部分`。先锁身份，再换场景 / 服装 / 动作。
- **写拍摄方式**：机位高度（`贴近地面低角拍摄` `平视中距离`）、焦段与景深（`中长焦、背景柔和虚化保留层次`）。
- **用设备与介质词锁质感**：CCD 卡片机正面直闪 / 轻微跑焦 / 边缘暗角与细小噪点 → 室内抓拍快照；`手机随手拍摄` `不经意的随意构图` → 生活照；`印象派油画、broken color、impasto 高光、可见笔触` → 画作，须同时声明 `保留构图、比例与可辨识文字、不留照片斑块或通用模糊`。

## 八、透明图与全景图（官方固定句式）

- **透明图（RGBA）**：官方要求首句 `这是一张带有透明度的 RGBA 图像……`、末句 `该图像具有 alpha 通道，背景是透明的。`（英文同理）。**MTNode 的 qwenimage_gen 打开「透明背景」开关时会自动补这两句，所以提示词正文里不要再写一遍**，只描述主体本身（`一只漂浮的玻璃水杯，杯壁高光清晰`），并保证主体边缘干净。
- **360° 全景图**：须写出 `true equirectangular projection`、360° 水平视野、180° 垂直视野、左右边缘无缝、严格 2:1。**本机比例桶没有 2:1**（只有 16:9 等 7 档），所以要么按 16:9 出图并明确告知接缝不保证，要么换支持 2:1 的云端出图 —— 不要假装能给到 2880×1440。

## 九、五套可直接套用的骨架

1. **文生图（全细节）**：主体定调句 → 分层描述（主体外观 → 环境前景 → 光照方向时段 → 材质纹理 → 构图占比）→ 文字区（逐字文案 + 分区位置 + 字体层级）→ 收束（整体风格 + 排除项）。
2. **文字密集图**：整体版式定调（配色、底色、风格）→ 分区编号逐区填（标题 / 图表 / 表格数值 / 图例 / 图注，逐字）→ 字体与层级 → 防乱码三件套。
3. **图像编辑**：引用输入图并说明角色 → `保持【清单】完全不变` → `移除【…】` → `新增/替换为【…】并逐元素描述` → `统一光影逻辑（光源方向 / 接触阴影 / 景深）` → `画面其余部分与输入图一致`。
4. **分镜 / 故事板**：画风定调 → 分格强约束（格数 / 排布 / 比例 / 编号防错）→ 角色一致性锚定 → 逐格脚本或时间轴 → 镜头语言与节奏 → `画风全程统一、人物不崩`。
5. **多图合成**：场景图定位（第 1 张图）→ 逐图指派角色 → 逐件摆放与遮挡 → `只取物体本身、忽略其原背景` → 统一到场景光照与接触阴影。

## 十、避坑清单

- 详略与后端不匹配：本机没智能改写，**只丢一句话必然糊**；写超长锁定文案才正确。
- 文字图漏掉防乱码三件套 → 乱码、臆造文案。
- 编辑类漏「保持不变清单」→ 误改商品 logo、人物五官；漏「光影统一」→ 人物与环境割裂、显假。
- 分镜不写「格数 / 排布 / 编号」硬约束 → 模型擅自改分格。
- 拿形容词代替具体描述：`高级、有氛围` 不如材质、光线角度、数值。
- 把像素尺寸 / 负面词框架 / 颜色代码（`#FF4500`）当官方写法 —— 官方案例里没有，属「非官方·经验补充」，可用但别当规范。
- 透明图重复写 RGBA 句式：节点开关已自动补，正文再写一遍只会占用注意力。

## 十一、交付形态

- 给用户的**只有提示词正文一段**（中文或英文，跟随用户语言）：不要 Markdown 标题、不要编号列表、不要 JSON、不要「提示词：」前缀、不要解释你用了哪套骨架。
- 长度：全细节版 **120–400 字**；需要逐字文案的图按文案量另计，但不塞无关设定。
- 用户只要一句「帮我写提示词」时，按上面骨架直接产出一版成品，末尾用一句话点明「参考图接端口 1 / 蒙版开关 / 比例桶」这类必须由用户自己设的项即可。
