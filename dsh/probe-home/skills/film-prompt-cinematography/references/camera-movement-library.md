# 运镜库（46 条）

按剧情功能反查运镜。每条的「模块」是可直接改进提示词的句子骨架，**必须结合主体、场景与时间点改写，不得整段照抄堆叠**。

## 调用原则

1. 先确定剧情功能，再选镜头运动。
2. 每个镜头通常只用一个主要运动；6–15s 视频通常全片使用 0–3 种主要运动。
3. 每次调用写清：起始主体/景别、摄影机实际路径或镜头变化、方向、速度、画面产生的新信息、结束主体/构图。
4. `Pan / Tilt / Zoom` 是机位不动时的镜头方向或焦距变化；`Dolly / Truck / Tracking / Crane` 是摄影机实际位移，不得混写。
5. 若参考图没有展示新角度所需空间，先补场景/关键帧参考，或改用当前空间能支持的运动。

## A. 固定、摇摄与俯仰

| # | 运镜 | 适用剧情功能 | 模块骨架 |
| --- | --- | --- | --- |
| 01 | `Static` 固定 | 克制表演、等待、尴尬、威压、喜剧停顿 | 机位全程锁定同一高度/角度/距离，节奏由人物动作与画内变化承担，结尾保持稳定构图 |
| 02 | `Pan Right` 右摇 | 顺着视线或声音揭示右侧人物/空间 | 从当前主体起，机位不动，水平向右平稳转动，沿视线或声源带出目标，停在可读构图 |
| 03 | `Pan Left` 左摇 | 揭示左侧人物/空间 | 同上，向左；新信息进入画面后稳定停住 |
| 04 | `Whip Pan Right` 快甩右 | 突发注意转移、惊讶、动作衔接 | 由清晰主体触发，快速甩向右侧新目标，中段短暂运动模糊，落点立即恢复清晰 |
| 05 | `Whip Pan Left` 快甩左 | 同上，向左 | 中段短暂模糊，结尾准确落在第二主体 |
| 06 | `Tilt Up` 上摇 | 从局部揭示人物、建筑高度、站起、威胁 | 机位不动，从下方细节沿垂直结构向上，主体轴线清楚，落在上方关键目标 |
| 07 | `Tilt Down` 下摇 | 从脸转向手/道具、坠落后果、低处线索 | 机位不动，向下摇，落在手、道具、脚步或地面结果 |

## 快速剧情索引

- 克制表演、停顿、威压：`Static`、极慢 `Dolly In`
- 视线/声音揭示：`Pan`、`Tilt`、`Rack Focus`
- 关系靠近或压迫：`Dolly In`、`Arc`
- 离开、孤独、后果：`Dolly Out`、`Crane Up`
- 行走对话：`Reverse Tracking`、`Side Tracking`
- 进入未知空间：`Follow Shot / OTS`、`Push Past`
- 追逐与逃跑：`Chase Shot`、`Low Tracking`、克制 `Handheld`
- 权力或站位变化：`Arc`、`Truck`、`Pedestal`
- 突发注意转移：一次 `Whip Pan` 或 `Crash Zoom`
- 宏观规模：`Crane`、`Drone`、`Helicopter Shot`
- 身体绑定或主观失衡：`Snorricam`；极少数重大认知转折可用 `Dolly Zoom`
- 时空/物理转场：`Pass-Through Objects`、`Infinite Zoom`、`Time-Lapse`

## 复杂连续运镜的连接控制（按需）

仅在跨空间连续移动、关键转向、离开后重新看见人物/物件时使用。

- **跨空间连接**：把相邻参考视图接成同一空间中的可通行路径，交代连接口、必要中间地标与可见顺序（外墙→窗沿→室内；车头→A 柱→已开的侧窗）。摄影机从上一段真实结束位置继续移动，不能用叠化、变形、位置重置代替路程。
- **事件触发**：用关键动作的完成条件连接镜头阶段（「人物完全进入门洞后才上升」「摄影机先退出窗口，人物随后靠近」）。秒数负责节奏预算，事件负责先后；冲突时调时长或减负荷，不靠瞬移赶点。
- **画外状态**：只交代会影响再次入画的行动、位置与道具状态（人物在画外上楼、车内人员始终在座）。关键接触或剧情证据必须可见，不能靠画外补完掩盖。

## 输出检查

- [ ] 每个镜头只有一个主运动，且已写明方向、速度、结束构图
- [ ] `Pan/Tilt/Zoom` 与 `Dolly/Truck/Crane` 没有混写
- [ ] 运动在给定秒数内做得完（15s 内不要安排三段大范围移动）
- [ ] 起点与终点都是可读构图，不是模糊或空镜
- [ ] 与前后镜头方向连续（不无故反轴）
