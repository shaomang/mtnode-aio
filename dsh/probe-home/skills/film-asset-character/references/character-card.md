本文件是 `film-asset-character` 的扩展。正文只留必填字段与最小模板，这里放完整词表与可粘贴的骨架。

### 台词与配音的换算

- 台词时长 = 字数 ÷ 语速 + 停顿次数 × 停顿秒数。
- 语速档：克制 2.5–3.2 字/秒；自然 3.5–4.2 字/秒。
- 必须为呼吸与动作留余量；写「他说了一句话」不给字数，等于把时长交给运气。

## 2. 表情词表

9 个核心表情（每个角色都必须有）：

| 键 | 中文 | 可见依据 |
| --- | --- | --- |
| `neutral` | 中性 | 眼睑放松、嘴角平 |
| `happy` | 喜 | 下眼睑上推、嘴角上扬 |
| `angry` | 怒 | 眉内侧下压、鼻翼张 |
| `sad` | 哀 | 眉内侧上抬、下唇轻颤 |
| `surprised` | 惊 | 眉抬高、嘴微张 |
| `fear` | 惧 | 眼睁大、下颌后缩 |
| `disgust` | 厌 | 鼻梁皱、上唇抬 |
| `doubt` | 疑 | 单眉抬、头微侧 |
| `resolve` | 决心 | 下颌前送、视线定 |

10 个扩展（按戏补）：

`relief` 释然、`shame` 羞、`longing` 渴望、`boredom` 倦、`pain` 痛、
`numb` 麻木、`amused` 好笑、`defensive` 防御、`tender` 温柔、`panic` 慌。

规则：

- 表情只描述「变化」，基准脸的默认值不重复写。
- 一个镜头只给一个主表情；叠加两个主表情会得到平均脸。
- 表情板与角色板同灰底、同光位，否则换镜头时脸会跟着光变。

## 3. 姿势库骨架（五类）

| 类 | 条目 |
| --- | --- |
| neutral | idle、breathe、listening |
| attention | look_up、look_down、look_left、look_right |
| emotion | 按上表 9 核心（与表情键同名） |
| action | reach、point、hold、jump、walk_contact、walk_passing |
| mouth | closed、small_o、wide_open、smile、frown、phoneme 形 |

表演节拍：`anticipation → action → hold → settle`。不要每个部件都在动；
hold 让表演可读。姿势数据只写变化部件，其余从基准取默认值。

```json
{
  "pose": "surprised",
  "parts": {
    "head": { "rotation": -6, "y": -4 },
    "pupil_left": { "x": 4, "y": -6 },
    "mouth": "small_o"
  },
  "hold_frames": 18,
  "transition": "back.out"
}
```

## 4. 2D 绑定（要做本地动画时才用）

| 项 | 规则 |
| --- | --- |
| 部件拆分 | 每个可独立运动的部件一个 part：body / head / arm_left / arm_right / eyes / pupils / mouth |
| 层级 | 显式写 `layer`，不依赖导出后的 SVG 源顺序 |
| 父级 | 需要跟随的部件写 `parent` |
| 枢轴 | 与画面同一坐标系，直接写像素坐标 `[x, y]` |
| 约束 | 每个转动件给角度区间，防止穿模与反关节 |
| 视图 | 先做一个视图，分镜需要才加视图 |

```json
{
  "character_id": "lin",
  "rig_type": "svg_rig",
  "parts": [
    { "id": "body", "kind": "torso", "layer": 10 },
    { "id": "head", "kind": "head", "layer": 30, "parent": "body" },
    { "id": "arm_right", "kind": "limb", "layer": 40, "parent": "body" }
  ],
  "joints": {
    "head": { "pivot": [320, 180], "rotation": [-20, 20] },
    "arm_right": { "pivot": [390, 310], "rotation": [-70, 95] }
  }
}
```

自查：每个转动件都有枢轴；需要层级的都有父级；嘴型与瞳孔独立；角色要碰或拿的道具独立成件。

## 5. 三视图 / 表情板提示词骨架

```
一张 3×2 六格角色板，16:9，中性灰底 #8a8a8a，无缝、无渐变。
六格同尺度、同光位、同风格，人物单人、无遮挡、无文字。
左上：正面脸部特写；中上：3/4 脸；右上：侧面；
左下：全身正面；中下：全身背面；右下：手部与随身物特写。
[粘贴 Identity Block 原文]
要求：所有格为同一个人，脸型、发型长度、疤与雀斑位置完全一致。
```

变体：

- 只要两图时：一张脸部特写 + 一张全身正背（同光位、同灰底），这是硬底线。
- 换装不漂脸：左栏幽灵模特展示整套服装，右栏「与输入脸 100% 一致」的特写；两侧同灰底。
- 亲属／同族：不另写「长得像」，而是从同一张脸派生——「取参考中这张脸，翻译到她身上：同样的眼、眉、鼻、唇，同样的痣与雀斑位置」。
- 群像：多角色 lineup 并声明为「多样参考」；单人参考直接扩群会得到同一张脸的克隆队。

## 6. 常见改法对照

| 现象 | 先改什么 | 不要做什么 |
| --- | --- | --- |
| 脸不像 | 加一张正脸特写进参考，权重回到 0.7 | 不要堆形容词 |
| 发型长度漂 | 在卡里补「发尾接触位置」（到下颌线还是到肩） | 不要写「短发」 |
| 全身比例错 | 用全身正背两张同尺度图 | 不要靠文字写「168cm」 |
| 服装换色 | 卡里给 hex，别给色名 | 不要写「深色外套」 |
| 表情糊 | 每镜一个主表情 + hold 帧 | 不要叠加两个情绪词 |
