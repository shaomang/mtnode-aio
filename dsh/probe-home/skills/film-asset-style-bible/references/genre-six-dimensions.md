# 七类型六维参数表

七个类型各一张六维表。色彩、光线、镜头三档、声源、类型风险、场景参数表来自上游预设库；
材质与构图两行为按该行场景例落地的通用经验值，已在表头注明。

通用口径（七个类型都成立）：

- 光源可以在画外，但位置、遮挡、反射路径必须可解释。
- 光比按场次显式标 3:1 / 6:1 / 8:1 / 10:1 / 12:1，不写「对比强」。
- 前景材质、中景主体、背景纵深分别指定区域分配。
- 声源只有在视频／声音任务且该场真实存在时才采用；不因列表增加物件、天气或人物。
- 台词时长 = 字数 ÷ 语速 + 停顿次数 × 停顿秒数；语速档：克制 2.5–3.2 字/秒、自然 3.5–4.2 字/秒。

| 低照度但不死黑 | noir / horror | 光比留在 10:1 上限，暗部写「可读细节」并点名保留项（眼白、金属高光） |
| 大尺度不空洞 | epic / cyberpunk | 加比例参照物（人、车、门），并用烟尘或雾分层 |
| 暖调不甜腻 | romance / fantasy | 饱和度压到 35–45%，把暖色收在一处，冷色留给暗部 |
| 强色不杂乱 | cyberpunk / war | 只留一个饱和强调色；爆炸或霓虹只作瞬时局部 |
| 硬光不脏 | war / epic | 硬光 + 烟尘漫射，材质写冷凝与接触痕迹，不用「脏」当形容词 |
