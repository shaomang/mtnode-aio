# 场景与对白：冲突·潜台词

## 何时用

- 某一场「什么都没发生」：人物聊了很久，价值没变，删掉不影响主线。
- 对白太直、太解释、人人一个腔调；观众提前猜到台词。
- 人物扁平、反派太弱、主角赢得太容易，或冲突写成了吵架。
- 要设计一场摊牌、一次审问、一段告白、一场群戏。
- 想写「安静但有力」的日常剧、群像剧、反高潮结尾。
- 不适用：还在定前提与类型（用 `film-script-story-architecture`）；竖屏短剧的 3 秒钩子与集尾卡点（用 `film-script-short-drama`）；戏曲唱词（用 `film-script-style-adaptation`）。

## 核心原则

1. **每场必须有一次价值转折**。开场价值为正，结尾转负（或反之）；同一价值、同一负荷就是废场，删或并。
2. **场景意图写成动名词**：不是「她很生气」，而是「逼他承认昨晚在哪」。人物要为某个具体东西使用策略。
3. **对白是行动**。每句台词都在试图改变对方（求、逼、哄、羞辱、试探、拖延）；遮住名字仍能认出是谁在说，才算性格化。
4. **潜台词优先于文本**。人物很少直说想要什么；说反话、换话题、谈物件、谈天气，才是活人。
5. **给对手一把刀，再减弱主角的有利条件**。对手必须能打到主角最疼处；打不到，就从主角性格内部找对手。
6. **晚进早出**。进场时冲突已经开始，出场停在最后一个动作或一句不可收回的话上；解释性前戏与情绪余波都删。
7. **一件道具只做一件功，重复三次含义递进**；细节要贴肉、可视、可复现，不能是形容词。
8. **大事件放画外**（契诃夫式）。观众要看的是事件在关系上激起的涟漪，不是事件本身。

## 工作流

1. **写场景卡**。输入：节拍表上的场号与功能。动作：填八字段（见模板 1）。产出：一张可执行的场景卡，写不出「价值对」就退回上一场重排。
2. **定价值与负荷**。输入：场景卡。动作：写开场价值（+3 到 -3）与结尾价值，标负荷（观众此刻多紧张）。产出：价值斜率一行 `+2 → -1`；斜率为 0 就重设冲突。
3. **定意图、策略、超意图**。输入：人物档案。动作：给场内每个人写「想要什么／怎么要／全片真正要什么」，并写清他知道对方哪个按钮。产出：意图表（每人一行）。
4. **选址**。输入：意图表。动作：列 12 个可替代地点，按三标准挑（服务立意／暴露人物／制造冲突）。产出：地点＋一句「为什么非此地不可」；写不出就换地点。
5. **定道具与细节**。输入：地点。动作：选一件核心道具（做一件具体的功）＋两三个可视细节；定哪个要重复、重复时含义怎么变。产出：道具表（道具／功能／出现场次／含义变化）。
6. **定悬念策略**。输入：观众已知信息。动作：决定观众比人物知道多还是少；把哪把钥匙交给观众；延宕几层。产出：悬念一行（谁知道什么／何时揭）。
7. **写节拍表**。输入：以上。动作：用「动名词行动／反应」逐拍写，标每拍价值变化；找到转折点，删除重复拍。产出：3–5 拍（长场可 7 拍）的节拍表。
8. **定进出点**。输入：节拍表。动作：把第一拍往前压到冲突已开始处，把最后一拍留在最后一个字或一个动作。产出：进出点标注（删掉的前后各几行）。
9. **写对白三稿**。输入：节拍表。动作：一稿写足（允许直白）；二稿删解释、删客套、删对称；三稿做潜台词与性格化（见模板 5）。产出：定稿场次，朗读计时。
10. **自检**。输入：定稿。动作：跑「三击测试」（有目的？有价值？这是最好的方式？）与契诃夫化清单（完整表见 `references/scene-dialogue-reference.md`）。产出：修改清单，逐条落到行号。

## 关键参数与模板

> 六种对白场景形态、对白手术清单、人物卡与场景诊断表见 `references/scene-dialogue-reference.md`。

### 1. 场景卡八字段

| 字段 | 填法 | 不合格信号 |
| --- | --- | --- |
| 场号／地点／时间 | `S12 INT. 厨房 — 夜` | 地点可随意替换 |
| 在场人物 | 最多 3 人；第 4 人要有功能 | 有人全程不说话也无功能 |
| 场景意图 | 动名词：逼他签／骗她留下 | 写成情绪或状态 |
| 价值对 | 安全／危险、忠／叛、赢／输 | 两个价值不是反义 |
| 开场负荷 | -3 到 +3 | 与上一场结尾接不上 |
| 转折点 | 第几拍、谁做了什么 | 转折靠外部消息 |
| 出场价值 | 与开场相反或负荷更高 | 与开场相同 |
| 留下问题 | 观众此刻想知道什么 | 无 |

### 2. 五步场景分析（改稿时逐场跑）

1. **价值**：这场押上什么价值？开场与结尾各在什么位置？
2. **节拍**：逐拍写「行动／反应」，看有没有两拍做同一件事。
3. **潜文本**：人物嘴上说的与真正要的是否不同？不同在哪一句？
4. **转折点**：哪一拍让价值翻面？没有就造一个，或把这场降为过场。
5. **节奏**：这场在整集里的位置（幕首／幕中／幕末）与长度是否匹配？幕末场要给钩，幕中场要推进。

### 3. 节拍表写法（动名词）

```
S12 厨房／夜   价值：婚姻安全感 +1 → -2
1. 她摆碗（掩饰）            → 他察觉不对
2. 他问加班（试探）          → 她反问他手机（转移）
3. 他递出收据（亮证据）      → 她沉默（价值翻转）
4. 她笑着说是给婆婆买的（撒谎）→ 他点头（假和解，负荷更高）
```

- 禁止写「两人争吵」「情绪激动」——那不是节拍，是结果。
- 一场 3–5 拍最稳；少于 3 拍通常是过场，多于 7 拍要拆。

### 4. 场景长度与位置（通用经验值）

| 载体 | 单场长度 | 一集场数 | 备注 |
| --- | --- | --- | --- |
| 剧情长片 | 1–3 页 | — | 平均 1.5 页；最短可一行 |
| 一小时剧集 | 1–2.5 页 | 20–40 场 | 幕末场可更短 |
| 竖屏短剧 | 20–40 秒 | 3–5 场（碎切写法 8–15 场） | 见 `film-script-short-drama` |
| 舞台剧 | 5–12 分钟 | 每幕 3–6 场 | 换场靠灯光与调度 |

### 5. 对白三稿法

| 稿次 | 只做一件事 | 具体动作 | 完成判据 |
| --- | --- | --- | --- |
| 一稿 | 写足信息 | 允许直白、允许重复；把人物想要什么全写出来 | 信息无缺 |
| 二稿 | 删 | 删解释、删问候、删「正如你所知」、删副词与括号提示；一句只留一个意思 | 每场少 20–30% 字数 |
| 三稿 | 变行动 | 每句改成「求／逼／哄／刺／躲」中的一种；关键句藏进闲话中段；给每人一句只有他会说的话 | 遮名可辨；朗读不拗口 |

### 6. 潜台词七技法

| 技法 | 做法 | 例 |
| --- | --- | --- |
| 说反话 | 嘴上给肯定，动作给否定 | 「你走吧。」手却拉着门 |
| 换话题 | 被问要害时谈一件小事 | 问「钱去哪了」→「你妈下周来吗」 |
| 谈物件 | 用物件的状态说关系 | 「这表又慢了七分钟。」 |
| 第三人在场 | 借第三人说给当事人听 | 对孩子说「你爸最会算账」 |
| 只说一半 | 句子被打断，后半句留给演员 | 「我不是不想……」（方括号写未说出口的后半句） |
| 沉默成句 | 用「……」占一整行台词 | 对方连问三次，只答「嗯」 |
| 仪式动作 | 用合影、削苹果、抹口红替代告白 | 不写「这是最后一次」 |

### 7. 对白四类毛病（逐条排查）

| 类型 | 症状 | 修法 |
| --- | --- | --- |
| 可信度 | 人物说出他不会知道的事；身份与用词不符 | 补信息来源；按教育程度／职业改词汇与句长 |
| 语言 | 所有人一个腔调；句子太整齐；书面语 | 给每人三个口头禅与一个语法习惯；打碎长句 |
| 内容 | 说主题、说情绪、说前情 | 改成行动或物件；前情用吵架承载 |
| 设计 | 一句台词同时干三件事，结果一件也没干好 | 拆成两句，删掉最不必要的那件 |

### 8. 人物与冲突配置

- **三维档案**：生理（年龄、外貌、健康）／社会（职业、阶层、家庭）／心理（欲望、恐惧、错误信念）。缺一维，人物只会执行功能。
- **编排（orchestration）**：列出每个人物对主题的态度，确保没有两人同型；太阳系式（主角为中心）或四位一体式（四种价值观互相牵制）。
- **四类冲突**：上升（每回合加码）／静止（同一拍重复）／跳跃（无过渡突然翻脸）。只允许上升；静止删拍，跳跃补过渡场。
- **给对手一把刀**：写一场对手精准打到主角最疼处的戏；若打不到，减弱主角的有利条件（钱、身份、盟友、健康）。
- **最强对手是自己**：外部对手解决后，主角必须面对自己的错误信念；禁止「祥云」——关键时刻外力解围、主角被动获救。

### 9. 契诃夫化十二条（写安静群像剧时逐条对）

1. 幕数为偶数，每幕一个情调关键词。
2. 最大的事件放在画外；画内的枪打不中。
3. 幕尾是停顿、否决或独白，不是爆点。
4. 每个人物一件随身物＋一句口头禅；口头禅在结尾反用。
5. 没有反派，或有一个「正直的迫害者」。
6. 正确答案在第一幕就被说出，并被拒绝。
7. 对话偏移半格：答非所问、话题差一点。
8. 哲学后面立刻接茶、伏特加或报纸。
9. 最痛的话最短；有人吹口哨。
10. 每幕环境声有来源；末幕只剩两种。
11. 全剧预告的一件事，结尾没有发生。
12. 结尾＝希望独白＋虚无者一句＋日常动作；坚持它是喜剧。

## 常见坑

- **症状**：场景读起来顺，拍出来平。**原因**：只有信息交换，没有价值转折。**修法**：给这场加一个「谁赢谁输」的判定物（一份文件、一句承认、一个座位），让结尾与开场相反。
- **症状**：人物说话像作者。**原因**：每句都在说主题，且语法一致。**修法**：跑遮名测试；给每人换一套词汇与句长；把主题句交给最不合时宜的人说，并被误读。
- **症状**：反派像纸片人。**原因**：他的理由只有「坏」。**修法**：写三段他的自辩，每段都能让观众短暂站到他那边；最后一击缩成只有一个人听得见的私语。
- **症状**：冲突忽然升级，观众不信。**原因**：跳过了过渡场。**修法**：补一场「代价被看见」的戏，让主角先失去一件具体的东西，再翻脸。
- **症状**：道具反复出现但没意义。**原因**：只做装饰，没做功。**修法**：给道具一个具体功能（开门、计时、证明身份），第二次出现改变关系，第三次出现反用。
