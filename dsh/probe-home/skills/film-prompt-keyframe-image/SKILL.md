# 关键帧与首帧图像提示词

首帧不是「一张好看的图」，而是**视频的初始状态**。本技能保证这张图能被下一步的 i2v 接住：静态信息写全、运动空间留够、模型选对。

## 何时用

- 要走「参考图优先」路径：先出角色卡/场景板/首帧，再拿去做 image-to-video 或多参考生成。
- 已经有一张图，要判断它能不能当首帧（构图、留白、动作状态是否可延伸）。
- 要写角色卡（多视图）、场景板、道具板、风格板。
- 要在多个图像模型之间选一个（人物/服装/场景/奇幻生物/文字排版各自的最优不同）。
- 不适用：直接文生视频；跨镜头身份锁定（见 `film-prompt-consistency`）；已出片的返修（见 `film-prompt-qc`）。

## 核心原则

1. **图像管「状态」，视频管「变化」。** 图像提示词写清可见的静态事实（谁、穿什么、在哪、光从哪来）；视频提示词只写从这一状态出发的运动。图像里写「镜头缓慢推进」会被当成构图指令，不是运动指令。
2. **首帧要让运动有地方去。** 动作停在中间态（手已抬起但未落）、主体偏向一侧留出 `lead room`、光有明确方向可延续、背景有可穿越的前景。静止的「完成态」会让 i2v 只能做微动或乱编。
3. **一张卡 = 一个身份 + 一套服装。** 四视图放同一身份的不同角度与背面，不放不同情绪、不同伤势、不同服装。不同身份、互斥的服装/伤势必须分开建卡。
4. **先设计、后排版。** 先写年龄、比例、脸/发、辨识细节、服装构造/材质/颜色、必要配饰；再把「四视图 + 中性站姿 + 灰底 + 分隔线」的排版合并进去。顺序反了，模型会先画版式再随便填人。
5. **图像模型按资产类选，不按「最强」选。** 人脸匹配、服装、场景、奇幻生物、文字排版的最优模型各不相同，同一项目里换模型是常态。
6. **首帧不要选戏剧高潮。** 选「事情即将发生」的那一帧；高潮帧留给视频中段。
7. **给裁切与字幕留安全区。** 主体与关键道具距边缘 ≥5%，上方留 8–10% 给 headroom 与字幕（**通用经验值**，平台无硬规范）。
8. **不用 negative prompt 兜底。** FLUX 系明确不支持；Seedance 系也以正向锁为准。想排除的写「替代物 + 具体事实」。

## 工作流

1. **判路径（输入：需求）** → 分支：用户明确要「先出参考图」→ 参考图优先；只给一句创意且单角色单场景 → 直接视频，不要为了「更稳」硬加一道图；翻拍/年代戏/多主角/道具归属关键 → 必须参考图优先。
2. **列资产清单** → 输出四类：角色（含服装态）、场景（含时间与天气）、关键道具、风格/色彩板。每类只留「会跨镜出现」的。
3. **选图像模型** → 查第 4 节选型表：人脸/小修 → Nano Banana 2；服装 → GPT Image 2；场景 → Soul Cinema；奇幻生物 → Seedream 5.0；文字排版 → FLUX.2 `flex`；批量便宜 → FLUX.2 `klein`。
4. **写身份块** → 按「年龄 → 体型比例 → 脸/发 → 辨识细节 → 服装构造/材质/颜色 → 配饰」六段写，一段一句。**同一身份的描述词以后每次逐字复用**（这是跨镜一致的基础）。
5. **排卡** → 默认一张文字设计的**四视图卡**（正面/3/4/侧面/背面），中性站姿、灰底、视图间留分隔。不要先生成一张肖像再生成卡。
6. **写首帧** → 用第 4 节首帧模板：`景别 + 主体状态 + 环境 + 光位/K 值 + 材质细节 + 构图落点`。写完跑第 4 节「可延伸性检查」。
7. **归一化尺寸** → 裁成目标视频的画幅与分辨率（例：16:9 → 1280×704；9:16 → 704×1280）。等比铺满 + 居中裁切，别让模型在生成时改比例。
8. **交接** → 视频提示词的第一句改成「从这张图的结束状态继续」，并**删掉**与参考图重复的静态外观描述（只留必须保住的 1–2 个身份特征）。

## 关键参数与模板

### 模板 A：角色卡（四视图）

```
Character sheet of [角色名], [年龄 + 体型比例], [脸型/五官/发型], [辨识细节：疤、痣、瞳色、纹身],
wearing [服装构造 + 材质 + 主色 + 配饰]. Four views: front, three-quarter, side profile, back.
Neutral standing pose, arms relaxed at sides, same neutral expression in all views, flat grey studio
background, thin separators between views, even soft lighting 5600K, full body visible head to toe,
no props, no scene, no text. Photorealistic, 50mm, f/5.6, sharp throughout.
```

要点：`same neutral expression in all views`、`full body visible head to toe`、`no props, no scene` 三句不能省——省了就会出现「海报表情」或道具黏在手上。

### 模板 B：首帧（可延伸）

```
[Shot size], [主体] [中间态动作：已抬起未落 / 正转身一半 / 手刚碰到门把],
[环境：空间 + 陈设 + 天气], [光位 + 质感 + K 值], [材质细节：布料褶皱、金属划痕、皮肤纹理],
[构图：主体落在左三分线, lead room to screen-right], [镜头: 35mm, f/2.8, shallow depth of field],
photorealistic, 35mm film grain, no text, no watermark.
```

反例（不要这样写首帧）：`she is screaming in triumph, arms raised, centered, extreme low angle, dutch angle 25°`——情绪已到顶、构图已极限，视频只能继续加码或崩。

### 首帧可延伸性检查（逐条打勾）

首帧构图公式、四视图卡布局、安全区与「面板 → 镜头」推断表见 `references/keyframe-composition.md`。

- [ ] 动作处于中间态，不是完成态
- [ ] 主体没有贴边，运动方向有 `lead room`
- [ ] 眼睛/脸没有被头发、手、道具遮住（i2v 最先崩的是脸）
- [ ] 光有明确方向与 K 值，后续镜头可延续
- [ ] 没有极浅景深 + 极端透视同时出现（模型难维持）
- [ ] 手部完整可见且不在快速动作中（少一只手就少一类崩坏）
- [ ] 画幅与目标视频一致（已归一化，不是后期再裁）
- [ ] 主体占画面比例合适：单人近景 30–50%，双人 50–70%（**通用经验值**）

### 模板 C：场景板（供多镜复用）

```
[地点], [时间 + 天气], [建筑/地形 + 关键陈设 3–5 件], [主光来源 + 方向 + K 值],
[色彩：主色 + 辅色 + 禁用色], [材质：地面/墙面/织物], [尺度参照：门高、人体高度对比],
wide establishing frame, no people, 24mm, deep focus, photorealistic.
```

要点：`no people` 必写，否则场景板里会塞进路人，后续每次参考都会换来一张不同的脸。

### 首帧 → 视频的交接写法

```
从 @Image1 的结束状态继续：她仍站在窗边，右手已抬起一半。
[只写运动与新信息，不重复外貌与服装。]
```

删静态重复的判据：**参考图已经能看见的，就不要在视频提示词里再描述一遍**；只保留 1–2 个「必须保住」的身份特征做锚点（如发色、标志性配饰），其余交给图。

### 画幅与分辨率

下表的具体像素为**通用经验值**（按 720p 档折算，便于与裁切命令对齐）；源里只给到 480p / 720p / 1080p / 2K / 4K 档位。

| 画幅 | 视频常用分辨率 | 说明 |
| --- | --- | --- |
| 16:9 | 1280×704 / 1920×1080 | 默认横屏 |
| 9:16 | 704×1280 / 1080×1920 | 竖屏短剧、社媒 |
| 1:1 | 1024×1024 | 头像、产品 |
| 4:3 | 1024×768 | 复古、纪录片 |
| 3:4 | 768×1024 | 人像竖构图 |
| 21:9 | 1280×544 | 宽银幕 |

## 常见坑

- **症状：首帧很漂亮，视频一动脸就变。** 原因：首帧里脸被遮挡、侧脸过大、或加了极限透视。修法：重出首帧——正面或 3/4 侧、脸完整、50mm 左右、f/2.8–4、别用 14mm 贴脸。
- **症状：i2v 几乎不动，或只做「呼吸式」微动。** 原因：首帧是完成态（坐定、站稳、表情到位），没有可发生的动作。修法：换成中间态；或在视频提示词里给出明确的新信息（谁进入画面、什么被拿起）。
- **症状：四视图里四个人的脸不是同一个人。** 原因：卡里写了四种表情/四种光，或视图描述各自成段。修法：统一 `same neutral expression`、统一光、统一背景；身份块逐字复用，只改视图名。
- **症状：参考图风格（黑白线稿、厚涂笔触）被带进成片，画风局部崩。** 原因：拿分镜稿/线稿直接当参考图。修法：参考图必须是成片质感；线稿只作构图参考，另出一张质感对的首帧。
- **症状：图像模型完全不理会「不要 XX」。** 原因：该模型不支持 negative。修法：正向替代（`no people` → `deserted, solitary`；`no text` → `clean unmarked surfaces`）。
- **症状：中文提示词出图偏「插画感」，商业片质感上不去。** 原因：中文语料与写实摄影词的绑定弱。修法：身份/剧情用中文写，摄影层（焦段、光位、胶片）用英文片段；或整体转英文再出图。
