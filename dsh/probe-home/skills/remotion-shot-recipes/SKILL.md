# 镜头配方与电影感动效

镜头不是"加个动画"，而是**一次信息投递**：谁在看、看什么、什么时候给下一拍。
本技能把 124 张上游镜头卡压成 9 个可复用模式族，每族给选型条件、数值和实现要点；
完整卡片索引见 `references/shot-vocabulary.md`，可粘代码见 `references/pattern-implementations.md`。

## 何时用

- 手上只有文案/功能清单，要排出一串"有电影感"的镜头，而不是一页页 PPT。
- 已经能做出画面，但节奏平、没有重音、观众看不下去（诊断用第 2 节的自检表）。
- 需要给某个具体动作选参数：急推多少帧、群体入场怎么加速、定格停多久。
- 要判断"这个镜头该用哪种转场"（硬切/甩镜/遮罩/光圈）。
- 不适用：只要曲线与组件（去 animation 技能）、只要字幕与配乐（去 audio 技能）。

## 核心原则

1. **一个节拍只有一个主角**：这一拍观众该看的东西只有一件；主角讲完立刻让位，不许两个元素抢戏。
2. **一种手法全片只当一次主角**：飞入、堆叠、翻页各用一次；重复即删（判例：重复的项目卡镜头被用户点名删掉）。
3. **速度感来自加速度，不来自快**：群体运动必须非线性错峰，匀速 = 廉价 PPT；批量入场"越来越快"，收尾留 0.5s 静止。
4. **节奏宁慢勿快**：开场主体动作弧 ≥3s；交互演示按真人速度；第一版几乎总偏快，默认放慢一档。
5. **关键信息落定必须呼吸**：字标/数字/全貌落定后静止 ≥1s（普通内容卡 ≥15–20 帧）再切。
6. **群体运动先找物理隐喻**：发牌、堆叠、瀑布、爆炸分解——先有隐喻再写代码；抽象 flood 往往多轮不收敛。
7. **只让一个元素发光/用主角色**：一帧里高亮元素 ≤1；两个以上就是"拉斯维加斯"。
8. **镜头必须服务语义**：急推=点名，拉远=孤立，俯冲=降临，贴面=巡视；没有语义的运镜只是抖动。

## 工作流

1. **列功能/信息清单**（输入：产品页或文案）→ 每条要点一行；核心要点漏拍等于返工。产出：`信息 → 镜头` 映射草表。
2. **定能量曲线**（输入：时长 + BGM）→ 30s 片：0–1.5s 钩子（前 15 帧必须有运动）→ 1.5–3s 语境 → 3–22s 主体 3–4 拍 → 22–27s 兑现（最大动作）→ 27–30s 收尾 CTA。产出：能量弧。
3. **选族**（输入：每一拍的信息类型）→ 见第 1 节选型表：文字用字形族、数量用数据族、列表用群体族、章节用转场族。产出：每拍一个模式名。
4. **落参数**（输入：模式名 + 画幅）→ 用第 1 节的参数列；所有时长写成秒再换帧。产出：`SHOTS` 表（id / 模式 / 起拍 / 时长 / 主角）。
5. **写实现**（输入：`SHOTS`）→ 一镜一组件，`useCurrentFrame` 驱动；共用 `theme.ts` 与动效组件。产出：可预览的镜头。
6. **卡点吸附**（输入：BGM 节拍网格）→ 切点对齐到拍号；音效早 2–3 帧。产出：对齐后的时间轴。
7. **验片**（输入：Studio 0.25 倍速 + 抽帧）→ 每镜抽首/中/末帧，检查：主角是否唯一、有没有匀速、有没有 hold、文字是否出安全区。产出：缺陷清单。
8. **去重**（输入：全片）→ 按"这个镜头给了什么新信息"过一遍，重复信息/重复手法删掉。产出：终版镜头表。

## 关键参数与模板

### 9 个模式族（选型 + 参数 + 要点）

**① 推拉与揭示（camera）**

| 模式 | 适用场景 | 参数 | 实现要点 |
| --- | --- | --- | --- |
| crash-zoom 急推 | 功能段"点名"、句尾重音 | 动作 6–11 帧；前 hold ≥30 帧建立全景，后 hold ≥45 帧读特写 | 落位二选一：过冲回弹（弹性，`bezier(0.3,0,0.25,1.15)`）或撞停震屏（重量，1 帧位移 4–8px 后归零） |
| push-in 极缓推近 | 任何 hold 段（防"像冻结"） | 60s 镜推 1.00→1.06；30s 镜 1.00→1.04 | 静止画面必须带 1–6% 推近，否则 QA 判为卡帧 |
| pull-back 拉远孤立 | 结论、孤立感、收尾 | 3–5s，scale 1.2→0.9 | 拉远同时降亮度 10–15%，主体才"沉"下来 |
| crane-rise 升起揭示 | 数据面板/仪表盘开场 | 4–6s，Y 轴升起 + 后拉，减速 | 位移用 easeInOutQuint，别匀速 |
| 贴面游走 / 强透视滑移 | 网页/UI 巡览 | 4–5s，倾斜 55–60° | 物动镜不动更稳；文字初始悬空 + 同形软影，随行进贴落 |
| 3D 空间运镜 | 多卡片/多终端叙事 | 每站停留 ≥30 帧，段间 28–32 帧飞行 | 相机按各步姿态取逆依次对齐；末步拉到总览 |

**② 快切与变速（rhythm）**

| 模式 | 适用场景 | 参数 | 实现要点 |
| --- | --- | --- | --- |
| beat-cut 硬切当拍 | 副歌、强鼓点 | 三次白闪各 3 帧，同画面三个裁切：全景→卡片→特写 | 白闪 `opacity 1→0` 3 帧；切点卡在拍上 |
| jump-cut punch-in | 逼近目标、强调 | 三级跳切，每级放大 1.25–1.35×，无补间 | 同一构图硬跳，不做缩放缓动 |
| speed-ramp-freeze | 长横移中"停下划重点" | 定格 ≥45 帧；解冻 smootherstep 22 帧 | 帧号 remap：流段斜率 1、定格段斜率 0；速度 <8px/帧不挂模糊 |
| trailer 前置速剪 | 开场钩子 | 三镜各 9 帧 + 黑场静默 1 拍 | 先给结论再开场标题 |
| 四宫格并行 | 副歌信息轰炸 | 四象限微场景，节拍错开 3–6 帧 | 每格独立 `Sequence`，不要同步起 |

**③ 字形动效（typography）**

| 模式 | 适用场景 | 参数 | 实现要点 |
| --- | --- | --- | --- |
| 逐词模糊揭示 | 标题主力 | 每词 12–18 帧；词间隔 4 帧；y +24px、blur 8→0 | 三通道同一条进度；中文按字切时词间隔降到 2–3 帧 |
| 字符坠落 | 轻松调性开场 | 第 i 字起跳 `4 + 36·(1−(1−i/(n−1))^1.5)`；重力 y 24 帧；弹跳 30% / 9%；歪角 ±6°；末拍 6 帧集体立正 | 歪角是物理感的一半；收尾必须真静止 ≥20 帧 |
| 打字机 / 改口 | 文档感、演示输入 | 每字 2–3 帧；退格 1 帧/字 | 光标闪烁周期 15–20 帧，别每帧闪 |
| 逐词高亮（karaoke） | 口播字幕、跟读 | 词级 `startMs/endMs`；高亮色全片唯一 | 见 audio 技能的字幕组件 |
| 字重脉冲 | 强节奏、蹦迪感 | 随拍在 600↔900 间 6–8 帧 | 用可变字体的 `fontVariationSettings`，别换字体 |
| 一字一词逐行上移 | 形容词列表、节拍器 | 每拍 0.6s 上移一行 | 行、色、场三通道锁死同一拍点 |

**④ 群体入场（ui-entrance）**

| 模式 | 适用场景 | 参数 | 实现要点 |
| --- | --- | --- | --- |
| 发牌硬加速 | 卡片墙、列表、信息密度 | 第 k 张 `cue = 36 + 4k − 0.0792·k(k−1)`（间隔 4 帧→0.2 帧）；单卡飞行 8 帧 + settle 4 帧 + press 2 帧；满板 hold ≥0.5s | 物理隐喻（发牌）优先；预备拍一次、不逐卡加；越落越快 |
| 卡堆弹入 | 模板/选项集合 | 3–5 帧/张错峰，落位压弹 2 帧 | 后一张的压缩带动整摞（传递感） |
| 对角波点阵 | 网格、图标矩阵 | 距波源欧氏距离 × 1.5 帧错峰；scale 过冲 1.5 再回 1 | 比从左到右整齐划一更有生气 |
| 原位显形 | bento 网格、蓝图 | 不位移，只做 opacity + 描边生长 | 与"飞入位移型"互补，同片只用一种 |
| 逐格描线 | 线稿、图示 | 描边 0.6–1.2s，`strokeDasharray` 生长 | 闭合瞬间闪一帧再放内容 |

**⑤ 数据可视化（data）**

| 模式 | 适用场景 | 参数 | 实现要点 |
| --- | --- | --- | --- |
| 数字滚动 | KPI、价格、结果 | 0.8–1.2s，easeOut；`tabular-nums` | 位数变化预留宽度，避免整行抖动 |
| 活体曲线 | "实时"感、增长 | 右端持续写入；突发尖峰 3–5 帧 | 曲线用 `path` 逐帧重算，点数控制在 ≤200 |
| 轴爆表重标 | 数值破表 | 新值冲出画框 8–12 帧后 y 轴重标 | 重标瞬间给一记 60–80ms 的顿帧 |
| 仪表扫针 | 自检、机械仪式 | 满弧扫针 0.8–1.2s，回落到真值 | 指针甩到 100% 再回落才像"自检" |
| 点阵重组 | 抽象概念→数字 | 三幕迁徙，每幕 20–30 帧 | 目标位置先算好，粒子只做缓动插值 |

**⑥ 纸张/印刷/手作质感（effects）**

| 模式 | 适用场景 | 参数 | 实现要点 |
| --- | --- | --- | --- |
| 套印错位（riso） | 撞停瞬间、复古感 | 双色偏移 6–10px，抖 2 下（各 2 帧）后套准 | 两版色用 `mix-blend-mode: multiply` |
| 马克笔划线 | 关键词强调 | 10 帧描完，笔宽中段 0.12em、首尾 0.6×，微上斜跟字势 | 斜向跟字势；画反一眼假（返工判例） |
| 纸卡压印 | 呼吸位、章节字卡 | 逐词压印，每词 6–8 帧；一句一个强调色斜体 | 纸张纹理用确定性噪声，不用随机 |
| 颗粒/暗角 | 全片质感层 | 颗粒 opacity 0.06–0.10，每 2 帧换一次 | 每帧都换会闪；暗角 45–60% 强度 |
| 墨渗/撕裂 | 转场、章节切换 | 0.6–1.0s，边缘噪声 scale 4–8 | 只做一次，重复会像故障 |

**⑦ 转场（transition）**

| 模式 | 适用场景 | 参数 | 实现要点 |
| --- | --- | --- | --- |
| 硬切藏切点 | 通用、最省 | 藏在遮挡/撞击/光峰的 1–3 帧里 | 观众看不见剪刀；比花式转场更高级 |
| whip-pan 甩镜 | 同层级切换 | 12–18 帧，模糊 12–20px | 甩出与甩入同向，速度连续 |
| 遮罩穿窗 | 纵深/空间切换 | 0.8–1.2s | 用同一形状跨越两景（门、字腔、圆） |
| 光圈匹配（iris） | 圆形元素之间 | 20–28 帧 | 圆心必须对得上语义锚点 |
| 整屏上推 | 分章、多色块 | 各章 0.5–0.7s | 内容随底色坐标系一起走 |
| 故障撕裂 | 数字/赛博语义 | 8–16 帧，横条 12–16 根错位 | 一帧硬切，别拖成 1s |

**⑧ 光与材质（effects / opening）**

| 模式 | 适用场景 | 参数 | 实现要点 |
| --- | --- | --- | --- |
| 聚光显影 | 暗场 UI 展示 | 光斑半径 220–380px，扫 2–3s | "光到即亮、光走即暗"，其余压到 15–25% |
| 扫光（sheen） | 金属/玻璃/卡片 | 单次 12–18 帧斜向 105–115° | 一次即可，重复读作加载动画 |
| 飞线连接 | 集成、拓扑 | 描线 0.6–1.0s，脉冲沿路径 1.2s/圈 | 线宽 1.5–2px，端点加小光点 |
| 氛围光斑 | 背景底噪 | 2–3 个径向渐变，缓慢漂移 ±8% | 与暗角、颗粒叠成"五层堆栈" |

**⑨ 收尾（outro）**

| 模式 | 适用场景 | 参数 | 实现要点 |
| --- | --- | --- | --- |
| 字标定版 | 品牌收束 | 字标 hold ≥1s，最后 15 帧才淡出 | 强调色只给一个字/一条标语 |
| 元素合影 | 发布会式收场 | 元素 0.6–1.2s 内围拢，舞台光 + 金尘 | 元素数量 ≤12，多了糊 |
| 减法收尾 | 工具类产品 | UI 层层蒸发，只剩主按钮 → 字标 | 从外围到中心错峰 3–5 帧 |

### 三支可改的骨架代码

```tsx
// 急推：全景 30 帧 → 6 帧推到特写 → 过冲落位 → hold 45 帧
import { Easing, interpolate, spring, useCurrentFrame, useVideoConfig } from "remotion";

const frame = useCurrentFrame();
const { fps } = useVideoConfig();
const START = 30;
const p = interpolate(frame, [START, START + 6], [1, 2.6], {
  easing: Easing.bezier(0.3, 0, 0.25, 1),
  extrapolateLeft: "clamp",
  extrapolateRight: "clamp",
});
const settle = spring({ frame: frame - (START + 6), fps, config: { damping: 12, stiffness: 180, mass: 0.7 } });
const scale = p + (1 - settle) * 0.06; // 落位后 6% 过冲回弹
```

```tsx
// 群体发牌：硬加速 + 单卡飞行/缓冲/压弹
const dealDelay = (k: number) => 36 + 4 * k - 0.0792 * k * (k - 1);
const cardProgress = (k: number, f: number) => {
  const local = f - dealDelay(k);
  const fly = interpolate(local, [0, 8], [0, 1], { easing: Easing.bezier(0.3, 0, 0.2, 1), extrapolateLeft: "clamp", extrapolateRight: "clamp" });
  const settle = interpolate(local, [8, 12], [0, 1], { easing: Easing.bezier(0.3, 0, 0.25, 1.15), extrapolateLeft: "clamp", extrapolateRight: "clamp" });
  const press = interpolate(local, [12, 14], [0.996, 1], { extrapolateLeft: "clamp", extrapolateRight: "clamp" });
  return { fly, settle, press };
};
```

```tsx
// 变速定格：帧号 remap（斜率即速率）
const remap = (f: number) => {
  const FLOW = 26;                 // px / 源帧
  if (f < 40) return f * FLOW;                       // 流动：斜率 1
  if (f < 40 + 67) return 40 * FLOW;                 // 定格：斜率 0（67 帧 ≥45）
  const u = Math.min(1, (f - 107) / 22);
  const s = u * u * u * (u * (u * 6 - 15) + 10);     // smootherstep
  return 40 * FLOW + s * FLOW * 1.8;                 // 解冻补偿：平均斜率 >1
};
```

### 节奏与构图硬指标

| 指标 | 数值 |
| --- | --- |
| 开场首个运动 | 前 15 帧内必须发生 |
| 新视觉元素间隔 | ≤90 帧（3s） |
| 每拍结构 | HIT → hold 15–20 帧 → build |
| 全片静止时刻 | ≥3 处 |
| 主体动作弧 | ≥3s |
| 竖屏安全区 | 上下各留 220px，关键文字在中间 75% |
| 高亮元素 | 每帧 ≤1 |
| 五层堆栈 | 背景网格 → 素材 → 图形 → 调色 → 颗粒+暗角 |

## 常见坑

- **片子"很平"但没有错**：每镜都在动、都在匀速、都没有 hold → 加静止、加速错峰、把重音集中到一处。
- **卡堆/瀑布不收敛**：用抽象 flood 反复调参数 → 换物理隐喻（发牌/堆叠/瀑布），一轮就过。
- **镜头越加越多、观众更晕**：同一手法当了两次主角，或两个镜头讲同一件事 → 按"给了什么新信息"删。
- **急推落位"软"**：只做了缩放没做落位缓冲 → 补 settle（4 帧）+ press（2 帧）；或改撞停震屏。
- **定格像卡顿**：没给"暂停信号" → 补快门白闪 3 帧 + 取景框四角 + 时间码变 PAUSED，观众才认得出是刻意。
- **转场比内容还抢戏**：每章都上花式转场 → 全片只留 1–2 次大转场，其余用藏切。
- **上游数值直接照抄后不成立**：所有参数是在占位素材上调校的起点 → 首次实战必须以真实素材回验一遍（这是上游的明文纪律）。
