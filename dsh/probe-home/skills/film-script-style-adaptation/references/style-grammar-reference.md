| 东京物语 | 1953 | 176 | 母亲病逝；儿女推诿赡养 | 父亲独坐，邻家太太一句「又冷清了啊」 |
| 浮草 | 1959 | 121 | 戏班解散；私生子身世揭破 | 父子在车站，和解留在画外 |
| 秋日和 | 1960 | 110 | 母亲劝女儿出嫁；三人组撮合 | 母亲独处，女儿已走 |
| 秋刀鱼之味 | 1962 | 98 | 女儿错过意中人；父亲迟疑 | 父亲独坐，哼军舰进行曲 |

可复用规律：

1. 场数 98–176；单场 1–1.5 页；最短一场只有一行场景标题。
2. 一次移动拆成多个场号；时间标注只在段落起点（「翌日」「当晚」「数日后」）。
3. 人物首次出场括注年龄与身份：「纪子（28 岁，周吉阵亡的二儿子的妻子）」。
4. 舞台指示可写导演视点：「（远摄）」「从里间远摄」「俯瞰」。
5. 关键台词藏在闲话中段：前后各用一句闲话包住。

## 二、戏曲两体例细节

### 2.1 板腔体唱段结构

| 项目 | 规则 | 自检 |
| --- | --- | --- |
| 分句 | 七字＝2·2·3；十字＝3·3·4 | 按分句念，后半截能成语 |
| 平仄 | 上句尾仄、下句尾平 | 抄末字列，看是否平仄交替 |
| 押韵 | 下句必押，上句可押可不押 | 下句末字是否同辙 |
| 句数 | 偶数；奇数必须标【扫头】 | 数句数 |
| 长度 | 超过八句要出变格 | 标出变格在哪句 |
| 重点句 | 一段只一句；唱段以它命名 | 观众会记住哪一句 |

常见板式（通用经验值，写标注本时按剧种核对）：原板（叙事）、慢板（抒情）、快板（冲突）、散板（自由）、摇板（紧张）、流水（连说带唱）。板式与情绪对应，不按字数长短选。

十三辙（通用经验值）：发花、梭波、乜斜、一七、姑苏、怀来、灰堆、遥条、由求、言前、人辰、江阳、中东。宽韵（人辰、江阳、言前）易写易雷同；险韵（乜斜、发花）字少，贴切则新。

### 2.2 曲牌体套数

| 项目 | 规则 |
| --- | --- |
| 杂剧 | 四折一楔子；一折一宫调，四折不重；第一折恒仙吕、第四折恒双调；一折一韵到底 |
| 楔子 | 只能仙吕〔赏花时〕或〔端正好〕，至多两支；装不下改成一折 |
| 传奇 | 明传奇率以四十出为度；长折八曲、短折六或四 |
| 主唱 | 杂剧一人主唱到底；主唱权＝主角权 |
| 套数 | 首尾数曲固定，中间可增删倒置；一套十二三支以内 |
| 下场诗 | 集唐四句，既收本出又暗示下出；末出可八句 |
| 南北合套 | 北曲给一人、南曲分众人，各支带合头 |

## 三、格式元素速查

| 元素 | 写法 | 用途 | 禁忌 |
| --- | --- | --- | --- |
| V.O. | `角色名（V.O.）` | 旁白、电话另一端、回忆 | 与 O.S. 混用 |
| O.S. | `角色名（O.S.）` | 在同一场景但不在画面内 | 用于画外叙述 |
| MORE / CONT'D | `角色名（MORE）`／`角色名（CONT'D）` | 台词被动作打断后继续 | 滥用成每句都加 |
| 双人对白 | 两列并排 | 抢话、同时说 | 用于正常轮流对话 |
| 闪回 | `FLASHBACK —`／`闪回` | 交代前史 | 一场内多次跳进跳出 |
| 插入镜头 | `INSERT — 物件` | 强调关键物证 | 用来救叙事漏洞 |
| 转场 | `CUT TO:`／`切至` | 场景切换 | 每场都标 |

中文交付注意：

- 全中文对白默认场号制，不用美式角色名居中版式。
- 一页≈一分钟只对美式排版成立；中文剧本按字数估：约 4.5 字／秒口播。
- Fountain 文件头声明 `Title:`、`Author:`、`Draft date:`；中文需在文件内注明编码 UTF-8。

## 四、改编案例与可迁移手法

| 案例 | 做法 | 可迁移点 |
| --- | --- | --- |
| 《女王的棋局》 | 小说起点与剧集起点不同，选更动态、能立刻建立落差处 | 改编先选起点，不按原书顺序 |
| 《亢奋》 | 几乎改掉一切，只留「鲁莽享乐、心理受损的青少年」 | 留精髓一句，其余可换 |
| 《无择》 | 柏林线全部虚构，刻意把虚构人物与真人拉开 | 真人题材先处理隐私与授权 |
| 《基本演绎法》 | 「Holmes in repair」：本来领先十步的人只领先两步 | 改人物设定要写成一句可复用的公式 |
| 《Vida》 | 手上是 world-building document，不是 story | 先判断素材类型，再谈改编 |
| 《继承之战》 | 每季换引擎压力；终季主角在 30% 处死亡 | 长线改编要算「引擎第几集失压」 |

改编页数换算（通用经验值）：一集 42 分钟正片≈55–65 页美式排版；中文一集约 1.2–1.5 万字对白本。改编前先定「一集覆盖原书多少章」，再谈删改。
