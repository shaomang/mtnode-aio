# 场景与道具资产

## 何时用

- 剧本里有会反复出现的空间（房间、巷子、车间、车内），需要先做一次成资产，而不是每个镜头重新描述。
- 要交付场景设定图、环境图、房间多角度、场景机位设定、九宫格机位板。
- 要交代平面布局：出入口、通道、遮挡、固定锚点、楼层关系。
- 有道具有剧情作用（枪、信、药瓶、钥匙），需要形制、材质、磨损、可见面与持有人一致。
- 场景要跨镜头「还是这间屋子」，或同一场要正反打、越轴不能穿帮。
- 不适用：只要一张气氛图（不必建资产）；角色本身（用 `film-asset-character`）；已锁定资产的质检（用 `film-asset-qc`）。

## 核心原则

1. **先读剧本再设计空间**。标出该空间出现的场次、时段、天气、光源开关、既有损坏；后续场次的破坏和天气不得提前带进当前场次。
2. **常规场景默认两张独立图：主图 + 反打**。用户明确只要单图、某角度或局部修订时按其要求，不补齐套餐；九宫格只在用户点名要时展开。
3. **五视图是资料上限**：直对宽景、左角透视、右角透视、反打、细节特写。四向视图 = 去掉细节格。
4. **平面图只用于推理，不进生成输入**。视频模型按帧思考，拿到俯视平面图只会把它当几何硬套；进提示词的是「左/中/右 + 前/中/后 + 站位」的分镜描述。
5. **空间不变，画面随相机重新推导**。换机位要重算左右、远近、遮挡、反射与受光；反打不是把原图水平翻转，广角也不能把原来不通的门打通。
6. **成组场景先做曝光归一化**：同一场要剪在一起的板，先统一曝光与光位，否则剪接点上会读成「换了个天气」。
7. **道具按「怎么被携带、握持、放置」定形**，不按「好看」定形；先整体轮廓与比例，再构件连接，再材质工艺，最后才是有作用的局部细节。
8. **一件道具一张卡一行镜头对照**，写明持有人、可见面、朝向、状态变化；不写这些，道具就会在不同镜头里换面、换手、换尺寸。

## 工作流

1. **读场次与提取需求**。输入：剧本。动作：列出该空间出现的场次、时段、天气、人物站位、道具使用点。产出：需求行（场次 / 时段 / 光源 / 必须可见的锚点）。
2. **定空间骨架**。输入：需求行。动作：定稳定方向（入口墙、窗墙、内墙）、边界与连接（门洞、走廊转角、楼梯）、固定锚点（大件家具、立柱、设备）、同一状态（时段、天气、光源开关）。产出：布局记录（写进场景卡 `布局` 段）。
3. **画平面布局（推理用）**。输入：布局记录。动作：俯视图标注每人的位置、面向、视线、相互距离与尺度参照。产出：平面图 + 一段可粘贴的分镜站位描述。平面图只给自己看。
4. **出主图**。输入：场景卡。动作：正对主视角、空景（除非要人物关系）、3/4 角度优先（看得见更多深度，运镜才有地方走）。产出：主图 1 张。
5. **出反打与其余视角**。输入：主图。动作：按五视图补左角、右角、反打、细节；反打单独存成 `@loc_reverse` 级资产；同一 seed 或 Grid 生成以保光与材质一致。产出：3–5 张一组。
6. **统一曝光与光位**。输入：整组板。动作：逐张对主版做「只改曝光与光位、其余不变」的编辑；检查色温、光比、饱和度是否一致。产出：可剪接的一组板。
7. **写道具卡**。输入：剧本中的使用方式。动作：定轮廓比例 → 构件连接与操作 → 材料与工艺 → 有作用的局部；出正 / 侧 / 背多视角，会翻倒或滚动的补底面，关键局部补微距。产出：`Pxx` 道具卡。
8. **建道具—使用镜头对照表**。输入：道具卡 + 场次表。动作：逐镜头填持有人、可见面、朝向、最终状态。产出：对照表（道具卡内）。
9. **交叉校核**。输入：全部图。动作：用共享锚点核对各视角是否同一空间；道具检查部件总数、连接、材料边界、左右手性是否漂移。产出：问题格清单，只修问题格。

## 关键参数与模板

### 1. 场景卡字段

| 字段 | 写什么 | 判定标准 |
| --- | --- | --- |
| 编号 / tag | `S01`–`S99` + `@loc_name` | 已确认编号不得复用 |
| 稳定方向 | 入口墙 / 窗墙 / 内墙 / 实际方位 | 不许用「画面左」当世界坐标 |
| 边界与连接 | 房间轮廓、墙段、门窗洞口、走廊转角、楼梯起止 | L 形、环廊、复式先有连通关系 |
| 固定锚点 | 3–5 件不可移、可辨认的大件（含朝向与体积） | 二阶同款家具不算锚点，是歧义 |
| 主色 / 辅色 / 强调色 | 3 个 hex，强调色只 1 个 | 与风格圣经的 5–7 色板同源 |
| 光照基调 | 光源类型 + 位置 + 色温 K + 光比 | 三项必须齐全，光比写 3:1 / 6:1 / 10:1 这类显式值 |
| 内置影调 | 该空间自带的调色倾向（暖高光冷暗部等） | 同一场所有镜头共用 |
| 材质与磨损 | 地面颗粒与湿度、墙面、金属、织物、接触痕迹 | 不写「很旧」 |
| 未看见区域 | 明确标为未知或候选推定 | 不许把透视图当全景证据 |
| 场景状态 | 时段、天气、开关、既有损坏 | 九宫格里所有格同一时刻 |

### 2. 视图组合与数量

| 组合 | 张数 | 每格锁什么 |
| --- | --- | --- |
| 常规交付（默认） | 2 | 主图（尺度、焦点、地平线）+ 反打（相机背后那面） |
| 四向视图 | 4 | 正、左角、右角、反打；同一美术与布局 |
| 五视图（地点资产） | 5 | 四向 + 细节特写（纹理、磨损、招牌、小物件） |
| 九宫格机位板 | 9（3×3） | 每格必须有真实摄影位置或视向变化；同机位变焦、裁切、换滤镜不算新机位 |
| 成对反打 | 2 | `@loc_room` + `@loc_room_reverse` 分开存、分开 @ 登记 |

九宫格机位关系可选（不套固定九种）：入口向内 / 主要使用区反看入口 / 两个角落斜向全景 / 沿长边侧向 / 门洞或柱间越界 / 场内可成立的高机位俯看 / 低位近功能区 / 夹层看下层 / 下层看上层。

### 3. 左右方向校验（有平面坐标时）

向前为 `(dx, dy)`、z 向上时，画面右方在平面上是 `(dy, -dx)`；目标相对相机的向量与它点积为正，才在画面右侧。

- 例：朝南看时，东侧在画面左——写成右侧就是穿帮。
- 没坐标时用可核对关系描述：「转角墙遮住桌子」，不凭空指定左右。

### 4. 道具卡字段

| 字段 | 写什么 | 判定标准 |
| --- | --- | --- |
| 编号 / tag | `P01`–`P99` + `@prop` | 与场景卡、角色卡互引 |
| 用途与使用方式 | 携带 / 握持 / 放置 / 操作 | 决定轮廓与握持区 |
| 轮廓与比例 | 长宽高相对关系 + 一个尺度参照物 | 无精确尺寸时只写有依据的关系 |
| 结构与连接 | 主要构件、铰接、接口、开合方式 | 部件总数跨视图不变 |
| 材料与工艺 | 每面材质 + 表面处理（拉丝/氧化/冷凝/织物/压褶） | 至少 2–4 个材质属性 |
| 颜色 | 主色 + 强调色 hex | 不用「银色」 |
| 磨损与标记 | 划痕、刻字、贴纸、编号 | 位置写具体到面 |
| 可动件 | 哪个部件会动、幅度 | 不动的不标 |
| 可见面 | 正面 / 侧面 / 背面 / 底面 | 会翻滚就必须有底面 |
| 尺度校验 | 与已定人物或环境的接触关系 | 手持镜头里必须成立 |

### 5. 道具—使用镜头对照表（道具卡内必备）

| 镜头 | 持有人 | 可见面 / 朝向 | 状态变化 | 参考格 |
| --- | --- | --- | --- | --- |
| S04-03 | `@lin` 右手 | 正面，镜头侧向 3/4 | 无 | P01-front |
| S07-01 | `@lin` 右手 | 侧面，开盖 | 盖打开 | P01-side |
| S07-09 | 放在桌面 | 背面朝上，镜头俯 30° | 有血迹 | P01-back |

规则：一行一镜头；不写这行的道具，必然在某镜里换手、翻面或改尺寸。

### 6. 场景卡模板

```markdown
# S07 @loc_workshop — v1
状态: draft        场次: S07 S11 S12
主图: assets/locations/workshop_main.png
反打: assets/locations/workshop_reverse.png

## 布局
- 稳定方向: 南墙为入口（卷帘门），北墙两扇高窗
- 边界与连接: 12×8m 矩形；东侧通走廊，西侧隔出一间隔间（无门）
- 固定锚点: 北墙工作台（长 3m，朝南）、东侧立柱（距入口 2.4m）、西南角油桶
- 未看见区域: 隔间内部（候选推定，未批准）

## 光照基调
- 光源: 高窗侧光 + 顶灯 2 盏（左亮右坏）
- 色温: 4500K    光比: 6:1    内置影调: 中性偏冷，暗部可读
- 主色 #6E6A63 / 辅色 #3C3A36 / 强调色 #B8860B（只用于工具金属）

## 材质
- 地面: 水泥，细颗粒，油渍集中在工作台前 1.5m
- 墙面: 涂料起皮，距地 40cm 有一道旧水痕

## 视图
| 视图 | 文件 | 锁什么 |
| main | workshop_main.png | 尺度、焦点、地平线 |
| reverse | workshop_reverse.png | 相机背后墙面与门 |
| left | workshop_left.png | 隔间开口与柱位 |

## 机位计划（spatial_contract / view_plan）
- view_plan.main: 位置=入口内 1m，看向工作台；高度 1.5m，平视；取景 24mm
- view_plan.reverse: 位置=工作台前，看向入口；高度 1.5m，平视
```

> 模板里的尺寸、色温、焦段、距离都是示例值，按实际空间替换；替换后同一场所有视图必须共用这一套值。

### 7. 多机位九宫格提示词骨架

```
一张 3×3 九宫格场景机位参考板，九格展示同一处【场景自然名称】，
同一时刻、同一美术设计与空间布局。
共同空间：【稳定方向、门窗/通路、固定家具及朝向、层高或楼层连接】。
共同视觉：【情绪、美术大形、材质与色块、有来源的光影关系】。
从左上到右下：【逐格写摄影位置→看向哪里、镜头高度/俯仰、取景、可见锚点与关键遮挡】。
保持建筑、物件位置与数量、光源世界位置及场景状态。各格只改变摄影机。
```

不打印后台资产编号、空字段、自检项；多张独立提示词不能只写「同上一张」。

- 场景卡完整字段与布局记录格式见 `references/scene-card.md`；道具卡、设定板版式与跨视图一致性检查见 `references/prop-card.md`。

## 常见坑

1. **每个镜头重新描述环境** → 墙会漂、家具会挪、尺度会变 → 先做地点资产，提示词里只引用 `@loc` 加本镜机位。
2. **反打造成水平翻转** → 窗光和门的位置一起被镜像，观众读成换了个房间 → 反打按几何重新推导，窗在画面右就是右。
3. **九宫格里同机位变焦凑数** → 九格信息量不足，仍不知道空间怎么连 → 每格必须换摄影位置或视向；真实约束只支持 3 个位置就交 3 个并说明缺口。
4. **把平面图当参考图喂给视频模型** → 模型把俯视几何硬塞进画面，出俯拍或错位 → 平面图只做推理，进提示词的是站位描述。
5. **成组板曝光不一致** → 剪接点上像换了天气 → 逐张对主版做「只改曝光与光位」的归一化。
6. **道具板只出正面** → 一转手就换造型、按键数量变化 → 正/侧/背必出，会翻滚补底面，关键局部补微距；主图六枚键，局部变七枚就是一致性错误。
7. **给道具临时加机关** → 后续镜头无法解释 → 未设定的内部结构不发明；需要剖面时标明「说明用，不是剧情当前状态」。
