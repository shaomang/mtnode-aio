# 重试、留痕与抢救

## 一、开拍前的三个数字

| 项 | 写什么 | 例子 |
| --- | --- | --- |
| 重试预算 | 这一镜最多付几次 | `S03_005：预算 3 次` |
| 够好标准 | 主缺陷 + 可放的次缺陷 | `手部不崩、脸一致；袖口褶皱可放` |
| 时间上限 | 到哪个时间点必须收 | `20:00 前必须定稿，否则降级为固定镜` |

没写这三个数，预算会静默变成「完美」，任何次数都不够。

## 二、重试阶梯（逐级升，不跳级）

```
L1  改一个子句 → 重抽
L2  换一个参数或模式（分辨率 / 时长 / std↔fast / 模式）
L2b 到预算一半仍无进展 → 停手，换策略（可与 L3 同时）
L3  拆镜 / 换参考 / 换首帧
L4  rewrite（改结构）或换模型
```

判定规则：

- **同一缺陷出现两次 → 直接 L4（rewrite）**，不再抽卡。
- **每次都是不同的随机缺陷 → 走批量抽卡 + 筛（batch-and-cull）**，不要逐条重写。
- L4 计的是「改写次数」，不是「重抽次数」；每次 rewrite 只改一行，所以 L1 的要求已被包含。

## 三、停损规则

| 规则 | 数值 | 说明 |
| --- | --- | --- |
| 单镜付费尝试 | 3 次 | 超过必须有「改了什么」的记录 |
| 绝对天花板 | 10–15 次 | 到此必须换方案（拆镜 / 换模型 / 放弃该镜） |
| 预算半程检查 | 50% | 无进展 → 换策略 |
| 整片漏斗参考 | 每保留一镜 65–100 次生成 | 这是**整片预算**的统计口径，不能拿来给单镜加抽卡 |

## 四、shot log 格式

```csv
shot_id,model,duration,prompt_rev,verdict,defect_class,variable_changed,attempt,result,note
S03_005,seedance2.0-std,8s,r3,re-roll,hand-morph,hand holds cup,1,pass,budget 1/3
S03_006,seedance2.0-std,8s,r1,rewrite,truncated-action,add completion state,1,pass,split into 2 shots
S03_007,kling3.0-pro,10s,r2,edit,lip-sync,quote line + 0.3s silence,1,pass,-
```

必填字段：镜号、模型/档位、时长、提示词版本、判决、缺陷类别、**改的唯一变量**、第几次、结果。

## 五、失败的抢救（不到万不得已不做）

| 可用素材 | 抢救方式 |
| --- | --- |
| 前 60–70% 可用，后段崩 | 在崩坏前切走，用下一镜的结果态接上 |
| 动作对但脸崩 | 只重出崩溃段，或用换脸/局部重绘修 |
| 画面好但节奏拖 | 后期提速 5–10%，配环境音补足 |
| 整段无可用帧 | 换模型重出；不要在原模型上继续加抽 |

注意：抢救会让镜头语言不统一，只用于收尾，不用于主力镜头。

## 六、验收与留痕

交付时附三样：

1. 成片（含可复现的提示词版本号与 seed，若平台支持）。
2. shot log（至少包含每条片子的判决与改动变量）。
3. 已知残留问题清单（明确写「这一处没修，因为…」）。

「修好了但说不清改了什么」等于没修——下一镜还会再犯一次。

## 七、把修复沉淀成规则

- 一个修复在**两次以上**不同镜头里生效 → 提升为模板（写进 `GLOBAL STYLE`、身份块或镜头清单）。
- 只在某一个镜头生效 → 记为个案，不改模板。
- 修复后要复测受影响的镜头（改了身份块 → 回看所有已生成的该角色镜头）。
- 不要因为一次高分或一条成功渲染就宣布规则成熟。
