# story2video 工作流搭建

应用把「这一步要建什么」算成清单派给你，你在**这一步的节点层**里建出来、接好参考图、把产物路径与英文提示词写进节点。

- 真源：应用仓库 `story2video/AGENTS.md`（§一 八步硬口径、§五 生成的提示词）。派单正文与它冲突时**以派单为准**（那是这一轮的具体事实）；派单没写的照 AGENTS.md。
- 两条总纪律：① **只建不跑**（跑节点是另一单 `s2v-run-v1`）；② **只碰自己的**（别人的层 / 节点 / 连线 / 标题 / 位置一个都不碰）。

## 一、一轮派单：清单 + 环境 + 差异

派单正文里三块机读内容：**清单 `items`**（`{slot, kind, title, prompt, promptZh, refs[], output, layer, seq}`）、**环境 `env`**（`step` / `layer` / `imageBackends` / `imageSelected` / `existingLayer` …），以及**差异** `{missing, extra, changed, dropped, canvas}`。另有一节用户说明（非空时最硬）。

- **清单里没有的不要自己加**；`refs` 是空数组就是一张参考图都不连。
- **画布上已有的、标题与清单一致的链，应用会先自己按标题认领**（只读画布，认到的写进登记表，不在派单里出现）：看到「画布上已经有这颗节点」就**复用那一颗、别再建一颗同名节点**；清单里没有的名字一个都别动，那是别人的节点。
- 链多时按批派单：看到「这一批：第 N / M 批（共 K 条链）」+ 只含本批的清单 → 这一轮**只建本批这几条**，回执 `chains` 也只写这几条 slot。别因为清单看起来不全就一条都不建，也别补清单外的链。

回执：回话最后只放一个 json 围栏，`mtnode` 必须一字不差是 `s2v-workflow-v1`：

```json
{ "mtnode": "s2v-workflow-v1", "step": 4,
  "layer": { "id": "层 id", "w": 2400, "h": 1600 },
  "chains": [{ "slot": "scene:雾港码头_03", "node": "出图节点 id", "kind": "qwenimage_gen",
               "backend": "qwen-image-21", "refs": [], "output": "", "notes": "" }],
  "nodes": { "style": "", "roles": {}, "videos": {} },
  "notes": "一句话总结",
  "prompts": [{ "slot": "scene:雾港码头_03", "zh": "精简后的中文", "en": "写进节点的英文" }],
  "noteEdits": [] }
```

- `prompts` **必须覆盖清单里每一条带 `prompt` 的链**；`noteEdits` 只在用户说明非空时必须非空（一条 = 哪颗节点 / 哪个字段 / 改前改后，应用会读画布逐条对）。
- `nodes` 里那五个表单键（`script` / `assets` / `export` / `refkit` / `look`）**不填**：五张 `input_form` 全归应用，会话一颗都不建。
- 回执只写真建出来的东西，id 照抄建完拿到的那一个。**一条链都没有 = 失败**（应用判 `empty_receipt`，一条都不登记）。

## 二、层与标题（硬规则）

每步一颗 `kind:"super"` 容器，标题**一字不差**、只有这八个：`创意` / `剧本` / `分镜` / `素材图` / `分镜图` / `视频` / `成片` / `导出`。已有就用那一颗（`env.existingLayer` 或画布同名 super），绝不新建第二颗同名层；层是纯容器，**不建外侧端子**。

节点标题只写「是什么」：`风格板` / `三视图·林` / `场景图·雾港码头` / `场景图·雾港码头 · 视角 夜` / `道具图·灯塔` / `分镜图·S03_SH012` / `视频·S03_SH012` / `成片` / `导出·project.json`。**不许**带：服务商 / 模型 / 后端名（`Qwen` / `MiniMax` / `ComfyUI` …）、节点种类后缀、`Step 0N` 或任何步号、节点 id / slot（`s1` / `scene:港口`）。撞名加 ` 2` 后缀。

坐标用**层内本地坐标**：源 x=0 → 参考 x=340 → 出图 / 合成 x=680（06 是文本 0 → 合成 340 → 保存 680，07 是文本 0 → 保存 340），一条链一行 `y = 120 + 620 × 行号`。层尺寸与展开归应用。

## 三、每步建什么

| 步 | 层标题 | 你建什么 |
| --- | --- | --- |
| 01 | 创意 | 风格板 + 每个角色一条三视图（图像节点 + 参考节点） |
| 02 | 剧本 | **只建 / 复用层**：零链零节点，`chains: []` |
| 03 | 分镜 | **零链**：只建 / 复用层（分镜这一步只出文字，不出图） |
| 04 | 素材图 | 每场一颗场景图主图 + 每件关键道具一颗道具图主图 + 每个视角一条衍生链 |
| 05 | 分镜图 | 每镜一颗关键帧出图节点（多参考） |
| 06 | 视频 | 每镜一条 H3 视频链（多参考，**没有首尾帧**） |
| 07 | 成片 | 每镜片段 + 台词音频成对 → `remotion` → `save` |
| 08 | 导出 | 三路 `input_text` → 各自 `save` |

- **图像节点**用 `env.imageSelected` 指的那只（`proc_image` / `qwenimage_gen` / `flux3klein_gen`）；认不出就如实报错，**不偷偷换后端**。
- **04 的视角链**（`layer:"derived"`）：登记键是带 `#` 的 slot（`scene:<场景名>#<视角名>`），回执照抄、别改写成主槽。
- **06** 只走 H3（`video_gen` 或 H3 视频节点）；多参考顺序：关键帧 → 场景图 → 主角三视图 → 其它角色三视图；超上限的那几张清单已写明没连上，不再硬塞。本机没装就如实说建不了，不换别的视频后端顶替。
- **07 / 08** 的台词节拍用 `input_text`（不用 `proc_text`）；导出三份**一份一颗保存节点**，别一份文档喂三颗保存。

## 四、参考图：`input_image` + 一条上游线，提示词里用 `@节点名`

**零参考是正常情况，不是漏建**：

- **场景图 / 道具图主图：一张参考图都不接** —— 不接风格板、不接概念图、不接三视图、不接别的场景 / 道具图。风格与画面全靠文字（世界设定 + 场景段 + 负面清单）；一接图所有场景就长成同一张脸。清单 `refs: []` 时**别自己补一张「看起来该有」的**。
- **视角链：只接这颗素材自己的主图**（不接风格板、不接别的图）。
- **关键帧（05）**：已采用的风格板（**没采用就没有风格图，不拿概念图兜底**）+ 同场非首镜的场景图（**同场第一个镜头不接**）+ 该镜角色三视图 + 该镜选中的素材。
- **视频（06）**：关键帧 + 场景图 + 三视图，多参考、无首尾帧。

接法：清单 `refs[].label` 就是参考节点标题；画布上已经有那颗节点（派单「参考图在画布上已经有节点」一节列到的）**直接连它、不新建**；没有才建一颗 `input_image`（出处：`refs[].src` → 上一轮「图源 · <短名>」→ 新建 `图源 · <短名>`，`imageAsset` 写绝对路径）放在参考档。接到出图节点端口 `1..N`，顺序 = 清单顺序 = 提示词里 `@` 的先后；同路径只连一次。`connect` **不幂等**，别重复连。

**`@` 契约（写错等于没接参考图）**：节点只认提示词里的 `@<参考节点标题>`；写「第 1 张图是…」这种按位置指代，节点取不到图。

| 谁 | 短名（= 参考节点标题） |
| --- | --- |
| 风格板 | `风格板` |
| refkit 概念图 | `概念图·<名称>`（只给 01 用；04 / 05 不接） |
| 角色三视图 | `三视图·<角色名>` |
| 场景主图 / 视角 | `场景图·<场景名>` / `场景图·<场景名> · 视角 <视角名>` |
| 道具主图 | `道具图·<道具名>` |
| 每镜分镜图 / 视频 | `分镜图·<镜号>` / `视频·<镜号>` |

`@` 与画布标题**一字不差**（撞名加了 ` 2` 就写带后缀那个）。改这句话要**读懂语义再改**，不用正则 / 字符串 replace 批量替换。

## 五、画布上的提示词一律英文（硬规则）

- 节点 `prompt` 字段**只写英文**，不许中英混排；中文只作 `promptZh` 底稿留在工程里给人改。
- 英文那份要**整段覆盖**：画面 + 世界设定 + 场镜（场次 / 故事时间 / 与上一镜的变化 / 可见道具 / 光源 / 机位）+ 负面清单。只把画面那半句译成英文、世界设定与负面清单还留着中文 = 没写英文。
- **照抄清单原文不算重写**（清单给的 `prompt` 已是英文那份，应用会比对重合度，太高就标「未优化」）：回执 `prompts: [{slot, zh, en}]` 一条一条给，`zh` = 你精简后的中文，`en` = 写进节点的那一份。
- **精简**：世界设定一行、场镜一段，不许重复拼；世界设定与「光源 + 机位」各只出现一次。

## 六、产物路径（照抄，不改名、不挑目录）

01 / 04 / 05 图像留空（节点自己落画布资产目录）；06 = 清单 `output` 的 `<工作目录>/story2video-assets/shot-<镜号>-<秒>s.mp4`；07 = `<工作目录>/story2video-render/film.mp4`；08 = `items[].path`（`story2video-export/` 下的 `project.json` / `storyboard.md` / `meta.md` 等）。绝对路径照抄，改成相对路径对账不过。

## 七、另一单：只跑不建（`s2v-run-v1`）

派单是「跑画布上这几颗已经建好的出图节点」时：只对清单里的 `node` 调 `runNode`，**不新建 / 不删 / 不改**任何节点与连线；一条跑完再跑下一条，挂了**停在那一镜**（不跳过、不换后端、不写占位文件），工具原话记进 `notes`。回执：

```json
{ "mtnode": "s2v-run-v1", "items": [{ "slot": "scene:雾港码头_03", "path": "<本机绝对路径>", "exists": true }], "notes": "" }
```

`path` 必须是**本机绝对路径**（能直接读盘的那一份），不要相对路径、不要 base64；没跑成写 `"exists": false` + 空 `path`，**别编路径**（应用逐条 `fsExists` 验，编了也登记不上）。

`slot` **一字不差照派单抄**：派单里是 `scene:<名>#<视角名>` 就写带 `#` 的那一个，**不许改成主槽**（少了 `#…` 应用就对不上登记键，判 `empty_receipt` 并把你写的那一个原样点名，一条都不入册）。

## 八、建不了的环节

跳过那一条，在 `notes` 里写清为什么（缺内容 / 本机没装那只后端 / 后端认不出）：**不造假节点占位**，也不因为一条建不了就整步罢工。

## 九、回执前自检（应用还会再核一遍）

- [ ] `layer.id` 是这一步那一颗层；层标题就是八个之一，没有 `Step 0N`、没有后端名。
- [ ] `chains[].node` 都是建完之后拿到的**真 id**；`slot` 一字不差照清单（`style` / `role:<名>` / `scene:<名>` / `scene:<名>#<视角>` / `prop:<名>` / `<镜头 id>` / `video:<镜头 id>` / `@film` / `@export`）。
- [ ] 场景 / 道具主图 `refs` 就是清单给的那份（空数组 = 一张都没连）；视角链只有这颗素材的主图那一张。
- [ ] `refs[].path` 是绝对路径且真在磁盘上；参考节点标题就是短名，`prompt` 里有对应的 `@<短名>`，没有「第 N 张图」。
- [ ] 节点 `prompt` 是英文，且世界设定 / 场镜 / 负面清单都在里面；`prompts` 覆盖每一条带 `prompt` 的链。
- [ ] 产物路径与清单逐字一致。
- [ ] 一颗 `input_form` 都没建，一个节点都没跑。

对账随时会挡下这几类：id 编了 / 参考图写成相对路径 / `layer` 没填 / 回执 tag 或 json 围栏不对 / `chains` 缺 slot / 清单里 `refs` 是空的画布上却连了图。
