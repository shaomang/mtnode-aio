# 十种导演风格完整参数

正文 `film-shot-director-styles` 引用本文件。每种风格给出：构图偏好、光、色彩、声音、表演、AI 生成口径（clip 时长 / 提示词偏向 / 已知风险 / 负向词）、适用与慎用。仅取方法层，禁止复制任何真实影片的具体镜头、台词、角色或剧情。

---

## 01 `spielberg` 斯皮尔伯格

| 项 | 值 |
| --- | --- |
| 一句话 | 先拍看见的人，再拍被看见的东西；奇观永远排在一张脸后面 |
| 焦段 | 21 / 35 / 50 / 135mm（21、35 撑三层纵深；135 从远处切反应） |
| 机位 | 对话眼平；奇观与威胁降到 1.0–1.3 m 的孩子视线，机位锁定 |
| 运动 | `slow dolly-in to close-up`、`walking-pace tracking follow`、`crane down into eye level`、`motivated pan`、`rack focus across three planes`；禁止荷兰角、无动机手持、环绕、急推、甩镜 |
| 景别偏好 | MCU 反应、带三层纵深的全景、双人中景、携带物插入、极远景量尺度 |
| 构图 | 三层纵深、明亮具名光源前的剪影、门框框中框、人物压在画面下三分之一、每个广角都有可见出口 |
| 光 | 混合光；3:1（温暖段）/ 8:1（威胁段）；实用光源驱动；薄雾中一束看得见的硬光柱 + 发梢逆光 |
| 色彩 | 琥珀、钨丝暖黄、灰蓝绿；强调色是单一高饱和红或纯白光点；中等饱和、中等反差 |
| ASL | 动作 3–7 秒；情绪 5–9 秒 |
| 声音 | 单人物动机旋律，比转折早 1–2 秒；威胁先由声音抵达，画面滞后 3–8 秒；揭示前 1.5–3 秒近乎全静音 |
| 表演 | 高可读性，观众 1 秒内能命名情绪；用肌肉指令导戏（眉毛抬起、嘴唇分开约 1 cm、屏住呼吸） |
| AI clip | 4–8 秒；一条只装一次「看」、一个摄影机行为、一个环境反应 |
| 风险 | 惊奇脸退化成呆滞空瞪。把表情写成可执行动作，并在同一条里写清引发它的光变化 |
| 负向词 | `dutch angle`、`handheld shake`、`camera orbit`、`slow motion`、`extra background crowd`、`modern screens`、`text or watermark`、`flat even lighting` |
| 适用 | 商业叙事、冒险、灾难、家庭创伤、童年视角、人道主义题材、品牌情绪片 |
| 慎用 | 反英雄、道德暧昧结局、要求观众保持分析距离的题材 |

## 02 `hitchcock` 希区柯克

| 项 | 值 |
| --- | --- |
| 一句话 | 把秘密先交给观众，再让角色慢慢走进去；等待本身就是段落 |
| 焦段 | 28 / 50 / 100 / 135mm（28 交代房间地图；100–135 做凝视的选择性压缩） |
| 机位 | 眼平为主；命运拍升到 3–6 m 俯拍；威胁拍降到 0.3–0.6 m |
| 运动 | `locked frame held past comfort`、`slow dolly-in on a detail`、`POV pan following an eyeline`、`high overhead`、`creep-in behind foreground obstruction`；禁止手持、环绕、甩镜、急推 |
| 景别偏好 | 物件 ECU、反应 CU、POV 中景、被遮挡的双人中景、一张全景当房间地图 |
| 构图 | 前景遮挡占 20–35%、门窗楼梯框中框、墙上的几何阴影、威胁将要进入的负空间、三镜共享视线轴 |
| 光 | 硬光 4:1；照度不降，降的是杂乱度；阴影是可辨认的几何形状（百叶、扶手、门缝），不是氛围雾 |
| 色彩 | 中性冷灰、米白、家具木色；正红/深绿/金属金只在信息转折时出现；中等饱和、高反差 |
| ASL | 4–9 秒基线；暴力瞬间 0.4–1.5 秒 |
| 声音 | 短、重复、音程尖锐的动机；每段一个「时钟」（滴水、脚步、门锁、电话铃）负责时间；最紧的 3–5 秒抽掉音乐，用一个非音乐硬声落点 |
| 表演 | 隐藏与泄露同时进行：手先泄露，脸后泄露 |
| AI clip | 延迟拍 3–6 秒；碎片插入 1–2 秒 |
| 风险 | 模型会给静止的威胁「补动作」，等待感立刻变动作戏。显式写 `the threat does not move`，并把 clip 压到 4 秒内 |
| 负向词 | `handheld shake`、`camera orbit`、`jump scare motion`、`blood or gore`、`sudden lighting change`、`extra people entering frame`、`lens flare` |
| 适用 | 悬疑、惊悚、犯罪、心理恐怖、跟踪、误认、密室、日常空间里的威胁 |
| 慎用 | 需要观众与角色同步无知的恐怖；开放式意象的作者电影；血浆片 |

## 03 `kubrick` 库布里克

| 项 | 值 |
| --- | --- |
| 一句话 | 用一个不肯让步的构图，把人和空间一起关进几何里 |
| 焦段 | 18 / 25 / 35mm（18、25 造单点透视与轻微脸变形；35 只作「正常」参照，≤20% 用量） |
| 机位 | 锁在层高一半（层高 2.8–3.2 m → 1.4–1.6 m），或 0.5–0.8 m 低位跟随；一场戏内高度不变 |
| 运动 | `locked symmetrical frame`、`constant-speed dolly-in along the vanishing axis`、`constant-speed dolly-out`、`low tracking follow`、`overhead perpendicular insert`；禁止手持、环绕、甩镜、**任何加速减速**、镜内重新构图 |
| 景别偏好 | 强消失点的对称全景、中轴正面中景、地面图案俯拍插入、长挂的正面特写、空空间的极远景 |
| 构图 | 单点透视、消失点在正中、双侧对称或精确镜像、人物骑中轴、走廊/房间成为压缩漏斗、平面沿纵深堆叠 |
| 光 | 硬光 2:1（压迫最强处 1.5:1）；画内可见且对称排布的硬光阵列；短硬阴影互相抵消，没有可藏身的暗部 |
| 色彩 | 冷白、灰、纯黑；强调色血红/金/单一饱和色块（一个空间一个色）；中等饱和与反差 |
| ASL | 12–40 秒，极少低于 6 秒 |
| 声音 | 音乐是结构装置：一段乐曲覆盖整段，独立于画面情绪；环境声是机械与身体的对立（通风、伺服、硬表面脚步）；对白比自然慢约 30% |
| 表演 | 刻意僵硬、过度精确、内部自洽；允许直视镜头把观众推回分析距离 |
| AI clip | 8–12 秒（短于 6 秒看不出匀速）；12–40 秒凝视用同参数分段续接 |
| 风险 | 模型自动给推轨加缓入缓出、在人物移动时重新构图，对称立刻塌。显式写 `constant speed, no ease-in or ease-out, no reframing` |
| 负向词 | `handheld shake`、`camera orbit`、`ease-in ease-out camera move`、`reframing`、`warm fill light`、`shallow depth of field`、`soft focus or bokeh` |
| 适用 | 高概念、体制与权力、冷峻讽刺、建筑感强的空间、仪式化场面 |
| 慎用 | 需要手持即时感、即兴表演、亲密温度的故事；2.39:1（削弱纵向压迫） |

## 04 `kurosawa` 黑泽明

| 项 | 值 |
| --- | --- |
| 一句话 | 让天气、地形和阵型替人演戏，身体是唯一的台词 |
| 焦段 | 50 / 100 / 250mm（250 把人群压成墙，让正面冲来的人几乎看不出在推进） |
| 机位 | 眼平或略低；泥地段 0.6–0.9 m，让泥水进入前景 |
| 运动 | 横移扫过阵型、长焦锁定等待的群体、摇镜扫线、一次决定性的纵深推进、多机位同拍（50/100/250）；禁止环绕、默认手持、急推、慢动作英雄化 |
| 景别偏好 | 人物 <1/6 画高的极远景、长焦压缩的群像带、湿透疲惫的脸的特写、泥里的脚、身体站姿的中景 |
| 构图 | 长焦堆叠的横向条带、三角/楔形阵型指向冲突、高地与低地=阶级、镜头与主体之间的天气层、开阔天空/旷野前的孤立身影 |
| 光 | 硬光 ≥6:1；逆光让雨丝、尘埃、白气变成亮线；去色后仍靠明暗分区成立 |
| 色彩 | 土黄、泥褐、湿布墨黑、雨天灰白；强调色正红/靛蓝/旗帜金贴在织物与盔甲上，不打在空气里 |
| ASL | 等待 8–20 秒；战斗 2–5 秒 |
| 声音 | 打击乐与管乐的重复动机，在集体行动开始那一刻进入；自然声承担叙事（暴雨掩脚步、风吹散号令、泥水声标记体力） |
| 表演 | 高度身体化，允许大幅度戏剧能量；疲惫（湿透、发抖、喘）是主要表演材料 |
| AI clip | 战斗 3–6 秒；等待 6–10 秒 |
| 风险 | 雨变成不影响人物的粒子，人物依然干燥挺拔。点名织物状态（`soaked cloth clinging to the back`）与步态改变（`feet sinking, gait heavy`），湿度写进关键帧 |
| 负向词 | `dry clothing in rain`、`clean faces`、`slow motion`、`camera orbit`、`shallow depth of field`、`zippers or nylon`、`flat frontal fill light` |
| 适用 | 史诗、群像、战斗、自然对抗人、集体行动 |
| 慎用 | 室内双人心理戏（长焦压缩把人变墙纸）；竖屏（横向调度失效，需按 9:16 改写为纵深调度） |

## 05 `scorsese` 斯科塞斯

| 项 | 值 |
| --- | --- |
| 一句话 | 摄影机是被魅力拖着走的，直到魅力用完，房间突然安静 |
| 焦段 | 18 / 27 / 40 / 75mm（急推由 27–75mm 变焦 0.5–1 秒完成，机位不动） |
| 机位 | 眼平 1.5–1.6 m 恒定；入场长镜头保持恒定；暴力拍可掉到腰高 |
| 运动 | 稳定器入场长镜头、加速后硬停的推轨、面部急推、沿吧台/餐桌横移、人物直视镜头时的锁定正面；禁止无动机抖动、无终点的漂移、对称锁定全景 |
| 景别偏好 | 稳定器中景跟随、兴奋或羞耻的特写、房间作为社会地图的全景、钱/手/杯子的插入、直面镜头的正面中景 |
| 构图 | 主体居中而世界在背后流过、背景里每个人都在忙自己的事、画内实用光源燃烧、越过肩膀看进一个还不许他进的房间、正面居中只用于直陈 |
| 光 | 硬光 5:1，方向混乱（多个实用光源互打）；入画且允许过曝的霓虹与灯罩；常驻烟雾让每个光源有可见光锥 |
| 色彩 | 酒吧红、后厨绿、钠黄街灯、包厢金；高光点是白炽过曝、单一冷蓝（警灯/电视）；高饱和高反差 |
| ASL | 音乐蒙太奇 1.5–3 秒；崩塌段 8–15 秒（无音乐） |
| 声音 | 画内可见来源的流行歌（点唱机、车载电台），可被人物关掉——关掉即转折；三层都市噪音；对白重叠打断、只需听清一条线 |
| 表演 | 魅力与危险并存；演「我在解释」，不许演「我知道我错了」 |
| AI clip | 蒙太奇碎片 2–4 秒；入场长镜头 8–12 秒 |
| 风险 | 「跟拍」变成无止境漂移，人物与背景脱节。每条 clip 指定停止点与停止时的构图，背景人物写成「各自有事在做」 |
| 负向词 | `handheld jitter`、`aimless floating camera`、`slow motion`、`empty background`、`clean even lighting`、`symmetrical composition` |
| 适用 | 犯罪、夜生活、魅力型人物的起落、都市群戏、音乐段落 |
| 慎用 | 极简室内剧、需要克制客观视角的题材、无法接受过曝的交付 |

## 06 `fellini` 费里尼

| 项 | 值 |
| --- | --- |
| 一句话 | 主角站着不动被环绕，人群绕着他运动，怪诞与可怜同时成立 |
| 焦段 | 18 / 25 / 32mm（18 装下整支队伍；25 做正面近景的漫画式透视；32 是人群中跟移默认） |
| 机位 | 眼平游动为主；垂直事件升到 2.5–4 m，让人群变成图案 |
| 运动 | 0.4–0.8 m/s 的轨道漂流、从一个脸交接到下一张脸的摇镜、正面广角近景（轻微畸变）、摇臂升过队伍、跟丢一个人又找到另一个；禁止锁定对称全景、长焦压缩、浅焦隔离、静态正反打 |
| 景别偏好 | 整支队伍的全景、单张怪脸的正面特写、穿过人体的中景跟随、越过前景路人的过肩、把人群变图案的高角度 |
| 构图 | 人物持续从两侧进入、前景路人占 10–30%、每 2–3 秒重新构图、一个垂直事件把某人抬出人群、直接对镜头说话 |
| 光 | 混合光 4:1，阴影保留细节；硬边舞台光区被常驻的雾柔化半米；人物走进走出光区，明暗切换本身是表演 |
| 色彩 | 粉、金、酒红、天蓝；纯白与纯黑服装对撞；高饱和、中等反差 |
| ASL | 6–14 秒；结尾段 15–30 秒 |
| 声音 | 圆舞曲/进行曲/马戏团铜管先于动作确定节拍，人物跟着音乐走路；环境声允许非写实；对白互相压过、听不清是人群的质地 |
| 表演 | 夸张、怪诞、可笑又可怜；选角标准是「一张脸能说完一个故事」 |
| AI clip | 6–12 秒 |
| 风险 | 人群被做成对称、同步、面目模糊的背景板。点名 3–5 个具体人物及各自动作与服装，写 `no two people doing the same thing` |
| 负向词 | `symmetrical composition`、`synchronised crowd`、`blurred faceless background people`、`shallow depth of field`、`long-lens compression`、`cold desaturated palette` |
| 适用 | 群像、节庆/马戏、回忆、荒诞喜剧、梦境 |
| 慎用 | 需要精确轴线与简洁覆盖的对话戏、极短交付（游动镜头需要时长才成立） |

## 07 `bergman` 伯格曼

| 项 | 值 |
| --- | --- |
| 一句话 | 把摄影机放在两个人之间，然后不动，让脸自己塌下来 |
| 焦段 | 75 / 100 / 150mm（长焦不给脸任何变形借口；单脸 f/11–16 让整张脸在景深内，双脸 f/2.8–4 留给变焦点） |
| 机位 | 眼平，精确对齐演员瞳孔高度，全场不变 |
| 运动 | 锁定正面特写、双脸构图（前景一张侧脸）、用变焦点代替切镜、0.02–0.05 m/s 的不可察觉推进、情绪高点之后继续挂；禁止手持、固定 A/B 正反打、环绕、广角建场 |
| 景别偏好 | 占画幅高度 60–80% 的大特写、双脸构图、75mm 中近景、手/物件插入、只在必须建场时用一个全景 |
| 构图 | 机位在视线轴上（偏差 <10°）、两张脸在边缘重叠、近黑或近白的平背景、人物回避那一侧留负空间、整张脸在景深内 |
| 光 | 硬光 6:1；正侧 90° 单光源，鼻影把脸分成两半；暗面不补光但保留轮廓；背景压成单色平面 |
| 色彩 | 灰蓝、灰绿、近黑、近白；皮肤的暖色是画面里唯一的暖；低饱和、高反差 |
| ASL | 20–90 秒；一场 4 分钟的戏只用 5–8 个镜头 |
| 声音 | 极少配乐，只在场景之间的空白；单一持续环境元素（钟摆、海浪、风穿窗缝）让沉默可被计量；对白干、近、无混响，呼吸与吞咽清晰 |
| 表演 | 高度抑制；最高强度是「没有哭出来但脸正在塌」，指令写成抑制目标 |
| AI clip | 8–15 秒（在能稳住身份的前提下取最长）；20 秒以上用同参数分段续接，接点选在动作完全静止那一帧 |
| 风险 | 模型给静止的脸补多余动作（转头、过频眨眼、微笑）并虚化背景。写 `no head turn, blinks only once, background flat and dark, no bokeh` |
| 负向词 | `shallow depth of field or bokeh`、`soft glamour lighting`、`head turning away`、`smiling`、`camera movement`、`warm colour grade`、`background detail or props` |
| 适用 | 婚姻/信仰/存在困境的双人室内戏、舞台改编、长时间对话 |
| 慎用 | 动作、群像、需要空间地理的段落；16:9（脸两侧留无用空间） |

## 08 `tarkovsky` 塔可夫斯基

| 项 | 值 |
| --- | --- |
| 一句话 | 时间不是被剪出来的，是被水、火、雾和墙皮一点点泡出来的 |
| 焦段 | 28 / 35 / 50mm，深焦分层；靠景深而不是切镜建立层次 |
| 机位 | 腰到胸，水平或略低，像被钉住的目击者 |
| 运动 | 锁定长挂、极慢横移、向物件缓慢推进、缓慢下摇到水面、以步行速度从背后跟随；禁止手持抖动、甩镜、环绕、急推、航拍揭示；10 秒位移 ≤1 m，恒速无加减速 |
| 景别偏好 | 全景、中远景、插入/细节、背后过肩、近景 |
| 构图 | ≥3 个平面的深焦、前景反射面、偏置或背对镜头的人物、从天花到地面的竖向分层、门槛式构图 |
| 光 | 柔光 2:1–3:1；阴天窗光 + 单一火点；无硬边阴影，湿表面自己发光 |
| 色彩 | 泥褐、湿石灰、苔绿、棕褐；强调火橙、乳白、铁锈；低饱和低反差 |
| ASL | 30–90 秒 |

## 10 `nolan` 诺兰

| 项 | 值 |
| --- | --- |
| 一句话 | 让人在一件过大的真实结构前面执行一件有时限的任务，情绪藏在选择里 |
| 焦段 | 14 / 21 / 35 / 50mm（14–21 给尺度，21 贴到 60–90 cm 给物理重量，50 是长焦上限） |
| 机位 | 眼平、贴身体；偶尔低机位给机械重量 |
| 运动 | 受控手持跟随、与动作并行的广角横移、向机械缓慢推进、升起揭示尺度、仪器上的锁定插入；禁止为环绕而环绕、甩镜、唯美慢动作、无人机穿场；镜头几乎总在动，但动是「跟上」不是表演 |
| 景别偏好 | 中近景、广角跟拍、量尺度的极远景、机械插入、过肩 |
| 构图 | 人物对着一件过大的真实结构、地平线压低给天空重量、机械在画面里可读、两条时间线靠形状匹配、前景硬件给纵深 |
| 光 | 混合光 3:1–4:1；真实天光 + 可见工作灯；夜景只有钠灯暖橙一个暖点 |
| 色彩 | 混凝土灰、钢蓝、黑、帆布卡其；强调钠灯琥珀、警示红；低饱和、中等反差 |
| ASL | 2–5 秒 |
| 声音 | 持续低频脉冲与无解决的上升音型，功能是报时；金属应力、气压、低频冲击、按空间尺寸变化的混响；对白在动作压力下说出 |
| 表演 | 理性克制，崩溃上限是一次呼吸失控 |
| AI clip | 3–6 秒；每条线单独生成，交叉在剪辑台完成 |
| 风险 | 模型把「高概念」渲染成发光全息与赛博界面，并把交叉剪辑压成一镜。负向词点名 `holographic UI` 与 `neon`；三条线各出一条 clip，用同一组材料词、色温、颗粒锁一致性 |
| 负向词 | `glowing holographic interface`、`floating blue data`、`neon signage`、`obvious CGI sheen`、`slow motion`、`dreamy diffusion`、`saturated color grade`、`lens flare` |
| 适用 | 高概念、时间结构、工业/科技、预告片、灾难与任务片 |
| 慎用 | 亲密双人戏、喜剧、需要柔光与柔焦的题材；1.85:1 以下会削弱纵向尺度 |

## 参数卡模板（复制后改数值）

```yaml
style_id: <上表 id>
lens_kit_mm: [21, 35, 85]      # 主用放在第一位
camera:
  height: "1.6m 恒定"           # 一律写相对主体眼睛的高度
  motion_budget: low            # low / medium / high
  prefer: ["locked frame", "slow dolly-in 25cm/6s"]
  avoid: ["handheld", "orbit"]
lighting:
  key_ratio: "4:1"
  fill: "none, plaster bounce only"
palette:
  dominant: ["冷灰", "米白"]
  accent: ["正红"]
editing:
  asl_s: "4-9"
aspect: "1.85:1"
negative_prompt_adds: ["handheld shake", "camera orbit", "text or watermark"]
```

填写纪律：`height` 必须带单位与「恒定/可变」；`motion_budget` 决定本段能有几个运动镜头（low ≤1/5 镜，medium ≈1/3，high ≥1/2）；`asl_s` 用来算镜头数，不许只写「快/慢」。
