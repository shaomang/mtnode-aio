# 导演风格叠加：10 种可执行参数

## 何时用

- 客户或导演说「要斯皮尔伯格那种感觉」「像王家卫」，需要把它翻译成可执行的镜头参数。
- 一条片要定视觉基调：机位高度、焦段、明暗比、色彩、平均镜长各定一档。
- 已经拍了/生成了几条，觉得「不像」，但说不出差在哪。
- 要在一支片里做风格对比（前段冷、后段暖；现实段 vs 记忆段）。
- 要给模型写风格块（`visual style` 段落）而不是每镜重写一遍。
- 不适用：还在定镜头语法本身（用 `film-shot-language`）；要拆场次与分镜表（用 `film-shot-list-breakdown`）；要求复刻某部真实影片的具体镜头、台词、角色（不做，见原则 7）。

## 核心原则

1. **一次只用一种透镜**。两种风格叠加会互相取消特征：库布里克的对称 + 王家卫的手持重新构图 = 一台不知道该不该晃的机器。要混，只能混**不同层**（例：王家卫的机位 + 塔可夫斯基的色彩），并写清哪层归谁。
2. **风格是参数差，不是形容词**。「作者电影感」不可执行；「镜头轴恒定 1.6 m、85mm 占七成、ASL 20–90 秒、明暗比 6:1、暗面不补光」可执行。
3. **先改四个参数，再谈气质**：机位高度 → 焦段倾向 → 平均镜长（ASL）→ 色彩与明暗比。这四项定了，风格就有七成；剩下三成是运动预算与表演调性。
4. **一种风格至少要能通过「闭眼辨识测试」**：遮住片名，让没读过需求的人只看三帧，能说出「这是 X 那一类」。说不出就说明特征不够硬。
5. **风格不改剧作**。透镜只决定怎么说，不决定说什么；不许为了像某导演而加戏、加人物、改结局。
6. **硬特征必须能被摄影机执行**。「宿命感」不是特征；「机位常在天花板高度俯拍，人物在画面下缘」是。
7. **只用方法，不用别人的具体表达**。取的是机位/焦段/节奏/调色这套方法，不复制任何真实影片的镜头设计、台词、角色或剧情。产出必须是原创。
8. **先写死禁止项**。每种风格真正的识别度一半来自它**不做**什么：库布里克不做缓入缓出，王家卫不做三脚架静止，伯格曼不做浅景深虚化。负面词是风格的一部分。

## 工作流

1. **收需求并落到一个 style_id**。输入：客户语言（「高级」「冷」「像诺兰」）。动作：从下表选一个 id；选不出就说明这是「无透镜」，走中性路线。产出：`style_id: nolan` 一行。
2. **搬四个主参数**。输入：style_id。动作：抄机位高度、焦段套装、ASL 区间、色彩/明暗比四行到项目卡上（见模板 1）。产出：四行参数，带数值。
3. **写 3–5 条硬特征**。输入：该风格的「可写进提示词的硬特征」。动作：从下节挑 3–5 条，改成本片的具体值（机位米数、mm、秒数、比例），每条都要能被一帧画面验证。产出：风格块（5 行以内）。
4. **写禁止项**。输入：该风格的 `avoid` 与 `negative_prompt_adds`。动作：选 4–6 条，只留本片真会犯的。产出：负面清单（详见 `references/director-style-matrix.md`）。
5. **验证 ASL 与运动预算**。输入：目标时长。动作：按 ASL 算镜头数；按运动预算（low/medium/high）算能动几镜。产出：`N = 时长 / ASL`，与「允许运动镜头数」两个数。
6. **落到关键帧**。输入：风格块。动作：把风格特征写进**关键帧**（对称、消失点、前景遮挡），不要只写进运动提示词——模型对静帧的服从度远高于对运动的服从度。产出：每镜关键帧的风格句。
7. **跑辨识测试**。输入：3 帧成品。动作：给没读过需求的人看，问「像哪一类」；答不出或答错，回第 3 步加硬特征，不要加形容词。产出：通过/打回，打回时记下「缺哪一条」。
8. **记录取舍**。输入：最终参数。动作：写一行「本片借了什么、拒绝什么」（例：借对称与匀速推轨，拒绝长凝视，因为交付是 15 秒竖屏）。产出：风格说明一段，随片交付。

### 2. 每种风格的硬特征（挑 3–5 条写进提示词即可辨识）

**`spielberg` 斯皮尔伯格**
1. 顺序固定：角色看见 → 观众看见角色的脸（1.5–3 秒）→ 观众看见奇观。反应永远早于揭示。
2. 低机位只在孩子视线高度（1.0–1.3 m）出现，成人对话立刻回眼平。
3. 每个广角里都能指出出口与危险在哪，三层纵深（前景遮挡/中景人/后景事件）。
4. 音乐比情绪转折早 1–2 秒进入，用来预告而不是追认。
5. 摄影机默认在轨道或稳定器上，晃动只出现在人物受物理冲击的那几帧。
- 适用：商业叙事、冒险、灾难、家庭创伤、童年视角、品牌情绪片。慎用：反英雄、道德暧昧结局、要求分析距离的题材（改库布里克/芬奇）。

**`hitchcock` 希区柯克**
1. 观众先知道危险，角色后知道；「被揭示」到「抵达角色」之间撑满 20–60 秒。
2. 看—所见—反应三镜结构占段落镜头数一半以上。
3. 威胁发生在明亮整洁、正在使用的空间里；降的是杂乱度不是照度，阴影是可辨认的几何形状（百叶、扶手、门缝）。
4. 摄影机有身体：偷窥位、前景遮挡后缓慢爬入；不做环绕与甩镜。
5. 暴力用碎片插入 + 声音完成，完整动作永远不在一个镜头里。
- 适用：悬疑、惊悚、犯罪、密室、跟踪。慎用：需要观众与角色同步无知的鬼屋式恐怖；血浆片。

**`kubrick` 库布里克**
1. 单点透视，消失点在画框正中；走廊两壁向中心收拢。
2. 绝对对称或精确镜像，人物骑在中轴上。
3. 匀速推轨，**无缓入缓出、无中途重新构图**；加速度就是风格的敌人。
4. 硬光阵列可见且对称排布，没有一块可以藏身的暗部（2:1，压迫处 1.5:1）。
5. 一场戏内机位高度不变；对话语速比自然慢约 30%，礼貌到不自然。
- 适用：高概念、体制/权力、冷峻讽刺、建筑感强的空间。慎用：需要手持即时感、即兴表演、亲密温度的故事。

**`kurosawa` 黑泽明**
1. 长焦把人群压成一堵墙（250mm），人物在 EWS 里 <1/6 画高。
2. 横向调度优先：横移扫过阵型，屏幕方向全段不变。
3. 天气进入前景并对身体做功：湿透的布贴背、泥里的脚、呼出的白气变成亮线。
4. 逆光 6:1 以上，雨丝/尘埃/白气成为亮线；明暗分区在去色后仍成立。
5. 阵型有顶点，顶点指向冲突方向；高地与泥地就是阶级。
- 适用：史诗、群像、战斗、自然对抗人的题材。慎用：室内双人心理戏（长焦压缩会把人变成墙纸）。

**`scorsese` 斯科塞斯**
1. 稳定器长镜头入场，背景始终贴着人物，终点必须有明确停止位与构图。
2. 急推由 27–75mm 变焦在 0.5–1 秒内完成，机位不动。
3. 画内实用光源入画且允许过曝，烟雾让每个灯有可见光锥。
4. 背景里的人「各自有事在做」，不是「人群」。
5. 上升段用流行歌（画内可见来源），崩塌段抽掉音乐只留房间底噪 ≥15 秒。
- 适用：犯罪、音乐/夜生活、魅力型人物的起落、都市群戏。慎用：极简室内剧、需要克制客观视角的题材。

**`fellini` 费里尼**
1. 摄影机在人群里漂流（0.4–0.8 m/s），从一个脸交接到另一张脸，不做正反打。
2. 人物持续从画面两侧进入，前景路人占 10–30%。
3. 每 2–3 秒重新构图，画面从不「安定」。
4. 一个垂直事件把某人抬到人群之上（升降/摇臂）。
5. 群众演员每人有一个身份动作，禁止同步、禁止面目模糊。
- 适用：群像、马戏/节庆、回忆、荒诞喜剧。慎用：需要精确轴线与简洁覆盖的对话戏。

**`bergman` 伯格曼**
1. 机位在视线轴上，偏差 <10°，精确对齐瞳孔高度，全场不变。
2. 大特写占画幅高度 60–80%，整张脸都在景深内（单脸 f/11–16）。
3. 双人构图：一张正脸 + 一张侧脸在边缘重叠；用变焦点代替切镜。
4. 正侧 90° 单光源，鼻影把脸分成两半；背景压成单色平面。
5. 情绪高点之后再拍 3–5 秒；每场指定 2–3 处 4–8 秒沉默。
- 适用：婚姻/信仰/存在困境的双人室内戏、舞台改编。慎用：动作、群像、需要空间地理的段落。

**`tarkovsky` 塔可夫斯基**
1. 一个机位一个角度解决一场戏，不拍反打。
2. 深焦分层 ≥3 个平面，前景常有反射面（水、镜、湿石）。
3. 运动恒速、10 秒位移 ≤1 m，无加减速。
4. 主体动作写到最小（呼吸、转头、放下一件东西），描述预算全给环境：水、火、雾、布、光的缓慢变化。
5. 低饱和低对比（2:1–3:1），阴天窗光 + 单一火点，湿表面自己发光。
- 适用：诗电影、记忆、废墟、宗教/精神性题材。慎用：需要节奏推进的商业短片、竖屏信息流。

**`wong_kar_wai` 王家卫**
1. 每帧都有前景遮挡（门框、玻璃、栏杆、人体），主体被推到画框边缘。
2. 手持是小幅**重新构图**而非抖动：几乎每秒微调，整镜位移 <1 m。
3. 裸灯泡/招牌直射给硬边与 6:1–10:1；霓虹只负责染色勾边。
4. 同一动作跳接三次、位置微移；关键进展留在两个镜头之间。
5. 两人同框不得正对：一个背对或隔玻璃，距离以厘米计。
- 适用：都市爱情、记忆碎片、霓虹夜戏、情绪大于情节的短片。慎用：需要清晰空间地理的动作段、群像史诗。

**`nolan` 诺兰**
1. 广角贴身体（21mm 贴到 60–90 cm），人永远在一件过大的真实结构前面。
2. 交叉剪辑是结构：两条线轮转周期从 12 秒收紧到 3 秒，每次切线带走一个新信息。
3. 一条 clip 只讲一个机制事实：一个动作、一个运动、一个可见的计时器变化。
4. 尺度翻译成材料与尺寸（混凝土、钢、帆布），绝不写「宏大」。
5. 低频脉冲与上升音型负责报时，不负责煽情；对白在动作压力下说出。
- 适用：高概念、时间结构、工业/科技题材、预告片。慎用：亲密双人戏、喜剧、需要柔光的题材。

### 3. 风格块骨架（贴进每条提示词的视觉段）

```text
[style_id] visual block:
camera height [X m, 恒定/可变]; lens [##mm] 为主，[##mm] 仅用于 [场景];
motion budget [low/medium/high]，本段允许 [N] 个运动镜头，其余 locked;
light [key 方向 + 明暗比 + 有无补光]; palette [3 个主色 + 1 个强调色];
texture [胶片/数字 + 颗粒 + 高光处理];
negative: [4–6 条本风格真会犯的错]
```

### 4. 参数搬运三原则

| 原则 | 做法 | 反例 |
| --- | --- | --- |
| 只搬能验证的 | 每条硬特征问「能不能在一帧里看出来」 | 「宿命感」 |
| 改成本片数值 | 把「广角」改成「21mm，距人 0.9 m」 | 「用广角拍」 |
| 保留一项反例 | 每种风格留一条「本片不做」 | 全盘照搬，变成模仿秀 |

### 5. 常见混搭（只混不同层）

| 组合 | 怎么分 | 风险 |
| --- | --- | --- |
| `wong_kar_wai` 机位 + `tarkovsky` 色彩 | 机位/遮挡归前者，低饱和与湿表面归后者 | 霓虹与低饱和会互相抵消，须保留一个强调色 |
| `kubrick` 构图 + `nolan` 剪辑 | 对称与消失点归前者，2–5 秒轮转归后者 | 对称需要长挂才成立，切太快对称读不出来 |
| `bergman` 光 + 任意 | 正侧 90° 单光源、暗面不补光 | 与 `fellini`/`scorsese` 的多光源互打冲突 |
| `hitchcock` 悬念结构 + `spielberg` 反应顺序 | 知情顺序归前者，反应早于揭示归后者 | 观众先知情会消解「先反应后揭示」的惊讶，只能用在威胁段 |

## 常见坑

- **只有形容词，没有参数**：症状是提示词写了「电影级、作者感、高级灰」，出来还是短剧。原因：风格没落到四个主参数。修法：先填机位高度、焦段、ASL、明暗比四格，再谈气质。
- **风格被模型抹平**：症状是库布里克的推轨被自动加了缓入缓出，对称在人物一动就塌。原因：风格只写在运动提示词里。修法：把对称、消失点、机位高度写进**关键帧**，运动句里显式写 `constant speed, no ease-in or ease-out, no reframing`。
- **混搭后什么都不像**：症状是又晃又对称、又暖又冷。原因：两种风格抢同一层（都在管机位）。修法：拆层——一层管机位/运动，一层管色彩/光，最多两层。
- **风格压过故事**：症状是观众只注意到「手法」。原因：每条硬特征都上了。修法：一种风格只用 3–5 条，其余留白；把最贵的那条留给转折拍。
- **辨识测试答成「像广告」**：症状是看不出导演。原因：硬特征太通用（浅景深、暖调、慢推）。修法：换成排他性特征——`bergman` 用「整张脸都在景深内、背景压成单色平面」，`kubrick` 用「消失点在正中、匀速无缓动」。
