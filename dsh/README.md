# 智能能力指南 —— 让 MTNode 里的 AI 替你「办事」

> 本指南面向普通用户,不需要任何编程知识。
> 开发者请另见 [DESIGN.md](DESIGN.md)。

## 一句话说明

以前,MTNode 里的模型只会「**生成**」:你喂给它内容,它还你一段文字或一张图。
现在,接入 DeepSeek Harness(dsh)之后,模型会「**办事**」:它能**读你电脑上的文件、把结果写进文件、联网查资料、执行命令**,多步做完之后再把结果交给你。

你仍然用熟悉的节点画布操作,只是多了一个开关:**智能**。

## 开启智能能力(一次性设置)

1. 打开 **设置 · API/配置**。
2. 确认有一个 **DeepSeek 文本服务商**且填好了 API Key(默认已内置,填 Key 即可;添加服务商时可**从目录选择**——选服务商 → 输入 Key → 自动载入模型列表)。
3. 智能能力**永久启用**,无需开关。保存设置,完成。

> 无需安装任何运行环境:智能引擎使用**应用自带的 Node(随安装包分发,与主程序同版本)**,开箱即用;引擎随应用启动,常驻后台。

### 设置中与智能能力相关的选项

| 选项 | 作用 |
|---|---|
| **Agent 预设** | 智能能力的角色风格:通用助手(默认)/ 精简执行(直奔结果)/ 代码专家 / Cordis 插件开发助手 |
| **默认模型** | 智能能力使用的模型(节点上也可单独选择) |
| **权限预设** | 沙箱模式 + 审批策略:无人值守(默认,工作区读写·不询问)/ 工作区读写·逐项审批 / 只读·逐项审批 / 完全放行(不限目录·不询问)。选「逐项审批」档位后,任务越权时会弹窗问你要不要放行 |
| **任务完成音效** | 开启后,运行超过 5 分钟的智能任务完成时播放提示音(默认开,可关);可**替换自定义音频文件**并点「试听」 |
| **主题色** | 10 款界面主题色,默认 Industrial(即时预览) |
| **对话节点发送行为** | Enter 发送 · Shift+Enter 换行(默认),或 Enter 换行 · Ctrl+Enter 发送 |
| **扩展商店 🛒** | 设置「插件」标题行右侧的「＋ 安装插件 / 🛒 商店」:商店弹窗按 **插件 / 技能 / MCP** 三个标签从**线上目录**拉取(npm registry + GitHub 官方仓库),一键安装 / 卸载;已安装插件列表默认收纳,点击展开管理 |

> 工作目录统一设置在**画布 Tab 条右侧的「工作目录」控件**上(设置后本画布所有智能节点只读继承);不设置则每个节点单独选择。

## 三个新入口:原来只能 X → 现在可以 Y

### ① 对话节点:「智能助手」开关

**原来**:只能聊天,模型答完就结束,不能碰你的文件。

**现在**:勾选对话节点里的 **「智能助手(可读文件 / 联网 / 执行命令)」**,然后直接下指令,例如:

> 把 E:\素材 下的所有 txt 汇总成一份大纲,存为 E:\素材\大纲.md

它会自己**打开文件 → 读取内容 → 整理 → 写入新文件**,然后回复你结果。聊天记录依然保存在工作流里,关了再开还在。

- 回复过程中能看到它**实时思考**(灰色流式)与**调用的工具(🔧)**;回复左侧的「◉ 思考内容」可回看全过程。
- 工作目录点**「浏览」**用文件夹窗口选择(也可手填),留空则使用应用数据目录。

### ② 文本处理节点:「🤖 智能」按钮

**原来**:只能处理你手动粘进画布的内容;提示词写什么,它就生成什么。

**现在**:点节点头部的 **🤖 智能** 按钮后,提示词变成「任务描述」,例如:

> 联网查一下这三个品牌的最新旗舰型号与价格,做成对比表,并保存为 E:\对比.md

它自己**搜索 → 整理 → 落盘**,节点输出面板照常显示最终文本,照常可以连线给保存节点、参与批量/聚合。

- 批量 + 智能 = 每条目派一个「会办事的小助手」,全部并行完成任务。
- 智能运行时思考过程在「◉ 思考」里实时可见,工具调用标有 🔧。

### ③ 智能任务节点(新节点)

**原来**:画布上没有「把一个完整任务交给 AI」的节点。

**现在**:右键画布 → **智能节点 → 🤖 智能任务**。它与文本处理节点**功能对齐**:

1. 填写任务描述(支持 `@` 引用已连接的输入节点,输入内容自动附为背景信息);
2. 点**「浏览」**用文件夹窗口选择工作目录(可留空);
3. 可接多个输入节点,批量输入时支持**批量 / 聚合**两种模式(批量 = 每条目派一个小助手,聚合 = 全部条目合并为一次任务);
4. 点 ▶,看它逐步执行;输出面板支持**复制 / 清空 / 浏览**,输出可继续连线给任何下游节点。

与文本处理节点的区别:智能任务节点**没有「多次尝试」按钮**(智能任务多步执行,由模型自行规划,不做并行抽卡);参数面板(预设 / 供应商 / 模型 / 思考强度)与「智能会话」完全一致,可一键「↗」扩展为会话,节点与会话内容双向同步。

### ④ 让智能助手帮你搭工作流

**原来**:节点只能自己在画布上右键添加、拖线、改标题。

**现在**:在智能任务 / 智能会话里直接说目标即可,例如:

> 实现物品配置的工作流:根据需求生成新物品配置,并写入项目的配置表。

它会在**当前画布**上创建多个节点、改好标题、连线,并在提示词里写上 `@标题` 引用;节点从左到右排开、互不重叠,你可以继续改提示词、改保存路径,点 ▶ 运行。典型结构:

1. **文本输入**「物品需求」——你要填的字段或说明;
2. **文本输入**「配置表格式」——表头 / 示例行;
3. **文本处理或智能任务**「生成物品配置」——提示词引用 `@物品需求` `@配置表格式`;
4. **保存文本**「写入配置表」——保存路径指向项目里的 yaml / json / csv。

连线后 `@引用` 才会生效;保存节点把生成结果写进文件,整条链以后都可以再跑。

## 任务中与模型的互动(提问 / 审批 / 命令)

智能任务与智能会话都支持 DeepSeek Harness 的三种人机互动:

### 提问(ask_user)

任务进行到一半,模型需要你拍板时(选方案、确认信息),右下角会弹出**提问卡片**:
选项点选或填「其他」→ 点「回答」,模型拿到你的答复后继续执行。

### 权限审批(approval)

当权限预设为「逐项审批」档位、任务要越出沙箱(比如写工作目录之外的文件)时,
会弹出**审批卡片**(显示工具名与原因):**允许一次** 或 **拒绝**。拒绝后模型会
按沙箱规则继续,不会卡住。

### 斜杠命令(智能会话输入框)

输入框里以 `/` 开头的行是命令,直接执行、不会发给模型:

| 命令 | 作用 |
|---|---|
| `/new` | 新建会话 |
| `/compact` | 压缩上文(保留最新上下文继续聊) |
| `/plan` | 切换规划模式:下一轮先制定分步计划再执行 |
| `/rename 标题` | 重命名当前会话 |
| `/export` | 把会话记录导出为文本文件 |
| `/permissions` | 查看当前权限预设与可选档位 |
| `/help` | 列出全部命令 |

## 过程中你能看到什么

| 现象 | 含义 |
|---|---|
| 节点显示「◉ 思考中」 | 模型正在规划/思考,点击可看流式全过程 |
| 思考内容里的 🔧 xxx | 它正在调用工具(读文件/写文件/联网/命令);会话里的 🔧 块可**点击展开查看参数与完整结果**(终端输出等) |
| 对话节点逐字流式回复 | 正文正在实时生成 |
| 执行按钮变为红色「■ 终止」 | 任务运行中,点击立即终止(引擎自动重启) |
| 设置里的「智能引擎状态:已连接」 | dsh 引擎正常 |

## 费用与安全(重要)

- **计费方式变了**:智能模式按「任务完成」计费——一次任务可能多次调用模型(思考 + 工具 + 总结),比普通单次调用贵。短任务与普通模式接近,复杂任务(读很多文件/多次搜索)会更多。
- **它会动你的文件**:请务必在节点里指定正确的工作目录;写文件前先想清楚。运行过程全程可见,发现不对可在设置里随时关闭总开关。
- **数据不离开你的配置**:API Key 依然只存本机;任务内容只发给你配置的 DeepSeek 服务商,与原来的普通模式一致。

## 降级保底:随时回到原来的样子

每个升级点都是**独立开关**:

- 对话节点:取消勾选「智能助手」→ 回到原聊天模式;
- 文本处理节点:再点一次「🐋 智能」→ 回到原处理模式。

原模式的行为、数据、结果与接入前**完全一致**,不会丢东西。

## 常见问题

**Q:提示「需要配置一个 DeepSeek 文本服务商」?**
设置 · API/配置 里确认存在 DeepSeek 服务商且填了 API Key(智能能力只走 DeepSeek 路由)。

**Q:提示「智能引擎状态:未连接」?**
点「检查引擎」重试;引擎随应用启动并自愈(崩溃后下次使用时自动重启),通常无需手动干预。

**Q:插件列表为什么分「已安装插件」和「运行时内置插件」?**
「已安装插件」是你通过 npm 安装的扩展,可启停/移除;「运行时内置插件」是引擎自带的组件(展开可查看清单),随引擎版本更新,不可单独移除。

**Q:任务卡住不动?**
智能任务可能耗时较长(尤其联网搜索)。若引擎崩溃,界面会提示「智能引擎已断开」,重试即可;长任务可先在智能任务节点里小范围验证。

**Q:能装更多能力(插件)吗?**
设置 · 智能能力区块的「插件」列表支持按 npm 包名安装/移除 dsh 插件(如 `@deepseek-ai/...`),安装后引擎自动重启。插件兼容性由插件作者保证,请谨慎安装不熟悉的包。
