# 轴线与连续性

正文 `film-shot-language` 引用本文件。这里的每条规则都要给两个答案：规则是什么，以及怎么把它编码进关键帧或提示词，让一个没有记忆的生成模型照做。

## 一、平面图：谁在左，谁在右

```text
俯视房间。轴线是穿过 A 与 B 的那条线；纸面越往下 = 离轴线越远。

                            [X]  机器在这里就是过线了

     A (*)= = = = = = = = = 轴线 = = = = = = = = = (*) B

     A 面朝画面右                 B 面朝画面左

 [1]                        [2]                           [3]

                                                             [4]

 [1] A 身后越过她拍 → OTS over A，看见 B
 [2] 轴线正中，正对轴线 → 双人
 [3] B 身后越过他拍 → OTS over B，看见 A
 [4] 从 B 更外侧 → A 的干净单人，B 出画

 [1]–[4] 全在轴线下方，所以在每一格里 A 都在画面左、朝右看，
 B 都在画面右、朝左看。切到 [X]，两人左右互换，观众读成「换座位」。
```

- 镜头不必待在窄弧里：轴线同侧的任意距离、任意角度都合法。重要的是**侧**。
- 三人以上：轴线属于**当前交换拍点的那一对**，注意力一转移就重画。分镜表每一行都要写 `axis: ANNA–MARCO`，否则模型会把第三个人按构图方便乱放。
- 重画轴线本身要么是一个镜头（把三人新关系收进去的全景），要么是一个运动（弧线把观众带到新线上）；不允许无声切开。

## 二、过线的五种合法路径

| # | 做法 | 成本 | 适用 |
| ---: | --- | --- | --- |
| 1 | 让人物自己走到另一侧，轴线重画 | 0 | 走位本来就该动 |
| 2 | 用横移/弧线把机器带过线 | 一个运动 | 想要连续感、不想多切 |
| 3 | 切一个压在线上的中性镜头（正面、沿运动方向直拍） | 一个镜头 | 短剧、对话段落最快 |
| 4 | 切到别处（插入、第三方）再回 | 一个镜头 + 一拍注意力 | 需要喘息 |
| 5 | 全景重建 | 一个镜头，戏的温度归零 | 段落转折 |

越轴的典型症状：观众觉得晕但说不出为什么；动作段里两个人像换了奔跑方向。

## 三、30 度规则

- 连续两镜拍同一主体，必须满足其一：绕主体 ≥30°；或同轴跳 ≥2 级尺寸。
- 两者都不做：同轴 MS→MCU 读作「机器卡了一下」；同尺寸换 20° 读作「机器打了个嗝」。
- 30° 不构成过线许可。新角度仍在轴线同侧。
- 编码方式：把角度写成可见变化——「现在从她另一侧拍，窗在她左肩后而不是右肩后」——并在同一句里改尺寸。

## 四、屏幕方向

| 情形 | 成立条件 |
| --- | --- |
| 单人行走 | 上一镜向右出画，下一镜仍向右；直到画内有东西让他转身 |
| 相向而行 | 两人必须朝**相反**方向移动 |
| 同向同行 | 两人必须朝**相同**方向移动 |
| 追逐 | 最容易翻车：反转一个跑者的方向，观众就认为他掉头了 |
| 出画/入画 | 右出 → 左入；朝镜头走近或走远是中性重置，可从任意侧入 |
| 擦镜 | 前景被身体擦过（wipe）既藏切点又重置方向，是 AI 序列最宽容的缝 |

提示词必须写死方向：「她从画面左走向画面右，走出右边缘」。不要写「她走开」——模型会替你选。

## 五、视线匹配

视线是**向量**，不是「瞥一眼」。三件事要同时成立：

1. **水平方向**：A 看向画外右，则反向镜里 B 必须看向画外**左**（两人看同一侧 = 没在互看）。机位放在 A 背后、偏离视线 20–35°，再镜像到另一侧。
2. **高度**：B 更高或站着、A 坐着，则 A 向上看、B 向下看。反向镜的机位高度取**画外那个人**的眼睛高度，不是被拍那个人的。两人都停在 1.6 m 是「几何正确、情绪已死」的经典错误。
3. **距离**：1 m 与 8 m 的对视不同，焦段要跟着变。

反打几何：两侧用同一支镜头、同一机距、同一头顶余量，除非你要一次刻意的权力失衡。前景肩必须镜像——拍 B 时 A 的肩在左下，拍 A 时 B 的肩在右下。肩换了角，就是过线了。

提示词写法：「他略微向上，看向画外左侧」——把画外目标的侧与高度写出来。不行就生成一条双人镜再裁两个单人，几何必然成立。

## 六、硬切的六项协议

A 的末帧与 B 的首帧要**五项相同、一项故意不同**：

| # | 项目 | 容差 |
| ---: | --- | --- |
| 1 | 主体屏幕位置 | 与预期位置相差 ≤15% 画宽，或刻意对置 |
| 2 | 运动屏幕方向 | 同向；反向必须隔一个中性镜头 |
| 3 | 光向与光量 | 主光同侧；整体曝光差 ≤0.5 档 |
| 4 | 状态 | 服装、道具位置、头发、湿度、哪只手拿什么 |
| 5 | 视线侧 | 两次都看画框同一边 |
| 6 | 景别 | **这一项就是你打破的**：同轴跳两级，或角度移 ≥30° 跳一级 |

最容易漏的是第 5 项，而它最容易被读成「错误」而不是「风格」。

## 七、覆盖模式与 AI 代价

| 模式 | 买到的 | AI 适配 |
| --- | --- | --- |
| 主镜 + 单人 | 完全剪辑自由 | 不能重演另一角度。先从主镜抽帧、再换角度重生成，别重新描述一遍 |
| 三角机位（两个单人 + 一个双人，同侧） | 可剪的对话 + 保证方向 | 三张关键帧从同一张源图派生；轴线写进 continuity 文件 |
| 长镜头（oner） | 实时、不断裂的压力 | 单条生成太短：链式拼接（上一条末帧当下一条首帧），缝藏在甩镜/擦镜/暗部 |
| 走谈（walk-and-talk） | 动量、不静态的说明 | AI 最差场景：步态 + 口型会换腿。压到 3–4 s，改侧面或正面 MS，踩脚步切 |
| 过肩对 | 双方在场 + 对抗 | 从一条双人关键帧派生两张，独立生成必翻车 |
| 插入簇 | 节奏、潜台词、救任何剪辑 | 回报最高：短、小、无脸、无步态。每场备 3–5 个 |

双人对话拍的默认覆盖：一个全景、两个单人、一个双人、两个插入 = 六个 setup，预期只用四个剪出来。六个 setup 不是六次生成，每次生成按难度分档预留重试。

## 八、复盘用检查表

- [ ] 每一行都写了 `axis: A–B`，且全段没有无声换侧。
- [ ] 每个相邻镜对：同轴跳 ≥2 级，或角度 ≥30°。
- [ ] 屏幕方向从上往下读一遍没有反转；反转处有中性镜头或转身动作。
- [ ] 反向镜的机位高度取的是画外那个人的眼高。
- [ ] 视线侧在两次里都指向画框同一边。
- [ ] 出画方向与下一镜入画方向相反（或朝镜头进出）。
- [ ] 光向没有在同一个时刻翻转。
- [ ] 至少每一场有一次全景，让观众拿到地理。
