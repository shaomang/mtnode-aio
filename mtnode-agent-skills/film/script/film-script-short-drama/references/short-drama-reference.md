# 竖屏短剧结构参考

供 `SKILL.md` 引用：一份排名靠前的 60 集骨架、分集表模板、钩子句型库、单集自检表。

## 一、60 集骨架范例（结构层，非原文）

样本：清单第三轮实测「写全剧骨架」中排名靠前的《验尸官的婚礼》（女频／大女主／复仇／悬疑／豪门，60 集，每集 1–2 分钟）。只摘结构，不抄正文。

### 1.1 发动机

- 真钩子①：三年前是谁杀了沈峥？
- 真钩子②：林晚什么时候亲手推翻自己签的那份报告？
- 回合机制：亮出一件看得见的证据 → 沈家毁证据、抹黑 → 她靠专业翻盘 → 离凶手近一步，也离自己的签名近一步。
- 证据阶梯：疤 → 切片 → 照片 → 录音 → 袖扣。逐级加码，同一种证据不重复翻盘。

### 1.2 前史（一页，全部可变成证据）

四年前订婚，男方送旧机械表；三年前男方发现舅舅洗钱，被砸死后推下海，死者扯下一枚袖扣；半个月后无名男尸上岸，法医原写「他杀」被逼改成「意外」并签字，私留一张切片；母亲为保股份找替身整容；一年前替身当众退婚。

### 1.3 知情边界（锁定，不得提前）

| 信息 | 观众 | 主角 |
| --- | --- | --- |
| 新郎是替身 | 第 1 集 | 第 1 集 |
| 法医主任背后另有人 | 第 10 集（只给声音或背影） | 第 30 集 |
| 弟弟当晚在船上 | 第 22 集 | 第 42 集 |
| 凶手是舅舅 | 第 30 集 | 第 40 集 |
| 母亲不知道是谋杀 | 第 35 集 | 第 49 集 |

硬约束示例：第 30 集之前，掌痕与袖扣不能同框，也不能剪在一起。

### 1.4 五段走向

| 段 | 集数 | 核心证据 | 段尾大卡点 |
| --- | --- | --- | --- |
| 一 | 1–10 | 疤：新郎是假的 | 卷宗被销毁，签名是她自己；幕后一句「问问她当年留了东西没有」 |
| 二 | 11–20 | 切片：死者是沈峥 | 股东会当众公布亲缘结果，替身被藏 |
| 三 | 21–30 | 照片：不是意外 | 中点：主任被带走，审讯里把责任推给母亲；舅舅探视，指尖碰袖扣 |
| 四 | 31–40 | 录音：至暗 | 主角被刑拘、证据全毁、盟友反水；看守所里看见第二枚新袖扣 |
| 五 | 41–60 | 袖扣：凶手与那份报告 | 第 50 集人质上船；第 60 集当庭推翻自己的报告，写下「他杀」并签名 |

可迁移的四条：

1. 两条真钩子：一条追凶手（外部），一条追主角自己的污点（内部）。缺内部那条，主角只是查案工具。
2. 证据阶梯决定回合格局：每一级证据都要「看得见、可被毁、毁后还有备份」。
3. 知情边界表把「观众知道、主角不知道」的张力写成硬约束，避免中途写崩。
4. 每段尾都是「赢一半＋失去一样」，不是纯爽。

## 二、分集表模板（可直接复制）

```
| 集 | 本集问题 | 开场钩子（0–3s） | 场1 | 场2 | 场3 | 爽点/打脸 | 代价 | 集尾卡点（型＋台词） | 知情变化 |
|----|----------|------------------|-----|-----|-----|-----------|------|----------------------|----------|
| 1  |          |                  |     |     |     |           |      |                      |          |
| 2  |          |                  |     |     |     |           |      |                      |          |
```

填写规则：

- 「本集问题」≤12 字，是可回答的句子。
- 「开场钩子」写第一帧画面，不写「紧张气氛」。
- 三场各写一句「谁要什么、被谁挡」。
- 「代价」必须具体（停职、失去证据、被拘、朋友反目）。
- 「卡点」写型＋台词；没有台词就写动作。
- 「知情变化」只填本集新增的「谁知道什么」。

## 三、钩子与卡点句型库

### 3.1 开场（0–3 秒）

| 型 | 句型 |
| --- | --- |
| 羞辱 | 「这种人也配进这个门？」 |
| 反常 | 所有人都在笑，只有新郎在看她身后。 |
| 动作 | 她抬手，把戒指扔进香槟塔。 |
| 身份 | 「叫她嫂子。——不对，该叫前嫂子。」 |
| 倒计时 | 「十分钟，警察就到。」 |
| 半句 | 「你根本不知道你娶的是——」 |

### 3.2 集尾卡点

| 型 | 句型 |
| --- | --- |
| 新信息 | 「这份报告的第二页，是你签的字。」 |
| 新威胁 | 「明天之前，我要她在这个城市待不下去。」 |
| 身份 | 「你不是他。他的表，慢七分钟。」 |
| 倒计时 | 「三分钟后投票。你现在走，还来得及。」 |
| 反常动作 | 她把唯一的证据，递给了对手。 |
| 半句 | 「你根本不是——」（门被推开） |

### 3.3 打脸句（爽点落地）

- 「你说我是外人。可这份股权书，写的是我的名字。」
- 「你让我滚。可以——先把这三年的账结了。」
- 「你查我？先看看你自己签过什么。」
- 打脸句必须由前面建立过的物证支撑；空口反转观众不认。

## 四、单集自检表（写完逐集跑）

**钩子**
1. 第一帧是否已经在冲突里？
2. 0–3 秒有没有出现「谁、要什么、被谁挡」中的至少两项？
3. 开场是否用了风景、旁白、字幕、起床洗脸？用了就重写。

**推进**
4. 本集问题能否用是／否回答？
5. 本集是否回答了它？
6. 主角本集主动做了几个决定？（少于 2 个＝被动）
7. 对手是否也主动出了一手？
8. 有没有一场删掉不影响本集？有就删。

**爽点与代价**
9. 爽点是否打在具体的对手脸上？
10. 主角赢了之后失去了什么？
11. 下一集的赌注是否比本集大？

**卡点**
12. 卡点是不是新信息／新威胁／身份／倒计时／反常动作／半句之一？
13. 卡点能不能用一句台词写出来？
14. 相邻两集是否用了同一型？
15. 看完卡点，能不能立刻写出下一集第一拍？

**可拍性**
16. 本集几个场景？超过 5 个就合并。
17. 本集出场几人？超过 6 人删或合并。
18. 有没有需要群演、爆破、雨夜大场面的戏？能否改成声音＋反应镜头？
19. 新出现的人物有没有一个可复用的视觉标识？
20. 全剧主场景是否控制在 3 个以内？

**一致性与合规**
21. 人物称呼、职务、亲属关系与上一集是否一致？
22. 伤势、服装、道具、时间线是否接得上？
23. 本集新增信息是否与知情边界表冲突？
24. 是否出现未经设定的「新证据」？新证据必须在前三集埋过。
25. 是否有 AI 生成标识与备案号预留位（上线版本）？

## 五、AI 排产参数（条目实测口径）

| 项目 | 数值 | 说明 |
| --- | --- | --- |
| 每集镜头数 | 36 个 | 4–10 秒／镜 |
| 分镜要素 | 每镜 7 项 | 景别、机位、动作、台词、时长、参考图、转场 |
| 单镜时长 | 3–6 秒 | 对白镜可到 8 秒 |
| 画面比例 | 9:16 | 竖屏固定 |
| 单集参考图 | ≤9 张／镜 | 超出会互相污染 |
| 场景复用 | 主场景 ≤3 | 降低生成与美术成本 |

注意：以上是清单里多个条目的实测口径，不同管线会有差异；写骨架时按你的生成工具反查，不要当成行业标准。
