# 场景卡扩展：布局记录、机位计划、光照基调、验收

## 1. 布局记录（先有空间，再决定从哪里看）

| 项 | 记录内容 | 反例 |
| --- | --- | --- |
| 稳定方向 | 入口墙 / 窗墙 / 内墙；复杂场所给统一坐标与原点、楼层标高 | 用「画面左」当世界坐标 |
| 边界与连接 | 房间轮廓、墙段、门窗洞口、走廊转角、楼梯起止与平台、栏杆或夹层开口 | L 形空间假装一台相机能看穿 |
| 固定锚点 | 3–5 件不可移、可互相辨认的大件，含位置、朝向、体积 | 两把同款椅子（歧义） |
| 同一状态 | 时段、天气、光源位置与开关、物件开合、既有损坏 | 九格里混着两个时刻 |
| 未看见区域 | 明确标「未知」或「候选推定」 | 把一张透视图当全景证据 |

复杂度纪律：

- 几何没有精确尺寸时只写相对关系或标「估计」，不堆虚假精度。
- 新补的空间可作为本轮候选，不自动成为已批准资产。
- 需要去顶、移墙、剖切才看清的图，标为技术布局图，不冒充真实机位。

## 2. 平面布局（推理用，不进生成）

平面图回答四件事：

1. 每人在哪（坐标或相对锚点的距离）。
2. 面向哪、看谁（视线连线）。
3. 相互距离（写数值或相对倍数，例如「两人相距 1.2m」）。
4. 尺度参照（门宽、桌高、层高）。

转成提示词时只写下面这一段，不贴图：

```
左侧：[固定建筑/遮挡/主光来源]；中部：[人物关系/可通行区域]；右侧：[出口、纵深或危险信息]。
前景：[遮挡/材质]；中景：[Cxx 站位]；背景：[尺度锚点、雾或实用灯]。
人物锁定左右位置、身高、朝向和距离；Pxx 记录持有人、可见面、朝向与最终状态。
```

方向校验：向前为 `(dx, dy)`、z 向上时，画面右方为 `(dy, -dx)`，目标向量与它点积为正才在右侧。朝南看时东侧在画面左。

## 3. 机位计划字段（view_plan）

| 字段 | 写什么 |
| --- | --- |
| `view_name` | main / reverse / left / right / detail / grid-1…9 |
| `camera_position` | 相对锚点的位置（「入口内 1m，偏东」） |
| `look_at` | 看向哪个目标或墙面 |
| `height_and_pitch` | 机位高度（m）+ 俯仰角 |
| `framing` | 焦段或视角宽窄、景别 |
| `visible_anchors` | 本格能看见哪些固定锚点 |
| `occlusion` | 谁挡住谁，挡多少 |
| `purpose` | 这一格补足什么空间信息 |
| `reference_role` | 作为外观参考还是说明用 |

`spatial_contract` 记：`basis`（依据）、`world_orientation`（世界朝向）、
`boundaries_and_connections`、`fixed_anchors`、`lighting_state`、`unseen_or_inferred_regions`。
图片生成前 `reference_images` 为空列表，机位计划不算图片成果。

## 4. 光照基调怎么写

| 项 | 必须给的值 | 说明 |
| --- | --- | --- |
| 光源类型 | 窗光 / 顶灯 / 台灯 / 路灯 / 火把 / 屏幕 / 霓虹招牌 | 允许光源在画外，但位置要可解释 |
| 光源位置 | 相对锚点或方位（「北墙高窗，右上方 45°」） | 换机位时世界位置不动，画面位置可变 |
| 色温 | 具体 K 值（2800 / 3200 / 3600 / 4200 / 4500 / 5000 / 5500） | 同场次所有镜头共用一个基准 |
| 光比 | 3:1 / 6:1 / 8:1 / 10:1 / 12:1 | 显式写出，不写「对比强」 |
| 饱和度 | 百分比 | 与风格圣经一致 |
| 暗部规则 | 暗部可读 / 允许压死黑（写明理由） | 「暗部可读而非死黑」是常见底线 |
| 反射路径 | 湿面、玻璃、金属高光落在哪 | 设了湿面就必须有对应反射 |

## 5. 成组板的曝光归一化

1. 选一张主版（通常是主图）。
2. 每张板对主版做一次快速编辑：「把这张的曝光与光位对齐到主版（第二张参考，同一空间），其余全部保持不变。只改曝光与光位。」
3. 只允许改曝光与光位；颜色、材质、家具位置一律不动。
4. 逐张比对色温、光比、饱和度；不一致就重做该张，不整体重生成。
5. 归一化完成后再进剪接；未归一化的板会在剪接点上读成换天气。

## 6. 验收清单（逐格打勾）

- [ ] 门窗数量与位置在每格一致，没有为了构图新开或封掉门窗。
- [ ] 固定锚点在每格位置与朝向一致；不在某格消失或镜像。
- [ ] 每格的可见锚点足够与相邻格重叠，能判定是同一空间。
- [ ] 每格只有一个摄影位置；没有同机位变焦、裁切、换滤镜冒充新机位。
- [ ] 相机没有落在实墙、楼板、天花板内。
- [ ] 世界光位不变；窗光在画面里可以从左变到右，实际窗和太阳没动。
- [ ] 反打不是水平翻转：画面左右按几何重算过。
- [ ] 广角没有拉长房间、没有放大或缩小家具、没有打通原来不通的门。
- [ ] 每格的光比、色温、饱和度与主版一致。
- [ ] 空景没有被塞进人物；需要人物的机位另建。
- [ ] 九格拼图不当成单幅电影画面输入；制作时用对应单格原图。
- [ ] 未看见区域仍标为未知或候选，没被写成已确认事实。

## 7. 只修问题格

- 发现问题先定位到格：门窗错、家具挪、楼层错、光源错、遮挡错。
- 只重生成该格，保留其余有效视图；不因一格错重做整套。
- 若只有拼图可用，说明裁出的单格分辨率限制，不把放大后的像素数当新增细节。
- 格数正确不能替代同空间一致性。
