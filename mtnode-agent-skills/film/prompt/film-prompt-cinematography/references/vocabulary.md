# 摄影词表（景别 / 光线 / 构图 / 镜头 / 材质 / 天气）

英文片段可直接进提示词；中文列是「什么时候用」。全部沿用上游词表，重复项已去重合并。

## 一、景别与角度

| 英文片段 | 用途 |
| --- | --- |
| `Extreme Close-up (Detail Focus)` | 眼睛、指纹、极小的细节，强调质感 |
| `Macro Angle (Texture Focus)` | 表面材质特写（织物、金属、皮肤） |
| `The Reaction Shot (Close Up)` | 只为抓一个情绪反应 |
| `Medium Close Up (MCU)` | 肩以上，表情为主 |
| `Medium Shot (MS)` | 腰以上，动作与表情兼顾 |
| `Full Body Shot` | 从头到脚，看服装与体态 |
| `Extreme Long Shot (ELS)` | 人只是小点，强调环境之大 |
| `Extreme Wide Shot (Small Subject)` | 人在广袤空间里显得孤独 |
| `Eye-Level Shot (Neutral Perspective)` | 平视，自然、中立 |
| `Low Angle` | 仰拍，权力、压迫感 |
| `High Angle (Dominating View)` | 俯拍，被支配、变小 |
| `Overhead / Bird's Eye` | 顶视，布局、图案、无助感 |
| `Dutch Angle` | 倾斜地平线，不安、失控 |
| `Worm's Eye` | 极低仰拍，戏剧性上升感 |
| `Shoulder-Level / Hip-Level` | 略高于视线 / 强调服装与场景 |

## 二、光线

### 自然光与时间

| 英文片段 | 用途 |
| --- | --- |
| `golden hour` | 日出/日落前后暖调，长柔影 |
| `Magic Hour with Sun-Kissed Effect` | 暖光轻扫皮肤 |
| `blue hour` | 日出前/日落后冷调蓝 |
| `Direct Sunlight (Midday)` | 正午硬光，影极锐 |
| `Overcast Light (Flat Light)` | 阴天漫射，无硬影，色彩真实 |
| `Window Light (Soft & Diffused)` | 窗光，柔和、安静 |
| `dappled light` | 树影斑驳 |
| `crepuscular rays` | 云隙光 |
| `volumetric lighting` | 空气中可见光柱 |
| `Sunburst Effect` | 通过缝隙的星芒 |
| `Backlit with strong lens flare` | 逆光 + 明显耀斑 |
| `silhouette` | 亮背景前的剪影 |
| `Atmospheric Perspective` | 远处因空气透视变淡 |
| `Chiaroscuro` | 强明暗对比，绘画感 |

| 英文片段 | 用途 |

### 材质级光效

| 英文片段 | 用途 |
| --- | --- |
| `Subsurface Scattering` | 光透过皮肤/蜡/玉，通透有生命感 |
| `Refraction and Caustics` | 光穿过水/玻璃，形成流动光斑 |
| `Anisotropic Reflection` | 拉丝金属、头发的条状高光 |
| `Specular Highlight` | 点状强反光，硬材质 |
| `Halation` | 高光边缘的红色光晕（胶片感） |

## 三、构图

| 英文片段 | 用途 |
| --- | --- |
| `rule of thirds` | 主体落三分线交点 |
| `centered composition` | 对称、稳定、仪式感 |
| `golden ratio / fibonacci spiral` | 更柔的视觉引导 |
| `leading lines` | 线条把视线带向主体 |
| `frame within frame` | 门框/窗/镜中框住主体 |
| `negative space` | 大量留白，极简、孤独 |
| `Rule of Space / lead room` | 运动或视线方向前方留空 |
| `Headroom` | 头顶留白，避免切头 |
| `foreground interest` | 前景虚化元素，制造纵深 |
| `Rule of Odds` | 主体数为奇数（3、5）更自然 |
| `Figure-Ground Relationship` | 主体与背景明确分离 |
| `Diagonal Placement` | 斜线构图，动感、紧张 |
| `Visual Tension (High Contrast Placement)` | 对立元素贴近，制造张力 |
| `symmetry` | 绝对对称，秩序/压迫 |
| `reflection composition` | 水面/镜面反射构图 |

## 七、常见错误词（写了也没用，甚至会退化）

| 别写 | 改成 |
| --- | --- |
| `cinematic`（单独使用） | `35mm film grain`, `anamorphic lens`, `teal-orange grade` |
| `8k, masterpiece, ultra detailed` | 具体材质 + 具体光位 |
| `fast` | `moves at 40 km/h` |
| `beautiful lighting` | `practical only, 3200K, hard falloff` |
| `epic` | 尺度对比（`as tall as four humans`） |
| `no blur / no noise` | `tack-sharp focus, clean gradients, low ISO` |
