# 出片质检与返修

返修的第一原则是**不要重写整条提示词**。先把症状归层，再只改那一层里最小的那一处。本技能给诊断表、五档判决、重试阶梯与停损规则。

## 何时用

- 已经生成过，用户说「脸不像」「手崩了」「动作没做完」「口型对不上」「画面抖」。
- 需要判断这条片是「提示词写错」还是「素材/首帧/参数/模型选错」。
- 要决定继续抽卡还是改写提示词（预算与停损）。
- 交付前要跑一遍验收，确认没有可修的硬伤。
- 不适用：还没出过片的首版写作（见 `film-prompt-video-models`）；跨镜锁定设计（见 `film-prompt-consistency`）。

## 核心原则

1. **先看片，再看提示词。** 至少抽 6 帧（头/1/4/中/3/4/尾）逐帧看，并单独听一遍音轨。凭记忆判断会漏掉重复帧、口型错位、道具跳手。
2. **每个成片只给一个判决**：`keep` / `fix-in-post` / `edit` / `re-roll` / `rewrite`。判决没定就不要开下一次生成。
3. **一次只改一个变量。** 改提示词的一句话、或换一个模式、或换一张参考——三者只能选一个，否则因果不可读。
4. **同一个缺陷出现两次 = 必须 rewrite，不能继续抽。** 每次都是不同的随机缺陷 = 走批量抽卡 + 筛，不要逐条重写。
5. **先查上游，再改文字。** 动作控制类失败大多在参考片、角色图、朝向/场景源设置，而不在提示词。
6. **最小改动顺序**：删掉与参考矛盾的句子 → 收窄一个子句 → 换一个参数 → 才考虑重写整条。
7. **开拍前先写两个数**：这一镜的重试预算（几次）与「够好」标准（主缺陷修掉、次缺陷可放）。没写，标准会自动变成「完美」，任何预算都不够。
8. **不要拿同一段文字原样重生成。** 同一文本会再次触发同一失败；至少改一个词。
9. **区分「模型做不到」与「提示词没写」。** 唱歌、长时间肢体接触、多人同框是最难的三类，遇到就直接换方案（预录 + 分段），不要靠迭代硬碰。

## 工作流

1. **取证（输入：成片 + 原始提示词 + 参数）** → 抽帧、听音、记录：哪一秒、哪一帧、哪个对象、什么现象。产出：症状句（`0:04 左手六指`）。
2. **归症状** → 查第 4 节诊断表，找到「症状 → 机制」那一行。找不到就归到「随机缺陷」，走抽卡路线。
3. **判层（按顺序问四个问题）**：
   - 参考图/首帧里是不是本来就有这个问题？（有 → 换素材，不改提示词）
   - 提示词里有没有与参考矛盾的句子？（有 → 删那句）
   - 参数/模式是否不匹配？（时长不够、分辨率过低、模式选错 → 改参数）
   - 模型是不是根本做不到？（是 → 换模型或换方案）
4. **定判决** → 第 4 节五判决表。
5. **执行最小改动** → 一次一个变量；`edit` 判决用局部编辑句式（带秒点 + 保留清单），不要整条重生成。
6. **记录 shot log** → 记下改的是哪个变量、结果如何；同一缺陷第二次出现时直接触发 rewrite 规则。
7. **到预算一半仍无进展** → 停手换策略：换模式、拆镜、换模型、或把这段改成后期处理。
8. **验收** → 跑第 4 节验收清单；`keep` 之后才交付。

## 关键参数与模板

每个症状的成因与修法详版见 `references/diagnosis-table.md`；重试阶梯、停损数值与 shot log 模板见 `references/retry-and-log.md`。

### 失败模式诊断表

| 症状（可观察） | 机制 | 最小改动 | 不要做什么 |
| --- | --- | --- | --- |
| 手指多/少、关节反向 | 手部在快速动作或遮挡中失去结构 | 让手离开动作焦点（插兜、握物、出画）；或改近景只拍上半身 | 加 `perfect hands`（无效）；继续堆手部描述 |
| 脸/身体畸变、五官融化 | 首帧脸被遮挡、极限透视、参考图混龄 | 换正面或 3/4 侧首帧；撤掉多余角度参考 | 在同一张坏首帧上反复重生成 |
| 身份漂移（3–4 个切点后换脸） | 身份块被改写或参考集互相竞争 | 身份块逐字复用；只留一张主身份图；补 `no face morph` | 增加更多参考图 |
| 穿模（人物穿家具/身体互穿） | 空间关系没写，或多人接触超模型能力 | 写清路径与间距（`passes on the left of the table`）；把接触改成前后景分离 | 用更长的形容词描述「自然地」 |
| 口型不符 / 台词像别人配的 | 台词没加引号、说话人未标、语速超时长 | `Character says: "..."`，单句 ≤6 词；用 2.5s 说完一句的节奏排 | 靠加 `lip sync accurate` 补救 |
| 动作被截断（手还在伸就切） | 只写了动作过程，没写完成状态 | 命名完成态：`the lid seats flush and stays`；或下一镜从结果开始 | 加时长但不写完成态（还是切在半路） |
| 手势空演（手在动，物体不动） | 操作对象没给物理反馈 | 写物体响应：`the drawer slides out`, `the page turns` | 只描述手部轨迹 |
| 孤儿肢体（群像里多出一条腿/手） | 人数与站位没锁 | 写人数锁 `exactly four people`；拉开站位避免重叠；拆成单人镜 | 用 `crowd` 这种不定量词 |
| 空间错乱（走廊方向反了、穿墙） | 没写空间拓扑与朝向 | 补拓扑句（门在左后、窗在右墙）+ 参考场景板 | 靠「同一个走廊」四个字 |
| 走路像滑行 | 走路是模型最难的动作之一 | 拆成 2–3 个短镜（起步/中段/停下）；写脚跟落地与重心转移 | 一次生成 10 秒连续行走 |
| 画面乱转、看不清 | 一镜叠了多个运镜 | 删到只剩一个主运动；复合运动分段带秒数 | 提高分辨率 |
| 画面糊、细节丢失 | 提示词过载（要素太多） | 删到 30–100 词的核心；把次要元素移出本镜 | 加 `8k, ultra detailed` |
| 播放卡顿、有重复帧 | 模型没兑现帧率，用重复帧补时长 | 提示词正文写帧率；降低动作密度；换 `standard` 档 | 认为是播放器问题 |
| 短台词被填成胡说 | 台词时长不足或语速不匹配 | 缩短台词或延长镜头；台词前后留 0.3s 静默 | 让模型「即兴发挥」 |
| 闪光/频闪段落显得一跳一跳 | 逐拍光脉冲被渲染成停顿 | 把脉冲改成缓慢连续的光涌；仍不行就改常亮 | 提高帧率 |
| 画面塑料感、像游戏 CG | 没写写实锚点；参考图过度美颜 | 加 `no 3D, no cartoon, no VFX aesthetic — photorealistic textures, real skin pores`；换掉美颜参考图 | 只加 `cinematic` |
| 关键帧没给的东西被凭空发明 | 提示词要求首帧里不存在的元素 | 改提示词只描述首帧已有的；或补一张带该元素的首帧 | 在视频提示词里硬加 |

### 五档判决

| 判决 | 判据 | 动作 |
| --- | --- | --- |
| `keep` | 主缺陷不存在，次缺陷可接受 | 通过，进入下一镜 |
| `fix-in-post` | 缺陷在剪辑/调色/音轨层可解（亮度、裁切、节奏、音画偏移） | 不改提示词，进后期 |
| `edit` | 单点错误，其余 90% 可用 | 局部编辑：带秒点 + 保留清单 |
| `re-roll` | 提示词没问题，是随机抽样不佳 | 原样或微调后重抽（计入预算） |
| `rewrite` | 同一缺陷已出现两次，或结构性错误（时长/结构/参考矛盾） | 改结构再生成，不再抽卡 |

### 局部编辑句式（`edit` 判决专用）

```
Around the 2-second mark, [具体改动]。Keep everything else identical — same framing, same lighting,
same performance, same timing.
```

```
从 0:02 起，把左手从桌面移到膝上。其余保持不变：构图、光线、表演、节奏都不动。
```

### 重试阶梯（按顺序升级，不可跳级）

| 档 | 动作 | 触发条件 |
| --- | --- | --- |
| 1 | 改一个子句再重抽 | 首次失败 |
| 2 | 换一个参数/模式（分辨率、时长、模式） | 同缺陷第二次 |
| 2b | **到预算一半仍无进展 → 停手换策略** | 与档 3 并列，可先触发 |
| 3 | 拆镜 / 换参考 / 换首帧 | 参数改了仍复发 |
| 4 | rewrite（改结构）或换模型 | 同缺陷第三次，或模型能力边界 |

停损硬规则：

- 默认 **3 次付费尝试** 为上限；超过必须有明确的「这次改了什么」记录。
- 任何一镜 **10–15 次** 为绝对天花板，到此必须换方案（拆镜/换模型/放弃该镜）。
- 预算不是成功承诺，是强制换策略的触发器。

### shot log（每镜一行，缺一不可）

```
镜号 | 模型/档位 | 时长 | 判决 | 缺陷类别 | 改的变量（只一个） | 结果 | 备注
S03_005 | Seedance 2.0 std | 8s | re-roll | 手部崩坏 | 手改为握杯 | 通过 | 预算用 1/3
```

### 归层速查（先问这四个问题）

| 问题 | 是 → 处理 |
| --- | --- |
| 参考图/首帧里本来就有这问题？ | 换素材，提示词不动 |
| 提示词里有与参考矛盾的句子？ | 删那一句（这是最高性价比的修法） |
| 参数/模式不匹配（时长、画幅、分辨率、模式）？ | 改参数，不重写 |
| 模型能力边界（唱歌、长时间接触、多人同框）？ | 换方案：预录分段、拆镜、换模型 |

### 验收清单（交付前）

- [ ] 逐帧看过：无重复帧、无孤儿肢体、无多指
- [ ] 身份：3 个以上切点后脸仍是同一人
- [ ] 空间：门/窗/家具方位与上一镜一致
- [ ] 动作：每个动作都有可见的完成态
- [ ] 口型：台词与嘴形对得上，没有说话人串音
- [ ] 音频：对白清晰、无填充胡说、无串轨
- [ ] 画幅与分辨率符合交付平台（国内平台 720p 足够）
- [ ] 无穿模、无漂浮道具
- [ ] 首尾帧能接上相邻镜头

## 常见坑

- **症状：改了七八版都没好，越改越差。** 原因：每版都同时改了好几处，或根本没归层（问题在素材却在改提示词）。修法：回到归层四问，一次只改一个变量，并把 shot log 补齐。
- **症状：明明参考图是对的，成片却不是那个人。** 原因：提示词里的外貌描述与参考图矛盾（文字覆盖了图）。修法：先删掉与参考冲突的文字；只在 `start_image` / I2V 镜头下才能删掉全部外貌文本。
- **症状：按提示词加了 `no blur, no noise` 之后更糊。** 原因：否定词在该模型上无效甚至反向强化。修法：改写正向事实 `tack-sharp focus, clean gradients, low ISO`。
- **症状：一镜反复抽 20 次终于有一条能用，但下一镜又要重来。** 原因：没有可复用的锁与结构，全靠运气。修法：把这一条的成功要素（结构声明、身份块、光位）固化成模板再往下拍。
- **症状：动作控制完全不听话，提示词怎么写都没用。** 原因：失败在上游——参考片时长不足、角色图朝向不符、场景源设置错。修法：先修素材（补足 4s 源片、换正向角色图），再谈提示词。
- **症状：把「不够好」当缺陷去返修，结果预算烧光。** 原因：没有事先写「够好」标准。修法：开拍前写下主缺陷与可放过的次缺陷，验收只对主缺陷负责。
