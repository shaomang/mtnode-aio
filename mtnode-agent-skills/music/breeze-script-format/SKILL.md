# Breeze 台词规范

**本技能是应用内置技能**（随安装包发版，与 `minimax-music-*` 同一套内置标记，`/` 菜单可点名）。

输入：**单条台词 / 独白**（一次一个说话人）。多角色剧本不在本技能范围内——按角色拆开，一角色一批。
输出：可直接粘进节点的 **台词正文 + 语气 instruction + 分段说明**。
音色本身（「这是什么声音」）交给内置技能 `breeze-voice-design`，本技能不重写音色描述。

依据：
- [Breeze TTS 2 官方 README（模型卡）](https://hf-mirror.com/BreezeBlue/breeze-tts-2/raw/main/README.md) —— 内联发声事件写法（中文方括号 / 英文圆括号）、instruction 场景 `--cfg-scale 4`、instruction 语言与目标文本一致、24kHz 单声道、instruction 覆盖「tone, emotion, pace, and delivery」。
- 本仓库 `breeze-pack/app/server.py` 的 `prepare_request()` —— 模式判定与参数校验（参考音频与参考文稿必须成对、design 不接受参考音频、direction 必须有 instruction）。
- 本仓库 `guides/nodes/breeze_gen.md` —— 节点端子与参数（端口 0 文本 / 3 指令、能力、cfg_scale、seed）。

## 输出格式（硬口径）

三个小节，台词与指令各放一个代码块（整段可复制），说明放正文：

````
## 台词

```text
[叹气] 没想到过了这么久，你还记得我的声音。
```

## 语气 instruction

```text
语速偏慢，语气克制而带一点怀念，句尾轻收。
```

## 分段说明

单段，一次合成。
````

- 单段时「分段说明」写一句 `单段，一次合成。`；分段时按下面的分段清单一节一条列。
- 台词代码块里**只放要念出来的字**：不含角色名、不含镜头 / 情绪注释、不含 Markdown。
- instruction 代码块里**只放表演描述**：不放音色身份（那是 `breeze-voice-design` 的活），不放台词原文。
- 不要输出 JSON、不要加推导过程。用户问「为什么这么改」时才列改动点。
- 语言：instruction 跟台词语言（中文台词 → 中文 instruction，英文台词 → 英文）。中英混排台词按**主体语言**定 instruction，另一语言整段保留原样。

## 语气怎么「合法」地进台词

官方只有两条通道，别自创：

1. **全局 instruction**（端口 3 / API `instruction`）：整段共享的语气、情绪、语速、表演方式。**默认走这条**。
2. **内联发声事件**：只用于真正的非语言声音，直接写在台词里，官方示例：
   - 中文（方括号）：`[笑]` `[咳嗽]` `[清嗓子]` `[叹气]`
   - English（parentheses）：`(laugh)` `(cough)` `(clears throat)` `(sigh)`

官方只举了这 4 类（原话是 such as，未给完整白名单）。按用户口径，事件可以自由写，但守三条：

- 写**能发出的声音**（`[笑]` `[哭]` `[喘气]` `[咂嘴]` `[惊呼]`），不写**指令**（`[愤怒地]` `[小声]` `[渐弱]` 这种是表演要求，进 instruction）。
- 中文用方括号、英文用圆括号，**不要**混用；方括号内不加标点、不加冒号。
- 官方示例之外的事件属**未验证**写法：效果不稳时先退回官方 4 类 + instruction。

**不合法、必须改写掉的**（这些会被当字念出来）：`（低声）` `*冷笑*` `<小声>` `【停顿】`、旁白式说明 `（他顿了顿）`、Markdown 强调 `**强调**`、emoji。

## 口播安全化（逐条过）

| 类型 | 写成 | 例子 |
| --- | --- | --- |
| 阿拉伯数字 | 中文台词用汉字，按读法写 | `2026 年` → `二零二六年`；`3 个` → `三个` |
| 时间 / 日期 | 按口播顺序 | `10:30` → `十点三十分`；`2026-08-25` → `二零二六年八月二十五日` |
| 金额 / 百分比 | 补量词与读法 | `¥1,299` → `一千二百九十九块`；`37.5%` → `百分之三十七点五` |
| 单位 / 度量 | 写成读法或用中文单位 | `5km` → `五公里`；`2TB` → `两 TB`（字母逐读） |
| 英文缩写 | 逐字母读或换中文 | `GPU` → `G P U`；`API` → `A P I`；`AI` → `AI`（可直读） |
| 符号 | 换成词或删掉 | `&` → `和`；`@` → `艾特`；`/` → `或`；`~` 删 |
| 括号注释 | 删，或按需转成事件 / instruction | `（笑）` → `[笑]`；`（小声）` → 进 instruction |
| 重复标点 / 省略号 | 收敛 | `！！！` → `！`；`……` → `……`（保留一个） |
| 换行 | 不靠换行做停顿（模型对换行停顿未验证），改成句号 / 逗号 | 分行写的短句 → 合成一句带标点 |
| 生僻字 / 多音字 | 保留原字，必要时在同音歧义处改写措辞（不要用拼音注音） | —— |

标点就是呼吸：逗号短停、句号换气、破折号拖长、问号上扬。想要停顿就在那里加标点，不要加空格或空行。

## 改写边界

允许：口播安全化（上表）+ **适度口语化润色**（书面语转口语、补语气词、拆长句、调语序让重音落在该落的地方）。
不允许：改事实、改人称、加台词里没有的信息、删掉用户要保留的句子、把方言 / 口头禅「规范化」掉。

## 什么时候分段

两种情况才分段：

1. **情绪转折**：同一段台词里语气明显换挡（先压着说、后半爆发；或从叙述转成对白）。
2. **超长**：中文约 **80 字**、英文约 **60 词**以上（节奏建议，非官方硬限制）——一次合成太长时节奏与音色会漂，在自然句处切开。真正的硬上限在服务端：单次生成 `max_new_tokens = 1500`，codec 帧率 12.5 tokens/秒 ≈ **120 秒音频**；按中文字速约 4–5 字/秒算约 480–600 字，超了会被截断。

分段输出这样写：

````
## 台词

```text
第 1 段：[叹气] 我以为你早就不记得了。
第 2 段：可是你站在这里，我就什么都想起来了。
```

## 语气 instruction

```text
第 1 段：语速偏慢，声音压低，语气克制而疲惫。
第 2 段：语速稍快，情绪往上走，尾句带一点哽咽。
```

## 分段说明

两段，按顺序合成，段间留 0.5 秒静音后拼接；两段用同一音色与同一 seed。
````

分段纪律：
- 切开处必须是**句末**，不要切在词中间；每段各自标点完整。
- 每段 instruction 只写**该段的表演**，段间共享的音色不放进来。
- 段与段保持同一说话人：同一音色（design 用同一句音色提示词 / clone 用同一参考音频）、同一 `seed`，只有 instruction 变。
- 报告里说清段数与拼接方式（节点一次只出一个文件，多段要分别合成再拼）。

## 三种模式下的台词写法

| 模式 | 参考音频 | instruction | 台词侧要点 |
| --- | --- | --- | --- |
| 音色设计 | 无 | **必须**（音色 + 语气） | 台词只嵌事件；音色描述由 `breeze-voice-design` 给 |
| 音色克隆 | 有 + 参考文稿（成对） | **不写**（写了就变导演） | 台词只嵌事件；语气靠原文与标点 |
| 音色导演 | 有 + 参考文稿 | **必须**（只写表演） | 台词只嵌事件；不重复描述音色 |

节点「能力」选**自动判定**时的判定顺序：有参考音频且无 instruction → 克隆；有 instruction → 导演；无参考音频 → 设计。所以**给了参考音频却写了语气 instruction，就不再是克隆**——要克隆就把 instruction 留空。

## 参数

- `cfg_scale = 4`（instruction 场景官方建议值），`seed = 42` 用于复现。
- 输出 24kHz 单声道，一次运行一个文件。

## 常见坑

| 现象 / 报错 | 原因 | 怎么办 |
| --- | --- | --- |
| `ref_text_required` | 接了参考音频没给参考文稿 | 补参考文稿（音频节点先转录），两者必须成对 |
| `mode_conflict` | 选「音色设计」却接了参考音频 | 改「音色导演」，或清掉参考音频 / 音色 |
| `instruction_required` | 选「音色导演」但 instruction 空 | 补语气 instruction |
| 括号里的词被念出来 | 写了非事件类舞台指示 | 改成官方事件或并进 instruction |
| 情绪完全不跟随 | instruction 语言与台词不一致 / cfg 太低 | 统一语言；`cfg_scale` 设 4 |
| 长台词后半走音 | 单次文本过长 | 按上节切段、分别合成 |
| 结尾被切掉 | 超过服务端 `max_new_tokens=1500`（≈120 秒音频） | 先分段合成再拼接 |

## 示例

**中文 · 单段（设计模式）**

原台词：`（冷笑）你以为这就完了？我告诉你，这才刚开始。2026 年，我们走着瞧！`

````
## 台词

```text
[笑] 你以为这就完了？我告诉你，这才刚开始。二零二六年，我们走着瞧！
```

## 语气 instruction

```text
语速偏慢，声音压得低，语气冷静而带威胁感，句尾向下收。
```

## 分段说明

单段，一次合成。
````

**English · two segments (direction mode)**

原文：`(sigh) I thought you'd forgotten. But you're standing here... and suddenly it all comes back.` → 情绪从疲惫转成松动，切成两段，各给一条 instruction，参考音频与文稿保持同一套。

## 校验清单

- [ ] 三个小节齐全，台词与 instruction 各在代码块里
- [ ] 台词里只有要念出来的字：无角色名、无镜头注释、无 Markdown、无 emoji
- [ ] 所有舞台指示已转成合法事件或并进 instruction，没有会被念出来的括号说明
- [ ] 数字 / 日期 / 金额 / 单位 / 英文缩写 / 符号都按读法写过，标点收敛
- [ ] instruction 语言与台词一致，且只写表演（不重复音色身份、不抄台词）
- [ ] 分段只在情绪转折或超长时发生，切口在句末，各段标点完整
- [ ] 模式自洽：克隆模式 instruction 为空；设计模式无参考音频；导演模式两者都有
- [ ] 参数口径 `cfg_scale=4`、`seed=42`；分段时说明拼接方式与统一 seed

## 交付

1. 三个小节按上面的格式给全（`## 台词` / `## 语气 instruction` / `## 分段说明`）。
2. 改动多的台词，只在小节外补一句「改了哪些类」（如「数字改汉字、括号指示转成 [笑]」），不逐条解释。
3. 用户要音色描述 → 指向内置技能 `breeze-voice-design`，本技能不代写。
