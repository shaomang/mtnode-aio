# H3 动态静图（首尾帧）· 识图 → 归一化 → 建图 → 写词 → 验缝

**一句话**：一张静图 → **识图拆元素** → **底图归一化到目标分辨率** → 画布搭「底图 → 中文提示词 → H3 fl2va（首尾同帧）→ mp4」并连好线 → **跑完量首尾 PSNR 验接缝**。

实测口径（1280×704 / 124 帧 / 5.17s，RTX 4090 本地 H3）：

| 做法 | 首帧↔末帧 PSNR | 首帧↔中间帧 | 结论 |
| --- | --- | --- | --- |
| 底图 1080×717 直接喂（比例与输出不符） | **12.5 dB** | 12.6 dB | 全程推近+变亮，根本不是循环 |
| 底图先裁成 1280×704（比例一致） | **30.8 dB** | 15.7 dB | 接缝肉眼不可辨，中间真的在动 |
| 再加「曝光恒定 + 幅度极小 + 一个完整周期」（= 本技能口径，官方英文对齐句 + 中文正文） | **30.1 dB** | 20.8 dB | 亮度泵动消失（YAVG 104.6→105.2→104.9），只剩元素微动 |

第一行就是「图像没有动态照片感、也不是 loop」的根因：**H3 的 first_frame 是「拉伸」到画布、last_frame 是「按比例居中裁切」**（`comfy_extras/nodes_minimax_h3.py` 的 `_resize(..., "disabled")` 与 `_resize(..., "center")`）。同一张图喂两端时，比例不符 → 两端其实是**两张不同的图** → 模型只能从「拉伸版」走到「裁切版」，表现出来就是推近 / 构图变化 / 收不回原位。

本技能只做这一件事：**识图 + 归一化 + 建图 + 写词 + 验缝**。不管音乐 / 旁白。

## 0. 何时用 / 何时不用

用：用户说「把这张图做成动态壁纸 / 循环背景 / 让画面动起来但别变样 / 像背景图像引擎那样」；只有一张静图，希望水、烟、光、发丝、植物、车流动起来，主体与构图不变；目标是长时间挂机循环播放。

不用：要叙事推进（人物走位、镜头推进）→ 普通 FL2VA / I2VA，不追求循环；要照片复活（人物说话、表情大改）→ 主体位移大；要多参考图 → 走 R2V（`ref2va`，不能与首尾帧混用）；要静态图 → H3 只出视频。

## 1. 开工四步（顺序不能换）

1. **看图**：确认底图路径与原始像素尺寸（`ffprobe` 或让用户给）。
2. **识图**：按第 3 节跑一次视觉分析，产出「元素 → 运动」表。**不识图就写词 = 写不出针对性微动**，本技能的提示词必须来自这张表。
3. **归一化底图**：按第 2 节把底图裁成目标分辨率，得到一份新文件。
4. **建图 + 写词**：第 4、5 节。

## 2. 必做：底图归一化（这一步决定 loop 成不成立）

目标分辨率取 H3 比例档的 `auto` 24G 安全档（`h3/main-h3.js`）：

| 比例 | 分辨率 |
| --- | --- |
| 16:9 | 1280×704 |
| 9:16 | 704×1280 |
| 1:1 | 768×768 |
| 4:3 | 1024×768 |
| 3:4 | 768×1024 |
| 21:9 | 1280×544 |

用 ffmpeg 做「等比铺满 + 居中裁切」，与 H3 末帧的 `center` 口径完全一致：

```powershell
ffmpeg -y -i "<原图>" -vf "scale=1280:704:force_original_aspect_ratio=increase,crop=1280:704" "<项目>/assets/img/<name>_16x9.png"
```

- 产物路径写进 `input_image.imagePath`，**不要**直接把原图喂进去（除非原图尺寸正好等于目标分辨率）。
- 裁切会切掉一点边缘，交付时告诉用户「已按 16:9 居中裁切，如需保留全幅请换 4:3 / 1:1 档或指定留白」。
- **没有 ffmpeg 时**：退而求其次，选与底图宽高比最接近的比例档（如 1080×717 ≈ 1.51 → 4:3 或 16:9），并在交付里写明「比例不匹配，接缝会比标准口径差，建议先裁图」。**不要假装已经归一化。**

## 3. 识图：先搞清楚「什么该动、怎么动」

调 `mtnode_vision`（绝对路径），一次问全，问题模板：

```text
只描述这张图，不要发挥。用「元素表」回答：
1) 主体：几个人/物，各自位置（画面宽高百分比）、朝向、姿态、被遮挡关系；
2) 固定不动的：脸、五官、手、文字 logo、主体骨架姿态；
3) 可动的介质元素（逐个列）：发丝、衣料/裙摆、尾巴、水、雾、烟、光斑、屏幕/代码、植物、尘埃、反射……每个给：位置 + 运动方式（摆/流/闪/浮/扩）+ 幅度（极小/小/中）+ 周期（快/慢）；
4) 光源与曝光：主光方向、是否有整体亮度渐变的风险点；
5) 明确判定：这张图适合做动态壁纸吗？哪些元素动了最好看？
```

拿到结果后填成表，接着**逐条翻译成提示词句子**（第 5 节）：

| 元素 | 位置 | 运动 | 幅度 | 周期 | 写进提示词的句子 |
| --- | --- | --- | --- | --- | --- |
| 鬓角发丝 | 左上部 | 轻摆 | 极小 | 约 2 秒一个来回 | 「发梢以约两秒一个来回轻轻飘动，幅度不超过一根发丝宽，末尾回到原位」 |
| 鲸尾 | 右中部 | 小幅左右摆 | 5° | 全程 1 次 | 「鲸尾以极小角度左右摆动约五度后回到原位，不甩动」 |
| 背景代码 | 左右两侧 | 向下滚动一小段 | 小 | 全程 | 「代码文字缓慢下移一小段后回到起始排列」 |

规则：**只让介质动，不让骨架动**。脸、五官、手、主体位置、构图、透视一律锁死。每个元素必须写「回到原位 / 回到起始排列」。

画布里也能做识图：`input_image`（输出 0）→ `proc_text`（`agent: true`，接图像输入自动开视觉）。没有 `mtnode_vision` 工具时走这条路；两条都不可用时，按第 10 节降级并在交付里写明「本次未识图，提示词按通用介质写」。

## 4. 建图（一次 `mtnode_canvas_edit` 建完，`layout: true`）

先 `mtnode_canvas_get`（`detail: "standard"`）看现有节点；**能复用就复用**（已有图像输入 / 已有「Minimax H3」只补线与改参数），全局同一时刻只允许 1 个音视频任务。建图硬规则见技能 `mtnode-canvas-edit-rules`。

| # | kind | 建议标题 | 关键参数 |
| --- | --- | --- | --- |
| 1 | `input_image` | `底图 · 动态静图` | `imagePath` = **第 2 节归一化后的**绝对路径 |
| 2 | `input_text` | `H3 提示词 · 微动循环` | `text` = 第 5 节产出的**整段**提示词（对齐句 + 三字段，原样） |
| 3 | `video_gen` | `H3 动态静图（首尾帧）` | `videoMode: "fl2va"` · `duration: 5` · `outputRes: "auto"` · `attempts: 1` · `outputPath: "assets/video/h3-loop-<slug>.mp4"` |
| 4 | `control` | `▶ 一键重跑` | `ctrlAction: "run"`，**不要**建 `clear` |
| 5 | `save`（可选） | `保存动态壁纸` | 仅当用户明确要保存节点：`savePath` 同上，且 3 号的 `outputPath` 留空 |

**连线（端口号 = 面板端子号）**

| 从 | 到 | 说明 |
| --- | --- | --- |
| 1 底图（输出 0） | 3 输入 **2**（首帧 F） | 第一条 |
| 1 底图（输出 0） | 3 输入 **3**（末帧 L） | **同一输出接两条线** |
| 2 提示词（输出 0） | 3 输入 **1**（提示词） | 整段贴 |
| 4 control（输出 0） | 3 输入 **0**（控制） | 端口 0 只吃控制线 |
| 3（输出 0） | 5 `save` 输入 0 | 仅保存节点方案，此时 3 的 `outputPath` 必须留空 |

**参数要点**

- **首尾同帧**：`Picture 1` 与 `Picture 2` 是同一张（已归一化的）图，两条线同源；不要额外造尾帧。
- **比例**：编辑工具没有 `ratio` 字段，换比例让用户在 ⚙ 里改；比例必须与归一化分辨率一致。
- **时长**：壁纸一律 5 秒 = 124 帧 ≈ 5.17s（循环越短越容易闭合、越省显存）；对齐句写两位小数有效时长。
- **分段衔接：关**（开了会引入段间差异）。
- **输出路径与保存节点二选一**，两边都设 = 路径打架。
- **抽卡**：H3 每次只出 1 个文件；`attempts` 是「跑几次挑一条」。

## 5. 写提示词：官方骨架 + 中文正文

**骨架（不可翻译、不可改形态）**：对齐句是官方英文，三个字段名是 schema；**正文用中文写**（同为未归一化底图时中英两版接缝 12.53 / 12.54 dB、中间帧 12.60 / 12.81 dB，语言不是变量；归一化后中文正文实测 30.1 dB 闭合）。

```text
How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot 1) aligns with the <S.SS>-second mark of the target video.

integrated_multimodal_description: [Shot 1] <中文正文>

overall_soundscape: N/A

non_diegetic_music: N/A
```

- `S.SS` = 后端实际有效时长（两位小数）。换算真源 `h3/main-h3.js` 的 `calcLength(seconds)`：`round(seconds*24)` 再上取到 `17k+5`。

| 节点时长 | 帧数 | `S.SS` |
| --- | --- | --- |
| 5（推荐） | 124 | `5.17` |
| 6 | 141 | `5.88` |
| 10 | 243 | `10.13` |
| 15 | 362 | `15.08` |

- 字段名、顺序、`[Shot 1]` 标记、破折号照抄；不要自创 schema，不要逗号标签串。

**正文必须包含这 6 件事**（缺一件就翻车）：

1. **画面复述**：一句话说清风格 + 主体 + 关键物件 + 背景，确保身份 / 服装 / 颜色 / 空间关系不变。
2. **机位锁死**：「静态镜头，机位完全固定在三脚架上，焦距、透视、取景范围、主体大小与位置全程不变，不推近、不拉远、不平移、不摇移」。
3. **曝光锁死**：「整体曝光、白平衡与色彩饱和度全程恒定，画面亮度不随时间升高或降低」——这条实测能把亮度泵动从 `104.6→109.9→104.8` 压到 `104.7→105.1→104.9`。
4. **逐元素微动**：按第 3 节的表写，每个元素「运动方式 + 幅度 + 速度 + 回到原位」，幅度一律极小（发丝 = 一根发丝宽，尾巴 = 五度，光斑 = 轻微明灭）。
5. **不动的部分点名**：脸、五官、视线、双手、头部姿态、身体位置、服装形状。
6. **周期闭合句**：「5.17 秒的时长正好是这个微动循环的一个完整周期，最后一帧的姿态、位置、亮度与色彩回到第一帧的状态，首尾可以直接相接循环播放」。

**禁止**：切镜（`[Shot 2]`）、变焦 / 推拉 / 摇移、主体位移与转身、新物体入画、新文字 / 字幕 / logo、整体明暗渐变、写「逐渐靠近 / 到达 Picture 2」（同帧下会让前半段变静止）。

**元素 → 微动 词表**（挑 2–4 条，不要全上）

| 画面里有什么 | 可以动的（幅度小、可回位） |
| --- | --- |
| 人像 | 发丝轻摆、鬓发飘动、呼吸带动的肩胸起伏、衣料褶皱轻微形变、眼神微移 |
| 兽耳 / 尾巴 / 翅膀 | 极小角度摆动、毛尖轻颤，**不甩动、不展开** |
| 裙摆 / 披风 / 领带 | 下缘轻微起伏、褶皱位置基本不变 |
| 水面 / 雨地 | 涟漪扩散并消失、倒影伸缩、雨丝细密落下、高光游移 |
| 天空 / 云 / 雾 | 薄云平移一小段、雾气轻翻、光比缓慢流动 |
| 植物 | 叶片轻颤、枝条小幅摆动、花瓣微开合 |
| 城市夜景 | 霓虹湿地反光伸缩、井盖蒸汽升起变淡、红绿灯循环 |
| 屏幕 / 代码 / 赛博背景 | 代码下移一小段后回到起始排列、方块与光点不同相位轻闪 |
| 室内 | 窗帘被风轻推、尘埃在光柱里飘、烛火闪烁、热气升腾 |
| 静物 / 产品 | 高光沿边缘滑动、反光板明暗缓变 |

## 6. 范例（实测跑过的一条，可直接改）

```text
How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot 1) aligns with the 5.17-second mark of the target video.

integrated_multimodal_description: [Shot 1] 静态镜头，机位完全固定在三脚架上，焦距、透视、取景范围、主体在画面中的大小与位置在整个镜头内保持不变，不推近、不拉远、不平移、不摇移。画面是一张深蓝夜间赛博风格的动漫插画：一位蓝色长发的少女身穿深蓝女仆装，双手在胸前合十，身体略朝画面左侧，身后右侧伸出一条鲸尾；背景是布满代码文字、发光方块与光点的深蓝空间，头部后方有一枚金色星形光效。整体曝光、白平衡与色彩饱和度全程恒定，画面亮度不随时间升高或降低。所有运动都是极小幅度的循环微动，像被风扇轻轻吹动的静态壁纸：少女的发梢与鬓发以约两秒一个来回的节奏轻轻飘动，幅度不超过一根发丝的宽度，末尾回到起始位置；鲸尾以极小的角度缓慢左右摆动约五度，然后回到原位，不甩动、不伸展；女仆装的裙摆与围裙下缘轻微起伏，褶皱位置基本不变；背景中的代码文字以很慢的速度向下滚动一小段后回到起始排列，发光方块与光点以不同相位轻微明灭，明灭幅度很小，不产生整体亮度变化；金色星形光效只做极轻微的闪烁。少女的双手始终合十不分开，面部、五官、视线与头部姿态完全静止，身体不做位移，服装与饰品的形状和位置保持不变。5.17 秒的时长正好是这个微动循环的一个完整周期，最后一帧的姿态、位置、亮度与色彩回到第一帧的状态，首尾可以直接相接循环播放。

overall_soundscape: N/A

non_diegetic_music: N/A
```

**静音口径**：官方规则是「只有用户**显式**要求全程静音时 `overall_soundscape` 才能写 `N/A`」。壁纸类默认静音，交付时声明「本技能口径 = 本次需求显式要求全程静音，两段声音写 N/A」。用户要环境音时 `overall_soundscape` 写 1–4 句环境声，`non_diegetic_music` 仍可 `N/A`；**绝不要**为了配音效加动作。

- [ ] 文本节点首行是官方英文对齐句，正文是中文，三字段名与顺序正确。
- [ ] `videoMode = fl2va`、`duration = 5`、`outputPath` 与 `save` 不同时存在。
- [ ] 标题互不重名；没有多建第二套 H3 / 图像输入。
- [ ] 识图结论已体现为具体元素（不是「让画面动起来」这种空话）。

## 8. 出片后验缝（必须做，30 秒）

```powershell
ffmpeg -y -i "<成片>.mp4" -vf "select=eq(n\,0)"   -frames:v 1 f0.png
ffmpeg -y -i "<成片>.mp4" -vf "select=eq(n\,123)" -frames:v 1 f1.png
ffmpeg -hide_banner -nostats -i f0.png -i f1.png -lavfi psnr -f null -    # 看 average
ffmpeg -hide_banner -nostats -i f0.png -i f1.png -lavfi "[0:v]scale=160:88[a];[1:v]scale=160:88[b];[a][b]psnr" -f null -
```

- `psnr` 滤镜正常退出码是 1，**不是失败**。
- 第 3 条给的是首帧↔末帧接缝；第 4 条缩到 160×88 再算，用来区分「差异是细节还是整体位移」。
- 判定（本机实测标定）：

| 首尾 PSNR | 含义 | 动作 |
| --- | --- | --- |
| ≥ 30 dB | 接缝肉眼不可辨 | 交付 |
| 26–30 dB | 能看出一点点 | 可交付，或换 seed 再抽 |
| 20–26 dB | 接缝可见 | 先查底图是否归一化，再查提示词是否写了位移/渐变 |
| < 20 dB | 没循环 | 一定是底图比例不符，回第 2 节 |

- 中间帧对照：`select=eq(n\,62)`，首↔中 PSNR 在 **18–24 dB** 说明「真的在动」；>28 说明太静（可加一个介质元素）；<15 说明动过头（会像推镜头）。

## 9. 常见翻车与修法

| 症状 | 原因 | 修法 |
| --- | --- | --- |
| 全程缓慢推近 / 变亮，收不回原位 | **底图比例 ≠ 输出比例**（首帧拉伸、末帧裁切） | 回第 2 节把底图裁成目标分辨率，重跑 |
| 首尾帧接错成两张图 / 只接了一条线 | 端口 2 或 3 少一条 | 同一输出接两条线 |
| 点 ▶ 提示「未设置输出路径」 | 既没 `outputPath` 也没接 `save` | 二选一 |
| 提示词接进端口 0 | 控制端子当数据口 | 提示词走端口 1 |
| 前 2 秒不动、后段才动 | 写了「逐渐靠近 Picture 2」 | 删收敛语义，改「往返 + 回到起点」 |
| 亮度整体泵动 | 写了光比渐变 | 加「曝光 / 白平衡 / 饱和度恒定」 |
| 人物脸或手变形 | 幅度写太大 | 降幅度（极小 / 一根发丝宽），`attempts` 加到 4 挑一条 |
| 中间自己切了镜头 | 描述里出现两个阶段 | 只留一个 `[Shot 1]` |
| 出现字幕 / 水印 | 提示词提到文字 | 不提任何文字 |
| 生成被别的任务挡住 | 全局只允许 1 个音视频任务 | 等当前任务结束再点 ▶ |

## 10. 降级路径

- **没有 `mtnode_vision`**：用画布内 `input_image → proc_text(agent:true)` 识图。
- **没有画布工具**（节点内运行 / 只读会话）：**不要假装建了图**。只交付：① 识图结论表；② 提示词正文；③ 接线与参数清单（第 4 节两张表逐条列出端口、时长、比例、输出路径）；④ 归一化命令。
- **两条识图路都没有**：按通用介质写提示词，并在交付里写明「本次未识图，元素运动按通用口径」。

## 附录 A：确实需要更大变化时

只在用户明确要「画面要有明显变化」时用，且提前说明**接缝有风险**。

1. 用图像生成节点（`proc_image` / `flux3klein_gen`，本技能不绑定）造一张尾帧：`Same camera angle, same framing, same subjects, same lighting and color grading as the input image; only <要变的元素> changes by <幅度>; everything else stays identical, no new objects, no text, no style change.`
2. 首帧 = 归一化原图接端口 2，末帧 = 新图接端口 3，提示词按普通 FL2VA 写「首帧 → 中间变化 → 落到末帧」。
3. 回环用 **pingpong**（正放 + 倒放）在播放器 / 剪辑软件里做，画布内没有 pingpong 节点。
