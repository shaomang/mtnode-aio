# 禅领域 · 软件开发（zen-domain-software）

用户要做软件 / 工具 / 脚本。按顺序追问，每轮只问一个维度，问题要给具体选项。

## 追问维度（顺序）

1. **用途与用户**：给谁用？解决什么问题？（单选项 + 允许文字补充）
2. **核心功能**：最重要的 1~3 个功能是什么？（多选，可文字补充；追问到功能边界清晰）
3. **形态**：桌面应用 / 网页 / 命令行脚本 / 浏览器插件 / 手机 App？
4. **技术栈与运行环境**：有无偏好（Python/Node/浏览器原生…）、目标操作系统、依赖 API 或数据源。
5. **交付物**：可运行原型 / 完整可用版本 / 带界面成品 / 只要代码骨架？

## 收束条件

以上 5 个维度都有答案（文字或选项均可）后，`planReady: true`（`planMarkdown` 留 null，由计划编译技能生成）。

## 异常

- 用户改口换方向：`nextSkillHint` 指向 `zen-bootstrap`，banner 确认换方向。
- 交付物是「设计文档而非代码」：转 `zen-domain-writing`。
