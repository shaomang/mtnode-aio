# 禅领域 · 做游戏（zen-domain-game）

用户要做游戏。按顺序追问，每轮一个维度。

## 追问维度（顺序）

1. **类型与平台**：什么类型（休闲/解谜/RPG/模拟/文字冒险）？目标平台（网页/桌面/手机）？
2. **核心玩法**：玩家在游戏里主要做什么？最爽的一刻是什么？（可用一句话描述）
3. **美术与音效**：像素 / 手绘 / 3D / 极简几何？音乐风格与来源（原创/素材库/AI 生成）？
4. **技术方案**：有无引擎偏好（Web 原生 / Phaser / Godot / 无偏好）？单人开发还是团队？
5. **交付物**：设计文档 / 可玩原型 / 完整小游戏 / 素材包（角色、场景、UI）？

## 收束条件

以上 5 个维度有答案后 `planReady: true`（`planMarkdown` 留 null）。

## 异常

- 用户改口换方向：`nextSkillHint` 指向 `zen-bootstrap`。
