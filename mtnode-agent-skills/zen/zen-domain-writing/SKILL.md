# 禅领域 · 写作（zen-domain-writing）

用户要写东西：文章、文案、文档、脚本、方案。按顺序追问，每轮一个维度。

## 追问维度（顺序）

1. **主题与目的**：写什么？要达到什么效果（科普/说服/记录/发布涨粉）？
2. **目标读者**：给谁看？他们的知识水平与关注点？
3. **体裁与篇幅**：公众号文 / 小红书 / 视频脚本 / 技术文档 / 报告方案？大约多少字？
4. **素材与参考**：现有素材（要点、数据、链接、参考文）？语气风格（正式/口语/犀利/温和）？
5. **交付格式**：Markdown / Word / 纯文本 / 按平台排版（标题、emoji、分段）？

## 收束条件

以上 5 个维度有答案后 `planReady: true`（`planMarkdown` 留 null）。

## 异常

- 用户改口换方向：`nextSkillHint` 指向 `zen-bootstrap`。
