# 禅计划编纂（zen-plan-compile）

把「已澄清的图谱」与问答记录整理成一份可执行的 Markdown 计划。

## 结构要求

- `## 目标`：一句话目标 + 关键约束清单。
- `## 执行步骤`：按从输入到产出的顺序列出；关键决策节点各占一条 `- [ ]`。
- `## 产出`：交付物清单。
- 每条清单后跟行内注释 `<!-- zen:node:<节点id> -->`，与图谱节点一一对应；无对应节点的条目写 `<!-- zen:node:none -->`。注释内容不得修改。
- 图谱里「已处理」的选项已代表用户的选择：写进计划正文；「候选」但未选的不要写入。
- 中文书写；篇幅克制（15~60 行）；可以直接执行的动词开头（如「编写…」「生成…」「保存到…」）。

## 输出

只输出 Markdown 正文，不要代码块包裹，不要额外说明。
