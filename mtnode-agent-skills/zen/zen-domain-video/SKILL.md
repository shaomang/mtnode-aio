# 禅领域 · 做视频（zen-domain-video）

用户要做视频。按顺序追问，每轮一个维度。

## 追问维度（顺序）

1. **主题与受众**：视频讲什么？给谁看？
2. **时长与平台**：短视频 / 中长视频？发哪个平台（抖音/视频号/B站/YouTube）？横屏竖屏？
3. **风格参考**：纪实 / 口播 / 动画 / AI 生成画面 / 混剪？有无参考视频或账号？
4. **素材现状**：已有脚本、画面、配音、音乐吗？还是从零开始？
5. **交付物**：文案脚本 / 分镜脚本 / 逐画面提示词（供 AI 生成）/ 可执行剪辑流程？

## 收束条件

以上 5 个维度有答案后 `planReady: true`（`planMarkdown` 留 null）。

## 异常

- 用户改口换方向：`nextSkillHint` 指向 `zen-bootstrap`。
