# v1.5.4（2026-10-16）

会话右栏的浏览器实况画面恢复可用，连不上时可手动重连；Markdown 编辑不再吃掉换行，Tab 缩进不再回滚、输入时不再失焦

## 新增

* 自动压缩长会话新增「省钱」档：大约 100k token 就开始压缩（对话越长越省，更早的细节丢得多一些）
* 压缩时机新增「自定义」档：可以自己填一个触发线，从 100k 到 500k token 之间选
* 自定义触发线在设置、右侧助手栏和会话设置里都能填，改完对新开的会话生效

## 改进

* 会话输入区新增「压缩上下文」：同时添加手动压缩按钮（以前需要调用Skill /compact）
* 压缩完出现「查看压缩摘要」（多少条、约多少字、时间等）
* Markdown 编辑里的 Tab 键稳了：所见即所得档在光标处插 4 个空格，选中多行就每行行首各插一次
* 源码档（Markdown 原文）里 Tab 把当前行缩进 4 个空格，Shift+Tab 退一档；本行没有缩进时 Shift+Tab 照旧跳到下一个控件
* 行首缩进当成正文内容原样保存（切档、保存、重开都在），不再被清掉
* 有序列表的编号回到浏览器原生编号（`1.` / `2.` / `3.`，子层也从 `1.` 起），从 `3.` 开始的列表照旧接着数
* Markdown 编辑器不再在空块里自动把 `- ` / `1. ` / `# ` / `> ` 变成对应的块：敲进去什么就是什么，要换块类型请用工具栏按钮
* 顶栏下面那行小字精简到只剩「🐋 DeepSeek Harness Empowered」，版本号改到右下角显示（点一下还是原来的详情窗）
* 画布的面包屑（画布 / 任务 / 壳…）挪到画布左上角，不再和画布标签挤在同一行，层级再多也看得清；并向右让开一条缝，不再压住画布左上角的端子

## 修复

* 修复会话右栏「浏览器活动」的实况画面偶尔不可见的Bug（状态停在「未连接」，必须用真窗口打开才看得到内容）
* 修复内置浏览器画面偶尔卡在遮罩上不更新
* 修复在画布界面偶尔点不开左侧栏的Bug
* 修复 Markdown 编辑器打开后正文被自动重新排版、段落之间与行内的换行被吃掉的问题（现在没动过就绝不回写）
* 修复段落之间被合并成一段、段中行内换行丢失、行内代码里的多余空格被压掉 —— 保存与导出后正文与所见一致
* 修复嵌套列表被写平、任务清单勾选态丢失、段落与列表首尾相接处被粘成一行
* 修复标题被误判成引用块，以及表格里的换行被压掉
* 修复 Markdown 编辑器里按 Tab 加的缩进（或刚调过的序号）过一会儿又自己还原的Bug
* 修复 Markdown 编辑器输入时频繁失焦、光标突然跳走的Bug（改一个字就整块重画的老毛病）
* 修复 Markdown 编辑器里按回车光标不往下走、点正文某处光标却落在别处的Bug
* 修复点工具栏按钮时内容没插在光标处（插到末尾或上一行）的Bug
* 修复待办项保存后行首多出一个空格
* Markdown 编辑器工具栏去掉「水平线」与「任务清单」两颗按钮（分隔线敲 `---`、待办写 `- [ ]`，旧文档里已有的照旧显示与保存）

* 修复点右上角进入节点层后、原来的节点层被收回成折叠卡的Bug（现在进入不改变它的展开状态，返回上一层与进入前一致）
