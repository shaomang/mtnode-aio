# v1.5.4（2026-10-16）

会话右栏的浏览器实况画面恢复可用，连不上时可手动重连；Markdown 编辑不再吃掉换行，Tab 缩进不再回滚、输入时不再失焦

## 新增

* 自动压缩长会话
* 压缩时机新增「自定义」档：可以填一个触发线，范围 100k 到 500k token

## 改进

* 会话输入区新增「压缩上下文」：同时添加手动压缩按钮（以前需要调用Skill /compact）
* 压缩完出现「查看压缩摘要」（多少条、约多少字、时间等）
* Markdown 编辑里的 Tab 键修复
* 行首缩进当成正文内容原样保存（切档、保存、重开都在），不再被清掉
* 有序列表的编号回到浏览器原生编号
* Markdown 编辑器不再在空块里自动把 `- ` / `1. ` / `# ` / `> ` 变成对应的块
* 顶栏下面那行小字精简，版本号改到右下角显示
* 画布的面包屑（画布 / 任务 / 壳…）挪到画布左上角，不再和画布标签挤在同一行

## 修复

* 修复会话右栏「浏览器活动」的实况画面偶尔不可见的Bug
* 修复内置浏览器画面偶尔卡在遮罩上不更新
* 修复在画布界面偶尔点不开左侧栏的Bug
* 修复 Markdown 编辑器打开后正文被自动重新排版、段落之间与行内的换行被吃掉等问题
* 修复窗口最小化、被别的窗口整片盖住或不在前台时，任务完成音与提问/审批提示音要等切回窗口才响的问题（现在后台也会当场响，回到窗口不再补响）
* 修复节点层展开后，里面的节点偶尔拿不出来以及其他Bug
