# v1.7.8（2026-11-19）

更新改在后台装好、点一下「重启更新」就换上新版本，应用不用再等安装

## 新增

* 下载完的更新在后台装好，整个过程应用照常可用；顶栏显示「更新已就绪」，点「立即重启并更新」就换上并自动打开新版本
* 更新装到一半被关掉或崩掉，下次启动会自动把机器状态复原，仍用原来那一版，不会留下装了一半的应用
* 后台装不成（比如目标目录被占住）时自动退回原来的方式装一遍，不需要用户处理
* 助手写代码、改代码、重构、选依赖时，先找仓库里已有的做法，再考虑标准库与已装依赖，最后才写新代码
* 会话正在跑的时候再按发送，不再悄悄排到队尾：会先问你一句「加入发送队列」还是「⚡ 插话」，选中哪一项、要不要以后都按它来，都在这一张卡片里；想直接插话不看这一步，就在正文开头写 /btw，或者按 Alt+Enter
* 输入补全（FIM补全-开发中）：在输入框里停一下，光标后面就会浮出一段半透明的「接下来大概写什么」，按 Tab 采纳、按 Esc 丢掉、接着打字就自动收掉；画布底部状态栏最左那颗按钮开关它，也能在那里选服务商、模型和触发延迟

## 改进

* 应用要读写画布、调用 agent 时不再弹「应用请求画布与 agent 能力」那张首次授权确认：在「应用设置 → 应用能力」里勾上就是**永久允许**，取消勾选即当场收回，不再问第二遍
* 会话批注框里也能插图了：点批注卡上的「插图」贴一张截图或选一张本机图片，这张图会跟着那条批注一起发给模型（卡片上方会列出这几张图，点缩略图即跳回批注里对应的那一行）。批注里还在用的图不会被当成没人要的图清掉；删掉批注后剩下的多余图片，请在「工作目录占用与清理」里看过清单再清
