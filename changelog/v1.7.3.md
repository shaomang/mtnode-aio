# v1.7.3（2026-11-16）

设置 · 外观新增「亮色」主题：浅灰底 + 白卡片 + 深墨字，全站逐个面板校准过对比度

## 新增

* 设置 · 外观新增第四档主题「**亮色**」：浅灰画布、白色卡片、深墨正文，画布节点、输入框、浮层、会话与各个扩展面板都换了配色
* 亮色下输入框、下拉框、浮层、代码块与表格都改用「成对的底色 + 字色」，不会再出现白底白字、黑底黑字这类撞色；正文对比度一律在 4.5:1 以上，小号说明文字另按更严的一档校准
* DeepSeek 的引导海报多了一张亮色版：切到亮色时自动换成浅色那张，不会再在亮色浮层里突兀地出现一整块深色

## 改进

* 亮色主题换了一版新色卡：底色更中性、按钮与输入框的边框一眼可辨，小号标签文字加深一档，浅底上不再发虚
* 亮色主题的强调色从青绿换成更通用的蓝：选中项、链接、输入框焦点框、「运行中」标记一起换掉，浅底上不再发青、也不再有发棕的色块
* 画布底部「建造」面板在亮色下补齐了层次：每颗按钮都有白底与描边，组与组之间的分隔线加深，一排按钮不再糊成一片灰字
* 顶栏、状态栏与画布节点卡片在亮色下补了描边与投影，白卡压在浅灰画布上分得清边界
* 顶栏选中项（画布 / 会话 / 专家团 / 工具库…）改成深蓝底白字，浅色下也能一眼看出当前在哪一页
* 次要文字、占位文字、节点底部状态行统一加深一档，10px 小字不再发虚

## 注意

* 另外三档主题（MTNode / DSH / 终末地）的外观没有任何变化
