# v1.5.6（2026-10-19）

Breeze 语音能存「角色」了：选一个角色，参考音频、样本文字和语气一次带好

## 新增

* 「Breeze 语音生成」支持角色预设：一个角色 = 名字 + 一组或多组样本
  * 每组包含一段参考音频、与它逐字一致的样本文字，以及一句语气指令
* 在插件「Breeze TTS 2 本地 TTS」的控制台里新建和管理角色：上传参考音频、填写样本文字与指令，一个角色可以存多组（比如日常、激动、耳语）
* 节点上方菜单条新增「角色」按钮：打开选择窗，左边挑角色，右边每组都能直接播放波形试听，同时看到样本文字与指令，点「用这一组」即刻生效
* 选择角色的窗口里就能直接新建角色：填角色名、选一段本机参考音频、写样本文字与指令，存完立刻用到当前节点，不用再跑去插件控制台
* 选定角色后，节点上的参考音频与参考文稿两个端口自动隐藏，卡片上只留要念的文本
* 指令可以临时覆写：节点上或指令端口填了内容就盖过角色自带的那句，留空则用角色里的
* 「MCP 服务端」补上了真正的干活能力：外面的客户端（Claude Code、Cursor、自研 Agent）现在能让 MTNode **直接生成**图片、音乐、语音、视频，也能跑单个节点或整张图、调用画布上的工具节点、新开一条会话跑任务
  * 这类活要跑一阵子，所以一起手就回一个任务号，结果另取；「服务端」页能看到这次运行里有哪些活在跑、哪些成了、哪些失败
  * 生成的东西照旧落成你本机的文件，并自动收进素材库；想顺便摆到画布上也可以
* 新增「自用回环」开关（默认开）：让 MTNode 自己也能调自己——应用里的 Agent 从此可以自己出图、出声、跑图，不必你手动点
  * 它与外面接进来的客户端走同一条路、同一套令牌与审计；关掉只是撤掉这一条，不影响外部客户端
* 新增内置技能「去 AI 味与写作润色」（`/humanizer-zh`）：把中文文稿里的空话、重复和模板化表达改掉，同时保住事实、确定程度和你原本的语气
  * 只改表达问题，不替你加事实、数字、经历或结论，也不把「可能」写成「确定」
  * 给出 31 条常见毛病的检查线索，以及改文件时不动代码、链接、表格这类内容的规矩

## 改进

* Breeze 节点卡片更干净：文本框上的标题行与状态标签去掉，说明改成鼠标悬停才出现；插件卡片与插件控制台顶部那些多余的文字说明也一并去掉
* 「角色」小按钮的图标换成单人标志：一眼看出这里挑的是「一个人的声音」
* 控制台试听区改为按「角色 + 第几组」选择，不用再自己找参考音频；试听结果都能在波形播放器里回放
* 原来的音色库首次打开会自动整理成同名角色，已有音色一个不丢，原目录保留
