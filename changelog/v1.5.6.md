# v1.5.6（2026-10-19）

Breeze 语音插件功能增强：一站式创建角色，参考音频、样本文字等一次直出

## 新增

* 在插件「Breeze TTS 2 本地 TTS」的控制台里新建和管理角色：上传参考音频、填写样本文字与指令，一个角色可以存多组（比如日常、激动、耳语）
* 新增内置技能「去 AI 味与写作润色」（`/humanizer-zh`）：用于去除AI味的 Skill
* **工作流库**：把一颗节点层（连同它内部整棵子树）存成一个可复用的「工作流」，像调用函数一样插到别的画布上
  * 顶栏「工作流库」按钮：一条条列着存过的工作流，可以插入当前画布、改名、分享到创意工坊、删除
  * 节点层右键即可「保存到工作流库」；存的时候只留最新一份，同名再存会先问一句要不要覆盖
  * 插入的工作流是一颗完整的节点层，展开就能改内部节点，和手搭的没区别；它不是新节点类型
* **创意工坊新增「工作流」类别**：别人封装好的工作流可以下载进你的工作流库，卡片上直接列出它有哪几个输入、哪几个输出
  * 分享前会自动去掉只对作者本机有意义的设置（本机文件路径、工作目录、别的画布上的引用、密钥），保存路径改成相对路径
  * 分享要求这颗节点层外侧至少有一个输入和一个输出，缺了会被拦住并提示怎么接
  * 下载的工作流只进本机工作流库，不会自动打开画布，也不会插进你正在做的事
* **节点层可以加封面**：给一颗节点层上传一张图当封面，折叠时铺满整块卡片、展开时垫在舞台底下，节点层一眼就能认出来
  * 头部一排按钮里多一个封面按钮，右键菜单里也能添加、更换、清除
  * 建议用透明背景的图，不会被拉伸；展开态的浓淡可以调，默认 20%
* 新增内置技能「工作流设计」：让 Agent 帮你把需求做成一颗合规、能直接分享的节点层
* **素材库的单项可以直接复制成画布节点**：条目行上的「复制为节点」（或右键菜单）把一条文本 / 图像复制成画布上一个独立的文本节点或图像节点，内容内联进节点，之后在素材库里删掉它也不受影响

## 改进

* 创意工坊原来的「模板」改名叫「画布」，和新的「工作流」分开：画布是整张图，工作流是图里的一颗功能块
* Breeze 节点卡片更干净
* 素材库左侧的分类与素材可以拖动重排，分类也能整段拖进别的分类；按住 Ctrl / Shift 多选可整批移动，Ctrl+Z 撤销上一次重排
* 全局助手与「会话」用同一份对话：助手栏里问的、写的，会话列表里就是同一条会话，切过去能接着看、接着发
* 助手这一轮的内容边写边存：长回答写到一半关窗口或重启，已经写出来的部分不会丢

## 修复

* **跑 Remotion 视频时会被要求「改应用 / 插件文件再重启」**：渲染工程与成片以前都写在插件安装目录里，出错时还会把人指向应用自己的文件
  * 现在合成代码、渲染清单与成片一律落在画布工作目录下的 `.mtnode\remotion\<节点>\`，随项目走，工作流包也能带着走
  * 渲染需要的依赖由应用按绝对路径注入，工作目录里不再出现任何硬编码路径
  * 画布没设工作目录时直接提示先选目录，不再偷偷写进别处
  * 安装目录如果选到了应用目录内会被拦住，并告诉你换一个普通用户目录
  * 插件安装 / 自检失败的提示改成你自己能做的事（重选安装目录、重新安装或更新 MTNode、看控制台），不再要求改文件或重启

* **Remotion 视频节点接不进画面 / 语音 / 台词**：它的输入端子以前只有「控制 + 描述」两颗，第三条线开始就没地方接（Agent 读画布时也只看得到这两颗）
  * 描述改成写在节点里（节点正文本框 / ⚙ 设置，可留空），不再占一颗端子
  * 输入端子改成无差别端子：连一条多一条，视频 / 图片当主素材、音频当语音、文本当台词，控制线也接同一批端子（先接先占）
  * 描述里可以写 `@节点标题` 引用已接线的上游内容；描述留空时直接按接线走内置台词卡版面
  * 老画布上「端口 1 = 描述」的那条线，加载时自动搬进节点描述（写成 `@上游标题`），其余线号顺移一位
* 视频生成节点的首帧与末帧可以被同一张图同时接上（此前会误报「这两节点已连接」）
* 全局助手与「会话」两边内容对不上（在助手栏发的问题会话里看不到、跑起来的状态两边不同步、会话视图停在上一轮的画面上）
* 助手栏那一轮不再另算一路运行：运行队列与「全部停止」里只有它所属的那条会话，不再多出一个孤立的「助手」条目
* 在会话视图里看助手会话时，运行进度、停止与排队和助手栏完全一致，哪一边都能停
* 从外部连进来的人工智能体现在能新建「Breeze 语音」与「YuE2 音乐」节点（此前这两类节点只能在界面里右键新建，建不出来就只能删掉重建别的类型）
* 全局助手的文件写到应用默认目录，而不是当前画布的工作目录：现在在助手栏聊还是在会话列表里聊，都跟着画布走（项目根优先，其次画布工作目录，画布没设目录时才用默认目录）
* **MiniMax H3 点「ComfyUI 编辑界面」要等很久才进得去**：以前要等后端整个起好才打开浏览器（首次加载模型要几分钟，期间点完像没反应）；现在点一下立刻有反馈，后端在后台启动，起好自动把网页打开，进度写进管理窗的 Console，连点也只起一次
  * 工作流库里的「打开」也不再卡着等模板灌进编辑器：编辑器先出来，模板在后台载入，载入中会写一句状态
* **MiniMax H3 管理窗顶上那行字被按钮条盖住**：ComfyUI 地址（● ComfyUI :8188）挪到标题行，按钮条只留两个按钮，不再压住下面的文字
* **MiniMax H3 显存不够时点执行会卡死一小时没有进度**：现在提交任务前先看一次空闲显存，不够就直接告诉你还差多少、至少预留 20G，并说明显存不足时后端不会报错、只会一直没进度；你可以确认后仍然执行这一次
  * 不改动你的任何设置参数，也不替你关别的程序；照着提示先关掉占显存的程序再重跑即可
  * 超分 / 补帧这类后处理的门槛低一些（12G），这条链吃的是内存
  * 任务跑起来以后，生成十分钟没有任何进度、后处理二十分钟没有任何进度，都会自动中止并指出显存嫌疑，不再死等一小时
