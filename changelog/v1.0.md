# v1.0 及更早（概述）

v1.0 是 MTNode 的起步形态：把 AI 工作流收束到一张可视化画布上——摆节点、连线、填提示词，运行后拿到文本或图像结果。这一阶段没有留下逐版的用户向更新记录，这里只作概述；从 v1.0.25 开始每版一份文件。

## 当时已有的能力

- 画布：节点与连线、框选多选、撤销 / 重做、缩放与平移，工作流本地自动保存
- 输入节点：文本就地编辑，图像点击选择或直接拖入
- 处理节点：文本大模型与图像生成，提示词里用 @ 引用上游节点，带参考图自动走图生图
- 保存节点：输出为 YAML 文本或图像文件，支持自动保存
- 批量与拆分 / 合并：批量逐条运行或聚合合并，拆分抽取单项、合并汇成批次
- 动画节点：图像按行列切成帧序列并编码 GIF，支持透明色键
- 对话节点：气泡式聊天，对话记录随工作流保存
- 多服务商 API：统一配置服务商与模型，API Key 只存本机
