# v1.7.0（2026-11-11）

研究视图上线（测试中）：以课题为中心的知识图谱、文献库、术语页与一键演示

## 新增

* **研究视图（测试中，当前仅对指定测试账号显示）**：顶栏新增「研究」入口，打开的是以课题为中心的知识图谱，笔记、术语、论断、问题、文献与图示连在同一张图上
* **Markdown 笔记库**：所有内容都是纯 Markdown 文件，存在当前画布的工作目录里，可以直接用外部编辑器改、备份、带走
* 中间所见即所得地写，也能切到源码；正文里用 `[[笔记标题]]` 建关联，用 `> [!claim]`、`> [!note]`、`> [!question]` 区分论断、批注与待解决问题
* 框选任意内容就地加批注或问 AI，回答可一键落回笔记并进图谱；下方会话与这条画布绑定的会话是同一条
* **知识图谱**：力导向 / 分层 / 径向三种排布，可一键换成时间线；搜索高亮、按验证态筛选、聚焦 N 跳邻域、两点之间找最短关系路径
* 论断带已验证 / 存疑 / 未验证三态并用颜色区分，找不到笔记的链接标成悬空；改一段文字只增量更新，不必整图重排
* **文献库**：粘贴或导入 BibTeX、按 DOI 添加、按标题在线检索后加入，也能把本地 PDF 全文抽进库，正文用 `[@引用键]` 引用并连到图上
* **初始化资料库**：一块界面收完课题、核心问题、核心文件与参考资料，两栏都能放文件、链接、笔记或一句检索式，每条还能写一句交代
* 点「开始处理」才建目录：文件复制进 `research/`（原件不动）并转成正文，参考资料做全文 / 关键原句 / 主题三层折叠
* 每条单独标出待抓取 / 已转 / 仅摘要 / 失败，失败的能单条重试，处理中还能继续往里加料
* agent 自动开一条专用会话逐篇处理，把关键内容标进正文并连成关系；之后「补充处理」只跑新投的那批，处理过的一律跳过
* **三遍读法拆变体**：略读（贡献 / 证据 / 局限）、关键概念、技术细节三份独立文件，可并排对照；中译 / 英译照旧，摘要与节选退场
* 每节都能切「一句话 / 一段话 / 原文」，可跟随全篇或单节钉住，选完当场存盘；缺哪一档会明说并退回原文
* **术语页**：按原文自动归纳第一层（一句话定义 / 直觉 / 公式 / 符号表 / 在原文里 / 还能引申），点「引申」才往下长，长出来的同时进图谱
* **演示**：把课题、主稿与三遍读法一键排成封面到大纲到正文到精读到术语到公式到文献到结语，六套主题与转场随页切换，可导出单文件 HTML 或打印成讲义
* 演示的讲稿能交给 Agent 一轮一轮改：整份或单页、每轮先说一句想怎么改、改了哪几页会报、改坏了能撤销

## 改进

* 改过的版本只留「变体一致化」：按改动最多的那一版重写同组其它版本，撤掉「还原到修改之前」
* 正文里的双链点击先弹浮空卡（指向的那一页 + 写过它的笔记 + 可新建一条），不再直接跳页
* 参考文献整行可点：本地已有全文直接打开，没有就交给 agent 检索、下载并入库
* 默认不再自己联网检索与下载全文，缺文献时给一条检索式建议由你决定
* 初始化只生成课题那一篇笔记，不再预置带示例文字的骨架；删掉 `research/` 就等于清空重来
* 左栏一篇稿只占一行，变体作为标签展开；文献改到顶栏浮层，左栏可以收起
