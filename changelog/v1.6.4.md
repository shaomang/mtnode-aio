# v1.6.4

## 会话的名字不会在重启后又变回「新会话」

以前给一条会话改好名字、或者等它自己按内容起好名，重启一次又变回「新会话」。现在不会了：

- 改过的名字、系统按内容起的名字，都会当场写进这条会话自己的存档里，重启、换窗口都还在
- 之前已经变回「新会话」的那些，只要左栏里还是真名，重启后会被自动纠正并记住

## 快捷会话小窗能发截图了

以前在小窗里按 Ctrl+V 粘一张截图，什么都没发生——它只认文字。现在和主窗口的输入框一样了：

- 截图粘进去就是一张真图：光标处出现一行图，输入框上方同时冒出缩略图胶囊，一枚对一张图，点胶囊跳到正文那一行、点 ✕ 删掉这张图
- 图跟着这一句话一起发出去，模型是真的「看见」了这张图，不是只收到一串路径
- 发出去之后，「你的指令」那一格里显示的是缩略图而不是文件路径；点缩略图用系统看图程序打开原图
- 图存在这条会话的项目文件夹里（没设文件夹就落在数据目录），换机器、换会话都不会指向不存在的文件

粘文字、粘文件照旧不受影响；连着粘几张也行，没有张数限制。

## 快捷会话左栏：文件夹能折起来，也能就地新建会话

会话多了，左栏一串文件夹铺得老长。现在每个文件夹标题前都有一个 ▾：

- 点标题就把这一组折起来（变成 ▸），列表一下子短下来，别的文件夹一眼就够得着；再点一下展开
- 折起来的样子会记住：关掉小窗、重启应用，还是按上次那样折着
- 鼠标移到某个文件夹上，标题右边会冒出一枚小 ＋，点它就在这个文件夹里新建一条会话 —— 不用先切到那条会话再新建，新会话会选中并自动展开这一组
- 没有设项目文件夹的那些会话排在最末一组，可以折，但不给 ＋（免得又造出一条没目录的会话）
- 正在看的会话就算在一个折起来的组里也不会自己弹开，折着就是你折的

## 助手栏可以换个进程来画了（实验档，默认关）

会话流、活动流和文件树是三块「一直有新内容进来」的界面。模型一边吐字，它们一边重画，
画布偶尔就跟着发涩。这一版给了它们一条新出路：

- 打开这个实验档之后，这三块交给一只独立的界面进程去画，主窗口这一侧不再重复绘制 ——
  长回答一边滚，画布和节点照样拖得动，单次最长卡顿明显缩短
- 会话记录、活动日志、文件树都照旧保存与刷新，只是「画」的地方换了，内容一份不少
- 关掉就完全回到原来的样子；那只进程自己出问题时也不会把窗口带崩，主窗口会立刻接手重画，
  界面不会空着
- 默认是关的，这一版也还没有开关界面：切换要手动改配置并重启应用 ——
  不做任何事的人完全不受影响

## 左下角多了一条 DeepSeek 侧栏

想顺口问一句、又不想切走画布的时候，现在从画布左下角就能把 DeepSeek 拉出来：

- 点左下角那枚入口开合，也可以直接按键盘上的 ` 键开关；侧栏宽度能拖着调，双击回到默认宽度
- 开着的样子、宽度和上次聊到哪儿都会记住，重启应用、切换画布都还是原样
- 登录一次就记住了，不必每次重开都重新登录；窗口最小化或被别的窗口盖住时，回答也照旧继续往下走

## 研究视图：改用「三遍读法」拆变体，摘要与节选退场

以前给一篇原文拆变体，能选的是「中译 / 英译 / 摘要 / 节选」。摘要和节选读起来是同一件事的两种缩法，用处却不清楚。现在换成按**三遍读法**拆：

- **略读**：这篇的贡献、证据、局限，一屏读完（200–320 字）
- **关键概念**：3–6 个概念，每个一句人话；原文里已有的图直接引过来，不够才补一张小示意图
- **技术细节**：方法步骤、公式原样照抄、实验设置与关键数字 —— 只写原文真有的

三份是**三个独立文件**，可以并排对照看；中译 / 英译照旧在。盘上已经生成过的摘要 / 节选稿不会被删，只是不再新写这两种。

## 研究视图：每节都能切「一句话 / 一段话 / 原文」

同一篇参考资料的正文，不同的时候想看的粗细不一样：查资料要原文，回顾要一段话，扫一眼只要一句话。现在在折叠视图里：

- 工具条上多一组「一句话 / 一段话 / 原文」，先给全篇定一个默认档
- 哪一节想单独看细一点（或粗一点），用那一节右上角的下拉钉住它；选「跟随全篇」放回去
- 切档是先收起再放开的动画，和你熟悉的折叠手感一致；选完当场存盘，下次打开还是你选的那档
- 某一节还没有这一档的稿子时，卡片上会写明「缺这一档，显示原文」，不会给你一张空卡
- 这套粗细和原来那三层折叠（全文 / 关键原句 / 主题）互不干扰，各切各的

## 研究视图：术语页 —— 让「看不懂的词」自己长出下一页

读完一篇，真正卡住人的往往不是结论，而是中间那几个词和公式。现在初始化时会**按原文自动归纳第一层术语页**：

- 每页是一个独立笔记，放在左栏新的「术语页」分组里，`terms/` 下，全库一个术语一页
- 一页的结构固定：一句话定义（鼠标停上去就能看）→ **直觉**（一句人话，讲清它在干嘛）→ 公式 / 记号 → 符号表 → 在原文里（哪一节讲的）→ 还能引申
- 打开术语页，工具条上多一颗「引申」：它列出这一页还能往下讲的术语或公式，每个带一句理由；你勾选后点「生成这一层」，才去写那些新页
- 新页会连回这一页，也连回它来源的原文 —— 所以术语能一层层往下长，长出来的东西同时进图谱（术语、符号、定理、数据集各有自己的颜色）
- 第一层之后**不会自动扩散**：递归要看你的意思，不替你烧 Token
- 已经初始化过的老库，打开投料台点「补跑一层」就能把术语页、三遍读法的三份变体、每节的三档补齐


## 研究视图：左栏的子项换成了「这一篇有哪几稿」

以前点开一篇文档，展开的是一串章节标题，和右边正文的目录重复。现在展开看到的是它的其它版本：

- 只列盘上真有稿子的那几种，一行一个标签：中译 / 英译 / 略读 / 关键概念 / 技术细节，不再写章节
- 点标签就直接打开那一稿；正在读的那一稿会高亮
- 原文行和衍生稿行下面都能展开各自的版本
- 章节没有消失，只是挪到了阅读时的正文目录里
- 左栏搜索现在也认这些标签：搜「略读」能找到有略读稿的那几篇

## 研究视图：点引用能直接写一条笔记

正文里的 `[@引用键]` 以前点了没反应。现在点一下会弹出这一处引用的卡片：

- 卡片列出与**这一处**真正对应的笔记 —— 靠引用键 + 所在笔记 + 行号认人，不会把同一个人名下、同一篇文章别处的引用混进来
- 卡片底部有「写一条笔记」：点一下就在 `notes/cites/` 落一篇只有骨架的新笔记（`> [!cite] @引用键` 加一行「来源：笔记:行号」），并立刻打开给你接着写
- 骨架不调用模型、不花 Token，也没有替你写好节选或链接 —— 要指到某个人物就自己写 `[[人物]]`
- 同一处再建一次不会覆盖原来那篇，会退成 -2、-3
- 这些引用笔记和普通笔记一样能打开、能被 `[[标题]]` 指到，重启后照样在

## 研究视图：术语说明里的 Markdown 和公式能正常显示了

鼠标停在术语上弹出的说明卡，以前把 `**粗体**`、列表、`$公式$` 当纯文字照抄出来。现在整段按 Markdown 排版：

- 粗体、列表、行内代码、引用、表格都按排版显示
- 公式和正文里一样用同一套排版渲染出来，不再是带美元符号的源码
- 点术语打开的那张大卡同样按排版显示


## 研究视图：左栏不再把同一篇稿重复列出

同一篇论文的原文和中译 / 略读 / 关键概念以前在「原文」分组里各占一行，每行下面又把另外几份列一遍，同一篇稿子能在左栏里出现四遍。现在：

- 一篇稿在分组里只占一行，显示的就是它的标题
- 中译 / 略读 / 关键概念只作为它下面的变体行出现，一行一个标签
- 「原文」分组右上的数字也按行算（一篇原文就是 1，不再把几份变体数进去）
- 分组里不再出现的那些稿子照样能搜到：搜它们的标题或正文，那一行仍会留下


## 研究视图：改过的版本只留「一致化」，点双链先弹卡

同一篇原文的几份变体里，你改过的那一版以前多一颗「还原到修改之前」—— 一不留神点下去，自己写的东西就退回去了。现在：

- 「还原到修改之前」撤了：金色那版上的 ↺ 与左栏右键里那一条都不再有，你的改动不会被悄悄退回
- 版本对不上时只剩一条路 —— **变体一致化**：它自己挑出**你改得最多的那一版**当基准，把同组其它版本按它重写（同组里别的也被改过的版本一起重写），跑完这一组就一致了
- 它照旧会调用模型、逐条串行跑，攒到一段修改做完再点一次更划算

正文里的 `[[双链]]` 以前点一下就直接跳走。现在和点术语一样先弹浮空卡：

- 卡片第一行是这条链接指向的那一页，点它才进整篇（淡青底，标着「这一页」）
- 下面列出库里写过它的笔记，一篇一张卡，点卡片跳到那一行
- 一条都对不上时卡片会说明，底下那颗「新建一条笔记」先让模型给几个角度的候选，你勾选后再写成一篇
- 一条链接对得上好几份内容时，也在这张卡里一次看全，不用先进去再退出来找


## 研究视图：核心原文与三遍读法能一键排成一份演示

课题、主稿和它的略读 / 关键概念 / 技术细节，以前只能一篇篇翻。现在顶栏「演示」那颗图标（或左栏原文行、变体行右键「生成演示…」）把这一摞稿子排成可以直接讲的页：

- 封面、大纲、正文、精读、术语、公式、文献、结语一路排下去，每页都能点回它出自哪一份稿子
- 放映时方向键 / 空格翻页、点左右半屏翻页，工具条上随手换主题（六套，各带明暗两档）与转场
- 想细改就进专属编辑器：左边排页、显隐、新增删除，中间改这一页的文字与版式并同屏看预览，右边换配色
- 改完可以导出成一份单文件 HTML，双击就能放，也能直接打印成讲义；要更口语的讲稿，可以让模型整份或单页重写（会花 Token，点了先确认）


## 研究视图：演示的讲稿可以交给 Agent 一轮一轮改，改坏了能退回去

演示刚出来时，模型重写只当一次性交付：改得不合意，只能自己再一句句敲回去。现在这条路能来回走了：

- 三个入口都通：顶栏「演示」菜单里的「让 Agent 重写整份 / 这一页…」、编辑器顶栏的「让 Agent 重写整份」、以及编辑器左栏页列表每行那颗「A」（只改这一页）
- 派活前先收一句「这次想怎么改」（可留空，留空就按受众与这一页本身该改的改）；第一次会写明「会消耗 Token」，点过一次之后同一份演示的后面每一轮都不再拦
- 派出去的是一条叫「重写演示」的会话：它只改讲稿文案，只按你这一轮点名的那几页改 —— 没提到的页（连同上面的手改）保持原样；页 id 原样照抄，不新增数字、结论与引文
- 页结构不归它管：新增页、删页、换页序、显隐照旧是你自己的事，模型碰不到
- 一轮改完就停手：状态行报「第几轮已合入、正在等第几轮写出」，下一轮换一句「想怎么改」再来，同一个文件再写一次就行
- 等久了不硬判失败：四分钟还没写出会问「继续等 / 放弃」—— 继续就再续一整个窗口，放弃就收工，去左栏那条「重写演示」会话看它卡在哪
- 交回来的稿子不能用（不是合法 JSON、里面没有页、页 id 一个都对不上）会自动在同一条会话里回它一句让它重写，只多给一次机会；这一版仍不合用就继续等下一版，不用你重新点一遍
- 改坏了能退：每次模型改写覆盖之前都先把当时那份稿子存一份，编辑器顶栏「撤销这次模型改写」一下退回最近这一次改写之前；快照最多留五份，再早的自动清掉
