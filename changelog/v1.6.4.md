# v1.6.4（2026-11-07）

按 Ctrl+Alt+A 框一块屏、标两笔，粘进对话就是「图 + 清单」

## 新增

* **截图标注**：`Ctrl+Alt+A` 冻住鼠标所在那块屏，拖框或点选窗口，矩形框住要改的地方、松手就地写字，编号与图上红点一一对应
* 点「完成并复制」把成品图与「编号 → 坐标 → 文字」清单一起写进剪贴板，粘到对话里模型就看到图和每一条备注；也可另存为图片
* Agent 也能反过来请你截图：它会先问一句，你点头后走同一套界面，标完图和备注直接回到这次会话
* **快捷会话小窗能发截图了**：粘进来就是一张真图，带缩略图胶囊、跟着这句话一起发出去；左栏的文件夹可折叠（折起的样子记住），组标题旁的 ＋ 就地在该文件夹里新建会话
* **设置新增「内置能力」**：所有注入给模型的指示与内置技能都能自行改写、与默认比差异、恢复默认；作者账号还能把满意的改动写回源码

## 修复

* **会话的名字不会在重启后又变回「新会话」**：改过的名字与系统按内容起的名字都会当场存进这条会话自己的存档
