# v1.6.3

## 研究视图（测试中）

顶栏多了一个「研究」入口（当前仅对指定测试账号显示）。它打开的不是画布，而是一张以你的课题为中心的知识图谱：笔记、术语、论断、问题、文献与图示都在同一张图上，靠关系连起来。

- **左边是 Markdown 笔记库**：所有内容都是纯 Markdown 文件，存在当前画布的工作目录里，可以直接用外部编辑器打开、备份、带走。
- **中间默认是一篇笔记**：所见即所得地写，也能切到源码。正文里用 `[[笔记标题]]` 建立关联，用 `> [!claim]`、`> [!note]`、`> [!question]` 这类段落区分论断、批注与待解决问题；图谱就是按这些关系生成的。
- **框选任意内容就地提问**：选中一句话或一个公式，浮出的工具条可以加批注、问 AI、把它改成一条论断。回答可以一键落回笔记并进入图谱。
- **下方是会话框**：和当前画布绑定的那条会话是同一条，在「研究」里问的、在「会话」里问的都接着同一段上下文。

## 知识图谱

- 力导向、分层、径向三种排布，可一键换成按日期排的时间线。
- 搜索高亮、按验证态筛选、聚焦某个节点的 N 跳邻域、两个节点之间找最短关系路径，以及「适应窗口」。
- 论断带三态：已验证 / 存疑 / 未验证，图上用颜色区分；找不到对应笔记的链接会标成悬空，方便回头补。
- 图谱随保存增量更新，改一段文字不需要整图重排。

## 文献库

- 支持 BibTeX（粘贴或选 `.bib` 文件）、按 DOI 添加、按标题在线检索后加入。
- 可以把本地 PDF 的全文抽进文献库，正文里用 `[@引用键]` 引用，图上会连到对应文献。
- 文献库、笔记与图谱都放在当前画布的 `research/` 目录下，一份画布一份研究资料。

## 研究初始化（投料 → 自动处理）

第一次进「研究」不再直接开一张空目录，而是先问清楚要研究什么、手里有什么。整块画布就是投料台，课题、核心文件、参考资料一次看全：

- **一块界面装完三件事**：最上面填课题名与核心问题，下面左右两栏——左边核心文件、右边参考资料，中间的竖条可以拖动改宽窄，比例会记住。不再弹小窗、也不用一步一步点。
- **两栏都能放文件，也能放「不是文件」的东西**：贴一条 arXiv / DOI / 网页链接、写一段自己的笔记、或直接给一句检索式，agent 会自己去取内容、去找文献；每条还能写一句交代（例如「重点看第 4 节」），它会照着做。
- **一次粘好几行不会乱**：多行内容先给一张预览，每行都能改成链接 / 笔记 / 检索式、也能换投到哪一栏，删掉不要的再确认加入。
- **点「开始处理」才建目录**：文件复制进 `research/`（原文件不动），核心文件转成正文，参考资料转成正文并做**三层折叠**——全文 / 关键原句 / 主题。第 1 层可编辑，后两层是只读投影。链接与检索式这类先落一份带标题、来源和你的交代的空正文，等 agent 抓到内容再补进去。
- **进度就显示在同一块界面上**：每条单独标出待抓取 / 已转 md / 仅摘要（存疑）/ 失败；抓不到全文的会自动退到文献元数据加摘要并标成存疑，真正取不到才算失败，可以单独重试；检索式自动带回来的文献不合适的可以一键剔除。处理过程中还能继续往里加东西，新加的照常排队，已在跑的照旧。
- **agent 自动接手**：开一条专用会话逐篇处理；处理完把关键内容标进正文，并把它们与课题、其他资料连成关系。之后再要补料，「＋ 添加资料」打开的还是这块界面，老条目只读留着，新条目接着排。
- **左侧栏可以直接看 `research/` 目录**：进入研究视图时自动定位到研究目录，离开回到你原来的位置。
- **初始化只生成课题那一篇笔记**：不再预置「术语 / 论断 / 文献笔记」这几篇带示例文字的骨架，你自己的研究目录里不会混进示例内容；需要哪篇就自己新建哪篇。
- **删掉 `research/` 就等于清空重来**：下次进「研究」直接回到初始化引导，重新投一次料就从一份干净目录开始，不会按上一轮的残留继续补料。
- **处理完的东西在主视图里看得见**：处理过的条目在笔记与文献列表里带「✓ 已处理」标记，顶栏进度变成「初始化完成 · N 篇已处理」，点开是一份只读清单——处理完就不必再打开投料台去回忆。

## 研究视图的这批修正

- **流程图按钮**：工具条的「Pele」改成「流程图」，点一下就在光标处插入一张改文字就能改的流程图代码块，正文里直接画出来；以前点了没反应、插进去的图一保存就散成文字，一并修好了。
- **正文分「阅读」和「编辑」两态**：默认看渲染后的 Markdown（图、公式、引用都画好），点「编辑」变回源码，左边写、右边实时预览，点「完成」回到阅读态。写文件只认源码，排版层不会再改坏文件。
- **图谱一点就开，也快了**：图谱页现在点开就有图（笔记多的课题首屏布局按规模降了计算量，不再卡住），点节点能跳回原文。
- **左栏更干净**：笔记栏里那排「笔记 / 文献」页签去掉了；文献改成顶栏「文献」按钮打开的一块浮层（导入 BibTeX / 按 DOI / 检索 / PDF 入库 / 插入引用都在），只有窗内 ✕ 或 Esc 才关。
- **左栏可以收起**：顶栏最左多了一颗小箭头，一点收起左边的文件栏，再点展开，状态会记住。

## 快捷会话小窗

- 左下角多了一颗 ✦：点开是一只独立的小窗，随手给会话下发指令，不用再切回主窗口
- 窗里只显示这条会话的最后一次回复，思考过程、工具调用与历史记录都不占地方
- 回复按 **Markdown 排版**显示：标题、列表、代码块、表格与公式都跟主窗口一致，不再是一坨原文；正文里的链接点开交给系统浏览器，不会把小窗带走
- 左边的会话列表默认收起，点 ☰ 展开，按**项目文件夹分组**（组标题写着文件夹名与条数，鼠标停上去看完整路径），组内按最近使用排序，点一条就切过去
- 窗里可以直接新建会话：新会话接着你当前选中的那条，用**同一个项目文件夹、同一张画布**
- 正在跑、排队中都标在会话名旁，跑着的时候可以在窗内一键停掉
- 「已下发」等提示改成浮在输入框上方的小条，出现与消失都不再顶动输入框
- 自己刚下发的那句排在消息结尾（AI 回复下方、紧贴输入框），带一行「你的指令」小字，发完立刻能看见，不用再往上翻
- 点 ↗ 把这条会话搬回主窗口，小窗随即关闭
- 按 F1 在任何地方都能把这只小窗叫到鼠标旁；Esc 或 ✕ 关闭，窗口大小与位置下次还记得
- 语音听写的按键从 F1 改为 F3，避免和这只小窗抢键
