# v1.5.0（2026-10-06）

浏览器智能体、评论、发布与语音输入

## 重大更新

* 新增 Agent 浏览器：智能体可在内置浏览器里打开网页并操作
* 新增应用上架与 MCP 服务端（外部工具可接进来操作 MTNode）
* 新增讨论区评论、顶栏消息、打赏与鲸圆币（透传中转官方Deepseek和GPT-Image-2.5）
* 新增全局语音输入：状态栏话筒说话即转文字，本地模型 SenseVoice 识别
* 新增会话轨迹

## 新增

* 文本节点新增 Markdown 编辑器，可批注并让 AI 逐轮修订
* 新增长时自治：会话可自动续跑并分阶段自检

## 改进

* 思考过程与图像生成入口的文案更清楚
* 「局部批注」改成一步到位：框选正文后按钮亮起，点它即可为这段写批注；没框选时按钮为灰
* 局部批注的输入框改用与界面一致的深色配色，并且不再显示选中原文

## 修复

* 修复局部批注框选后没反应、批注加不上的问题
