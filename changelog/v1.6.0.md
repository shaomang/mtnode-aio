# v1.6.0（2026-10-22）

助手会话固定在自己那张画布上，切画布不再跟着跑

## 重大更新

* **工作流库**：把一颗节点层存成一个可复用的「工作流」，像调用函数一样插到别的画布上
  * 顶栏「工作流库」按钮：一条条列着存过的工作流，可以插入当前画布、改名、分享到创意工坊、删除
  * 节点层右键即可「保存到工作流库」；存的时候只留最新一份，同名再存会先问一句要不要覆盖
  * 插入的工作流是一颗完整的节点层，展开就能改内部节点，和手搭的没区别；它不是新节点类型
* **创意工坊新增「工作流」类别**：别人封装好的工作流可以下载进你的工作流库，卡片上直接列出它有哪几个输入、哪几个输出
  * 分享前会自动去掉只对作者本机有意义的设置（本机文件路径、工作目录、别的画布上的引用、密钥），保存路径改成相对路径
  * 分享要求这颗节点层外侧至少有一个输入和一个输出，缺了会被拦住并提示怎么接
  * 下载的工作流只进本机工作流库，不会自动打开画布，也不会插进你正在做的事

## 新增

* **工作目录里攒下的临时文件，现在能一眼看到多大、一键清掉**
  * 顶栏「工作目录」右侧多了一颗按钮（进入文件夹与全局助手之间），点开就是这张画布的占用明细：按目录分组，渲染工程再按节点一行展开，能看到源码、素材副本、校验片与成片各占多少
  * 默认只勾选可以重新生成的中间产物；成片、录音、别的画布的工程、24 小时内刚动过的内容都不预勾，要清自己勾
  * 清理一律进系统回收站，误点了可以在资源管理器还原；正在渲染的工程与正被别的程序占用的文件会自动跳过，删不掉的会汇总告诉你
  * 设置 ·「存储占用与清理」里也开了同一个入口，两边是同一个面板

* **插件库新增「Blender 本地插件」（测试中）**：一次装好官方 Blender、MCP for Blender 插件与 MCP 服务端；重启 MTNode 后，智能体会话里就多出 `blender` 工具，可以直接读场景、跑脚本

* ** Agent 能直接听音频、做字幕、看视频**：它自带两件本机工具，不用再另装 whisper / 在线转写
  * 转写用的就是平时语音输入那台本地 SenseVoice（同一份模型、不上传）：给一段音频或视频，它按停顿切句给出全文与每句的起止秒，长文件自己切片拼接

* **做字幕不用再自己拼时间码**：智能体会话多了一件本机字幕工具，给一段音频或视频，直接拿回每条字幕的起止时间与整份 SRT / VTT 文本
  * 用的是同一台本地 SenseVoice（不上传），在停顿处切句，再按标点、每行字数和单条最长时长排成一条条字幕；长句按字数比例分配时间

* **素材节点的文本条目也能直接看到正文了**

* **节点层多了一颗 ▶，点一下整层按顺序跑完**：以前层里每个节点都要各点一次 ▶，现在头部就有这颗键，把层里能跑的节点按「上游 → 下游」依次跑一遍，跑的过程中按钮上显示跑到第几个（如 3/7）

## 调整

* **产品中文名改为「MTNode AI工作站」**：界面标题、桌面与开始菜单快捷方式、安装包、商店显示名、官网与教程页一起换新名，图标与所有功能不变；英文名仍是 MTNode AI Orchestrator，数据目录与旧设置原样保留，覆盖安装后照旧能打开原来的画布与工作流

* **线接到已经占着线的端子上，现在会直接换掉旧的那根**
* **节点的参数可以从「参数」端子来，助手不能再替你改掉节点参数**
* **助手能直接改 Remotion 节点的动效工程了**：以前它只能改节点上的需求描述、时长这些参数，动效源码与端子接法写不进去（读回也没有变化）；现在会话里的助手可以读写整棵动效源码与端子表
## 修复

* **Minimax H3 的流式超分不再因为缺一个组件就退回旧路径**：以前机器上没装过 OpenCV 时，逐帧流式超分在第一帧就停下、整单不出片，日志里只留一行报错，然后悄悄改走那张更吃内存的旧图链
  * 安装脚本会把它一并装上（四路 pip 源都拿不到时只提示、不中断安装），已经装好的机器重跑一次安装就补齐
  * 开始超分前，控制台会直接说清缺哪个组件、怎么补，不用等出片失败才发现；真的回退旧路径时也会写明原因

* **保存节点的卡片不再因为一份大文件把界面卡住**
* **文本 / 图像 / 出图 / 智能体任务与各类输入节点不再拒绝控制线**
* **Minimax H3 首尾帧接同一张图反而接不回原位**：底图不是输出比例时，首帧被拉伸、末帧被裁切，两端其实成了两张不同的图。现在首帧与末帧按同一口径裁切，首尾同图能真正连上
* **复制节点不再自动改标题**：以前复制 / 粘贴出来的节点会变成「原名 2」，靠标题互相指认的地方（提示词里的 @节点名、标签、开发块与会话按标题认人）就跟不上复制品了；现在复制出来的节点沿用原来的标题，先复制一份再改内容不会再牵动引用
  * 从工具库 / 工作流库把内容插入到当前画布时仍按画布已有名字避让（同名就加序号），避免两个同名来源分不清
* **优化会话中的模型思考，减少界面卡顿**
  * 思考弹窗开着时的实时刷新也放慢了节奏，长思考不再一边跳字一边拖慢界面；一段思考写完时会把最后的内容补齐，不会漏字
