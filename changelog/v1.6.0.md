# v1.6.0（2026-10-22）

助手会话固定在自己那张画布上，切画布不再跟着跑

## 新增

* **插件库新增「Blender 本地插件」**：一次装好官方 Blender、MCP for Blender 插件与 MCP 服务端；重启 MTNode 后，智能体会话里就多出 `blender` 工具，可以直接读场景、跑脚本
  * 每次安装都从 blender.org 官方目录取最新稳定版，下载后做 sha256 校验，支持断点续传；已经装过就跳过、不自动升级
  * 装完会真的拉起一次 Blender 做端到端检查（插件起服务 → MCP 握手拿回工具列表），过了才算装好
  * 控制台能启停插件拉起的那只 Blender、测试连接、检查更新；MCP 那一行丢了点「安装 / 重装」就补回来，不会重下 Blender
  * 卸载只删它自己装的东西，保留你的 `.blend` 工程、偏好备份和本机已装的 uv

## 调整

* **上下文压缩的「省钱」档改名为「低」，并把触发时机从约 10 万 token 推到约 15 万 token**：长会话不会刚过 10 万就压缩，省钱与保留上下文的平衡点往后挪了一档；原来选过这一档的会话保持不变，档位还在，只是名字与时机变了

## 修复

* **在右侧助手栏聊出来的会话会跟着切换画布而换图**：这类会话现在在第一次发消息时就认下当时那张画布，之后你切到别的画布干活，它照旧只在自己那张图上读写
  * 会话列表里这一行直接标出它属于哪张画布（「▣ 画布名」），一眼能看出它说的不是屏幕上这张图
  * 每张画布各留各的助手会话：切到别的图就开一段新的，切回来之前那段还在，接着聊
  * 会话的工作目录也跟着这张画布定下来，不会因为你切图就换成另一个项目
  * 助手栏的工作目录改成「跟随所属画布」：有项目根就用项目根，其次是这张画布自己的文件夹；两者都没配时才用默认文件夹
  * 屏幕上看的不是你所属的那张图时，助手这一轮不再把「你正看着的图」当成自己的范围；需要跨图参考其他画布，仍可把助手的「范围」改成「全局」
  * 重启应用后归属也不丢；本次修复之前就已经在聊的助手会话，下次发消息时按当时那张画布补认一次，此后固定不变
* **插件安装时也留得住「关闭窗口」**：以前装到一半窗底只剩一颗「取消安装」，想先去干别的就只能把这次安装一起停掉；现在「关闭窗口」「复制日志」一直在，关窗只是把窗收掉、安装在后台继续跑，再打开就能接上看进度，真要停才点「取消安装」
* **Blender 装到一半点「取消安装」，这次安装会真的停下**：以前点了取消，后面的装插件、注册 MCP 甚至拉起 Blender 检查还会照跑，跑完状态既像装好又写着「已取消」；现在会当场收手，已下好的文件留着，点「重试」接着装
* **Minimax H3 首尾帧接同一张图反而接不回原位**：底图不是输出比例时，首帧被拉伸、末帧被裁切，两端其实成了两张不同的图，成片一路推近、结尾跳回开头；现在首帧与末帧按同一口径裁切，首尾同图能真正连上
* **Minimax H3 只接首帧时的构图不再被拉变形**：首帧改为等比铺满后居中裁切，比例不符的底图会裁掉少许边缘，而不是整幅被压扁拉宽
