# v1.6.0（2026-10-22）

助手会话固定在自己那张画布上，切画布不再跟着跑

## 新增

* **插件库新增「Blender 本地插件」**：一次装好官方 Blender、MCP for Blender 插件与 MCP 服务端；重启 MTNode 后，智能体会话里就多出 `blender` 工具，可以直接读场景、跑脚本
  * 每次安装都从 blender.org 官方目录取最新稳定版，下载后做 sha256 校验，支持断点续传；已经装过就跳过、不自动升级
  * 装完会真的拉起一次 Blender 做端到端检查（插件起服务 → MCP 握手拿回工具列表），过了才算装好
  * 控制台能启停插件拉起的那只 Blender、测试连接、检查更新；MCP 那一行丢了点「安装 / 重装」就补回来，不会重下 Blender
  * 卸载只删它自己装的东西，保留你的 `.blend` 工程、偏好备份和本机已装的 uv

* **智能体会话能直接听音频、做字幕、看视频**：它自带两件本机工具，不用再另装 whisper / 在线转写
  * 转写用的就是平时语音输入那台本地 SenseVoice（同一份模型、不上传）：给一段音频或视频，它按停顿切句给出全文与每句的起止秒，长文件自己切片拼接
  * 要看视频内容时，它按时间点抽帧再识图（与识图工具同一套许可），一次告诉你每个时间点画的是什么
  * 需要转码、抽音轨、截片段时可以用它跑 ffmpeg：优先用本机已有的，其次用安装 Remotion 时自带的那份，都没有会提示你先装 Remotion，不会自己去下载
  * 只能写本轮工作区、数据目录与临时目录，也不会悄悄覆盖同名文件；单个媒体默认上限 2 小时 / 1GB，可以放宽

* **做字幕不用再自己拼时间码**：智能体会话多了一件本机字幕工具，给一段音频或视频，直接拿回每条字幕的起止时间与整份 SRT / VTT 文本
  * 用的是同一台本地 SenseVoice（不上传），在停顿处切句，再按标点、每行字数和单条最长时长排成一条条字幕；长句按字数比例分配时间
  * 想调节奏可以改：单条最长秒数（默认 6 秒）、每行字数（默认中文 18 字／英文 42 字符，自动判）、静音阈值（默认 -35dB）、最小停顿（默认 0.4 秒）
  * 它只把字幕文本交回来，不往盘里写文件：要存成 .srt / .vtt 时由助手按你的工作目录落盘
  * 与原来的转写工具共用同一个「音频转写」许可开关，关掉就两件都不出现

* **素材节点的文本条目也能直接看到正文了**：以前一条文本在没选中时只有一行标题，被端子接出去也看不见里面写了什么；现在只要这条内容的输出端子连到了下游，标题下方就多出一块只读正文预览 —— 与图像 / 视频缩略图同一位置、同一高度上限（约 120px），长文在框里自己往下滚，段落换行照原样保留，点一下节点就能进编辑态改它

* **素材正文框可以拖高了**：选中素材节点后，正文框底部多出一条横杠，按住往下拖就变高、往上拖就变矮，双击复位；每条正文的高度各记各的，随画布保存，关掉重开还是那个高度，框拖得再高也不会改动素材节点本身的尺寸（超出部分在节点里滚动）

## 调整

* **线接到已经占着线的端子上，现在会直接换掉旧的那根**：以前会弹「该输入端子已被占用」把线挡回去，只能先删掉旧线再接；现在同类的线接上去就顶掉旧的（比如把另一路视频接到一个已经接着上游视频的端子），被换掉的那根进撤销栈，一次 Ctrl+Z 就回到原样
  * 拖线时端子会先变成替换色，即将被换掉的那根线一起高亮，松手前就能看出会换掉什么
  * 「参数」端子、批量（数组）端子、动态节点的控制端子这类本来就能接多根线的不受影响；类型接错了照旧拦下，旧线不动
  * 完全相同的线重复连不再弹「这两节点已连接」，什么都不会发生

* **Minimax H3 长时间出片不再十分钟就被判死**：生成的「无进度」阈值从 10 分钟放宽到 30 分钟，单次总上限提到 60 分钟；自建工作流、分段衔接这类本来就要跑半小时的任务不会再被误杀
* **上下文压缩的「省钱」档改名为「低」，并把触发时机从约 10 万 token 推到约 15 万 token**：长会话不会刚过 10 万就压缩，省钱与保留上下文的平衡点往后挪了一档；原来选过这一档的会话保持不变，档位还在，只是名字与时机变了

## 修复

* **文本 / 图像 / 出图 / 智能体任务与各类输入节点不再拒绝控制线**：以前把控制线拖到这些节点上会被判成「这是数据端子」接不进去，助手照着端子说明也找不到能接的口；现在它们末端都固定留着一颗专用控制端子（画布上按控制色显示），控制线只落它、数据线永远不会占它，同一颗上可以接多条控制线，任一条到达就跑一次
  * 老画布打开时自动把原先挤在数据端子上的控制线挪到这颗专用端子，数据线的端子号一个都不变，不用手动重连
* **节点的参数只能从「参数」端子来，助手不能再替你改掉节点参数**：以前助手会绕开端子把一份参数直接写进节点，你在设置窗里改完却不生效——运行时还是按它写的那份跑；现在这种写法会被直接拒绝，助手要给参数必须建一颗文本节点接到「参数」端子
  * 之前已经写进老画布的这类参数，打开画布时自动清掉并告诉你哪些节点受影响，这些节点立刻回到设置窗里的值
  * 你自己在设置窗改任何一项都以你为准

* **在右侧助手栏聊出来的会话会跟着切换画布而换图**：这类会话现在在第一次发消息时就认下当时那张画布，之后你切到别的画布干活，它照旧只在自己那张图上读写
  * 会话列表里这一行直接标出它属于哪张画布（「▣ 画布名」），一眼能看出它说的不是屏幕上这张图
  * 每张画布各留各的助手会话：切到别的图就开一段新的，切回来之前那段还在，接着聊
  * 会话的工作目录也跟着这张画布定下来，不会因为你切图就换成另一个项目
  * 助手栏的工作目录改成「跟随所属画布」：有项目根就用项目根，其次是这张画布自己的文件夹；两者都没配时才用默认文件夹
  * 屏幕上看的不是你所属的那张图时，助手这一轮不再把「你正看着的图」当成自己的范围；需要跨图参考其他画布，仍可把助手的「范围」改成「全局」
  * 重启应用后归属也不丢；本次修复之前就已经在聊的助手会话，下次发消息时按当时那张画布补认一次，此后固定不变
* **插件安装时也留得住「关闭窗口」**：以前装到一半窗底只剩一颗「取消安装」，想先去干别的就只能把这次安装一起停掉；现在「关闭窗口」「复制日志」一直在，关窗只是把窗收掉、安装在后台继续跑，再打开就能接上看进度，真要停才点「取消安装」
* **Blender 装到一半点「取消安装」，这次安装会真的停下**：以前点了取消，后面的装插件、注册 MCP 甚至拉起 Blender 检查还会照跑，跑完状态既像装好又写着「已取消」；现在会当场收手，已下好的文件留着，点「重试」接着装
* **Minimax H3 首尾帧接同一张图反而接不回原位**：底图不是输出比例时，首帧被拉伸、末帧被裁切，两端其实成了两张不同的图，成片一路推近、结尾跳回开头；现在首帧与末帧按同一口径裁切，首尾同图能真正连上
* **Minimax H3 只接首帧时的构图不再被拉变形**：首帧改为等比铺满后居中裁切，比例不符的底图会裁掉少许边缘，而不是整幅被压扁拉宽
* **Remotion 动效视频节点点「▶」直接报错、跑不起来**：上游只要有一路还没产出内容（或接的是其它生成节点的输出），这颗节点就会在开始渲染前中断；现在这类「暂时读不到值」的输入按空值跳过，节点照常往下跑
* **动效代码里顺手写的图标 / 工具库引用不再让整条成片失败**：以前生成的动效代码只要带了一条用不到的第三方依赖引用，节点就整颗报错；现在这类没被用到的引用会被自动去掉，真在用的才会提示你删掉那一行或改用内置能力
